ダッシュボードはあなたのホームベースです。各サーバーのライブステータスと、何が起こっているかの実行中のフィードが表示されます。

![ダッシュボード](/docs/images/dashboard.png)

## サマリータイル

一番上に表示されます：

- **オンラインサーバー数** - 現在実行中のサーバーの数。
- **接続中のプレイヤー数** - 実行中の全サーバーの合計プレイヤー数。
- **利用可能なアップデート** - 新しいバージョンがあるサーバー、パック、またはMODの数（[アップデートを確認する](/docs/updates/)）。
- **Docker** - パネルがDockerデーモンに到達できるかどうか、およびそのバージョン。

## サーバーカード

各サーバーは、ステータス（実行中、起動中、停止中、クラッシュ）、タイプとMinecraftバージョン、およびゲームポートとともにカードとして表示されます。実行中のサーバーでは、ライブの**プレイヤー数**、**CPU**、**メモリ**、および**ディスク**の使用状況も継続的に更新されます。

カードをクリックすると、そのサーバーが開きます。空の**サーバーを作成**カードと、トップバーの**サーバーを作成**ボタンは、どちらも[作成ウィザード](/docs/servers/)を開始します。

サーバーを検索および並べ替えたり、右側のトグルでグリッドとリストのレイアウトを切り替えたりできます。

## 最近のアクティビティ

一番下のフィードは、人間が読めるライブ監査ログです。ログイン、バックアップ、ブループリントのエクスポート、アップデートチェック、チャットコマンドの変更、サーバーの起動と停止などが行われます。各エントリには、それが属するサーバー（またはパネル自体）と、それがいつ発生したかがタグ付けされています。完全な履歴は[アクティビティ](/docs/activity/)ページにあります。
