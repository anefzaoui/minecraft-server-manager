ダッシュボードはあなたのホームベースです。各サーバーのライブステータスと、何が起こっていたかの実行中のフィードが表示されます。

![ダッシュボード](/docs/images/dashboard.png)

## サマリータイル

一番上に表示されます：

- **オンラインサーバー数**: 現在実行中のサーバー数と合計数。
- **接続中のプレイヤー数**: 実行中の全サーバーの合計プレイヤー数。
- **利用可能なアップデート**: 新しいバージョンがあるサーバー、パック、またはMODの数（[アップデートを確認](/docs/updates/)）。
- **Docker**: パネルがDockerデーモンに到達できるかどうか、およびそのバージョン。

2行目には、**割り当てられたメモリ**（および使用量）、全サーバーデータフォルダの**使用済みストレージ**、**ヘルス · 24時間**（過去1日間のクラッシュ、メモリ不足による停止、自動再起動）、およびMODとサーバーレベルのアップデートに分かれた**アップデート**が追加されます。その下には、**ステータス別サーバー数**が各状態のサーバー数をカウントし、**リソース概要**がメモリとCPUの各サーバーのシェアをグラフ化します。

## サーバーカード

各サーバーは、ステータス（実行中、起動中、停止中、クラッシュ、および異常、遅延などの途中状態）、タイプとMinecraftバージョン、ゲームポート、タグとともにカードとして表示されます。各カードには、クォータに対する**プレイヤー数**と**ディスク**使用量が表示され、実行中のサーバーにはライブの**CPU**と**メモリ**も継続的に更新されて表示されます。

カードをクリックすると、そのサーバーが開きます。空の**サーバーを作成**カードと、トップバーの**サーバーを作成**ボタンは、どちらも[作成ウィザード](/docs/servers/)を開始します。

サーバーを検索（名前、タイプ、バージョン、またはタグ別）、ステータス、名前、サイズ、最終起動、または作成日で並べ替え、右側のトグルでグリッドとリストのレイアウトを切り替えることができます。

## 最近のアクティビティ

一番下のフィードには、パネルの人間が読める監査ログからの最新のエントリが表示されます：ログイン、バックアップ、ブループリントのエクスポート、アップデートチェック、チャットコマンドの変更、サーバーの起動と停止など。各エントリには、それが属するサーバー（またはパネル自体）と、どれくらい前に発生したかがタグ付けされています。**すべて表示**をクリックすると、[アクティビティ](/docs/activity/)ページで履歴全体が表示されます。
