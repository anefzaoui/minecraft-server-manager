**ストレージ**ページでは、ディスクの使用状況がカテゴリ別、各サーバーのクォータに対する使用量、最も大きなファイル、および最近のスキャンでの全体的な使用量の傾向が表示されます。管理者のみが利用できます。

![ストレージ](/docs/images/storage.png)

## ディスククォータはパネルによって強制されます

Dockerはバインドマウントのディスク使用量を制限できないため、パネルがそれを実行します。バックグラウンドで動作するサイズインデクサーがデータフォルダを（15分ごと、変更後、または**今すぐ再スキャン**を押したときに）スキャンし、各サーバーのフットプリントをキャッシュして、サーバーごとに設定したディスククォータを強制します。MODやワールドのインストール、ファイルのアップロードなど、サーバーのフォルダ（ワールド、MOD、設定、ログ、その他すべて）がクォータを超過するような操作は、1つのサーバーがホストを使い果たすのを防ぐために、スペースが解放されるかクォータが引き上げられるまでブロックされます。

サーバーのクォータは、その[設定](/docs/servers/#server-settings)で設定します。そこで**クォータ超過時にサーバーを停止**をオンにすると、フォルダがクォータを10%以上超過した場合、実行中のサーバーも停止し、サーバーの履歴に記録されます。MOD導入サーバーは大きくなる可能性があるため、十分なスペースを確保してください。[バックアップ](/docs/backups/)は別途保存され、クォータには含まれません。

## クリーンアップ

**ワンクリッククリーンアップ**カードは、パネルが安全に解放できるスペースを解放します。1時間以上経過した一時ファイル、孤立したライブラリファイル、および30日以上経過したアーカイブログとクラッシュレポートです。それぞれがどれだけのスペースを解放するかを示し、削除前にプレビューを開きます。**カテゴリ別**および**最も大きなファイル**のリストはファイルマネージャーに直接リンクされているため、スペースがなくなる前に他に削除できるものを探すことができます。
