**ストレージ**ページでは、ディスクの使用状況をサーバーごとの使用量と時間の経過に伴う傾向で表示します。

![ストレージ](/docs/images/storage.png)

## ディスククォータはパネルで強制されます

Dockerはバインドマウントのディスク使用量を制限できないため、パネルがそれを実行します。バックグラウンドで動作するサイズインデクサーがデータディレクトリをスキャンし、各サーバーのフットプリントをキャッシュして、サーバーごとに設定したディスククォータを強制します。サーバーのデータ（ワールド＋バックアップ＋その他すべて）がクォータに近づくと、パネルは1つのサーバーがホストを使い果たすのを防ぐために、急激な成長を停止させます。

サーバーのクォータは、[設定](/docs/servers/)で設定します。Moddedサーバーとその[バックアップ](/docs/backups/)は大きくなる可能性があるため、十分な容量を確保してください。

## クリーンアップ

ストレージビューは、スペースがなくなる前に、削除すべきもの（古いバックアップ、未使用のワールド、または予想をはるかに超えて成長したサーバー）を見つけるのに役立ちます。
