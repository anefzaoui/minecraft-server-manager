このリストを順番に見ていきましょう。回答となる頻度順に並んでおり、最初の4つでほとんどの場合に対応できます。

## 1. 最初の20行ではなく、最後の20行を読む

ログの**末尾**までスクロールしてください。Javaのスタックトレースは内側から順に表示されるため、大量のテキストの先頭は最も興味のない部分です。知りたいのは、最後の `Caused by:` 行とその後に続く内容です。その1行で問題が特定できることがほとんどです。

状況を把握するための2つの手がかりがあります。

- `Exception in thread "main"` または末尾近くのクラッシュレポートのパスは、ゲーム自体が失敗したことを意味します。
- ログが途中で途切れ、例外が全くない場合は、外部からプロセスが強制終了されたことを意味します。3番目の項目に進んでください。

## 2. UnsupportedClassVersionError は Java のバージョンが間違っていることを意味する

```
java.lang.UnsupportedClassVersionError: net/minecraft/server/Main has been compiled
by a more recent version of the Java Runtime (class file version 65.0)
```

クラスファイルバージョン52はJava 8、60は16、61は17、65は21、69は25です。このメッセージは、サーバーが現在実行されているJavaよりも新しいバージョンのJavaを必要としていることを意味します。逆に、古いパックを新しいJavaで実行すると、通常はMixinやリフレクションのエラーが発生します。

| Minecraftのバージョン | Java |
| --------------------- | ---- |
| 1.16.5以前            | 8    |
| 1.17                  | 16   |
| 1.18 および 1.19      | 17   |
| 1.20 から 1.20.4      | 17   |
| 1.20.5 から 1.21.x    | 21   |
| 26.1 以降             | 25   |

古いパックにはJava 8が本当に必要です。新しいバージョンはここでは役に立ちません。

## 3. Exit code 137 は mod ではなくカーネルの問題

ログが途中で途切れ、クラッシュレポートがなく、コンテナが137を報告した場合。これはメモリ不足による強制終了です。プロセスがマシンにないメモリを要求したため、終了させられました。

ほとんどの場合、Javaヒープサイズがマシンのメモリと同じ値に設定されています。ヒープには、マシンのメモリからJVM自体のオーバーヘッド（Mod入りサーバーでは0.5〜1.5 GB）を**引いた**値が必要です。ヒープサイズを下げるか、マシンをアップグレードしてください。[サーバーに必要なRAMの量](/docs/guide-server-memory/)に詳しい数値が記載されています。

## 4. EULA とポート

よくある2つの問題と、その1行での解決策です。

- `You need to agree to the EULA in order to run the server.` `eula=true` を `eula.txt` に設定するか、使用しているセットアップの環境変数で設定してください。
- `Address already in use` または `FAILED TO BIND TO PORT`。25565ポートが他の何かに使用されています。多くの場合、完全に停止していない同じサーバーの以前のコピーです。ポートを変更するのではなく、それを見つけて停止してください。そうしないと、2つになってしまいます。

## 5. mod が依存関係を欠いている

```
Mod X requires mod Y, which is missing
Fabric API is not installed
```

Fabric modのほとんどは、Fabric APIを別のファイルとして必要とします。ForgeとNeoForgeのmodは、エラー自体に依存関係をリストします。最新バージョンではなく、指定されたバージョンをインストールしてください。「0.91.x が必要」は、その行を意味し、0.92では同じチェックが失敗します。

依存関係が欠けているのがローダー自体である場合もあります。

```
Mod X requires forge 47.4.14 or above
Mod ID: 'forge', Requested by: 'x', Expected range: '[47.4.14,)', Actual version: '47.4.10'
```

修正は、異なるmodではなく、より新しいローダービルドです。「47.4.14以上」は、そこからの任意のビルドを意味し、Forgeはすべての番号を公開しているわけではないため、インストールするビルドは次のものになる可能性があります。modパックの場合は、まずパックを更新してください。ローダーバージョンがmodに比べて古いパックは、作者が修正すべきバグです。

## 6. mod が間違ったローダーまたはバージョン用である

異なるローダー用のjarは、丁寧には失敗しません。Mixinエラー、`NoClassDefFoundError`、または聞いたことのないクラス内のクラッシュを予想してください。jarのページを確認してください。ローダーとMinecraftのバージョンは両方とも正確に一致する必要があります。modに関しては、1.20.1と1.20.4は異なるゲームです。

## 7. ワールドが新しいバージョンからのものである

```
This world was created by a newer version of Minecraft
```

ワールドは前方へのアップグレードのみで、後方へのダウングレードはできません。アップグレード前に作成したバックアップを復元するか、ワールドが期待するバージョンを実行してください。チャンクを維持したままダウングレードするパスはありません。

## 数週間正常に動作していたのにクラッシュした場合

質問が異なります。通常、回答も異なります。

- **負荷がかかるとクラッシュした**（タイミングが長い一時停止を示している）：ガベージコレクションなので、modの前にヒープサイズを確認してください。
- **ワールドの同じ場所でクラッシュした**：破損したチャンクまたは壊れたエンティティ。クラッシュレポートには通常、座標が記載されています。
- **アップデート直後にクラッシュした**：トレースが別の場所を指していても、アップデートされたmodが原因である可能性が高いです。ロールバックして確認してください。
- **以前は問題なかったのに再起動時にクラッシュした**：ディスクを確認してください。ディスクがいっぱいになると、派手で誤解を招くエラーが発生します。

## 実際に役立つヘルプを得る方法

**ログ全体**を、最後の行だけでなく、投稿し、問題が発生する前に何を変更したかを述べてください。チャットに貼り付けるのではなく、[mclo.gs](https://mclo.gs) のような専用の場所に貼り付けてください。Minecraftのバージョン、ローダー、パックとそのバージョン、およびサーバーが持つヒープメモリ量を記載してください。これらの4つの情報を含むレポートは1回の返信で回答が得られますが、それがない場合は5回かかります。

## Minecraft Server Manager で

クラッシュはコンテナ自体の終了から検出されるため、深夜に終了したサーバーは、翌日見つけるのではなく、ログの抜粋とともに記録されます。このページでよくある原因（EULA、間違ったJava、新しいバージョンのワールド、ポートが既に使用されている、Javaのメモリ不足）は、そのログで認識され、履歴エントリに修正方法とともに名前が付けられます。自動再起動はそれらをそのままにしておきます。再起動しても修正されないためです。クラッシュレポートは到着時に解析されます。例外はハイライトされ、スタックは折りたたみ可能で、トレースに表示されるmodは疑わしいものとしてリストされます。

ヘルプが必要な場合は、カードから mclo.gs に共有できます（ペーストは公開されるため、確認が必要です）。コンソールの**ダウンロード**メニューには、すべてのログファイルが1つのzipファイルとして含まれているため、「ログ全体を投稿する」は考古学的な作業ではなく、ダウンロードになります。メモリ不足による強制終了は、メモリ不足による強制終了として記録されるため、modを疑うのに通常かかる1時間を節約できます。他に本当にポートが必要な場合は、**設定 → 設定** の **ゲームポート** カードで、サーバーを空いているポートに移動させます。

ローダーが古すぎる場合は、サーバーの**バージョン**タブから変更します。これにより、ビルドが存在することを確認し、サーバーを再構築する前にバックアップを取得します（[modローダーのバージョンを変更する](/docs/updates/#changing-the-mod-loader-version)）。
