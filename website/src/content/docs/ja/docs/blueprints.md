**ブループリント**は、サーバーの構成全体（タイプ、バージョン、リソース、環境、パックピン、カスタムMOD、オプションで設定とワールド）を、新しいサーバーを作成するためのポータブルな`.mcserver.zip`ファイルにキャプチャします。秘密情報（環境内のパスワード、トークン、キー）はブループリントに書き込まれることはありません。

![Blueprints](/docs/images/blueprints.png)

## エクスポート

サーバーの**設定 → 設定**タブから、**ブループリントとしてエクスポート**を使用し、含めるものを選択します。常にサーバーの設定、設定ディレクトリ（デフォルトでオン）、オプションでカスタムMODファイル自体（何もダウンロードせずにインストールできる大きなファイル）、およびアクティブなワールドを含めることができます。結果はブループリントライブラリに保存され、共有のためにダウンロードできます。

同じカードにある**サーバーのクローン**は、エクスポートとインポートを1ステップで行い、ワールドの有無にかかわらずサーバーのコピーを作成します。

## ブループリントからのインポートと作成

ブループリントファイル（**ブループリント**ページの**ブループリントをインポート**）をインポートするか、ライブラリから選択します（カードの**サーバーを作成**、またはウィザードの**ブループリントから**タブ）と、元のサーバーとまったく同じように事前設定された新しいサーバーが作成されます。新しいサーバーは独自のポートと新しいRCONパスワードを取得します。埋め込まれていなかったカスタムMODは再度ダウンロードされ、ブループリントが記録したハッシュと比較されます。ライブラリには、PaperとFabricの2つのスターターブループリントも用意されています。

これは以下のための最も速い方法です。

- 同一のサーバーを起動する（ミニゲームサーバーのネットワーク、本番環境のステージングコピー）。
- サーバーをパネル間で移動する。
- いつでも元に戻れる既知の良いテンプレートを保持する。

ブループリントは正確な[パックピン](/docs/modpacks/)を記録するため、ブループリントから作成されたMODパックサーバーは、サプライズアップグレードなしで同じピン留めされたバージョンをインストールします。
