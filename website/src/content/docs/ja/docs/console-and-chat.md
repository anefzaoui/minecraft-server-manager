## ライブコンソール

**コンソール**タブは、サーバーログをリアルタイムでストリーミングし、サーバーコマンドを送信するためのコマンドボックスを提供します。`docker exec`もSSHも不要です。出力はインラインで、色付けされたまま返されます。

![コンソール](/docs/images/server-console.png)

コンソールは、パネルがサーバーの状態を読み取る場所でもあります。ログを監視して起動フェーズ（「Loading mods」、「Generating world」、「Finishing startup」）を分類し、`list`を呼び出してオンラインプレイヤーを追跡するため、ダッシュボードとサーバーカードは常に実際の状態を反映します。

このポーリングは、サイクルごとに短命なRCON接続を開きます。これはサーバーログに約20秒ごとに`Thread RCON Client … started` / `shutting down`のペアとして記録され、（コアまたはプラグインがそれをエコーするサーバーでは）読み取り専用のポーリングごとに`Rcon issued server command: …`行として記録されます。プレイヤー数を確認するための`list`、およびワールドコントロールページが開いている間の`time query …`と`gamerule <name>`の読み取りです。ログの上にある**RCONノイズを非表示**トグルは、これらの行（RCONリスナーの起動行を含む）をフィルタリングします。これはデフォルトでオンになっており、ブラウザごとに記憶されます。生のストリームを表示するにはオフにしてください。

パネルから送信されたコマンドは、サーバーごとのラベルの下でゲーム内にアナウンスできるため、プレイヤーは謎のコンソールではなくオペレーターが操作したことを知ることができます。

## チャットコマンド

チャットコマンドを使用すると、プレイヤーはゲームチャットにプレフィックスコマンドを入力することでパネルアクションをトリガーできます。たとえば、ランダムテレポートするには`!spawn`を使用します。検出はログベースであり、実行はサーバーを経由するため、**MODは不要**です。

![チャットコマンド](/docs/images/chat-commands.png)

各コマンドには以下が含まれます。

- **トリガー**（例：`spawn`）と**プレフィックス**（デフォルトは`!`）。
- **アクション**：ランダムテレポート、構造物へのテレポート、バイオームへのテレポート、または生のコンソールコマンドの実行。
- **権限レベル**：全員、ホワイトリストに登録されたプレイヤー、またはオペレーターのみ。
- **クールダウン**、および`{distance}`のようなプレースホルダーを使用したカスタマイズ可能な保留中/成功/失敗メッセージ。

### 安全性に関する注意

サーバーを破壊する可能性のあるコマンド（`stop`、`op`、`ban`、`whitelist`など）は、**オペレーターのみ**のトリガーでのみ許可されます。パネルは、`execute … run …`チェーンにネストされている場合でも、これらのコマンドをチェックするため、低い権限のトリガーが危険なコマンドを密かに実行することはできません。`say`メッセージのように、これらの単語を単に言及する通常のチャットテキストはそのままにされます。
