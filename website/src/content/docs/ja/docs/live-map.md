サーバーの「**ワールド → マップ**」タブには、プレイヤーの位置とすべてのディメンションを含む、[BlueMap](https://bluemap.bluecolored.de/)（無料かつオープンソース）によって描画された、ライブでズーム可能な3Dマップが表示されます。パネルがこれをインストール、設定し、提供します。ポートを開いたり、設定ファイルを編集したりする必要は一切ありません。

## 有効化する

1. サーバーを開き、「**ワールド → マップ**」に移動します。
2. 「**ライブマップを有効にする**」を押します。パネルは、サーバーのローダーとMinecraftのバージョンに合わせてModrinthからBlueMapのビルドをインストールし、BlueMapのリソースダウンロードを受け入れ、空いているポートを割り当てます。
3. サーバーを再起動します（変更は次回の起動時に適用され、サーバーは再起動待ちとしてマークされます）。

BlueMapはバックグラウンドでレンダリングするため、新しいマップが最初のタイルを描画するのに数分かかります。それまでは、タブにマップがまだ利用可能でないと表示され、自動的に再確認されます。「**フルスクリーン**」でマップが利用可能になると、独自のブラウザタブで開かれます。

これは、モッドローダー（Fabric, Quilt, Forge, NeoForge）を使用するサーバーや、プラグインサーバー（Paper, PurpurおよびPaperファミリーのその他、Spigot）、モッドパックサーバーでも動作します。バニラサーバーにはBlueMapのビルドがないため、タブにその旨が表示されます。

## 誰が見ることができるか

マップはパネルを通じてのみ提供され、パネルのサインインの後ろにあります。パネルでサーバーを表示できる人は誰でもそのマップを開くことができますが、それ以外の人はいかなるアクセスもできません。BlueMap自体のポートはインターネットに公開されることを意図していません（[ポート一覧](https://github.com/anefzaoui/minecraft-server-manager#ports-at-a-glance)）。マップのオン/オフの切り替えには、サーバーの「**設定**」権限が必要です（[ユーザーとロール](/docs/users-and-roles/#per-server-permissions)）。

パネル自体がDockerで実行されている場合、サーバーコンテナ内のBlueMapにアクセスします。[README](https://github.com/anefzaoui/minecraft-server-manager#installation)に、リバースプロキシ設定の詳細が記載されています。

## 無効化する

「**マップを無効にする**」は、パネルがインストールしたBlueMapのjarファイルを削除し、ポートを解放します。これも次回の再起動から適用されます。ワールド自体は変更されません。レンダリングされたマップタイルはサーバーのフォルダに残りますが、「**ファイル**」タブで削除するまでそのままです。

関連情報: [ワールドとファイル](/docs/worlds-and-files/)、[招待とステータスページ](/docs/invites-and-status-page/)。
