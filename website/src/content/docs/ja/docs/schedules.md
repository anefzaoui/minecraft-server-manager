**スケジュール**ページでは、cron式を使用して定期的なタスクを自動化します。外部cronやスクリプトは不要です。

![スケジュール](/docs/images/schedules.png)

## スケジュールできること

- **再起動** - 長時間稼働しているサーバーを健全に保つための毎晩の再起動。
- **バックアップ** - 定期的なスナップショット（[バックアップ](/docs/backups/)ページで `scheduled` としてタグ付けされます）。
- **コマンド** - スケジュールに従って任意のサーバーコマンドを実行します。
- **アップデートチェック** - 定期的に古いものを更新します。

各スケジュールは、特定のサーバー（またはパネル全体）を対象とし、独自のcron式で実行され、削除せずに有効または無効にできます。最後に実行された時間が表示されるため、正しく実行されていることを確認できます。
