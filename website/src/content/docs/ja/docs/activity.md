**アクティビティ**ページは完全な監査ログです。パネルで発生したすべてのイベントを検索可能な時系列で記録します。サーバーまたはイベントタイプでフィルタリングし、概要を検索して、フィルタリングした結果をCSVまたはJSONとしてエクスポートできます。ログ（クラッシュなど）をキャプチャしたエントリは、その場で開かれます。

![アクティビティ](/docs/images/activity.png)

## 記録される内容

- **認証**: サインイン（2FAまたはバックアップコードが使用されたかどうかにかかわらず）、アカウントロックアウト、パスワード変更、および2FAの有効化、無効化、リセット。
- **サーバーライフサイクル**: 作成、起動、停止、再起動、クラッシュ、自動再起動、およびメモリ不足イベント。
- **アラート**: ブート遅延、停止失敗、スケジュール失敗、クォータ停止、コンテナ異常、再起動後のオフライン。
- **データ**: バックアップの作成と復元、ブループリントのエクスポート、パックのインストールとアップグレード、MODとワールドの変更、およびファイル編集。
- **プレイヤー**: キック、BAN、ホワイトリストとOPの変更、およびプレイヤーノート。
- **設定**: チャットコマンドの変更、ユーザーとロールの変更、サーバーごとの権限の変更、ゲームポートの変更、および設定の編集。

各エントリは、誰が（ユーザー名、または自動化されたアクションの場合はパネル/スケジューラ）、どのサーバーに関連しているか、およびいつ実行されたかを記録します。[ダッシュボード](/docs/dashboard/)には最新のエントリが表示されますが、このページは完全な履歴です。オペレーターとビューアは、表示できるサーバーのエントリ（およびパネル全体のものを除く）のみを表示し、サーバーごとの権限の変更は管理者のみに表示されます。ライフサイクルおよびアラートイベントは、Discordに転送することもできます（[インテグレーション](/docs/integrations/)を参照）。

セキュリティ関連のイベント（ログイン、2FAの変更、ロールと権限の変更）をキャプチャするため、アクティビティログは、アカウントに何か問題がある場合の最初の確認場所でもあります。
