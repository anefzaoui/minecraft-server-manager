パネル外からサーバーのステータスを取得するための、小さく読み取り専用のHTTP APIです。ステータスダッシュボード、アップタイムモニター、Discordボット、ホームオートメーションルールなどに利用できます。パネル自体によって提供され、パネルのページが表示するのと同じライブデータを（インメモリキャッシュから）返します。そのため、ポーリングしてもDockerにアクセスすることはありません。

これは**管理者が使用するまで無効**であり、**管理者によって制御**されています。トークンが存在しない限り、何も公開されません。

## 有効化する

**設定 → 公開API → 新規キー**。名前を付け、表示するサーバー（全サーバー、または特定のサブセット）を選択し、オプションで有効期限を設定します。完全なキー（Bearerトークン）はダイアログで**一度だけ**表示されます。後で識別するために短いプレフィックスのみが保持されるため、今すぐコピーしてください。

![公開API設定](/docs/images/settings-public-api.png)

最初のキーを作成すると、APIは自動的にオンになります（**外部アプリにステータスを読み取らせる**スイッチは一時停止コントロールです。キーをキャンセルせずに提供を停止するにはオフにします）。いつでも同じテーブルからキーをキャンセルできます。それを使用しているクライアントは即座にアクセスできなくなります。

トークンはSHA-256ハッシュとして保存され（平文では決して保存されません）、パネルの再起動後も保持され、スコープが設定されたサーバーよりも長く有効です（削除されたサーバーは、そのトークンの結果から単純に除外されます）。

## 認証

トークンをBearer認証情報として送信します。

```
Authorization: Bearer msm_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Cookieはなく、**CORSもありません**。これはサーバー間通信やCLIからの呼び出し用であり、他のオリジンからのブラウザアプリ用ではありません。パネルがリバースプロキシの背後にある場合は、プロキシが`Authorization`ヘッダーを転送するようにしてください。

失敗した場合は、`{ "ok": false, "error": "..." }`とともに`401`が返されます。`GET`（または`HEAD`）以外のメソッドは`405`を返します。不明なパスは`404`を返します。APIが無効な場合、すべてのルートが`404`を返します。

## レート制限

各トークンには独自の予算があります。`RATE_LIMIT_PUBLIC_API_PER_MIN`（デフォルトは`120`リクエスト/分、`0`はリミッターを無効にします）。制限を超えると`429`が返されます。有効なトークンが決して提示されないリクエスト（欠落、不正な形式、失効、または期限切れ）は、クライアントIPごとにその数値の5倍に個別に制限されるため、トークンをローテーションしてもプロービングによって予算を回避することはできません。

## エンドポイント

### `GET /api/v1/servers`

トークンがスコープされているすべてのサーバー。

```json
{
  "ok": true,
  "total": 1,
  "online": 1,
  "servers": [
    {
      "id": "srv_ab12cd34",
      "name": "SMP",
      "type": "PAPER",
      "state": "running",
      "cpuPct": 18.4,
      "memoryMb": 2048,
      "memoryLimitMb": 4096,
      "uptimeSeconds": 11722,
      "players": { "online": 3, "max": 20 }
    }
  ]
}
```

### `GET /api/v1/servers/:id`

1つのサーバー。`server`キーの下に同じオブジェクトが返されます。不明なID**および**トークンがスコープされていないサーバー（存在しない場合）に対しては`404`を返します。不正な形式のIDに対しては`400`を返します。

## レスポンスフィールド

| フィールド      | 説明                                                                                 |
| --------------- | ------------------------------------------------------------------------------------ |
| `total`         | このトークンから見えるサーバーの数（スコープフィルター適用後）。                     |
| `online`        | そのうち`running`状態のサーバーの数。                                                |
| `id`            | 安定したサーバーID（`srv_...`）。                                                    |
| `name`          | 表示名。                                                                             |
| `type`          | itzgサーバータイプ（`PAPER`、`FABRIC`、`AUTO_CURSEFORGE`など）。                     |
| `state`         | `running`、`starting`、`stopped`、または`crashed` - パネルの内部状態の安定した概要。 |
| `cpuPct`        | 最近のCPU使用率（%）、またはサーバーが実行されていない場合は`null`。                 |
| `memoryMb`      | メモリ使用量（MB）、または`null`。                                                   |
| `memoryLimitMb` | 設定されたコンテナメモリ制限（MB）、または`null`。                                   |
| `uptimeSeconds` | コンテナ起動からの秒数、または`null`。                                               |
| `players`       | `{ online, max }`、またはサーバーがプレイヤーリストを報告するまで`null`。            |

## 例

```sh
curl -s https://panel.example.com/api/v1/servers \
  -H "Authorization: Bearer $MSM_TOKEN" | jq
```
