## ワールド

**ワールド**ページは、ワールドライブラリです。保存されたすべてのワールドがここに集まります。**ワールドのアップロード**は、`.zip`または`.tar`アーカイブを受け取り、その中のワールドを自動的に検出します。**ライブラリに保存**は、サーバーの実行中のワールドのスナップショットを作成します（サーバー実行中に機能します）。ライブラリ内の各ワールドは、**インストール先…**からダウンロードまたは任意のサーバーにインストールできます。インストールは、サーバーのワールドを置き換える（サーバーは停止する必要があり、現在のワールドは最初にバックアップされます）か、後で有効にするために並べて追加します。インストール前には常に互換性チェックが実行されます。

サーバー固有の**ワールド → ワールド**タブには、そのサーバー上のワールドが一覧表示されます。そこから、別のワールドを有効にする（サーバー停止時）、ダウンロード、複製、名前変更、または[縮小](/docs/world-shrink/)する、別のサーバーにコピーする、非アクティブなものを削除する、そして新しい、保持された、またはカスタムシードでアクティブなワールドをリセットする（最初に安全のためのバックアップが提供されます）ことができます。同じライブラリが下にあり、**ここにインストール**があります。

![Worlds](/docs/images/worlds.png)

## ファイルマネージャー

サーバーの**ワールド**セクションの下にある**ファイル**タブは、そのサーバーのデータディレクトリ用の完全なブラウザ内ファイルマネージャーです。ファイルのリスト表示、読み取り、編集、名前変更、移動、コピー、削除、アップロード、フォルダの作成、およびフォルダ下のファイルテキストの検索（**ファイル内検索**）が可能です。SSH経由で通常行うすべての操作をブラウザから実行できます。

![File manager](/docs/images/server-files.png)

テキストファイルは、8MBの制限付きでエディタで開かれます。より大きなファイルはダウンロードできます。アップロードは一度に最大20個のファイルを受け付けます。

### サンドボックス内での操作

すべてのファイル操作は、サーバー固有のデータディレクトリ内に限定されます。パネルは各パスを解決し、脱出を試みる操作を拒否します：`..`トラバーサル、絶対パス、およびディレクトリ外を指すシンボリックリンク（存在しないものも含む）も同様です。Modやプラグインがファイルマネージャーを騙してホスト上の他の場所を読み書きさせようとしても、リンクを配置することはできません。

## Mod

Modやプラグインサーバーの場合、**Mod**タブ（サーバーサイドバーの独立したグループ）はModセットを管理します：Modの閲覧と追加、およびインストールされているModの確認ができます。インストールされている各Modの行から、それを更新する（またはその更新を無視する）、[元に戻す](/docs/updates/#undoing-a-mod-update)、無効にする、または削除することができます。**すべて更新**は、1回の再起動で利用可能なすべての更新を適用します。Modとパックの更新は、[更新](/docs/updates/)ページにも表示されます。

### Modの追加

![Mods](/docs/images/mods.png)

4つの方法があり、すべてModタブのツールバーからアクセスできます：

- **Modの検索**: **ModrinthまたはCurseForge**を検索します（CurseForgeチップは、**設定 → APIキー**にAPIキーが保存されると表示されます）。プラグインサーバーでは、**Hangar**（PaperMC独自のプラグインレジストリ）および**SpigotMC**（SpigetのCDNプロキシ経由）も検索できます（どちらもAPIキー不要）。**データパック**タブはModrinthのデータパックを検索します。すべてサーバーのローダーとMinecraftバージョンにフィルタリングされます（チェックボックスで互換性がないと表示されているビルドもリスクを承知で表示できます）。Quiltサーバーは、QuiltがFabric Modを実行するため、fabricタグ付きのビルドも自動的に表示します。サーバーに既に存在する結果には**インストール済み**バッジが表示されます。CurseForgeの作者が自動ダウンロードを許可しない場合（またはSpigotMCリソースが外部でホストされている場合）、パネルはそれを前面に表示し、インストール中に失敗する代わりに**CurseForgeを開く**（または**SpigotMCを開く**）+**Jarをアップロード**のパスを提供します。

  ![Hangar search](/docs/images/mods-search-hangar.png)

- **Zipのインポート**: 1つのボタン、3つの形状、自動検出：
  - **Modrinth Modpack (`.mrpack`)**: ピン留めされたすべてのファイルは、ハッシュルックアップを通じてModrinthプロジェクトに正規化されます（そのため、インポートされたModは実際の名前、アイコンを保持し、更新チェック可能のままになります。Modrinthが知らないファイルはパック自体のURLからインストールされます）。ダウンロード中にパックのsha512チェックサムに対して検証され、適合判定とともにプレビューされます。クライアント専用ファイルは非表示でスキップされ、両方のオーバーライドツリー（`overrides/`、次に`server-overrides/`；サーバー固有のコピーが優先されます）が適用されます。

    ![mrpack import](/docs/images/mrpack-import.png)

  - **CurseForge Modpackのエクスポート**（CurseForgeアプリが生成するzip、`manifest.json`付き）：ピン留めされたすべてのModは一括で解決され、警告付きでプレビューされます（このサーバーには不適切なローダー/MC、CurseForgeに存在しないファイル、手動ダウンロードが必要なMod）。実際の進捗とともにインストールされます。パックの`overrides/`（設定、スクリプト）もオプションで適用できます。上書きされるファイルは、サーバーフォルダ内の`.import-backups/<タイムスタンプ>/`に最初にバックアップされます。
  - **自分で収集したJarのプレーンzip**: 各Jarは識別され（Modrinthハッシュ一致 → CurseForgeフィンガープリント → Jar自体のメタデータ）、サーバーに対して判定されます（_適合 / 不適切なローダー / 不適切なMCバージョン / すでにインストール済み / 不明_）。これにより、実際に必要なものをインストール前に選択できます。
- **URLから追加**: ほとんどのものを貼り付けます：Modrinth、CurseForge、Hangar、またはSpigotMCプロジェクトページ、GitHubリポジトリまたはリリースURL（単純な`owner/repo`でも可；GitHubインストールは最新の安定リリースを優先し、`-sources`/`-javadoc`サイドカーJarはスキップします）、単純なModrinthスラッグ、または任意の直接的な`.jar`URL。パネルはサーバーのローダーとMCバージョンに適切なビルドを解決します。

  ![Add by link](/docs/images/mods-add-by-link.png)

- **Jarをアップロード**（検索フォールバックまたは保留中ダウンロード解決から）：アップロードされたJarは同じように識別されるため、実際の名前、バージョン、アイコンを保持し、更新チェック可能になります。

すべてのレジストリインストールは、**ダウンロード中にチェックサム検証されます**：ストリームは、レジストリが公開する最も強力なダイジェスト（sha512 → sha256 → sha1 → md5）に対してチェックされ、不一致の場合は何もサーバーに着陸する前に中止されます。

Zip全体（`.mrpack`を含む）も**サーバーを作成**できます：ウィザードの**Modpackから**タブで、それをアップロードすると、パックマニフェスト（または識別されたJar間の多数決）がローダー、Minecraftバージョン、およびローダービルドを埋めます。
