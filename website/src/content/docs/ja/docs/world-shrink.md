時間とともにワールドは広がっていきます。プレイヤーが歩いたり、飛んだり、エンダーパールで運ばれたりした場所すべてで、誰も戻ってこなかったとしても、ディスクにはチャンクが生成され続けます。**ワールドの縮小**は、ほとんど誰も時間を費やさなかったチャンクを削除し、ワールドのディスク容量を削減します。Minecraftは、誰かが再びその場所を訪れた瞬間に、ワールドシードから削除されたエリアを再構築します。そのため、誰も使用していない土地にとっては安全ですが、プレイヤーがほとんど立ち止まらなかった場所に**構築した**ものはすべて失われる可能性があるため、最初にバックアップを取ることが重要です（バックアップが元に戻す手段となります）。

## 「ほとんど訪問されなかった」とは

各チャンクは、プレイヤーがその中にどれだけの時間を費やしたかを記録しています（Minecraftではこれを`InhabitedTime`と呼びます）。ワールドの縮小は、デフォルトで合計プレイヤー時間が**30秒未満**のチャンクを削除します。縮小ダイアログで、このしきい値（1秒から1時間）と、スポーン周辺に保持するチャンクの数（デフォルトは8、`0`にするとスポーン保護が無効になります）を変更できます。

常に保持されるもの：

- オーバーワールドのワールドの**スポーン地点**周辺のエリア（`level.dat`から読み取られます）。ネザー、エンド、カスタムディメンションにはスポーンエリアはありません。
- 訪問時間を読み取れなかったチャンク。例えば、パネルがデコードできない圧縮形式（LZ4）で保存されたワールドなどです。プレビューと結果には、スキップされたチャンクの数が表示されます。

ワールドのすべてのディメンションが対象となります。Bukkitスタイルの兄弟フォルダ（`world_nether`、`world_the_end`）と、バニラおよびForge/Fabricのレイアウト（`world/DIM-1`、`world/DIM1`、`world/dimensions/<namespace>/<name>`）の両方です。チャンクが削除されると、そのエンティティと村人のPOIも一緒に削除されるため、再生成されたチャンクには古いモブ、トロッコ、またはジョブサイトは引き継がれません。

## ワールドタブからの実行方法

1. **バックアップ**タブからバックアップを取得します。ワールドタブからの縮小は、自動的にバックアップを取得しません。
2. **ワールド → ワールド**を開き、ワールドを見つけて、縮小アイコンをクリックします。
3. **プレビュー**をクリックして、削除されるチャンクの数（およびメガバイト数）のおおよその目安を確認します。まだ何も変更されていません。プレビューはサーバー実行中でも機能します。
4. **ワールドを縮小**をクリックします。縮小はワールドファイルを直接編集するため、サーバーは停止している必要があります。事前に停止するか、停止して縮小し、再度開始するオプションをチェックしてください（縮小に失敗した場合でもサーバーは再起動されます）。進捗はタスクトレイに表示されます。

## バックアップの一部としての実行方法

**バックアップ**タブで、**今すぐバックアップ**の前に**「後でワールドも縮小する」**をチェックします。バックアップアーカイブが最初に書き込まれ（そのアーカイブが元に戻す手段となります）、その後ワールドが縮小されますが、これはサーバーが停止している場合に限ります。サーバーが実行中の場合、バックアップは実行されますが、縮小はメモとともにスキップされます。

スケジュールされたバックアップにも同様のオプションがあります。スケジュールエディタで、**バックアップ**タスクを選択し、**「各バックアップ後にワールドを縮小する」**をチェックします。無人で実行したい場合は、数分前に**サーバー停止**スケジュールと組み合わせてください。
