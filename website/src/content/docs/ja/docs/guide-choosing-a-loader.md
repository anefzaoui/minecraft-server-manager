プレイヤーにインストールしてほしいものを選んでください。一番速そうなものではなく。

| 欲しいもの                                     | これを実行する           | プレイヤーがインストールするもの |
| ---------------------------------------------- | ------------------------ | -------------------------------- |
| フレンドとのサバイバル、特に変わったことはない | Vanilla                  | なし                             |
| ランク、領地、管理機能付きのパブリックサーバー | Paper                    | なし                             |
| CurseForge または Modrinth の特定のModパック   | それに記載されているもの | パック                           |
| 自分で構築中の最新Modパック                    | Fabric または NeoForge   | 同じMod                          |
| 1.7 から 1.12 時代の古いパック                 | Forge                    | 同じMod                          |

ほとんどの人はこれで十分です。このページの残りはその理由です。

## プラグインとModは同じものではありません

これが他のすべてが決まる区別です。

**プラグイン**はサーバーでのみ実行されます。Paper、Spigot、Bukkit がロードします。プレイヤーは通常の
変更されていないクライアントで参加し、その存在を知ることはありません。ルール、権限、経済、
領地、ミニゲーム、管理機能に関するものはすべてプラグインであり、ほぼすべてのパブリックサーバーが Paper を実行する理由です。

**Mod**はゲーム自体を変更します：新しいブロック、新しい次元、新しい機械。クライアントはサーバーと同じ Mod をロードする必要があります。そうしないと、サーバーが伝えていることを理解できません。
Modded サーバーに参加する人は、まずパックをインストールします。

サーバーが実質的に両方になることはありません。Mod ローダーにプラグイン API を追加するハイブリッドプロジェクトは存在し、機能しますが、機能しなくなることもあります。通常は最悪のタイミングで。両方が必要な場合は、プロキシを使用して、ハイブリッドサーバーではなく、その背後に Modded サーバーとプラグインサーバーを実行してください。

## プラグイン側

**Paper** がデフォルトの選択肢です。これは Spigot のフォークで、長年のパフォーマンス改善と、
管理者を悩ませてきたほぼすべての動作に対する設定ファイルがあります。Bukkit 時代の Vanilla プラグインのほとんどは引き続き動作します。

**Purpur** は Paper のフォークで、さらに多くの設定項目があり、ゲームプレイに関するものも含まれます。
それらの特定のスイッチが必要な場合はこれを選択してください。それ以外の場合は Paper を選択してください。

**Vanilla** は、変更されていないゲームそのものが目的の場合に実行する価値があります。プレイヤーが多いと遅くなり、
権限システムがないため、管理は手動になります。

Paper はパフォーマンス向上のために、デフォルトで一部の Vanilla の動作を変更します。
ビデオで見たいずれかのレッドストーン装置がサーバーで動作しない場合、通常はその理由であり、
通常は設定の問題です。

## Mod 側

**Fabric** は軽量で、数日以内に新しい Minecraft バージョンにアップデートされ、ほとんどの最新の
パフォーマンス Mod をサポートしています。ほぼすべての Fabric Mod は Fabric API も必要としますが、これは別途ダウンロードする必要があります。
少数の便利な Mod を備えた高速サーバーが目標の場合は、これが最適です。

**NeoForge** は、現在のバージョンの古い Forge エコシステムが作業を行う場所です。
1.20.1 の間に Forge から分岐し、1.20.2 以降で構築されたほとんどの大型パックはこれをターゲットにしています。
現在、大規模なパックを新規に構築する場合は、これが最適です。

**Forge** は過去を所有しています。1.7.10、1.12.2、1.16.5 時代のパックの多くは、
愛されているパックの大部分であり、これからもそうであり続けます。それらのためにこれを保持してください。

**Quilt** は Fabric のフォークで、ほとんどの Fabric Mod を実行できます。
正当な理由があって存在しますが、特に理由がない場合は Fabric を選択してください。

あるローダー用の Mod は別のローダーでは実行されません。Mod のページに Fabric と記載されている場合は Fabric 用です。

## パックをインストールする場合、パックが決定します

選択しないでください。パックにはローダーとその正確な Minecraft バージョンが記載されており、両方を一致させる必要があります。
「ほぼ同じ」はここでは通用しません：1.20.1 用のパックは 1.20.4 では実行できず、1.20.1 の NeoForge
パックは 1.20.1 の Forge では実行できません。

Mod を手動で選択するのではなく、パックの ID またはリンクでインストールし、バージョンを固定してください。パックは
更新されるため、シーズン中に予期せず更新されるとワールドが破損する可能性があります。

## どの Java バージョンを使用するか

Minecraft の要件はゲームと共に移動し、間違ったバージョンを実行すると、明確なメッセージではなく、
役に立たない `UnsupportedClassVersionError` が発生します。

| Minecraft バージョン | Java |
| -------------------- | ---- |
| 1.16.5 以前          | 8    |
| 1.17                 | 16   |
| 1.18 および 1.19     | 17   |
| 1.20 から 1.20.4     | 17   |
| 1.20.5 から 1.21.x   | 21   |
| 26.1 以降            | 25   |

古いパックは本当に Java 8 を必要とします。これはソフトウェアにおいて、最新バージョンが間違っている数少ない例の 1 つです。

## Minecraft Server Manager で

作成ウィザードは、実行したいものを尋ね、上記の表から Java バージョンを選択するため、
不一致が誤って発生することはありません。Vanilla、Paper、Purpur は **Vanilla** タブにあります。
**From Mods** タブは Fabric、Forge、NeoForge、または Quilt を受け入れ、Minecraft バージョンとローダー
ビルド（最新または固定したもの）を指定します。CurseForge、Modrinth、または GT New Horizons からパックをインストールすると、
正確なバージョンに固定されます。アップグレードは、適用したとき（またはサーバーの更新ポリシーが **Auto-Update** の場合の毎日のチェック後）にのみ行われ、
常に最初にバックアップを取り、ロールバックできます。

Mod ブラウザは、サーバーがどのローダーを実行しているかを認識し、それに応じて提供されるものをフィルタリングするため、
Fabric jar が誤って NeoForge サーバーに配置されることはありません。
