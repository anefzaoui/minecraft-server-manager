כל שרת נושא את האינטגרציות שלו תחת קבוצת **הגדרות**: **Discord**, **דף סטטוס** ציבורי, **הזמנות** בלחיצה אחת, וטאב **צ'אטבוט** אופציונלי (למנהלים בלבד). דף זה מכסה את Discord; [הזמנות ודף סטטוס](/docs/invites-and-status-page/) מכסים את שני אלו, ול[צ'אטבוט](/docs/chatbot/) יש דף משלו.

## התראות Discord

הפאנל מעביר אירועי שרת לערוץ Discord דרך Webhook. ללא בוט, ללא OAuth.

### הגדרה

1. ב-Discord: **הגדרות שרת → אינטגרציות → Webhooks → Webhook חדש**. בחר את הערוץ והעתק את כתובת ה-Webhook.
2. בפאנל, פתח את הטאב **הגדרות → Discord** של השרת, הדבק את הכתובת בשדה **Webhook URL**, הפעל את הכרטיס **on**, ו**שמור**. הכתובת נשמרת מוצפנת (באותו אחסון במנוחה כמו מפתחות ה-API שלך).
3. השתמש ב-**Send Test** כדי לוודא שזה עובד.

![Discord integration](/docs/images/integrations-discord.png)

כדי להחליף כתובת שמורה, הדבק כתובת חדשה ושמור; השאר את השדה ריק כדי לשמור את הקיים. הכתובת השמורה מוצגת מוסתרת (הטוקן מוסתר).

### מה נשלח

התראות מקובצות לקטגוריות הניתנות להפעלה/כיבוי. כולן מופעלות כברירת מחדל.

| קטגוריה            | אירועים                                  |
| ------------------ | ---------------------------------------- |
| **הפעלה / עצירה**  | השרת הופעל, השרת נעצר                    |
| **קריסות**         | קריסה, זוהתה לולאת קריסות, דוח קריסה חדש |
| **גיבויים**        | גיבוי נוצר, גיבוי שוחזר                  |
| **עדכונים**        | עדכון הוחל, עדכון בוטל, עדכון נכשל       |
| **בעיטות / באנים** | שחקן נבעט, שחקן נחסם                     |
| **התראות**         | הדברים שמשאירים שרת שבור בשקט (ראה להלן) |

### קטגוריית ההתראות

`Alerts` הוא ערוץ "משהו דורש התערבות אנושית", עבור תנאים שהיו גלויים רק בפאנל בעבר:

| אירוע                   | משמעות                                                                               |
| ----------------------- | ------------------------------------------------------------------------------------ |
| `oom`                   | הקונטיינר נעצר עקב מחסור בזיכרון.                                                    |
| `unhealthy`             | התהליך פועל אך בדיקת ה-`mc-health` נכשלת: שרת חי אך מת.                              |
| `startup-stalled`       | עדיין מתחיל לאחר כ-10 דקות ללא "Done" בלוגים (עם אבחון של מה לתקן, היכן שניתן לדעת). |
| `stop-failed`           | עצירה חלקה לא הצליחה והקונטיינר עדיין פועל.                                          |
| `schedule-failed`       | הפעלה מחדש / גיבוי / פקודה מתוזמנים נכשלו.                                           |
| `quota-exceeded`        | מכסת דיסק במצב קפדני הופעלה והשרת נעצר.                                              |
| `offline-after-restart` | השרת היה פעיל לפני שהפאנל הופעל מחדש, כעת אינו פעיל, ולא יופעל מחדש אוטומטית.        |
| `port-change-failed`    | שינוי פורט נכשל והשרת לא הצליח לחזור לפורט הישן שלו, ולכן הוא מושבת.                 |
| `auto-restart-gave-up`  | שרת שקרס לא הופעל מחדש מכיוון שפעולה אחרת השביתה אותו למשך זמן רב מדי.               |

### איך המשלוח עובד

גשר רקע בודק את [יומן הפעילות](/docs/activity/) כל 15 שניות ומעביר שורות ממופות. אם POST של Webhook נכשל באופן זמני, השורה הזו מנסה שוב בסריקות מאוחרות יותר במקום להיזרק; לאחר מספר ניסיונות כושלים השורה מדולגת, וכשלים במשלוח נרשמים לכל היותר פעם בשעה לשרת. לאחר הפעלה מחדש של הפאנל, הגשר שולח את האירועים שהוא עדיין לא מסר, אך לעולם לא יותר משעתיים אחורה; בהרצתו הראשונה הוא מתחיל מהאירוע החדש ביותר.
