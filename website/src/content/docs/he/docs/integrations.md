כל שרת נושא את האינטגרציות שלו תחת קבוצת **הגדרות**: **Discord**, **דף סטטוס** ציבורי, **הזמנות** בלחיצה אחת, וטאב ה-**צ'אטבוט** האופציונלי. דף זה מכסה את Discord (לשאר יש תיעוד משלהם ועזרי הגדרה בפאנל).

## התראות Discord

הפאנל מעביר אירועי שרת לערוץ Discord דרך Webhook. ללא בוט, ללא OAuth.

### הגדרה

1. ב-Discord: **הגדרות שרת → אינטגרציות → Webhooks → Webhook חדש**. בחר את הערוץ והעתק את כתובת ה-Webhook.
2. בפאנל, פתח את טאב **הגדרות → Discord** של השרת, הדבק את הכתובת בשדה **Webhook URL**, הפעל את הכרטיסייה **on**, ו**שמור**. הכתובת נשמרת מוצפנת (באותו אחסון במנוחה כמו מפתחות ה-API שלך).
3. השתמש ב-**שלח בדיקה** כדי לוודא שזה עובד.

![אינטגרציית Discord](/docs/images/integrations-discord.png)

כדי להחליף כתובת שמורה, הדבק כתובת חדשה ושמור; השאר את השדה ריק כדי לשמור את הקיים. הכתובת השמורה מוצגת ממוסכת (הטוקן מוסתר).

### מה נשלח

התראות מקובצות לקטגוריות הניתנות להפעלה/כיבוי. כולן מופעלות כברירת מחדל.

| קטגוריה            | אירועים                                  |
| ------------------ | ---------------------------------------- |
| **הפעלה / עצירה**  | השרת הופעל, השרת נעצר                    |
| **קריסות**         | קריסה, זוהתה לולאת קריסות, דוח קריסה חדש |
| **גיבויים**        | גיבוי נוצר, גיבוי שוחזר                  |
| **עדכונים**        | עדכון הוחל, עדכון בוטל, עדכון נכשל       |
| **בעיטות / באנים** | שחקן נבעט, שחקן נחסם                     |
| **התראות**         | הדברים שמשאירים שרת שבור בשקט (ראה להלן) |

### קטגוריית ההתראות

`התראות` הוא ערוץ "משהו דורש התערבות אנושית", עבור תנאים שהיו גלויים רק בפאנל בעבר:

| אירוע                   | משמעות                                                                                 |
| ----------------------- | -------------------------------------------------------------------------------------- |
| `oom`                   | הקונטיינר נעצר עקב מחסור בזיכרון.                                                      |
| `unhealthy`             | התהליך פועל אך בדיקת ה-`mc-health` נכשלת: שרת חי אך מת.                                |
| `startup-stalled`       | עדיין בתהליך הפעלה לאחר כ-10 דקות ללא "Done" בלוגים (עם אבחון של מה לתקן, היכן שידוע). |
| `stop-failed`           | עצירה חלקה לא הצליחה והקונטיינר עדיין פועל.                                            |
| `schedule-failed`       | הפעלה מחדש / גיבוי / פקודה מתוזמנים נכשלו.                                             |
| `quota-exceeded`        | מכסת דיסק במצב קפדני הופעלה והשרת נעצר.                                                |
| `offline-after-restart` | השרת היה פעיל לפני שהפאנל הופעל מחדש, כעת אינו פעיל, ולא יופעל אוטומטית.               |
| `crash-report`          | דוח קריסה חדש נלכד ונותח.                                                              |
| `update-failed`         | שדרוג מוגן לא עלה כבריא.                                                               |

### איך המסירה עובדת

גשר רקע סוקר את [יומן האירועים](/docs/activity/) כל 15 שניות ומעביר שורות ממופות. אם POST של Webhook נכשל באופן זמני, השורה הזו מנסה שוב בסריקות מאוחרות יותר במקום להיזרק; Webhook שאינו זמין באופן קבוע מושתק (שורה אחת לכל שעה) לאחר מספר ניסיונות. הגשר לעולם אינו מנגן מחדש אירועים מלפני שהפאנל הופעל.
