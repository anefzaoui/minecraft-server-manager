## הקונסולה החיה

לשונית ה**קונסולה** מציגה את יומן השרת בזמן אמת ומספקת תיבת פקודות לשליחת כל פקודה לשרת. ללא צורך ב-`docker exec` או SSH. הפלט חוזר באופן מיידי, כולל צבעים. שליחת פקודות דורשת את הרשאת ה-Console עבור אותו שרת; בלעדיה, עדיין ניתן לצפות ביומן.

מעל ליומן ניתן לסנן שורות לפי טקסט (או `/regex/`) ולפי רמה (INFO, WARN, ERROR), וכן **הורדה** מציעה את הפלט האחרון, את `latest.log` המלא, או את כל קבצי היומן כקובץ zip.

![Console](/docs/images/server-console.png)

הקונסולה היא גם המקום שבו הפאנל קורא את מצב השרת: הוא צופה ביומן כדי לסווג את שלב האתחול ("טוען מודים", "יוצר עולם", "משלים אתחול") וקורא לפקודת `list` כדי לעקוב אחר מי מחובר, כך שהדשבורד וכרטיסי השרת תמיד ישקפו את המציאות.

סריקה זו פותחת חיבור RCON קצר-חיים בכל מחזור, אשר השרת רושם ביומן כזוג `Thread RCON Client … started` / `shutting down` כל כ-20 שניות, ו-(בשרתים שליבתם או התוספים שלהם משכפלים זאת) שורה של `Rcon issued server command: …` עבור כל קריאה לקריאה בלבד (player counts, בנוסף לקריאות `time query …` ו-`gamerule <name>` כאשר World Controls פתוח). המתג **הסתר רעשי קונסולה** מעל ליומן מסנן את השורות הללו (יחד עם שורות ההפעלה של מאזין ה-RCON). הוא מופעל כברירת מחדל ונשמר לכל דפדפן; כבה אותו כדי לראות את הזרם הגולמי.

פקודות הנשלחות מהפאנל יכולות להיות מוכרזות במשחק תחת תווית לכל שרת (התיבה **הכרז כ...**), כך ששחקנים יידעו שמפעיל מערכת פעל ולא קונסולה מסתורית.

## צ'אט

**קונסולה → צ'אט** שולח הודעות למשחק בזמן שהשרת פועל: הודעות **מעוצבות** מקבלות צבעים ועיצוב ויכולות להישלח לכולם או לשחקן מחובר אחד, ו-**פשוט** שולח שידור פשוט של `[Server]` לכולם.

![Console → Chat](/docs/screenshots/04-chat.png)

## פקודות צ'אט

פקודות צ'אט (**קונסולה → פקודות**) מאפשרות לשחקנים להפעיל פעולות בפאנל על ידי הקלדת פקודת קידומת בצ'אט המשחק, לדוגמה `!spawn` לטלפורט אקראי. הזיהוי מבוסס על היומן והביצוע עובר דרך השרת, כך ש**אין צורך במודים**.

![Chat commands](/docs/images/chat-commands.png)

לכל פקודה יש:

- **טריגר** (למשל `spawn`), המוקלד אחרי **קידומת** השרת (`!` כברירת מחדל, תו אחד או שניים, לעולם לא `/`).
- **פעולה**: טלפורט אקראי, טלפורט למבנה, טלפורט לביום, או הרצת פקודות קונסולה גולמיות.
- **רמת הרשאה**: כולם, שחקנים ברשימה הלבנה, או מפעילים בלבד.
- **קירור** לכל שחקן (30 שניות כברירת מחדל), והודעות הניתנות להתאמה אישית להמתנה / הצלחה / כישלון עם מקומות שמורים כמו `{distance}`.

### הערה בנוגע לבטיחות

פקודות שיכולות להרוס שרת (`stop`, `op`, `ban`, `whitelist`, וחברים) מותרות רק בטריגרים של **מפעילים בלבד**. הפאנל בודק זאת גם כאשר הן מקוננות בתוך שרשרת `execute … run …`, כך שטריגר עם הרשאה נמוכה לא יכול להבריח פקודה מסוכנת. טקסט צ'אט רגיל שרק מזכיר מילים אלו (כמו הודעת `say`) אינו משפיע.
