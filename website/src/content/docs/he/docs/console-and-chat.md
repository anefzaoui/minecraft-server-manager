## הקונסולה החיה

לשונית **הקונסולה** מציגה את יומן השרת בזמן אמת ומספקת תיבת פקודות לשליחת פקודות שרת. ללא `docker exec`, ללא SSH. הפלט חוזר באופן מוטמע, עם צבעים וכל השאר.

![קונסולה](/docs/images/server-console.png)

הקונסולה היא גם המקום שבו הפאנל קורא את מצב השרת: הוא עוקב אחר היומן כדי לסווג את שלב האתחול ("טוען מודים", "יוצר עולם", "מסיים אתחול") וקורא לפקודה `list` כדי לעקוב אחר מי מחובר, כך שהדשבורד וכרטיסי השרת תמיד ישקפו את המציאות.

סקר זה פותח חיבור RCON קצר-חיים בכל מחזור, שמתועד ביומן השרת כצמד `Thread RCON Client … started` / `shutting down` כל כ-20 שניות, ו (בשרתים שליבה או תוספים שלהם משקפים זאת) שורה של `Rcon issued server command: …` עבור כל קריאה לקריאה בלבד - `list` לספירת שחקנים, בתוספת `time query …` וקריאות `gamerule <name>` כאשר דף בקרות העולם פתוח. המתג **הסתר רעשי RCON** מעל היומן מסנן את השורות הללו (יחד עם שורות ההפעלה של מאזין RCON). הוא מופעל כברירת מחדל ונשמר לדפדפן; כבה אותו כדי לראות את הזרם הגולמי.

פקודות שנשלחות מהפאנל יכולות להיות מוכרזות במשחק תחת תווית לכל שרת, כך ששחקנים יידעו שמפעיל פעל ולא קונסולה מסתורית.

## פקודות צ'אט

פקודות צ'אט מאפשרות לשחקנים להפעיל פעולות בפאנל על ידי הקלדת פקודת קידומת בצ'אט המשחק, לדוגמה `!spawn` לטלפורט אקראי. הזיהוי מבוסס על היומן והביצוע עובר דרך השרת, כך ש**אין צורך במודים**.

![פקודות צ'אט](/docs/images/chat-commands.png)

לכל פקודה יש:

- **טריגר** (למשל `spawn`) ו**קידומת** (`!` כברירת מחדל).
- **פעולה**: טלפורט אקראי, טלפורט למבנה, טלפורט לביום, או הרצת פקודות קונסולה גולמיות.
- **רמת הרשאה**: כולם, שחקנים ברשימה הלבנה, או מפעילים בלבד.
- **קירור**, והודעות מותאמות אישית של ממתינה / הצלחה / כישלון עם מקומות כמו `{distance}`.

### הערה בנוגע לבטיחות

פקודות שיכולות להרוס שרת (`stop`, `op`, `ban`, `whitelist`, וחברים) מותרות רק בטריגרים של **מפעילים בלבד**. הפאנל בודק זאת גם כאשר הן מקוננות בתוך שרשרת `execute … run …`, כך שטריגר בעל הרשאה נמוכה לא יכול להבריח פקודה מסוכנת. טקסט צ'אט רגיל שרק מזכיר מילים אלו (כמו הודעת `say`) נשאר ללא שינוי.
