דף **אחסון** מציג לאן הדיסק שלך הולך: שימוש פר-שרת וכיצד הוא מתפתח לאורך זמן.

![Storage](/docs/images/storage.png)

## מכסות דיסק נאכפות על ידי הפאנל

Docker אינו יכול להגביל את השימוש בדיסק של bind mount, לכן הפאנל עושה זאת. אינדקס גודל ברקע סורק את ספריית הנתונים, שומר במטמון את טביעת הרגל של כל שרת, ואוכף את מכסת הדיסק שקבעת לכל שרת. כאשר הנתונים של שרת (עולם + גיבויים + כל השאר) מתקרבים למכסה שלו, הפאנל עוצר צמיחה בלתי מבוקרת במקום לאפשר לשרת אחד למלא את המארח שלך.

קבע מכסה לשרת בהגדרות שלו [settings](/docs/servers/). שרתים עם מודים והגיבויים שלהם [backups](/docs/backups/) יכולים להיות גדולים, אז תן להם מקום.

## ניקוי

תצוגת האחסון עוזרת לך למצוא מה לגזום (גיבויים ישנים, עולמות שאינם בשימוש, או שרת שצמח הרבה מעבר לציפיות) לפני שיגמר לך המקום.
