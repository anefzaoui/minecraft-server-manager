**พิมพ์เขียว** (blueprint) คือการบันทึกการตั้งค่าทั้งหมดของเซิร์ฟเวอร์ (ประเภท, เวอร์ชัน, ทรัพยากร, สภาพแวดล้อม, การปักหมุดแพ็ก, และอาจรวมถึงการตั้งค่าและโลก) ลงในไฟล์เดียวที่สามารถพกพาได้ ซึ่งคุณสามารถนำไปสร้างเซิร์ฟเวอร์ใหม่ได้

![Blueprints](/docs/images/blueprints.png)

## การส่งออก

จากเซิร์ฟเวอร์ ให้ส่งออกพิมพ์เขียวและเลือกว่าจะรวมอะไรบ้าง: การตั้งค่าเสมอ และอาจรวมถึงไฟล์ที่ฝังและโลก ผลลัพธ์จะถูกบันทึกไว้ในคลังพิมพ์เขียวของคุณและสามารถดาวน์โหลดเพื่อแชร์ได้

## การนำเข้าและการสร้างจากพิมพ์เขียว

นำเข้าไฟล์พิมพ์เขียว (หรือเลือกจากคลัง) เพื่อสร้างเซิร์ฟเวอร์ใหม่ที่ตั้งค่าไว้เหมือนต้นฉบับทุกประการ นี่เป็นวิธีที่เร็วที่สุดในการ:

- สร้างเซิร์ฟเวอร์ที่เหมือนกัน (เครือข่ายเซิร์ฟเวอร์มินิเกม, สำเนาการผลิตสำหรับการทดสอบ)
- ย้ายเซิร์ฟเวอร์ระหว่างแผงควบคุม
- เก็บเทมเพลตที่ทราบว่าดีซึ่งคุณสามารถย้อนกลับไปใช้ได้เสมอ

เนื่องจากพิมพ์เขียวบันทึก [การปักหมุดแพ็ก](/docs/modpacks/) ที่แน่นอน เซิร์ฟเวอร์ modpack ที่สร้างขึ้นใหม่จากพิมพ์เขียวจะติดตั้งเวอร์ชันที่ปักหมุดไว้เดียวกัน โดยไม่มีการอัปเกรดที่น่าประหลาดใจ
