แดชบอร์ดคือฐานหลักของคุณ: เซิร์ฟเวอร์ทุกเครื่อง สถานะสด และฟีดกิจกรรมที่กำลังดำเนินอยู่

![แดชบอร์ด](/docs/images/dashboard.png)

## กระเบื้องสรุป

ด้านบนสุด:

- **เซิร์ฟเวอร์ออนไลน์** - จำนวนเซิร์ฟเวอร์ของคุณที่กำลังทำงานอยู่
- **ผู้เล่นที่เชื่อมต่อ** - จำนวนผู้เล่นทั้งหมดในเซิร์ฟเวอร์ที่กำลังทำงานอยู่
- **อัปเดตพร้อมใช้งาน** - จำนวนเซิร์ฟเวอร์ แพ็ก หรือม็อดที่มีเวอร์ชันใหม่กว่า ([ดูอัปเดต](/docs/updates/))
- **Docker** - ว่าแผงควบคุมสามารถเข้าถึง Docker daemon ได้หรือไม่ และเวอร์ชันของมัน

## การ์ดเซิร์ฟเวอร์

เซิร์ฟเวอร์แต่ละเครื่องจะแสดงเป็นการ์ดพร้อมสถานะ (กำลังทำงาน, กำลังเริ่ม, หยุด, ขัดข้อง), ประเภทและเวอร์ชัน Minecraft, และพอร์ตเกม สำหรับเซิร์ฟเวอร์ที่กำลังทำงาน คุณจะได้รับข้อมูลสดเกี่ยวกับผู้เล่น, CPU, หน่วยความจำ และการใช้งานดิสก์ ซึ่งอัปเดตอย่างต่อเนื่อง

คลิกที่การ์ดเพื่อเปิดเซิร์ฟเวอร์นั้น การ์ด **สร้างเซิร์ฟเวอร์** ที่ว่างเปล่า และปุ่ม **สร้างเซิร์ฟเวอร์** ที่แถบด้านบน จะเริ่ม [วิซาร์ดการสร้าง](/docs/servers/)

คุณสามารถค้นหาและจัดเรียงเซิร์ฟเวอร์ของคุณ และสลับระหว่างมุมมองแบบกริดและรายการด้วยสวิตช์ทางด้านขวา

## กิจกรรมล่าสุด

ฟีดด้านล่างคือบันทึกการตรวจสอบที่อ่านได้แบบสด: การเข้าสู่ระบบ, การสำรองข้อมูล, การส่งออกบลูปริ้นต์, การตรวจสอบอัปเดต, การเปลี่ยนแปลงคำสั่งแชท, การเริ่มและหยุดเซิร์ฟเวอร์ และอื่นๆ อีกมากมาย แต่ละรายการจะถูกแท็กด้วยเซิร์ฟเวอร์ที่เกี่ยวข้อง (หรือแผงควบคุมเอง) และเวลาที่เกิดขึ้น ประวัติฉบับเต็มอยู่ในหน้า [กิจกรรม](/docs/activity/)
