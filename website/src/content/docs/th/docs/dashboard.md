แดชบอร์ดคือฐานหลักของคุณ: เซิร์ฟเวอร์ทั้งหมด สถานะสด และฟีดกิจกรรมที่กำลังดำเนินอยู่

![แดชบอร์ด](/docs/images/dashboard.png)

## กระเบื้องสรุป

ด้านบนสุด:

- **เซิร์ฟเวอร์ออนไลน์**: จำนวนเซิร์ฟเวอร์ของคุณที่กำลังทำงานอยู่จากทั้งหมด
- **ผู้เล่นที่เชื่อมต่อ**: จำนวนผู้เล่นทั้งหมดในเซิร์ฟเวอร์ที่กำลังทำงานอยู่
- **อัปเดตพร้อมใช้งาน**: จำนวนเซิร์ฟเวอร์ แพ็ก หรือม็อดที่มีเวอร์ชันใหม่กว่า ([ดูอัปเดต](/docs/updates/))
- **Docker**: แผงควบคุมสามารถเข้าถึง Docker daemon ได้หรือไม่ และเวอร์ชันของมัน

แถวที่สองจะเพิ่ม **หน่วยความจำที่จัดสรร** (และปริมาณที่ใช้งานอยู่) **พื้นที่จัดเก็บที่ใช้** ในโฟลเดอร์ข้อมูลเซิร์ฟเวอร์ทั้งหมด **สุขภาพ · 24 ชม.** (การขัดข้อง การหยุดเนื่องจากหน่วยความจำไม่เพียงพอ และการรีสตาร์ทอัตโนมัติในวันสุดท้าย) และ **อัปเดต** แบ่งเป็นอัปเดตระดับม็อดและเซิร์ฟเวอร์ ด้านล่างคือ **เซิร์ฟเวอร์ตามสถานะ** จะนับจำนวนเซิร์ฟเวอร์ของคุณในแต่ละสถานะ และ **ภาพรวมทรัพยากร** จะแสดงส่วนแบ่งหน่วยความจำและ CPU ของเซิร์ฟเวอร์แต่ละเครื่อง

## การ์ดเซิร์ฟเวอร์

เซิร์ฟเวอร์แต่ละเครื่องจะแสดงเป็นการ์ดพร้อมสถานะ (กำลังทำงาน เริ่มต้น หยุดแล้ว ขัดข้อง และสถานะระหว่างนั้น เช่น ไม่แข็งแรง หรือ หยุดชะงัก) ประเภทและเวอร์ชัน Minecraft พอร์ตเกม และแท็ก การ์ดแต่ละใบจะแสดง **ผู้เล่น** และการใช้ **ดิสก์** เทียบกับโควตา เซิร์ฟเวอร์ที่กำลังทำงานอยู่จะแสดง **CPU** และ **หน่วยความจำ** แบบสด ซึ่งอัปเดตอย่างต่อเนื่อง

คลิกที่การ์ดเพื่อเปิดเซิร์ฟเวอร์นั้น การ์ด **สร้างเซิร์ฟเวอร์** ที่ว่างเปล่า และปุ่ม **สร้างเซิร์ฟเวอร์** ที่แถบด้านบนสุด จะเริ่ม [วิซาร์ดการสร้าง](/docs/servers/)

คุณสามารถค้นหาเซิร์ฟเวอร์ของคุณ (ตามชื่อ ประเภท เวอร์ชัน หรือแท็ก) จัดเรียงตามสถานะ ชื่อ ขนาด เริ่มล่าสุด หรือสร้าง และสลับระหว่างเลย์เอาต์แบบกริดและรายการด้วยสวิตช์ทางด้านขวา

## กิจกรรมล่าสุด

ฟีดด้านล่างจะแสดงรายการล่าสุดจากบันทึกการตรวจสอบที่มนุษย์อ่านได้ของแผงควบคุม: การเข้าสู่ระบบ การสำรองข้อมูล การส่งออกพิมพ์เขียว การตรวจสอบอัปเดต การเปลี่ยนแปลงคำสั่งแชท การเริ่มและหยุดเซิร์ฟเวอร์ และอื่นๆ รายการแต่ละรายการจะติดแท็กด้วยเซิร์ฟเวอร์ที่เกี่ยวข้อง (หรือแผงควบคุมเอง) และระยะเวลาที่ผ่านมา **ดูทั้งหมด** จะเปิดประวัติฉบับเต็มในหน้า [กิจกรรม](/docs/activity/)
