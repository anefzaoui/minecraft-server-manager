หน้า **Modpacks** (และแท็บ **From Modpack** ใน [วิซาร์ดการสร้าง](/docs/servers/)) จะติดตั้ง modpack เป็นเซิร์ฟเวอร์ โดยจะ **ตรึงไว้กับเวอร์ชันแพ็กที่แน่นอนเสมอ** เพื่อให้การรีสตาร์ทไม่สามารถอัปเกรดแพ็กโดยไม่แจ้งให้ทราบได้

![Modpacks](/docs/images/modpacks.png)

## แพลตฟอร์มที่รองรับ

- **CurseForge**: ค้นหาตามชื่อ ต้องใช้ CurseForge API key (เพิ่มได้ที่ **Settings → API Keys**)
- **Modrinth**: ค้นหาตามชื่อ
- **FTB**: Feed The Beast packs ผ่าน API เท่านั้น (ต้องใช้ numeric pack ID และ explicit version ID) แผงควบคุมยังไม่ได้ตรวจสอบแพ็ก FTB สำหรับการอัปเดต
- **GT New Horizons**: แพ็ก 1.7.10 expert pack ติดตั้งจาก GTNH's own release index GTNH จะเลือก Java runtime ตามเวอร์ชันแพ็ก (2.8.0+ ทำงานบน **Java 25** ผ่านการแก้ไข lwjgl3ify ที่รวมมาด้วย รุ่นเก่ากว่าทำงานบน Java 21 หรือ 17) และวิซาร์ดจะเพิ่ม RAM และดิสก์ของเซิร์ฟเวอร์ให้เพียงพอสำหรับแพ็กนั้น
- **Custom zip**: ไม่ใช่แพ็กที่เผยแพร่เลย อัปโหลด **CurseForge modpack export** (ไฟล์ zip ที่มี `manifest.json` ซึ่งแอปของ CurseForge สร้างขึ้นสำหรับชุด mod ที่เลือกด้วยตนเอง), **Modrinth `.mrpack`**, หรือ **ไฟล์ zip ของ mod jars ใดๆ** แผงควบคุมจะประมวลผล manifest เป็นชุด (หรือระบุ jar แต่ละไฟล์ด้วย hash/fingerprint/metadata) แสดงตัวอย่างสิ่งที่เข้ากันได้ และติดตั้งทั้งหมดในงานเดียว รวมถึงคอนฟิก `overrides/` ของแพ็ก หากคุณเลือก Mod ที่ผู้เขียนไม่อนุญาตให้ดาวน์โหลดอัตโนมัติจะแสดงพร้อมลิงก์เบราว์เซอร์และช่องสำหรับอัปโหลดด้วยตนเองแทนที่จะล้มเหลวในการติดตั้ง

## การตรึงเวอร์ชันทำงานอย่างไร

เมื่อคุณเลือกแพ็ก แผงควบคุมจะระบุเวอร์ชันที่แน่นอน บันทึกไว้ และติดตั้งเวอร์ชันนั้น ในหน้า **Updates** คุณจะได้รับแจ้งเมื่อมีเวอร์ชันใหม่พร้อมใช้งาน (เว้นแต่ [นโยบายการอัปเดต](#update-policy) ของเซิร์ฟเวอร์คือ **Manual Only**) การอัปเกรดเป็นการดำเนินการที่ตั้งใจและมีการป้องกัน พร้อมการสำรองข้อมูลก่อนอัปเดตและการย้อนกลับ เซิร์ฟเวอร์ที่ติดตามเวอร์ชันเสถียรจะไม่ได้รับข้อเสนอเวอร์ชันเบต้า แท็บ **Versions** ของเซิร์ฟเวอร์เองจะตอบคำถามอีกส่วนหนึ่ง: เวอร์ชัน Minecraft ในอนาคตที่ mod ที่มีอยู่สามารถรองรับได้ ([updates](/docs/updates/#minecraft-version-compatibility))

เวอร์ชัน mod loader จะมาพร้อมกับแพ็กด้วย: เซิร์ฟเวอร์จะติดตั้ง Forge, NeoForge หรือ Fabric build ที่แพ็กประกาศไว้ หากแพ็ก Forge หรือ Fabric CurseForge ประกาศเวอร์ชันที่เก่าเกินไปสำหรับ mod ของตัวเอง แท็บ **Versions** สามารถแทนที่ได้จนกว่าแพ็กจะได้รับการแก้ไข การอัปเดตแพ็กจะลบการแทนที่ออก เนื่องจากเวอร์ชันใหม่จะประกาศเวอร์ชันของตัวเอง ([changing the mod loader version](/docs/updates/#changing-the-mod-loader-version))

เซิร์ฟเวอร์ที่สร้างขึ้นบนเวอร์ชันแผงควบคุมที่เก่ามาก (ก่อน 0.9.7) อาจถูกปล่อยให้ _ไม่ถูกตรึง_ ซึ่งหมายความว่าคอนเทนเนอร์อิมเมจจะติดตั้งเวอร์ชันแพ็กล่าสุดอย่างเงียบๆ ทุกครั้งที่เริ่มทำงาน ตอนนี้แผงควบคุมจะแก้ไขสิ่งเหล่านี้เมื่อบูต: มันจะล็อคแต่ละรายการไปยังเวอร์ชันที่ติดตั้งอยู่จริง (อ่านจากบันทึกของแผงควบคุมเองหรือ manifest การติดตั้งของอิมเมจ ไม่ใช่ "ล่าสุด" ที่เพิ่งระบุ) และบันทึกเหตุการณ์ หากไม่สามารถระบุได้ว่าติดตั้งอะไร หน้า Settings ของเซิร์ฟเวอร์จะแสดงคำเตือนพร้อมปุ่ม **Pick a Version…** (สำหรับแพ็ก CurseForge, Modrinth และ GTNH) ซึ่งจะเปิด [ตัวเลือกเวอร์ชัน](#changing-the-pack-version) และการพยายามบันทึกการกำหนดค่า modpack ที่ไม่ถูกตรึงจะถูกปฏิเสธทันที

## นโยบายการอัปเดต

เซิร์ฟเวอร์แต่ละเครื่องมี การ์ด **Update Policy** ในแท็บ **Settings → Configuration** และทั้งสามตัวเลือกมีความหมายตามที่ระบุไว้:

- **Manual Only** (ค่าเริ่มต้น): จะไม่มีอะไรเปลี่ยนแปลงด้วยตัวเอง และเซิร์ฟเวอร์จะไม่อยู่ในรายการ badge การอัปเดตและหน้า Updates โหมด "ปล่อยฉันไว้คนเดียว": เหมาะสำหรับแพ็กที่ปรับแต่งด้วยตนเองหรือนำเข้าที่คุณไม่ต้องการให้ใครมายุ่งเกี่ยว มันไม่ได้ล็อคเวอร์ชัน: [**Change Version…**](#changing-the-pack-version) ยังคงใช้งานได้ภายใต้นโยบายทุกข้อ หากต้องการรับทราบเกี่ยวกับเวอร์ชันใหม่และนำไปใช้ด้วยการคลิกเพียงครั้งเดียว ให้เลือก **Notify Me**
- **Notify Me**: การตรวจสอบรายวันจะแสดงการอัปเดตที่พร้อมใช้งานเป็น badge และในหน้า Updates การนำไปใช้จะเป็นการคลิกของคุณเสมอ
- **Auto-Update**: หลังจากการตรวจสอบรายวันตามกำหนด การอัปเดต **แพ็ก** ที่รอดำเนินการจะถูกนำไปใช้ผ่านเส้นทางที่มีการป้องกันเช่นเดียวกับการอัปเกรดด้วยตนเอง: การสำรองข้อมูลก่อนอัปเดต การตรวจสอบสุขภาพ และการย้อนกลับอัตโนมัติหากเวอร์ชันใหม่ไม่สามารถบูตได้ การอัปเดตที่จะย้ายเซิร์ฟเวอร์ไปยัง Minecraft เวอร์ชันที่แตกต่างกันจะถูกข้ามไปเสมอพร้อมกับเหตุการณ์แทน: การแปลงเวิลด์อย่างถาวรเป็นการตัดสินใจที่แผงควบคุมปฏิเสธที่จะทำแทนคุณ ปุ่ม **Check Now** ด้วยตนเองจะตรวจสอบเท่านั้น จะไม่กระตุ้นการอัปเดตอัตโนมัติ

## การอัปเกรดแพ็ก

จากเซิร์ฟเวอร์ที่ถูกตรึง คุณสามารถอัปเกรดเป็นเวอร์ชันที่ใหม่กว่าได้ในขั้นตอนเดียว แผงควบคุมจะสำรองข้อมูลก่อน สลับเวอร์ชันที่ถูกตรึง สร้างเซิร์ฟเวอร์ใหม่ (ระบุ Java ใหม่หากเวอร์ชันใหม่ต้องการ runtime ที่แตกต่างกัน) และตรวจสอบการบูตครั้งแรก โดยมีระยะเวลาที่เพียงพอสำหรับแพ็กขนาดใหญ่เช่น GTNH ที่ดาวน์โหลดข้อมูลหลายกิกะไบต์และสร้างเวิลด์ที่มี mod หลายร้อยรายการในการเริ่มต้นครั้งแรก

## การเปลี่ยนเวอร์ชันแพ็ก

หากต้องการรันเวอร์ชันที่เฉพาะเจาะจง ไม่ว่าจะใหม่กว่าหรือเก่ากว่า ให้ใช้ **Change Version…** บนการ์ดแพ็กของแท็บ **Overview** ของเซิร์ฟเวอร์ ในหน้า **Modpacks** การเปิดการ์ดของแพ็กที่ติดตั้งจะให้ตัวเลือกเดียวกัน: เลือกเวอร์ชันในเมนูแบบเลื่อนลงแล้วคลิก **Switch to This Version** ทั้งสองอย่างต้องใช้สิทธิ์ **Content** ของเซิร์ฟเวอร์ และทั้งสองอย่างมีให้สำหรับแพ็ก CurseForge, Modrinth และ GTNH (แพ็ก FTB ยังไม่มีรายการเวอร์ชัน) รายการจะแสดง 25 เวอร์ชันล่าสุดสำหรับ CurseForge และ Modrinth และทุกรุ่นของ GTNH

การสลับจะผ่านเส้นทางที่มีการป้องกันเช่นเดียวกับการอัปเกรด: การสำรองข้อมูลก่อนการอัปเดต การตรึงเวอร์ชันใหม่ การสร้างใหม่ และการบูตครั้งแรกที่ได้รับการตรวจสอบ พร้อมการย้อนกลับด้วยการคลิกเพียงครั้งเดียวหากเซิร์ฟเวอร์ไม่ทำงานอย่างถูกต้อง Mod ที่กำหนดเองของคุณจะถูกนำไปด้วย เช่นเดียวกับ mod ของแพ็กที่คุณปิดใช้งาน พร้อมกับการตั้งค่าการติดตั้งอื่นๆ ของแพ็ก (mod ที่บังคับใส่ ไฟล์ที่จะละเว้น โปรเจกต์เพิ่มเติม) การติดตั้งแพ็กที่แตกต่างกันจะเริ่มต้นการตั้งค่าเหล่านั้นใหม่ เพราะการตั้งค่าเหล่านั้นจะสมเหตุสมผลเฉพาะกับแพ็กที่สร้างขึ้นมาเท่านั้น

แต่ละเวอร์ชันจะแสดงพร้อมกับเวอร์ชัน Minecraft ที่ทำงานอยู่ โดยเปรียบเทียบกับเวอร์ชันที่เวิลด์ของคุณถูกบันทึกล่าสุด:

- **Minecraft เวอร์ชันเดียวกัน**: สลับหลังจากการยืนยันตามปกติ การย้อนกลับไปยังเวอร์ชันแพ็กที่เก่ากว่าอาจทำให้บล็อกและไอเทมจาก mod ที่เวอร์ชันนั้นไม่มีหายไป ดังนั้นการสำรองข้อมูลจะยังคงอยู่ในแท็บ Backups ไม่ว่าจะกรณีใดก็ตาม
- **Minecraft เวอร์ชันใหม่กว่า**: อนุญาตหลังจากการยืนยันที่เตือนว่าเวิลด์จะถูกแปลงอย่างถาวร การสำรองข้อมูลที่ทำไว้ก่อนหน้านี้เป็นวิธีเดียวที่จะกลับไปยังเวิลด์เก่าได้
- **Minecraft เวอร์ชันเก่ากว่า**: ไม่พร้อมใช้งาน Minecraft ไม่สามารถโหลดเวิลด์ด้วยเวอร์ชันที่เก่ากว่าเวอร์ชันที่บันทึกล่าสุดได้ ดังนั้นแผงควบคุมจะปฏิเสธแทนที่จะปล่อยให้เซิร์ฟเวอร์ที่ล่มเมื่อบูต
