API HTTP ขนาดเล็กที่อ่านอย่างเดียวสำหรับดึงสถานะเซิร์ฟเวอร์จากภายนอกแผงควบคุม: แดชบอร์ดสถานะ, ตัวตรวจสอบความพร้อมใช้งาน, บอท Discord, กฎระบบอัตโนมัติภายในบ้าน มันถูกให้บริการโดยแผงควบคุมเองและส่งคืนข้อมูลสดเดียวกันกับที่หน้าของแผงควบคุมแสดง (จากแคชในหน่วยความจำ) ดังนั้นการเรียกดูจึงไม่เคยแตะต้อง Docker

มัน **ปิดอยู่จนกว่าผู้ดูแลระบบจะใช้งาน** และ **ถูกจำกัดโดยผู้ดูแลระบบ** จะไม่มีอะไรถูกเปิดเผยจนกว่าจะมีโทเค็น

## การเปิดใช้งาน

**การตั้งค่า → Public API → New Key** ตั้งชื่อ เลือกสิ่งที่สามารถมองเห็นได้ (เซิร์ฟเวอร์ทั้งหมด หรือชุดย่อยที่เฉพาะเจาะจง) และวันหมดอายุที่เป็นทางเลือก คีย์เต็ม (โทเค็น Bearer) จะแสดง **เพียงครั้งเดียว** ในกล่องโต้ตอบ ให้คัดลอกตอนนี้ เพราะหลังจากนั้นจะเก็บไว้เพียงส่วนต้นสั้นๆ เพื่อระบุในรายการเท่านั้น

![Public API settings](/docs/images/settings-public-api.png)

การสร้างคีย์แรกจะเปิดใช้งาน API โดยอัตโนมัติ (สวิตช์ **Let outside apps read status** เป็นตัวควบคุมการหยุดชั่วคราว: ปิดเพื่อหยุดการให้บริการโดยไม่ยกเลิกคีย์ใดๆ) ยกเลิกคีย์จากตารางเดียวกันได้ตลอดเวลา ไคลเอ็นต์ที่ใช้คีย์นั้นจะสูญเสียการเข้าถึงทันที

โทเค็นจะถูกจัดเก็บเป็นแฮช SHA-256 (ไม่เคยเป็นข้อความธรรมดา) ทนทานต่อการรีสตาร์ทแผงควบคุม และมีอายุยืนยาวกว่าเซิร์ฟเวอร์ที่ถูกจำกัดขอบเขต (เซิร์ฟเวอร์ที่ถูกลบจะถูกลบออกจากผลลัพธ์ของโทเค็นนั้น)

## การยืนยันตัวตน

ส่งโทเค็นเป็นข้อมูลรับรอง Bearer:

```
Authorization: Bearer msm_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

ไม่มีคุกกี้และ **ไม่มี CORS**: นี่สำหรับผู้เรียกเซิร์ฟเวอร์ต่อเซิร์ฟเวอร์และ CLI ไม่ใช่แอปเบราว์เซอร์จากต้นทางอื่น หากแผงควบคุมอยู่เบื้องหลังพร็อกซีผกผัน ตรวจสอบให้แน่ใจว่าพร็อกซีส่งต่อส่วนหัว `Authorization`

ความล้มเหลวจะส่งคืน `401` พร้อมกับ `{ "ok": false, "error": "..." }` สิ่งอื่นนอกเหนือจาก `GET` (หรือ `HEAD`) จะส่งคืน `405` เส้นทางที่ไม่รู้จักจะส่งคืน `404` เมื่อ API ถูกปิดใช้งาน ทุกเส้นทางจะส่งคืน `404`

## การจำกัดอัตรา

แต่ละโทเค็นจะได้รับงบประมาณของตนเอง `RATE_LIMIT_PUBLIC_API_PER_MIN` (ค่าเริ่มต้น `120` คำขอ/นาที; `0` ปิดใช้งานตัวจำกัด) เกินขีดจำกัดจะส่งคืน `429` คำขอที่ไม่เคยแสดงโทเค็นที่ถูกต้อง (ขาดหายไป ผิดรูปแบบ ถูกเพิกถอน หรือหมดอายุ) จะถูกจำกัดแยกต่างหากต่อ IP ไคลเอ็นต์ที่ห้าเท่าของจำนวนนั้น ดังนั้นการสอดแนมจึงไม่สามารถหลีกเลี่ยงงบประมาณได้ด้วยการหมุนเวียนโทเค็น

## Endpoint

### `GET /api/v1/servers`

เซิร์ฟเวอร์ทุกเครื่องที่โทเค็นถูกจำกัดขอบเขต

```json
{
  "ok": true,
  "total": 1,
  "online": 1,
  "servers": [
    {
      "id": "srv_ab12cd34",
      "name": "SMP",
      "type": "PAPER",
      "state": "running",
      "cpuPct": 18.4,
      "memoryMb": 2048,
      "memoryLimitMb": 4096,
      "uptimeSeconds": 11722,
      "players": { "online": 3, "max": 20 }
    }
  ]
}
```

### `GET /api/v1/servers/:id`

เซิร์ฟเวอร์หนึ่งเครื่อง วัตถุเดียวกันภายใต้คีย์ `server` ส่งคืน `404` สำหรับ id ที่ไม่รู้จัก **และ** สำหรับเซิร์ฟเวอร์ที่โทเค็นไม่ได้ถูกจำกัดขอบเขต (ไม่มีแหล่งข้อมูลการมีอยู่) และ `400` สำหรับ id ที่ผิดรูปแบบ

## ฟิลด์การตอบกลับ

| ฟิลด์           | ความหมาย                                                                               |
| --------------- | -------------------------------------------------------------------------------------- |
| `total`         | จำนวนเซิร์ฟเวอร์ที่มองเห็นได้โดยโทเค็นนี้ (หลังจากการกรองขอบเขต)                       |
| `online`        | จำนวนของเซิร์ฟเวอร์เหล่านั้นอยู่ในสถานะ: `running`                                     |
| `id`            | id เซิร์ฟเวอร์ที่เสถียร (`srv_...`)                                                    |
| `name`          | ชื่อที่แสดง                                                                            |
| `type`          | ประเภทเซิร์ฟเวอร์ itzg (`PAPER`, `FABRIC`, `AUTO_CURSEFORGE`, ...)                     |
| `state`         | `running`, `starting`, `stopped`, หรือ `crashed` - สรุปสถานะภายในของแผงควบคุมที่เสถียร |
| `cpuPct`        | CPU % ล่าสุด หรือ `null` เมื่อเซิร์ฟเวอร์ไม่ทำงาน                                      |
| `memoryMb`      | หน่วยความจำที่ใช้งานจริงในหน่วย MB หรือ `null`                                         |
| `memoryLimitMb` | ขีดจำกัดหน่วยความจำคอนเทนเนอร์ที่กำหนดค่าไว้ในหน่วย MB หรือ `null`                     |
| `uptimeSeconds` | วินาทีตั้งแต่คอนเทนเนอร์เริ่มทำงาน หรือ `null`                                         |
| `players`       | `{ online, max }` หรือ `null` จนกว่าเซิร์ฟเวอร์จะรายงานรายการผู้เล่น                   |

## ตัวอย่าง

```sh
curl -s https://panel.example.com/api/v1/servers \
  -H "Authorization: Bearer $MSM_TOKEN" | jq
```
