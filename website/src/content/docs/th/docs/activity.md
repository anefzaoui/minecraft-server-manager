หน้า **Activity** คือบันทึกการตรวจสอบฉบับสมบูรณ์: บันทึกตามลำดับเวลาที่สามารถค้นหาได้ของทุกสิ่งที่เกิดขึ้นในแผงควบคุม กรองตามเซิร์ฟเวอร์หรือตามประเภทเหตุการณ์ ค้นหาสรุป และส่งออกสิ่งที่กรองแล้วเป็น CSV หรือ JSON รายการที่บันทึกเหตุการณ์ (เช่น การขัดข้อง) จะเปิดขึ้นมาในตำแหน่งนั้น

![Activity](/docs/images/activity.png)

## สิ่งที่ถูกบันทึก

- **การยืนยันตัวตน**: การลงชื่อเข้าใช้ (รวมถึงการใช้ 2FA หรือรหัสสำรองหรือไม่), การล็อกบัญชี, การเปลี่ยนรหัสผ่าน, และการเปิดใช้งาน, ปิดใช้งาน, หรือรีเซ็ต 2FA
- **วงจรชีวิตเซิร์ฟเวอร์**: การสร้าง, เริ่ม, หยุด, รีสตาร์ท, การขัดข้อง, การรีสตาร์ทอัตโนมัติ, และเหตุการณ์หน่วยความจำไม่พอ
- **การแจ้งเตือน**: การบูตที่ค้าง, ความล้มเหลวในการหยุด, กำหนดการที่ล้มเหลว, การหยุดเนื่องจากโควต้า, คอนเทนเนอร์ที่ไม่สมบูรณ์, การออฟไลน์หลังรีสตาร์ท
- **ข้อมูล**: การสำรองข้อมูลที่สร้างและกู้คืน, บลูพริ้นท์ที่ส่งออก, การติดตั้งและอัปเกรดแพ็ค, การเปลี่ยนแปลงม็อดและเวิลด์, และการแก้ไขไฟล์
- **ผู้เล่น**: การเตะ, การแบน, การเปลี่ยนแปลงรายการที่อนุญาตและผู้ดูแล, และบันทึกของผู้เล่น
- **การกำหนดค่า**: การเปลี่ยนแปลงคำสั่งแชท, การเปลี่ยนแปลงผู้ใช้และบทบาท, การเปลี่ยนแปลงสิทธิ์ต่อเซิร์ฟเวอร์, การเปลี่ยนแปลงพอร์ตเกม, และการแก้ไขการตั้งค่า

แต่ละรายการจะบันทึกว่าใครเป็นผู้ดำเนินการ (ชื่อผู้ใช้ หรือแผงควบคุม/ตัวตั้งเวลาสำหรับดำเนินการอัตโนมัติ), เซิร์ฟเวอร์ที่เกี่ยวข้อง, และเวลา [แดชบอร์ด](/docs/dashboard/) แสดงรายการล่าสุด หน้าเว็บนี้คือประวัติทั้งหมด ผู้ดูแลระบบและผู้ดูจะเห็นเฉพาะรายการสำหรับเซิร์ฟเวอร์ที่พวกเขาสามารถดูได้ (รวมถึงรายการทั่วทั้งแผง) และการเปลี่ยนแปลงสิทธิ์ต่อเซิร์ฟเวอร์จะแสดงให้ผู้ดูแลระบบเท่านั้น เหตุการณ์วงจรชีวิตและการแจ้งเตือนยังสามารถส่งต่อไปยัง Discord ได้ (ดู [การผสานรวม](/docs/integrations/))

เนื่องจากบันทึกนี้จับเหตุการณ์ที่เกี่ยวข้องกับความปลอดภัย (การเข้าสู่ระบบ, การเปลี่ยนแปลง 2FA, การเปลี่ยนแปลงบทบาทและสิทธิ์) บันทึกกิจกรรมจึงเป็นจุดแรกที่คุณควรตรวจสอบหากมีสิ่งผิดปกติกับบัญชี
