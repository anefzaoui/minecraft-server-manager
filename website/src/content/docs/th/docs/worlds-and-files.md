## Worlds

หน้า **Worlds** จัดการข้อมูลโลกของเซิร์ฟเวอร์ทั้งหมดของคุณ: สลับโลกที่ใช้งานอยู่, อัปโหลดโลก, หรือดาวน์โหลดโลก

![Worlds](/docs/images/worlds.png)

## ตัวจัดการไฟล์

ภายใต้ส่วน **World** ของเซิร์ฟเวอร์ แท็บ **Files** คือตัวจัดการไฟล์แบบเต็มในเบราว์เซอร์สำหรับไดเรกทอรีข้อมูลของเซิร์ฟเวอร์นั้น แสดงรายการ, อ่าน, แก้ไข, สร้าง, เปลี่ยนชื่อ, ย้าย, คัดลอก, ลบ, และอัปโหลดไฟล์: ทุกอย่างที่คุณทำผ่าน SSH ได้ตามปกติ จากเบราว์เซอร์

![File manager](/docs/images/server-files.png)

ไฟล์ข้อความจะเปิดในโปรแกรมแก้ไขที่มีขีดจำกัด 2 MB; ไฟล์ที่ใหญ่กว่าสามารถดาวน์โหลดได้ การอัปโหลดรองรับหลายไฟล์พร้อมกัน

### อยู่ภายใน Sandbox

การดำเนินการไฟล์ทั้งหมดจะจำกัดอยู่ภายในไดเรกทอรีข้อมูลของเซิร์ฟเวอร์เอง แผงควบคุมจะแก้ไขเส้นทางแต่ละเส้นทางและปฏิเสธทุกอย่างที่จะหลุดออกไป: การข้าม `..`, เส้นทางสัมบูรณ์, และแม้แต่ symlinks ที่ชี้ออกนอกไดเรกทอรี (รวมถึงอันที่ค้างอยู่ซึ่งยังไม่มีอยู่) ม็อดหรือปลั๊กอินไม่สามารถสร้างลิงก์เพื่อหลอกตัวจัดการไฟล์ให้อ่านหรือเขียนที่อื่นบนโฮสต์ได้

## Mods

สำหรับเซิร์ฟเวอร์ที่ลงม็อด แท็บ **Mods** (กลุ่มของตัวเองในแถบด้านข้างของเซิร์ฟเวอร์) จัดการชุดม็อด: เรียกดูและเพิ่มม็อด และดูว่ามีอะไรติดตั้งอยู่บ้าง การอัปเดตม็อดและแพ็คจะแสดงในหน้า [Updates](/docs/updates/)

### การเพิ่มม็อด

![Mods](/docs/images/mods.png)

สี่วิธีในการเพิ่ม ทั้งหมดจากแถบเครื่องมือแท็บ Mods:

- **Search mods** - ค้นหา **Modrinth หรือ CurseForge** (ปุ่ม CurseForge จะปรากฏขึ้นเมื่อเก็บ API key ไว้ใน Settings → API keys) และบนเซิร์ฟเวอร์ปลั๊กอิน ยังมี **Hangar** (รีจิสทรีปลั๊กอินของ PaperMC เอง) และ **SpigotMC** (ผ่านพร็อกซี CDN ของ Spiget) - ทั้งสองอย่างนี้ไม่ต้องใช้คีย์ ทุกอย่างจะถูกกรองตาม loader และเวอร์ชัน Minecraft ของเซิร์ฟเวอร์; เซิร์ฟเวอร์ Quilt จะเห็น build ที่ติดแท็ก fabric โดยอัตโนมัติด้วย เนื่องจาก Quilt รันม็อด fabric ผลลัพธ์ที่มีอยู่แล้วบนเซิร์ฟเวอร์จะแสดงป้าย **Installed** หากผู้เขียน CurseForge ไม่อนุญาตให้ดาวน์โหลดอัตโนมัติ - หรือทรัพยากร SpigotMC โฮสต์อยู่นอกเว็บไซต์ - แผงควบคุมจะแจ้งให้ทราบล่วงหน้าและเสนอเส้นทาง **Open page** + **Upload jar** แทนที่จะล้มเหลวระหว่างการติดตั้ง

  ![Hangar search](/docs/images/mods-search-hangar.png)

- **Import zip** - ปุ่มเดียว, สามรูปแบบ, ตรวจจับอัตโนมัติ:
  - **Modrinth modpack (`.mrpack`)**: ไฟล์ที่ปักหมุดทั้งหมดจะถูกทำให้เป็นมาตรฐานกลับไปยังโปรเจกต์ Modrinth เดิมผ่านการค้นหา hash (ดังนั้นม็อดที่นำเข้าจะคงชื่อจริง ไอคอน และยังคงตรวจสอบการอัปเดตได้; ไฟล์ที่ Modrinth ไม่รู้จักจะติดตั้งจาก URL ของแพ็คเอง) ตรวจสอบกับ checksum sha512 ของแพ็คขณะดาวน์โหลด และแสดงตัวอย่างพร้อมผลการตรวจสอบ Client-only files จะถูกข้ามไปอย่างชัดเจน และทั้งสอง override trees (`overrides/`, จากนั้น `server-overrides/` - สำเนาเฉพาะเซิร์ฟเวอร์จะชนะ) สามารถนำไปใช้ได้

    ![mrpack import](/docs/images/mrpack-import.png)

  - **CurseForge modpack export** (zip ที่แอป CurseForge สร้างขึ้น พร้อม `manifest.json`): ม็อดที่ปักหมุดทั้งหมดจะถูกแก้ไขเป็นชุด แสดงตัวอย่างพร้อมคำเตือน (loader/MC ผิดสำหรับเซิร์ฟเวอร์นี้, ไฟล์ไม่อยู่บน CurseForge แล้ว, ม็อดที่ต้องดาวน์โหลดด้วยตนเอง) และติดตั้งพร้อมความคืบหน้าที่แท้จริง `overrides/` ของแพ็ค (configs, scripts) สามารถนำไปใช้ได้เช่นกัน - ไฟล์ใดๆ ที่จะถูกเขียนทับจะถูกสำรองข้อมูลก่อนเข้าสู่ `.import-backups/<timestamp>/` ภายในโฟลเดอร์เซิร์ฟเวอร์
  - **plain zip of jars** ที่คุณรวบรวมเอง: jar แต่ละอันจะถูกระบุ (ตรงกับ Modrinth hash → ลายนิ้วมือ CurseForge → metadata ของ jar เอง) และประเมินเทียบกับเซิร์ฟเวอร์ - _พอดี / loader ผิด / MC version ผิด / ติดตั้งแล้ว / ไม่ระบุตัวตน_ - ดังนั้นคุณจึงเลือกสิ่งที่ถูกต้องก่อนที่จะติดตั้งอะไรก็ตาม
- **Add by link** - วางอะไรก็ได้: หน้าโปรเจกต์ Modrinth, CurseForge, Hangar, หรือ SpigotMC, URL ของ GitHub repo หรือ release (แค่ `owner/repo` ก็ใช้ได้ - การติดตั้ง GitHub จะเลือกใช้ release เสถียรล่าสุดและข้ามไฟล์ sidecar `-sources`/`-javadoc`) slug ของ Modrinth เปล่าๆ, หรือ URL `.jar` โดยตรงใดๆ แผงควบคุมจะแก้ไข build ที่ถูกต้องสำหรับ loader และเวอร์ชัน MC ของเซิร์ฟเวอร์

  ![Add by link](/docs/images/mods-add-by-link.png)

- **Upload jar** (จาก fallback การค้นหาหรือตัวแก้ไขการดาวน์โหลดที่รอดำเนินการ) - jar ที่อัปโหลดจะถูกระบุด้วยวิธีเดียวกัน ดังนั้นจึงคงชื่อจริง เวอร์ชัน ไอคอน และสามารถตรวจสอบการอัปเดตได้

การติดตั้งรีจิสทรีทุกครั้งจะ **ตรวจสอบ checksum ขณะดาวน์โหลด**: สตรีมจะถูกตรวจสอบกับ digest ที่แข็งแกร่งที่สุดที่รีจิสทรีเผยแพร่ (sha512 → sha256 → sha1 → md5) และการไม่ตรงกันจะยกเลิกก่อนที่สิ่งใดจะถูกบันทึกลงบนเซิร์ฟเวอร์

ทั้ง zip (`.mrpack` รวมอยู่ด้วย) สามารถ **สร้างเซิร์ฟเวอร์ได้**: ในแท็บ _From modpack_ ของวิซาร์ด อัปโหลดแล้ว manifest ของแพ็ค (หรือการโหวตส่วนใหญ่จาก jar ที่ระบุ) จะเติม loader, เวอร์ชัน Minecraft, และ build ของ loader
