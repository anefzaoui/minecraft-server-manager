แผงควบคุมแบบโฮสต์เองที่สมบูรณ์สำหรับ [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server) สร้าง รัน และจัดการเซิร์ฟเวอร์ Minecraft จากเบราว์เซอร์ของคุณ ไม่ต้องใช้บรรทัดคำสั่ง ไม่ต้องแก้ไข YAML ด้วยตนเอง

![แดชบอร์ด](/docs/images/dashboard.png)

## เริ่มต้นที่นี่

- **[เริ่มต้นใช้งาน](/docs/getting-started/)** - การตั้งค่าครั้งแรก การเข้าสู่ระบบ และการทำความคุ้นเคย
- **[แดชบอร์ด](/docs/dashboard/)** - ภาพรวมของเซิร์ฟเวอร์ ผู้เล่น และกิจกรรมทั้งหมด

## การรันเซิร์ฟเวอร์

- **[การสร้างและจัดการเซิร์ฟเวอร์](/docs/servers/)** - ตัวช่วยสร้างการสร้าง ประเภทเซิร์ฟเวอร์ เวอร์ชัน และการตั้งค่าต่อเซิร์ฟเวอร์
- **[คอนโซลและคำสั่งแชท](/docs/console-and-chat/)** - คอนโซลสด และคำสั่งแชทในเกมแบบกำหนดเองที่ทำงานในฐานะผู้เล่น
- **[Modpacks](/docs/modpacks/)** - ติดตั้งแพ็ค CurseForge, Modrinth, FTB และ GT New Horizons โดยตรึงไว้กับเวอร์ชันที่แน่นอนเสมอ
- **[โลกและไฟล์](/docs/worlds-and-files/)** - สลับโลก จัดการม็อด และแก้ไขไฟล์โดยตรงในเบราว์เซอร์
- **[การย่อขนาดโลก](/docs/world-shrink/)** - เรียกคืนพื้นที่ดิสก์โดยการลบส่วนที่ไม่มีใครเข้าชม ด้วยตัวเองหรือเป็นส่วนหนึ่งของการสำรองข้อมูล
- **[แผนที่สด](/docs/live-map/)** - แผนที่ 3 มิติ BlueMap แบบคลิกเดียวของโลก อยู่เบื้องหลังการเข้าสู่ระบบของแผงควบคุม
- **[คำเชิญและหน้าสถานะ](/docs/invites-and-status-page/)** - ที่อยู่ ข้อความเชิญ และ modpack ไคลเอ็นต์สำหรับเพื่อน และหน้าสถานะสาธารณะ

## ข้อมูลและระบบอัตโนมัติ

- **[แชทบอทต่อเซิร์ฟเวอร์](/docs/chatbot/)** - การสนทนาในเครื่อง/ที่เข้ากันได้กับ OpenAI การเข้าถึง การเก็บรักษาบันทึกการสนทนา และการจำกัดอำนาจในการเล่นเกม
- **[การสำรองข้อมูล](/docs/backups/)** - การจับภาพหน้าจอด้วยคลิกเดียว การสำรองข้อมูลตามกำหนดเวลา จำนวนที่จะเก็บ (ทั่วทั้งแผงหรือต่อเซิร์ฟเวอร์) และการกู้คืน
- **[พิมพ์เขียว](/docs/blueprints/)** - บันทึกการกำหนดค่าทั้งหมดของเซิร์ฟเวอร์และสร้างเซิร์ฟเวอร์ใหม่จากนั้น
- **[กำหนดการ](/docs/schedules/)** - การรีสตาร์ท การสำรองข้อมูล และคำสั่งที่ขับเคลื่อนด้วย cron
- **[พื้นที่จัดเก็บข้อมูล](/docs/storage/)** - การใช้งานดิสก์ต่อเซิร์ฟเวอร์และโควต้าที่บังคับใช้โดยแผงควบคุม
- **[การอัปเดต](/docs/updates/)** - ติดตามเวอร์ชันเซิร์ฟเวอร์ แพ็ค อิมเมจ และม็อดใหม่ ตรวจสอบว่าม็อดของคุณรองรับเวอร์ชัน Minecraft ใดบ้าง และยกเลิกการอัปเดตม็อด
- **[บันทึกกิจกรรม](/docs/activity/)** - บันทึกการตรวจสอบของทุกสิ่งที่เกิดขึ้น
- **[การผสานรวม](/docs/integrations/)** - การแจ้งเตือน Discord webhook และหมวดหมู่การแจ้งเตือน
- **[API สาธารณะ](/docs/public-api/)** - API HTTP แบบอ่านอย่างเดียวที่รับรองความถูกต้องด้วยโทเค็น สำหรับการดึงสถานะเซิร์ฟเวอร์จากภายนอกแผงควบคุม

## บัญชีและการรักษาความปลอดภัย

- **[ผู้ใช้และบทบาท](/docs/users-and-roles/)** - ผู้ดูแลระบบ ผู้ดำเนินการ และผู้ดู สิ่งที่แต่ละคนสามารถทำได้ และสิทธิ์ต่อเซิร์ฟเวอร์ที่ปรับแต่งสิ่งเหล่านั้น
- **[การยืนยันตัวตนสองปัจจัย](/docs/two-factor-authentication/)** - ปกป้องการเข้าสู่ระบบของคุณด้วยแอปยืนยันตัวตน

## คู่มือ

ไม่เฉพาะเจาะจงกับแผงควบคุมนี้: คำถามที่เจ้าของเซิร์ฟเวอร์ Minecraft ทุกคนต้องเจอ

- **[เซิร์ฟเวอร์ต้องการ RAM เท่าใด?](/docs/guide-server-memory/)** - ตัวเลขสองตัวที่ต้องตั้งค่า และเหตุผลที่เซิร์ฟเวอร์ที่ไม่ได้ใช้งานอ่านค่าได้ 12 GB
- **[Vanilla, Paper, Fabric, Forge, NeoForge, Quilt](/docs/guide-choosing-a-loader/)** - ตัวเลือกที่จะรัน และความแตกต่างของปลั๊กอิน/ม็อดที่อยู่เบื้องหลังการเลือก
- **[เซิร์ฟเวอร์ของคุณจะไม่เริ่มทำงาน](/docs/guide-server-wont-start/)** - การอ่านบันทึก และสาเหตุเล็กน้อยที่อยู่เบื้องหลังความล้มเหลวส่วนใหญ่
- **[การสำรองข้อมูลที่กู้คืนได้จริง](/docs/guide-backups/)** - สำเนาที่สอดคล้องกัน สิ่งอื่นที่ต้องเก็บ และการทดสอบก่อนที่คุณจะต้องการ
- **[การย้ายเซิร์ฟเวอร์ไปยังโฮสต์อื่น](/docs/guide-moving-a-server/)** - ลำดับที่ทำให้เวลาหยุดทำงานสั้นและสินค้าคงคลังยังคงอยู่
