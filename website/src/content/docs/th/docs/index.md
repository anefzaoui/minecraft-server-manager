แผงควบคุมแบบครบวงจรที่โฮสต์เองได้สำหรับ [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server) สร้าง รัน และจัดการเซิร์ฟเวอร์ Minecraft จากเบราว์เซอร์ของคุณ ไม่ต้องใช้บรรทัดคำสั่ง ไม่ต้องแก้ไข YAML ด้วยตนเอง

![แดชบอร์ด](/docs/images/dashboard.png)

## เริ่มต้นที่นี่

- **[เริ่มต้นใช้งาน](/docs/getting-started/)** - การตั้งค่าครั้งแรก การลงชื่อเข้าใช้ และการทำความคุ้นเคยกับส่วนต่างๆ
- **[แดชบอร์ด](/docs/dashboard/)** - มุมมองภาพรวมของเซิร์ฟเวอร์ ผู้เล่น และกิจกรรมทั้งหมด

## การรันเซิร์ฟเวอร์

- **[การสร้างและจัดการเซิร์ฟเวอร์](/docs/servers/)** - ตัวช่วยสร้างการสร้าง ประเภทเซิร์ฟเวอร์ เวอร์ชัน และการตั้งค่าเฉพาะเซิร์ฟเวอร์
- **[คอนโซลและคำสั่งแชท](/docs/console-and-chat/)** - คอนโซลแบบเรียลไทม์ และคำสั่งแชทในเกมแบบกำหนดเองที่รันในฐานะผู้เล่น
- **[Modpacks](/docs/modpacks/)** - ติดตั้งแพ็ค CurseForge, Modrinth, FTB และ GT New Horizons โดยตรึงไว้กับเวอร์ชันที่แน่นอนเสมอ
- **[โลกและไฟล์](/docs/worlds-and-files/)** - สลับโลก จัดการม็อด และแก้ไขไฟล์โดยตรงในเบราว์เซอร์
- **[การย่อขนาดโลก](/docs/world-shrink/)** - เรียกคืนพื้นที่ดิสก์โดยการลบส่วนที่ไม่มีใครเข้าชม โดยแยกต่างหากหรือเป็นส่วนหนึ่งของการสำรองข้อมูล

## ข้อมูลและระบบอัตโนมัติ

- **[แชทบอทเฉพาะเซิร์ฟเวอร์](/docs/chatbot/)** - การสนทนาภายในเครื่อง/ที่เข้ากันได้กับ OpenAI การติดต่อสื่อสาร บันทึกการสนทนาที่เก็บไว้ และการจำกัดอำนาจในการเล่นเกม
- **[การสำรองข้อมูล](/docs/backups/)** - สแนปชอตในคลิกเดียว การสำรองข้อมูลตามกำหนดเวลา และการกู้คืน
- **[พิมพ์เขียว](/docs/blueprints/)** - จับภาพการกำหนดค่าทั้งหมดของเซิร์ฟเวอร์และสร้างเซิร์ฟเวอร์ใหม่จากนั้น
- **[กำหนดการ](/docs/schedules/)** - การรีสตาร์ท การสำรองข้อมูล และคำสั่งที่ขับเคลื่อนด้วย cron
- **[พื้นที่จัดเก็บข้อมูล](/docs/storage/)** - การใช้งานดิสก์เฉพาะเซิร์ฟเวอร์และโควต้าที่บังคับใช้โดยแผงควบคุม
- **[การอัปเดต](/docs/updates/)** - ติดตามเวอร์ชันใหม่ของเซิร์ฟเวอร์ แพ็ค อิมเมจ และม็อด
- **[บันทึกกิจกรรม](/docs/activity/)** - บันทึกการตรวจสอบของทุกสิ่งที่เกิดขึ้น
- **[การผสานรวม](/docs/integrations/)** - การแจ้งเตือน Discord webhook และหมวดหมู่การแจ้งเตือน
- **[API สาธารณะ](/docs/public-api/)** - API HTTP แบบอ่านอย่างเดียวที่รับรองความถูกต้องด้วยโทเค็น สำหรับการดึงสถานะเซิร์ฟเวอร์จากภายนอกแผงควบคุม

## บัญชีและความปลอดภัย

- **[ผู้ใช้และบทบาท](/docs/users-and-roles/)** - ผู้ดูแลระบบ ผู้ดำเนินการ และผู้ดู และสิ่งที่แต่ละคนสามารถทำได้
- **[การยืนยันตัวตนสองปัจจัย](/docs/two-factor-authentication/)** - ปกป้องการเข้าสู่ระบบของคุณด้วยแอปยืนยันตัวตน

## เบื้องหลัง

- **[สถาปัตยกรรม](/docs/architecture/)** - วิธีการประกอบแผงควบคุม
- **[เว็บไซต์](/docs/website/)** - วิธีการสร้าง แปล และปรับใช้ minecraft-server-manager.com จากคลังเก็บนี้
