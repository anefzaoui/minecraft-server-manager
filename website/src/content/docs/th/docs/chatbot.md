แผงควบคุมมีแชทบอทที่ผู้ดูแลระบบกำหนดค่าสำหรับเซิร์ฟเวอร์ Minecraft แต่ละเซิร์ฟเวอร์ที่จัดการ โดยตั้งค่าในแท็บ **การตั้งค่า → แชทบอท** ของเซิร์ฟเวอร์ เชื่อมต่อกับจุดสิ้นสุดการสนทนาที่เข้ากันได้กับ OpenAI รวมถึง Ollama บนโฮสต์ LAN อื่น แต่ละเซิร์ฟเวอร์มีจุดสิ้นสุด โมเดล ชื่อการเรียกใช้ บุคลิก นโยบายการถอดความ ข้อความแจ้ง และนโยบายพลังงานของตัวเอง การเรียกใช้เริ่มต้นคือ `@wizard` และบุคลิกเริ่มต้นแสดงถึงพ่อมดโบราณที่ขี้เล่นในเกม ทั้งสองอย่างนี้สามารถแก้ไขได้

![การตั้งค่าแชทบอท](/docs/images/integrations-chatbot.png)

## ประสบการณ์ผู้เล่น

- ผู้เล่นทุกคนสามารถใช้ `@wizard <ข้อความ>` (หรือชื่อที่กำหนดค่าไว้) เพื่อสนทนาและขอความช่วยเหลือเกี่ยวกับสูตรอาหารแบบวานิลลาที่คำนึงถึงเวอร์ชัน Minecraft และมีความแน่นอน
- การทักทายเมื่อเข้าร่วมและข้อความแจ้งการตรวจสอบการเล่นแบบครั้งเดียวที่กำหนดค่าได้จะเตือนผู้เล่นว่ามีแชทบอทอยู่ `@wizard chat` จะเปิดหน้าต่างสนทนาแบบเลือกเข้าร่วมสั้นๆ `@wizard bye` จะปิดหน้าต่างนั้น
- **ผู้ใช้ทั่วไป** สามารถเรียกใช้พลังงานตนเอง/โลกที่เปิดใช้งาน **ผู้ควบคุมพลังงาน** สามารถเรียกใช้การดำเนินการที่ตรวจสอบแล้วแยกต่างหากซึ่งส่งผลกระทบต่อผู้เล่นออนไลน์คนอื่น ผู้เล่นที่ไม่อยู่ในกลุ่มใดกลุ่มหนึ่งจะยังคงสนทนาได้อย่างเดียว
- การให้ไอเทมแก่ตนเองของผู้ใช้ทั่วไปจะใช้รายการที่อนุญาต ผู้ควบคุมสามารถให้ไอเทมวานิลลาหรือไอเทมที่ปรับแต่งแล้วที่ถูกต้องแก่ผู้เล่นคนอื่น โดยขึ้นอยู่กับขีดจำกัดปริมาณและมาตรการรักษาความปลอดภัยอื่นๆ

![การถอดความแชทบอท](/docs/images/chatbot-transcripts.png)

## การออกแบบและความปลอดภัย

การกำหนดค่าและการถอดความมีไว้สำหรับผู้ดูแลระบบเท่านั้น โมเดลจะไม่ได้รับ RCON ดิบหรือการดำเนินการคำสั่งตามอำเภอใจ ข้อความจะเปิดเผยเฉพาะเครื่องมือคงที่เดียวที่ตรงกับเจตนาที่ชัดเจนเท่านั้น โค้ดเซิร์ฟเวอร์จะตรวจสอบสิทธิ์ อาร์กิวเมนต์ แฟล็ก ปริมาณ การจำกัดเวลา และชื่อผู้เล่นออนไลน์ที่แน่นอนก่อนที่จะดำเนินการตามการดำเนินการบริการที่มีอยู่ ตัวเลือก Minecraft จะถูกปฏิเสธ การดำเนินการข้ามผู้เล่นไม่สามารถกำหนดเป้าหมายผู้เรียกได้ พลังงานจะเริ่มต้นในโหมดทดลอง และพลังงานที่พยายามทุกครั้งจะถูกตรวจสอบ โมเดลการเรียกใช้เครื่องมือที่ไม่รองรับจะกลับไปเป็นการสนทนาเท่านั้น

การตอบกลับจะถูกจำกัดสำหรับแชท Minecraft สูตรอาหารแบบวานิลลาที่รู้จักมาจากข้อมูลสูตรอาหารเวอร์ชันที่รวมมา และแสดงผลเป็นแถว 2x2/3x3 ที่เสถียร LLM จะไม่ได้รับความไว้วางใจในการสร้างเลย์เอาต์สูตรอาหาร สูตรอาหารที่ไม่รู้จักหรือที่ปรับแต่งแล้วจะนำผู้เล่นไปยัง JEI/REI แทนที่จะสร้างคำตอบขึ้นมา

## ไฟล์การใช้งานหลัก

- `src/services/wizard.js`: การกำหนดค่าต่อเซิร์ฟเวอร์, คำขอที่เข้ากันได้กับ OpenAI, การจัดการแชท, การแจ้งเตือน, การเก็บรักษาการถอดความ และขีดจำกัดการตอบกลับ
- `src/services/wizardPowers.js`: การตรวจสอบสิทธิ์, สคีมาเครื่องมือเฉพาะเจตนา, การตรวจสอบความถูกต้อง, การดำเนินการ, การจำกัดเวลา และการตรวจสอบพลังงาน
- `src/services/wizardRecipes.js`: การค้นหาและจัดรูปแบบกริดสูตรอาหารเวอร์ชันที่แน่นอน ข้อมูลสูตรอาหารและไอเทมมาจากแพ็คเกจ [`minecraft-data`](https://github.com/PrismarineJS/minecraft-data) ที่รวมมา (ร่างก่อนหน้านี้ของเอกสารนี้ชี้ไปยังโฟลเดอร์ `src/data/recipes/` ที่ไม่เคยถูกคอมมิต ไม่มีโฟลเดอร์ดังกล่าว และข้อมูลอยู่ในแพ็คเกจ ดู "ขนาดของส่วนประกอบ")
- `src/analytics/ingest.js`: ส่งต่อการเข้าร่วม การออกจากระบบ และการแชทของผู้เล่นที่แยกวิเคราะห์ไปยังแชทบอท
- `src/web/routes/wizard.js`, `public/js/pages/integrations.js`, และ `views/partials/server/integrations.hbs` (ผ่าน `chatbot.hbs`): API ผู้ดูแลระบบและแท็บ การตั้งค่า → แชทบอท ต่อเซิร์ฟเวอร์
- `src/db/migrations/011_wizard_chat.js`, `013_wizard_invocation_name.js`, `015_wizard_powers.js`, `017_wizard_outreach.js`, และ `019_wizard_power_controllers.js`: สคีมาถาวร
- `test/wizard.test.js`: การทดสอบสิทธิ์, ขอบเขตเครื่องมือ, การเก็บรักษา, การแจ้งเตือน และพฤติกรรมการแชท

ชื่อเส้นทาง/โมดูล/ตาราง `wizard` ภายในจะยังคงไว้เพื่อความเข้ากันได้ในการอัปเกรดและ API "chatbot" เป็นคำศัพท์ผลิตภัณฑ์ที่ผู้ใช้เห็น ในทำนองเดียวกัน ฟิลด์ `power_testers_json` ที่จัดเก็บไว้จะแมปกับกลุ่ม **ผู้ใช้ทั่วไป** ใน UI

## ขนาดของส่วนประกอบ (`minecraft-data`)

ความช่วยเหลือเกี่ยวกับสูตรอาหารใช้แพ็คเกจ `minecraft-data` มีขนาดใหญ่บนดิสก์ (ประมาณ 429 MB เมื่อติดตั้ง) และรวมอยู่ในอิมเมจการผลิตเนื่องจากเป็นส่วนประกอบที่ต้องใช้ขณะรันไทม์ ไม่ใช่ส่วนประกอบสำหรับการพัฒนา เราเก็บไว้โดยเจตนาเพื่อให้ความช่วยเหลือเกี่ยวกับสูตรอาหารทำงานแบบออฟไลน์สำหรับ Minecraft ทุกเวอร์ชันโดยไม่ต้องเรียกเครือข่าย

หมายเหตุสำหรับผู้ที่จะดูสิ่งนี้ต่อไป (มนุษย์หรือ AI) เพื่อให้ขนาดไม่น่าประหลาดใจ:

- ขณะนี้ใช้เฉพาะข้อมูล Java (`pc`) เท่านั้น `wizardRecipes.js` อ่าน `minecraftData.versions.pc` และตาราง `recipes`, `items`, และ `blocks` ของแต่ละเวอร์ชัน ไฟล์ที่สัมผัสจริงรวมกันประมาณ 15 MB ในทุกเวอร์ชัน pc
- ประมาณ 330 MB ของแพ็คเกจคือ `data/bedrock` และไม่มีส่วนใดที่อ่านข้อมูลนี้ในขณะนี้ เราปล่อยทิ้งไว้โดยเจตนา หากแผงควบคุมเพิ่มการรองรับ Bedrock Minecraft ในอนาคต ข้อมูลสูตรอาหารและไอเทมของ Bedrock จะอยู่ที่นี่แล้ว ดังนั้นฟีเจอร์สูตรอาหารจึงสามารถขยายครอบคลุมเซิร์ฟเวอร์ Bedrock ได้โดยไม่ต้องเพิ่มส่วนประกอบใหม่ เริ่มต้นจาก `minecraftData.versions.bedrock` และทำตามรูปแบบเดียวกับเส้นทาง pc
- หากขนาดต้องลดลงก่อนที่จะรองรับ Bedrock จะมีรูปแบบสำหรับสิ่งนั้นในที่เก็บนี้อยู่แล้ว `src/services/itemRegistry.js` ดึงไฟล์ `minecraft-data` จาก jsDelivr CDN เมื่อต้องการและแคชไว้ใน `api_cache` วิธีการนั้น หรือชุดย่อย `src/data/recipes/` ขนาดเล็กที่เลือกสรรมาอย่างดีซึ่งครอบคลุมไม่กี่เวอร์ชันที่พบบ่อย จะช่วยลดขนาดอิมเมจได้อย่างมาก

## ที่เก็บข้อมูลภายในและตรวจสอบด้วยตนเอง

การตั้งค่าและการถอดความที่เก็บไว้ทั้งหมดอยู่ในฐานข้อมูล SQLite ของแผงควบคุมที่ `/data/panel.db` ภายในคอนเทนเนอร์แผงควบคุม ด้วยการเมานต์ Compose มาตรฐาน เส้นทางโฮสต์คือ `${DATA_DIR_HOST}/panel.db` (เช่น `/opt/msm/data/panel.db`) ตารางที่เกี่ยวข้องคือ `wizard_configs`, `wizard_transcripts`, และ `wizard_outreach` การตรวจสอบพลังงานคือแถวในตาราง `events` ที่มีประเภท `wizard-power` คีย์ API LLM ที่เลือกได้จะถูกเข้ารหัส AES-256-GCM ด้วยคีย์ที่พักของแผงควบคุม `.secret-key` ในโฟลเดอร์ข้อมูล (แยกจาก `SESSION_SECRET`)

สำรองข้อมูลฐานข้อมูลและหยุดแผงควบคุมก่อนทำการแก้ไข SQLite โดยตรง เพื่อให้ WAL ได้รับการจัดการอย่างปลอดภัย การใช้ UI/API ของผู้ดูแลระบบเป็นที่ต้องการเนื่องจากมีการตรวจสอบความถูกต้องและการเข้ารหัส ให้เก็บไฟล์ `panel.db`, `panel.db-wal`, และ `panel.db-shm` ไว้ด้วยกันเมื่อคัดลอกฐานข้อมูลสด
