[← กลับไปยังสารบัญเอกสาร](/docs/)

Fork นี้เพิ่มแชทบอทที่ผู้ดูแลระบบกำหนดค่าไว้ในแต่ละเซิร์ฟเวอร์ Minecraft ที่จัดการอยู่ โดยเชื่อมต่อกับ
จุดปลายการสนทนาที่เข้ากันได้กับ OpenAI รวมถึง Ollama บนโฮสต์ LAN อื่น แต่ละเซิร์ฟเวอร์มี
จุดปลาย, โมเดล, ชื่อการเรียกใช้, บุคลิก, นโยบายการถอดความ, ข้อความแจ้งเตือน และนโยบายพลังงานของตัวเอง การเรียกใช้เริ่มต้นคือ `@wizard` และบุคลิกเริ่มต้นคือพ่อมดโบราณที่ขี้เล่นในเกม ทั้งสองอย่างนี้สามารถแก้ไขได้

![การตั้งค่าแชทบอท](/docs/images/integrations-chatbot.png)

## ประสบการณ์ผู้เล่น

- ผู้เล่นทุกคนสามารถใช้ `@wizard <ข้อความ>` (หรือชื่อการเรียกใช้ที่กำหนดค่าไว้) เพื่อสนทนาและ
  ขอความช่วยเหลือเกี่ยวกับสูตรอาหาร vanilla ที่คำนึงถึงเวอร์ชัน Minecraft และมีความแน่นอน
- การทักทายเมื่อเข้าร่วมและข้อความแจ้งเตือนแบบครั้งเดียวที่กำหนดค่าได้จะเตือนผู้เล่นว่ามีแชทบอทอยู่ `@wizard chat` จะเปิดหน้าต่างสนทนาแบบเลือกเข้าร่วมสั้นๆ; `@wizard bye` จะปิดหน้าต่างนั้น
- **ผู้ใช้ทั่วไป** สามารถเรียกใช้พลังงานตนเอง/โลกที่เปิดใช้งานได้ **ผู้ควบคุมพลังงาน** สามารถเรียกใช้การดำเนินการที่ตรวจสอบแล้วแยกต่างหากซึ่งส่งผลกระทบต่อผู้เล่นออนไลน์คนอื่น ผู้เล่นที่ไม่อยู่ในกลุ่มใดเลยจะยังคง
  สนทนาได้อย่างเดียว
- การให้ไอเทมแก่ตนเองของผู้ใช้ทั่วไปจะใช้รายการที่อนุญาต ผู้ควบคุมสามารถให้ไอเทม vanilla หรือ modded ที่มีชื่อเนมสเปซที่ถูกต้องแก่ผู้เล่นคนอื่นได้ โดยขึ้นอยู่กับขีดจำกัดปริมาณและมาตรการป้องกันพลังงานอื่นๆ

![การถอดความแชทบอท](/docs/images/chatbot-transcripts.png)

## การออกแบบและความปลอดภัย

การกำหนดค่าและการถอดความมีไว้สำหรับผู้ดูแลระบบเท่านั้น โมเดลจะไม่ได้รับ RCON ดิบหรือการดำเนินการคำสั่งตามอำเภอใจ ข้อความจะเปิดเผยเฉพาะเครื่องมือคงที่เดียวที่ตรงกับเจตนาที่ชัดเจนเท่านั้น เซิร์ฟเวอร์จะตรวจสอบสิทธิ์ อาร์กิวเมนต์ แฟล็ก ปริมาณ คูลดาวน์ และชื่อผู้เล่นออนไลน์ที่แน่นอนก่อนดำเนินการตามการดำเนินการบริการที่มีอยู่ ตัวเลือก Minecraft จะถูกปฏิเสธ การดำเนินการข้ามผู้เล่นไม่สามารถกำหนดเป้าหมายผู้เรียกได้ พลังงานจะเริ่มต้นในโหมดทดลอง และพลังงานที่พยายามทุกครั้งจะถูกตรวจสอบ โมเดลการเรียกเครื่องมือที่ไม่รองรับจะกลับไปเป็นการสนทนาเท่านั้น

การตอบกลับจะถูกจำกัดสำหรับแชท Minecraft สูตรอาหาร vanilla ที่รู้จักมาจากข้อมูลสูตรอาหารเวอร์ชันที่รวมอยู่ด้วย และจะแสดงเป็นแถว 2x2/3x3 ที่เสถียร LLM จะไม่ได้รับความไว้วางใจในการสร้างเลย์เอาต์สูตรอาหาร สูตรอาหารที่ไม่รู้จักหรือ modded จะนำผู้เล่นไปยัง JEI/REI แทนที่จะสร้างคำตอบขึ้นมา

## ไฟล์การใช้งานหลัก

- `src/services/wizard.js`: การกำหนดค่าต่อเซิร์ฟเวอร์, คำขอที่เข้ากันได้กับ OpenAI, การจัดการแชท, การแจ้งเตือน, การเก็บรักษาการถอดความ และขีดจำกัดการตอบกลับ
- `src/services/wizardPowers.js`: การตรวจสอบบทบาท, สคีมาเครื่องมือเฉพาะเจตนา, การตรวจสอบความถูกต้อง, การดำเนินการ, คูลดาวน์ และการตรวจสอบพลังงาน
- `src/services/wizardRecipes.js`: การค้นหาสูตรอาหารเวอร์ชันที่แน่นอนและการจัดรูปแบบตาราง ข้อมูลสูตรอาหารและไอเทมมาจากแพ็กเกจ [`minecraft-data`](https://github.com/PrismarineJS/minecraft-data) ที่รวมอยู่ด้วย (ร่างก่อนหน้านี้ของเอกสารนี้ชี้ไปยังโฟลเดอร์ `src/data/recipes/` ที่ไม่เคยถูกคอมมิต ไม่มีโฟลเดอร์ดังกล่าว และข้อมูลอยู่ในแพ็กเกจ ดู "ขนาดของทรัพยากรที่ต้องพึ่งพา")
- `src/analytics/ingest.js`: ส่งต่อการเข้าร่วม, การออกจากระบบ และแชทผู้เล่นที่แยกวิเคราะห์ไปยังแชทบอท
- `src/web/routes/wizard.js`, `public/js/pages/integrations.js`, และ
  `views/partials/server/integrations.hbs`: API ผู้ดูแลระบบและ UI การผสานรวมต่อเซิร์ฟเวอร์
- `src/db/migrations/011_wizard_chat.js` ถึง `019_wizard_power_controllers.js`: สคีมาถาวร
- `test/wizard.test.js`: การทดสอบสิทธิ์, ขอบเขตเครื่องมือ, การเก็บรักษา, การแจ้งเตือน และพฤติกรรมการแชท

ชื่อเส้นทาง/โมดูล/ตาราง `wizard` ภายในจะยังคงไว้เพื่อความเข้ากันได้ในการอัปเกรดและ API "chatbot" เป็นคำศัพท์ผลิตภัณฑ์ที่ผู้ใช้มองเห็น ในทำนองเดียวกัน ฟิลด์ `power_testers_json` ที่จัดเก็บไว้จะแมปกับกลุ่ม **ผู้ใช้ทั่วไป** ใน UI

## ขนาดของทรัพยากรที่ต้องพึ่งพา (`minecraft-data`)

ความช่วยเหลือเกี่ยวกับสูตรอาหารใช้แพ็กเกจ `minecraft-data` มีขนาดใหญ่บนดิสก์ (ประมาณ 429 MB เมื่อติดตั้ง) และจะถูกรวมอยู่ในอิมเมจการผลิตเนื่องจากเป็นทรัพยากรที่ต้องพึ่งพาขณะรันไทม์ ไม่ใช่ขณะพัฒนา เราเก็บไว้โดยเจตนาเพื่อให้ความช่วยเหลือเกี่ยวกับสูตรอาหารทำงานแบบออฟไลน์สำหรับ Minecraft ทุกเวอร์ชันโดยไม่ต้องเรียกเครือข่าย

หมายเหตุสำหรับผู้ที่จะดูสิ่งนี้ต่อไป (มนุษย์หรือ AI) เพื่อให้ขนาดไม่น่าประหลาดใจ:

- ขณะนี้ใช้เฉพาะข้อมูล Java (`pc`) เท่านั้น `wizardRecipes.js` อ่าน `minecraftData.versions.pc` และตาราง `recipes`, `items`, และ `blocks` ต่อเวอร์ชัน ไฟล์ที่แตะต้องจริงๆ มีขนาดรวมประมาณ 15 MB ทั่วทุกเวอร์ชัน pc
- ประมาณ 330 MB ของแพ็กเกจคือ `data/bedrock` และไม่มีอะไรที่นี่อ่านมันในตอนนี้ เราปล่อยทิ้งไว้โดยเจตนา หากแผงควบคุมเพิ่มการรองรับ Bedrock Minecraft ในอนาคต ข้อมูลสูตรอาหารและไอเทมของ Bedrock จะอยู่ที่นี่แล้ว ดังนั้นฟีเจอร์สูตรอาหารจึงสามารถขยายครอบคลุมเซิร์ฟเวอร์ Bedrock ได้โดยไม่ต้องเพิ่มทรัพยากรที่ต้องพึ่งพาใหม่ เริ่มต้นจาก `minecraftData.versions.bedrock` และทำตามรูปแบบเดียวกับเส้นทาง pc
- หากขนาดต้องลดลงก่อนที่การสนับสนุน Bedrock จะมาถึง มีรูปแบบสำหรับสิ่งนั้นอยู่แล้วใน repo นี้ `src/services/itemRegistry.js` ดึงไฟล์ `minecraft-data` จาก jsDelivr CDN เมื่อต้องการและแคชไว้ใน `api_cache` ไม่ว่าจะเป็นแนวทางนั้น หรือชุดย่อยขนาดเล็กที่เลือกด้วยมือ `src/data/recipes/` ที่ครอบคลุมไม่กี่เวอร์ชันที่ใช้กันทั่วไป จะช่วยลดขนาดอิมเมจลงอย่างมาก

## พื้นที่จัดเก็บภายในเครื่องและการตรวจสอบด้วยตนเอง

การตั้งค่าทั้งหมดและการถอดความที่เก็บไว้จะอยู่ในฐานข้อมูล SQLite ของแผงควบคุมที่ `/data/panel.db` ภายในคอนเทนเนอร์แผงควบคุม ด้วยการเมานต์มาตรฐาน เส้นทางโฮสต์คือ
`${DATA_DIR_HOST}/panel.db` (เช่น `/opt/msm/data/panel.db`) ตารางที่เกี่ยวข้องคือ
`wizard_configs`, `wizard_transcripts`, และ `wizard_outreach`; การตรวจสอบพลังงานคือแถวในตาราง `events` ที่มีประเภท `wizard-power` คีย์ API LLM ที่เลือกได้จะถูกเข้ารหัส AES-256-GCM โดยใช้ `SESSION_SECRET` ของแผงควบคุม ซึ่งปกติจะถูกจัดเก็บเป็น `${DATA_DIR_HOST}/.session-secret`

สำรองฐานข้อมูลและหยุดแผงควบคุมก่อนทำการแก้ไข SQLite โดยตรง เพื่อให้ WAL ได้รับการจัดการอย่างปลอดภัย การใช้ UI/API ของผู้ดูแลระบบเป็นที่ต้องการเนื่องจากมีการตรวจสอบความถูกต้องและการเข้ารหัส โปรดเก็บไฟล์ `panel.db`, `panel.db-wal`, และ `panel.db-shm` ไว้ด้วยกันเมื่อคัดลอกฐานข้อมูลสด
