## การตั้งค่าครั้งแรก

ครั้งแรกที่คุณเปิดแผงควบคุม ระบบจะขอให้คุณสร้างบัญชีผู้ดูแลระบบ นี่เป็นบัญชีเดียวที่มีอยู่จนกว่าคุณจะเพิ่มบัญชีอื่น และบัญชีนี้มีการควบคุมเต็มรูปแบบ

เลือกชื่อผู้ใช้และรหัสผ่านที่มีความยาวอย่างน้อย 8 ตัวอักษร เพียงเท่านี้ คุณก็สามารถเข้าสู่ระบบและไปยังหน้าแดชบอร์ดได้ทันที

> **การติดตั้งที่เปิดเผยจะถูกจำกัดด้วย PIN** หากคุณเริ่มแผงควบคุมโดยผูกกับที่อยู่ที่ไม่ใช่ loopback (`PANEL_HOST` นอกเหนือจาก `127.0.0.1`) หน้าตั้งค่าจะขอ **PIN 6 หลัก** ด้วย แผงควบคุมจะแสดง PIN นี้ในคอนโซลเมื่อเริ่มต้น ให้ป้อน PIN นี้พร้อมกับชื่อผู้ใช้และรหัสผ่านของคุณ เพื่อป้องกันไม่ให้คนแปลกหน้าที่เข้าถึงพอร์ตก่อนทำการอ้างสิทธิ์บัญชีผู้ดูแลระบบ PIN จะหายไปเมื่อบัญชีผู้ดูแลระบบถูกสร้างขึ้น

## การลงชื่อเข้าใช้

หลังจากการตั้งค่า แผงควบคุมจะได้รับการป้องกันด้วยหน้าจอเข้าสู่ระบบ ป้อนชื่อผู้ใช้และรหัสผ่านของคุณเพื่อดำเนินการต่อ

![ลงชื่อเข้าใช้](/docs/images/login.png)

หาก [การยืนยันตัวตนแบบสองปัจจัย](/docs/two-factor-authentication/) เปิดใช้งานในบัญชีของคุณ คุณจะถูกขอรหัส 6 หลักจากแอปยืนยันตัวตนของคุณทันทีหลังจากรหัสผ่าน

## การทำความเข้าใจการใช้งาน

ทุกอย่างจะเชื่อมโยงกับแถบด้านข้างด้านซ้าย:

- **แดชบอร์ด** - เซิร์ฟเวอร์ทั้งหมดในภาพรวม ([รายละเอียด](/docs/dashboard/))
- **เซิร์ฟเวอร์**, **Modpacks**, **Worlds**, **Blueprints** - สร้างและจัดการเซิร์ฟเวอร์และเนื้อหาของเซิร์ฟเวอร์
- **การอัปเดต**, **การสำรองข้อมูล**, **ตารางเวลา**, **พื้นที่จัดเก็บ**, **กิจกรรม** - ด้านการปฏิบัติการ: สิ่งที่ล้าสมัย, สแนปชอตของคุณ, ระบบอัตโนมัติ, การใช้งานดิสก์ และบันทึกการตรวจสอบ
- **การตั้งค่า** (ด้านล่าง): ผู้ใช้, คีย์ API และการกำหนดค่าแผงควบคุม

แถบด้านบนมีปุ่ม **สร้างเซิร์ฟเวอร์**, **สลับธีม** (มืด/สว่าง) และ **เมนูบัญชีของคุณ** ซึ่งคุณสามารถจัดการ [การยืนยันตัวตนแบบสองปัจจัย](/docs/two-factor-authentication/) หรือลงชื่อออกได้

## บนโทรศัพท์หรือแท็บเล็ต

ทุกหน้าถูกจัดวางสำหรับหน้าจอแคบก่อน แล้วจึงขยายออกไป: แถบด้านข้างจะซ่อนอยู่หลังปุ่มเมนู, ตารางข้อมูลจะซ้อนกันเป็นบัตร, แถบเครื่องมือจะพันกัน และแถบควบคุมเซิร์ฟเวอร์จะยุบเป็นบัตรที่คุณเปิดเมื่อต้องการ ปุ่มและชิปมีขนาดเป้าหมายการสัมผัสที่แท้จริง ไม่มีอะไรสำหรับเดสก์ท็อปเท่านั้น

## สิ่งที่คุณต้องการ

แผงควบคุมจะสื่อสารกับ Docker เพื่อรันเซิร์ฟเวอร์ ดังนั้นจึงต้องการการเข้าถึง Docker daemon (Docker Desktop หรือ Docker Engine socket) เมื่อ Docker สามารถเข้าถึงได้ ไทล์ Docker บนแดชบอร์ดจะแสดง **เชื่อมต่อแล้ว** และเวอร์ชันของ Docker หากไม่สามารถเข้าถึงได้ แผงควบคุมยังคงทำงานอยู่ คุณเพียงแค่ไม่สามารถเริ่มเซิร์ฟเวอร์ได้จนกว่า daemon จะทำงาน
