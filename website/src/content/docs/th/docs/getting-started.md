## การตั้งค่าครั้งแรก

ครั้งแรกที่คุณเปิดแผงควบคุม ตัวช่วยตั้งค่าสั้นๆ จะแนะนำคุณตลอด:

1.  **ตรวจสอบระบบ** ตรวจสอบว่าสามารถเชื่อมต่อ Docker ได้, Node.js มีเวอร์ชันที่ใหม่พอ, และโฟลเดอร์ข้อมูลสามารถเขียนได้ หาก Docker ยังไม่ทำงาน คุณยังคงดำเนินการต่อได้ การสร้างและเริ่มเซิร์ฟเวอร์จะรอจนกว่า Docker จะพร้อมใช้งาน
2.  **สร้างบัญชีผู้ดูแลระบบของคุณ** นี่เป็นบัญชีเดียวที่มีอยู่จนกว่าคุณจะเพิ่มบัญชีอื่น และมีสิทธิ์ควบคุมเต็มรูปแบบ เลือกชื่อผู้ใช้ (2 ถึง 32 อักขระ) และรหัสผ่านอย่างน้อย 8 อักขระ คุณจะเข้าสู่ระบบทันทีที่สร้างบัญชีเสร็จ
3.  **การกำหนดค่าแผงควบคุม** (ไม่บังคับ): โดเมนสาธารณะเพื่อแสดงให้ผู้เล่นเห็นในที่อยู่การเชื่อมต่อ, คีย์ API ของ CurseForge, และเขตเวลาของคุณ ทั้งหมดนี้สามารถเปลี่ยนแปลงได้ในภายหลังใน **การตั้งค่า**

ขั้นตอนสุดท้ายจะเสนอ **สร้างเซิร์ฟเวอร์** หรือ **ไปที่แดชบอร์ด**

![ขั้นตอนการตรวจสอบระบบของการตั้งค่าครั้งแรก](/docs/images/setup-system-check.png)

> **การติดตั้งที่เปิดเผยจะถูกจำกัดด้วย PIN** หากคุณเริ่มแผงควบคุมโดยผูกกับที่อยู่ที่ไม่ใช่ loopback (`PANEL_HOST` นอกเหนือจาก `127.0.0.1`) หน้าตั้งค่าจะขอ **PIN 6 หลัก** ด้วย แผงควบคุมจะแสดง PIN นี้ในคอนโซลเมื่อเริ่มต้น ให้ป้อน PIN พร้อมกับชื่อผู้ใช้และรหัสผ่านของคุณ วิธีนี้จะป้องกันไม่ให้คนแปลกหน้าที่เข้าถึงพอร์ตก่อนอ้างสิทธิ์บัญชีผู้ดูแลระบบได้ PIN จะหายไปเมื่อบัญชีผู้ดูแลระบบถูกสร้างขึ้น

## การเข้าสู่ระบบ

หลังจากการตั้งค่า แผงควบคุมจะได้รับการป้องกันด้วยหน้าจอเข้าสู่ระบบ ป้อนชื่อผู้ใช้และรหัสผ่านของคุณเพื่อดำเนินการต่อ

![เข้าสู่ระบบ](/docs/images/login.png)

หาก [การยืนยันตัวตนแบบสองปัจจัย](/docs/two-factor-authentication/) เปิดใช้งานสำหรับบัญชีของคุณ คุณจะถูกขอรหัส 6 หลักจากแอปยืนยันตัวตนของคุณทันทีหลังจากรหัสผ่าน

## การใช้งานแผงควบคุม

ทุกอย่างจะเชื่อมโยงกับแถบด้านข้างด้านซ้าย:

- **แดชบอร์ด** - ทุกเซิร์ฟเวอร์ในภาพรวม ([รายละเอียด](/docs/dashboard/))
- **เซิร์ฟเวอร์**, **Modpacks**, **Worlds**, **Blueprints** - สร้างและจัดการเซิร์ฟเวอร์และเนื้อหาของเซิร์ฟเวอร์
- **การอัปเดต**, **การสำรองข้อมูล**, **ตารางเวลา**, **พื้นที่จัดเก็บ**, **กิจกรรม** - ด้านการปฏิบัติงาน: สิ่งที่ล้าสมัย, สแนปชอตของคุณ, ระบบอัตโนมัติ, การใช้งานดิสก์, และบันทึกการตรวจสอบ
- **สิทธิ์** (ด้านล่าง, เฉพาะผู้ดูแลระบบ): ผู้ใช้แต่ละคนสามารถทำอะไรกับเซิร์ฟเวอร์แต่ละเครื่องได้ ([รายละเอียด](/docs/users-and-roles/#per-server-permissions))
- **การตั้งค่า** (ด้านล่าง, เฉพาะผู้ดูแลระบบ): คีย์ API, การกำหนดค่าแผงควบคุม, ค่าเริ่มต้นสำหรับเซิร์ฟเวอร์ใหม่, [การเก็บรักษาข้อมูลสำรอง](/docs/backups/#retention), ผู้ใช้, ความปลอดภัยในการเข้าสู่ระบบ, และ API สาธารณะ

ด้านล่างนั้น แถบด้านข้างจะแสดงรายการเซิร์ฟเวอร์ของคุณ การเปิดเซิร์ฟเวอร์จะแสดงแท็บของเซิร์ฟเวอร์นั้นๆ: **ภาพรวม**, **คอนโซล**, **ผู้เล่น**, **ม็อด**, **โลก**, **การสำรองข้อมูล**, **การตรวจสอบ**, และ **การตั้งค่า** ส่วนใหญ่จะมีแท็บย่อยที่เกี่ยวข้อง (เช่น **การตั้งค่า → การกำหนดค่า** จะมี การตั้งค่าของเซิร์ฟเวอร์และพอร์ตเกม) ดู [เซิร์ฟเวอร์เดียว](/docs/servers/#a-single-server)

แถบด้านบนมีปุ่ม **สร้างเซิร์ฟเวอร์**, **สลับธีม** (มืด/สว่าง), และ **เมนูบัญชี** ของคุณ ซึ่งคุณสามารถเปลี่ยนรูปโปรไฟล์, จัดการ [การยืนยันตัวตนแบบสองปัจจัย](/docs/two-factor-authentication/), หรือลงชื่อออก

## บนโทรศัพท์หรือแท็บเล็ต

## สิ่งที่คุณต้องการ

แผงควบคุมจะสื่อสารกับ Docker เพื่อรันเซิร์ฟเวอร์ ดังนั้นจึงต้องการการเข้าถึง Docker daemon (Docker Desktop หรือ Docker Engine socket) เมื่อ Docker สามารถเชื่อมต่อได้ ช่อง Docker บนแดชบอร์ดจะแสดง **เชื่อมต่อแล้ว** และเวอร์ชัน หากไม่สามารถเชื่อมต่อได้ แผงควบคุมยังคงทำงานอยู่ คุณเพียงแค่ไม่สามารถเริ่มเซิร์ฟเวอร์ได้จนกว่า daemon จะพร้อมใช้งาน
