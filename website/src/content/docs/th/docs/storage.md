หน้า **พื้นที่จัดเก็บข้อมูล** แสดงให้เห็นว่าดิสก์ของคุณกำลังจะเต็มที่ไหน: การใช้งานต่อเซิร์ฟเวอร์ และแนวโน้มเมื่อเวลาผ่านไป

![พื้นที่จัดเก็บข้อมูล](/docs/images/storage.png)

## โควต้าดิสก์ถูกบังคับใช้โดยแผงควบคุม

Docker ไม่สามารถจำกัดการใช้งานดิสก์ของ bind mount ได้ ดังนั้นแผงควบคุมจึงทำหน้าที่นี้ ตัวทำดัชนีขนาดในพื้นหลังจะสแกนไดเรกทอรีข้อมูล แคชขนาดของเซิร์ฟเวอร์แต่ละเครื่อง และบังคับใช้โควต้าดิสก์ที่คุณตั้งไว้ต่อเซิร์ฟเวอร์ เมื่อข้อมูลของเซิร์ฟเวอร์ (โลก + การสำรองข้อมูล + ทุกอย่างอื่น) ใกล้ถึงโควต้า แผงควบคุมจะหยุดการเติบโตที่มากเกินไป แทนที่จะปล่อยให้เซิร์ฟเวอร์หนึ่งเครื่องเต็มโฮสต์ของคุณ

ตั้งค่าโควต้าของเซิร์ฟเวอร์ในการ [ตั้งค่า](/docs/servers/) เซิร์ฟเวอร์ที่ลง mod และ [การสำรองข้อมูล](/docs/backups/) ของเซิร์ฟเวอร์เหล่านั้นอาจมีขนาดใหญ่ ดังนั้นควรเผื่อพื้นที่ให้เพียงพอ

## การล้างข้อมูล

มุมมองพื้นที่จัดเก็บข้อมูลช่วยให้คุณค้นหาสิ่งที่จะลบออก (การสำรองข้อมูลเก่า โลกที่ไม่ได้ใช้งาน หรือเซิร์ฟเวอร์ที่เติบโตเกินความคาดหมาย) ก่อนที่คุณจะหมดพื้นที่
