## คอนโซลสด

แท็บ **คอนโซล** จะสตรีมบันทึกเซิร์ฟเวอร์แบบเรียลไทม์ และมีช่องสำหรับป้อนคำสั่งเพื่อส่งคำสั่งใดๆ ไปยังเซิร์ฟเวอร์ ไม่ต้องใช้ `docker exec` หรือ SSH ผลลัพธ์จะแสดงขึ้นมาพร้อมสีสัน

![Console](/docs/images/server-console.png)

คอนโซลยังเป็นที่ที่แผงควบคุมอ่านสถานะของเซิร์ฟเวอร์: มันจะคอยดูบันทึกเพื่อจำแนกเฟสการบูต ("Loading mods", "Generating world", "Finishing startup") และเรียกใช้ `list` เพื่อติดตามว่าใครกำลังออนไลน์อยู่ ดังนั้นแดชบอร์ดและการ์ดเซิร์ฟเวอร์จะสะท้อนความเป็นจริงเสมอ

การสำรวจข้อมูลนั้นจะเปิดการเชื่อมต่อ RCON ระยะสั้นทุกรอบ ซึ่งเซิร์ฟเวอร์จะบันทึกเป็นคู่ `Thread RCON Client … started` / `shutting down` ทุกๆ ประมาณ 20 วินาที และ (บนเซิร์ฟเวอร์ที่คอร์หรือปลั๊กอินสะท้อนออกมา) บรรทัด `Rcon issued server command: …` สำหรับการอ่านแต่ละครั้งที่ไม่เปลี่ยนแปลง - `list` สำหรับจำนวนผู้เล่น, บวกกับการอ่าน `time query …` และ `gamerule <name>` ขณะที่หน้า World Controls เปิดอยู่ ตัวเลือก **ซ่อนข้อความ RCON** เหนือบันทึกจะกรองบรรทัดเหล่านั้นออก (พร้อมกับบรรทัดเริ่มต้นของ RCON listener) ตัวเลือกนี้เปิดใช้งานโดยค่าเริ่มต้นและจะจำไว้สำหรับแต่ละเบราว์เซอร์ ปิดเพื่อดูสตรีมดิบ

คำสั่งที่ส่งจากแผงควบคุมสามารถประกาศในเกมภายใต้ป้ายกำกับต่อเซิร์ฟเวอร์ได้ เพื่อให้ผู้เล่นทราบว่าผู้ดำเนินการได้กระทำการบางอย่าง แทนที่จะเป็นคอนโซลลึกลับ

## คำสั่งแชท

คำสั่งแชทช่วยให้ผู้เล่นสามารถเรียกใช้การดำเนินการของแผงควบคุมได้โดยการพิมพ์คำสั่งนำหน้าในแชทของเกม เช่น `!spawn` เพื่อสุ่มย้ายตำแหน่ง การตรวจจับจะอิงตามบันทึกและการดำเนินการจะผ่านเซิร์ฟเวอร์ ดังนั้น **จึงไม่จำเป็นต้องใช้ม็อด**

![Chat commands](/docs/images/chat-commands.png)

แต่ละคำสั่งมี:

- **ทริกเกอร์** (เช่น `spawn`) และ **คำนำหน้า** (`!` โดยค่าเริ่มต้น)
- **การดำเนินการ**: สุ่มย้ายตำแหน่ง, ย้ายไปยังโครงสร้าง, ย้ายไปยังชีวนิเวศ, หรือรันคำสั่งคอนโซลดิบ
- **ระดับสิทธิ์**: ทุกคน, ผู้เล่นที่อยู่ในรายการอนุญาต (whitelisted), หรือเฉพาะผู้ดำเนินการ (operators) เท่านั้น
- **คูลดาวน์**, และข้อความที่กำหนดเองได้สำหรับข้อความที่รอดำเนินการ / สำเร็จ / ล้มเหลว พร้อมตัวยึดตำแหน่ง เช่น `{distance}`

### หมายเหตุเกี่ยวกับความปลอดภัย

คำสั่งที่อาจทำให้เซิร์ฟเวอร์เสียหาย (`stop`, `op`, `ban`, `whitelist` และคำสั่งที่คล้ายกัน) จะได้รับอนุญาตเฉพาะกับทริกเกอร์ที่ตั้งค่าเป็น **เฉพาะผู้ดำเนินการ** เท่านั้น แผงควบคุมจะตรวจสอบสิ่งเหล่านี้แม้ว่าจะถูกซ้อนอยู่ภายในโซ่ `execute … run …` ก็ตาม เพื่อให้ทริกเกอร์ที่มีสิทธิ์ต่ำไม่สามารถส่งคำสั่งอันตรายผ่านไปได้ ข้อความแชททั่วไปที่เพียงแค่กล่าวถึงคำเหล่านั้น (เช่น ข้อความ `say`) จะไม่ถูกดำเนินการ
