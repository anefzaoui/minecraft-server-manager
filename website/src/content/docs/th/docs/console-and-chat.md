## คอนโซลสด

แท็บ **คอนโซล** จะสตรีมบันทึกเซิร์ฟเวอร์แบบเรียลไทม์ และมีช่องสำหรับป้อนคำสั่งเพื่อส่งคำสั่งใดๆ ไปยังเซิร์ฟเวอร์ ไม่ต้องใช้ `docker exec` หรือ SSH ผลลัพธ์จะแสดงกลับมาทันที พร้อมสีสันและทุกอย่าง การส่งคำสั่งต้องได้รับอนุญาต Console บนเซิร์ฟเวอร์นั้น หากไม่มีสิทธิ์ คุณยังคงสามารถดูบันทึกได้

เหนือบันทึก คุณสามารถกรองบรรทัดตามข้อความ (หรือ `/regex/`) และตามระดับ (INFO, WARN, ERROR) และ **ดาวน์โหลด** จะมีผลลัพธ์ล่าสุด, `latest.log` ฉบับเต็ม, หรือไฟล์บันทึกทั้งหมดเป็น zip

![Console](/docs/images/server-console.png)

คอนโซลยังเป็นที่ที่แผงควบคุมอ่านสถานะของเซิร์ฟเวอร์: มันจะเฝ้าดูบันทึกเพื่อจำแนกเฟสการบูต ("Loading mods", "Generating world", "Finishing startup") และเรียกใช้ `list` เพื่อติดตามว่าใครออนไลน์อยู่ ดังนั้นแดชบอร์ดและบัตรเซิร์ฟเวอร์จะสะท้อนความเป็นจริงเสมอ

การสำรวจข้อมูลนั้นจะเปิดการเชื่อมต่อ RCON ชั่วคราวทุกรอบ ซึ่งเซิร์ฟเวอร์จะบันทึกเป็นคู่ `Thread RCON Client … started` / `shutting down` ทุกๆ ประมาณ 20 วินาที และ (บนเซิร์ฟเวอร์ที่คอร์หรือปลั๊กอินสะท้อนออกมา) บรรทัด `Rcon issued server command: …` สำหรับการสำรวจแบบอ่านอย่างเดียวแต่ละครั้ง (`list` สำหรับจำนวนผู้เล่น, บวกกับการอ่าน `time query …` และ `gamerule <name>` ขณะที่ World Controls เปิดอยู่) ตัวเลือก **ซ่อนเสียงรบกวนคอนโซล** เหนือบันทึกจะกรองบรรทัดเหล่านั้นออก (พร้อมกับบรรทัดเริ่มต้น RCON listener) ตัวเลือกนี้เปิดใช้งานโดยค่าเริ่มต้นและจะจำไว้สำหรับแต่ละเบราว์เซอร์ ปิดเพื่อดูสตรีมดิบ

คำสั่งที่ส่งจากแผงควบคุมสามารถประกาศในเกมภายใต้ป้ายกำกับต่อเซิร์ฟเวอร์ (ช่อง **ประกาศเป็น...**) เพื่อให้ผู้เล่นทราบว่าผู้ดำเนินการได้กระทำการบางอย่าง แทนที่จะเป็นคอนโซลลึกลับ

## แชท

**คอนโซล → แชท** ส่งข้อความเข้าสู่เกมขณะที่เซิร์ฟเวอร์ทำงาน: ข้อความ **จัดรูปแบบ** จะรับสีและการจัดรูปแบบ และสามารถส่งถึงทุกคนหรือผู้เล่นออนไลน์คนเดียว และข้อความ **ธรรมดา** จะส่งการกระจายเสียงแบบง่ายๆ `[Server]` ไปยังทุกคน

![Console → Chat](/docs/screenshots/04-chat.png)

## คำสั่งแชท

คำสั่งแชท (**คอนโซล → คำสั่ง**) ช่วยให้ผู้เล่นสามารถเรียกใช้การดำเนินการของแผงควบคุมได้โดยการพิมพ์คำสั่งนำหน้าในแชทของเกม เช่น `!spawn` เพื่อสุ่มย้ายตำแหน่ง การตรวจจับจะอิงตามบันทึกและการดำเนินการจะผ่านเซิร์ฟเวอร์ ดังนั้น **ไม่จำเป็นต้องใช้ม็อด**

![Chat commands](/docs/images/chat-commands.png)

แต่ละคำสั่งมี:

- **ทริกเกอร์** (เช่น `spawn`) พิมพ์ตามหลัง **คำนำหน้า** ของเซิร์ฟเวอร์ (`!` โดยค่าเริ่มต้น, หนึ่งหรือสองอักขระ, ไม่เคย `/`)
- **การดำเนินการ**: สุ่มย้ายตำแหน่ง, ย้ายตำแหน่งไปยังโครงสร้าง, ย้ายตำแหน่งไปยังชีวนิเวศ, หรือรันคำสั่งคอนโซลดิบ
- **ระดับสิทธิ์**: ทุกคน, ผู้เล่นที่อยู่ในรายการที่อนุญาต, หรือเฉพาะผู้ดำเนินการเท่านั้น
- **คูลดาวน์ต่อผู้เล่น** (30 วินาทีโดยค่าเริ่มต้น) และข้อความแจ้ง/สำเร็จ/ล้มเหลวที่ปรับแต่งได้พร้อมตัวยึดตำแหน่ง เช่น `{distance}`

### หมายเหตุเกี่ยวกับความปลอดภัย

คำสั่งที่อาจทำให้เซิร์ฟเวอร์เสียหาย (`stop`, `op`, `ban`, `whitelist` และคำสั่งที่คล้ายกัน) จะได้รับอนุญาตเฉพาะในทริกเกอร์ **เฉพาะผู้ดำเนินการเท่านั้น** แผงควบคุมจะตรวจสอบสิ่งเหล่านี้แม้ว่าจะซ้อนอยู่ภายในโซ่ `execute … run …` ก็ตาม ดังนั้นทริกเกอร์ที่มีสิทธิ์ต่ำจึงไม่สามารถส่งคำสั่งอันตรายผ่านไปได้ ข้อความแชทธรรมดาที่เพียงแค่กล่าวถึงคำเหล่านั้น (เช่น ข้อความ `say`) จะไม่ถูกดำเนินการ
