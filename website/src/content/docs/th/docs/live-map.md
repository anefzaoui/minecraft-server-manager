แท็บ **World → Map** ของเซิร์ฟเวอร์จะแสดงแผนที่ 3 มิติแบบสดที่ซูมได้ของโลกในเซิร์ฟเวอร์ของคุณ ซึ่งสร้างโดย [BlueMap](https://bluemap.bluecolored.de/) (ฟรีและโอเพนซอร์ส) พร้อมตำแหน่งของผู้เล่นและทุกมิติ แผงควบคุมจะติดตั้ง กำหนดค่า และให้บริการแผนที่นี้ คุณไม่จำเป็นต้องเปิดพอร์ตหรือแก้ไขไฟล์การกำหนดค่าใดๆ

## การเปิดใช้งาน

1. เปิดเซิร์ฟเวอร์ จากนั้นไปที่ **World → Map**
2. กด **Enable Live Map** แผงควบคุมจะติดตั้ง BlueMap เวอร์ชันที่ตรงกับ loader และเวอร์ชัน Minecraft ของเซิร์ฟเวอร์จาก Modrinth ยอมรับการดาวน์โหลดทรัพยากรของ BlueMap ให้คุณ และเลือกพอร์ตที่ว่างสำหรับแผนที่
3. รีสตาร์ทเซิร์ฟเวอร์ (การเปลี่ยนแปลงจะมีผลในการเริ่มทำงานครั้งถัดไป และเซิร์ฟเวอร์จะถูกทำเครื่องหมายว่ากำลังรอการรีสตาร์ท)

BlueMap จะเรนเดอร์ในพื้นหลัง ดังนั้นแผนที่ใหม่จะใช้เวลาสองสามนาทีในการสร้างไทล์แรก จนกว่าจะถึงตอนนั้น แท็บจะแสดงว่าแผนที่ยังไม่พร้อมใช้งาน และจะตรวจสอบอีกครั้งด้วยตนเอง เมื่อพร้อมใช้งาน **Fullscreen** จะเปิดแผนที่ในแท็บเบราว์เซอร์แยกต่างหาก

แผนที่นี้ใช้งานได้กับเซิร์ฟเวอร์ที่มี mod loader (Fabric, Quilt, Forge, NeoForge) และเซิร์ฟเวอร์ปลั๊กอิน (Paper, Purpur และตระกูล Paper อื่นๆ, Spigot) รวมถึงเซิร์ฟเวอร์ modpack เซิร์ฟเวอร์ Vanilla จะไม่มี BlueMap และแท็บจะแจ้งให้ทราบ

## ใครสามารถดูได้

แผนที่จะให้บริการผ่านแผงควบคุมเท่านั้น โดยอยู่หลังการลงชื่อเข้าใช้: ใครก็ตามที่สามารถดูเซิร์ฟเวอร์ในแผงควบคุมได้ จะสามารถเปิดแผนที่ของเซิร์ฟเวอร์นั้นได้ และจะไม่มีใครอื่น พอร์ตของ BlueMap เองไม่จำเป็นต้องเปิดสู่อินเทอร์เน็ต ([ภาพรวมพอร์ต](https://github.com/anefzaoui/minecraft-server-manager#ports-at-a-glance)) การเปิดหรือปิดแผนที่ต้องได้รับอนุญาต **Settings** ของเซิร์ฟเวอร์ ([ผู้ใช้และบทบาท](/docs/users-and-roles/#per-server-permissions))

เมื่อแผงควบคุมเองทำงานใน Docker มันจะเข้าถึง BlueMap ภายในคอนเทนเนอร์ของเซิร์ฟเวอร์ [README](https://github.com/anefzaoui/minecraft-server-manager#installation) อธิบายรายละเอียดสำหรับการตั้งค่า reverse-proxy

## การปิดใช้งาน

**Disable Map** จะลบไฟล์ jar ของ BlueMap ที่แผงควบคุมติดตั้งไว้และคืนพอร์ตที่ใช้งานอยู่ โดยจะมีผลอีกครั้งตั้งแต่การรีสตาร์ทครั้งถัดไป โลกเองจะไม่ได้รับผลกระทบ ไทล์แผนที่ที่เรนเดอร์แล้วจะยังคงอยู่ในโฟลเดอร์ของเซิร์ฟเวอร์จนกว่าคุณจะลบออกในแท็บ **Files**
