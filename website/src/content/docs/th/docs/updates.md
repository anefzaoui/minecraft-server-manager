[← กลับไปยังดัชนีเอกสาร](/docs/)

หน้า **Updates** ติดตามสิ่งที่ล้าสมัยในกลุ่มเซิร์ฟเวอร์ของคุณได้ในที่เดียว:

- เวอร์ชัน **Modpack** ([modpacks](/docs/modpacks/)) เทียบกับ Modrinth / CurseForge / ดัชนีการเปิดตัว GTNH
- **เนื้อหาที่กำหนดเอง** ที่คุณเพิ่มเอง - mods, datapacks, resource packs, plugins - แต่ละรายการเทียบกับแหล่งที่มา: Modrinth, CurseForge, Hangar, SpigotMC (Spiget) หรือ GitHub Releases การค้นหา GitHub ใช้การตรวจสอบ ETag ใหม่ ดังนั้นการตรวจสอบรายวันจึงแทบไม่กระทบต่อขีดจำกัดอัตรา
- **Docker image** ที่ล้าสมัย: ID ของ image ของคอนเทนเนอร์ที่กำลังทำงานแต่ละรายการเทียบกับแท็กที่ดึงมาใหม่ (ลดซ้ำกันระหว่างเซิร์ฟเวอร์ที่มีแท็กเดียวกัน) นำเสนอเป็นการอัปเกรดที่สามารถสร้างใหม่ได้เท่านั้น
- **การปักหมุดเวอร์ชันแบบสแตนด์อโลน**: สำหรับเซิร์ฟเวอร์ที่ไม่มีแพ็กที่จัดการ การปักหมุด `mc_version` ที่ชัดเจนเทียบกับ manifest ของ Mojang และตัวแปรสภาพแวดล้อมการสร้าง loader ที่ชัดเจน (`PAPER_BUILD`, `FORGE_VERSION` และอื่นๆ) เทียบกับ registry ของ loader การสร้าง Paper มาจาก **Fill v3 API** ปัจจุบันของ PaperMC (จุดสิ้นสุด v2 แบบเก่าหยุดรับเวอร์ชัน Minecraft ใหม่)

## วิธีการทำงาน

แผงควบคุมจะตรวจสอบเวอร์ชันที่ปักหมุดของเซิร์ฟเวอร์แต่ละเครื่องกับแหล่งต้นทาง และแสดงรายการสิ่งที่ใหม่กว่า การนับที่ตรงกันจะปรากฏบนไทล์ "Updates available" ใน [dashboard](/docs/dashboard/) ด้วย

การตรวจสอบจะทำงานตามต้องการและสามารถตั้งเวลาได้ ([Schedules](/docs/schedules/)) **นโยบาย** การอัปเดตเป็นแบบต่อเซิร์ฟเวอร์: คุณตัดสินใจว่าแผงควบคุมจะแจ้งให้คุณทราบเท่านั้น หรือปล่อยให้ทุกอย่างเป็นแบบแมนนวล

## การใช้การอัปเดต

การอัปเดตไม่เคยเงียบ เมื่อคุณเลือกที่จะอัปเกรดแพ็ก แผงควบคุมจะ:

1. ทำ **การสำรองข้อมูลก่อนอัปเดต** (เพื่อให้สามารถย้อนกลับได้; สำรองข้อมูลก่อนอัปเดต 10 รายการล่าสุดต่อเซิร์ฟเวอร์จะถูกเก็บไว้)
2. ปักหมุดเวอร์ชันใหม่ที่แน่นอนอีกครั้ง
3. สร้างคอนเทนเนอร์ใหม่ โดยแก้ไข runtime ของ Java หากจำเป็น
4. ตรวจสอบการบูตครั้งแรก ด้วยงบประมาณเวลาต่อแพลตฟอร์ม

หากไม่สามารถบูตได้อย่างสมบูรณ์ คุณจะย้อนกลับไปยังข้อมูลสำรองก่อนอัปเดต เซิร์ฟเวอร์ที่ติดตามเวอร์ชันเสถียรจะไม่ได้รับข้อเสนอเบต้า และลิงก์ changelog จะชี้ไปยัง diff แบบต่อเวอร์ชันจริงที่แหล่งต้นทางมีให้ การอัปเดตที่ล้มเหลวจะส่งการแจ้งเตือน Discord [alert](/docs/integrations/) หากการผสานรวมได้รับการกำหนดค่า
