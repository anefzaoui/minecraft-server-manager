เลือกตามสิ่งที่ผู้เล่นต้องการให้ติดตั้ง ไม่ใช่ตามสิ่งที่ฟังดูเร็วที่สุด

| คุณต้องการ                                          | รันสิ่งนี้           | ผู้เล่นติดตั้ง |
| --------------------------------------------------- | -------------------- | -------------- |
| เอาชีวิตรอดกับเพื่อน ๆ ไม่มีอะไรพิเศษ               | Vanilla              | ไม่มี          |
| เซิร์ฟเวอร์สาธารณะพร้อมยศ, การอ้างสิทธิ์ และการดูแล | Paper                | ไม่มี          |
| ชุดม็อดเฉพาะจาก CurseForge หรือ Modrinth            | อะไรก็ตามที่ระบุ     | ชุดม็อด        |
| ชุดม็อดสมัยใหม่ที่คุณกำลังสร้างเอง                  | Fabric หรือ NeoForge | ม็อดเดียวกัน   |
| ชุดเก่าจากยุค 1.7 ถึง 1.12                          | Forge                | ม็อดเดียวกัน   |

นั่นคือการตัดสินใจทั้งหมดสำหรับคนส่วนใหญ่ ส่วนที่เหลือของหน้านี้คือเหตุผล

## ปลั๊กอินและม็อดไม่ใช่สิ่งเดียวกัน

นี่คือความแตกต่างที่ทุกสิ่งทุกอย่างขึ้นอยู่กับ

**ปลั๊กอิน** ทำงานเฉพาะบนเซิร์ฟเวอร์เท่านั้น Paper, Spigot และ Bukkit โหลดปลั๊กอินเหล่านี้ ผู้เล่นเข้าร่วมด้วยไคลเอ็นต์ธรรมดาที่ไม่ได้แก้ไข และไม่เคยรู้เลย สิ่งใดก็ตามที่เกี่ยวข้องกับกฎ, สิทธิ์, เศรษฐกิจ, การอ้างสิทธิ์, มินิเกม หรือการดูแล คือปลั๊กอิน และนี่คือเหตุผลที่เซิร์ฟเวอร์สาธารณะเกือบทั้งหมดรัน Paper

**ม็อด** เปลี่ยนแปลงตัวเกมเอง: บล็อกใหม่, มิติใหม่, เครื่องจักรใหม่ ไคลเอ็นต์ต้องโหลดม็อดเดียวกันกับเซิร์ฟเวอร์ มิฉะนั้นจะไม่สามารถเข้าใจสิ่งที่เซิร์ฟเวอร์กำลังบอกได้ ใครก็ตามที่เข้าร่วมเซิร์ฟเวอร์ที่มีม็อดต้องติดตั้งชุดม็อดก่อน

เซิร์ฟเวอร์ไม่สามารถเป็นทั้งสองอย่างได้อย่างมีความหมาย มีโปรเจกต์แบบไฮบริดที่เพิ่ม API ปลั๊กอินเข้าไปในตัวโหลดม็อด และมันทำงานได้จนกว่าจะไม่ได้ผล มักจะเป็นในเวลาที่แย่ที่สุด หากคุณต้องการทั้งสองอย่าง ให้รันพร็อกซีที่มีเซิร์ฟเวอร์ม็อดและเซิร์ฟเวอร์ปลั๊กอินอยู่เบื้องหลัง แทนที่จะเป็นแบบไฮบริดเดียว

## ฝั่งปลั๊กอิน

**Paper** คือคำตอบเริ่มต้น มันคือฟอร์กของ Spigot ที่มีการปรับปรุงประสิทธิภาพมาหลายปี และมีไฟล์การตั้งค่าสำหรับพฤติกรรมเกือบทุกอย่างที่เคยสร้างความรำคาญให้กับผู้ดูแล ปลั๊กอิน Vanilla จากยุค Bukkit ส่วนใหญ่ยังคงทำงานได้

**Purpur** คือฟอร์กของ Paper ที่มีตัวเลือกมากขึ้น รวมถึงตัวเลือกเกี่ยวกับเกมเพลย์ เลือกอันนี้หากคุณต้องการสวิตช์เฉพาะเหล่านั้น มิฉะนั้นให้เลือก Paper

**Vanilla** มีค่าที่จะรันเมื่อจุดประสงค์คือตัวเกมที่ไม่มีการเปลี่ยนแปลง มันช้ากว่าเมื่อมีผู้เล่นจำนวนมาก และไม่มีระบบสิทธิ์ ทำให้การดูแลต้องทำด้วยตนเอง

Paper เปลี่ยนพฤติกรรม Vanilla บางอย่างโดยค่าเริ่มต้นเพื่อประสิทธิภาพ หากกลไก Redstone จากวิดีโอไม่ทำงานบนเซิร์ฟเวอร์ของคุณ นั่นมักจะเป็นเหตุผล และมักจะเป็นการตั้งค่า

## ฝั่งม็อด

**Fabric** มีขนาดเล็ก อัปเดตเป็นเวอร์ชัน Minecraft ใหม่ภายในไม่กี่วัน และรองรับม็อดประสิทธิภาพสมัยใหม่ส่วนใหญ่ ม็อด Fabric เกือบทั้งหมดต้องการ Fabric API ซึ่งเป็นการดาวน์โหลดแยกต่างหาก หากเป้าหมายของคุณคือเซิร์ฟเวอร์ที่รวดเร็วพร้อมม็อดคุณภาพชีวิตเพียงไม่กี่ตัว นี่คือตัวเลือกของคุณ

**NeoForge** คือที่ที่ระบบนิเวศ Forge เดิมทำงานสำหรับเวอร์ชันปัจจุบัน มันแยกออกจาก Forge ในช่วง 1.20.1 และชุดม็อดขนาดใหญ่ส่วนใหญ่ที่สร้างขึ้นสำหรับ 1.20.2 และเวอร์ชันที่ใหม่กว่าจะกำหนดเป้าหมายไปที่นี่ หากคุณกำลังเริ่มต้นชุดม็อดหนัก ๆ ใหม่ในวันนี้ นี่คือตัวเลือกของคุณ

**Forge** ยังคงเป็นเจ้าของอดีต สิ่งใดก็ตามจากยุค 1.7.10, 1.12.2 และ 1.16.5 ซึ่งเป็นชุดม็อดที่ได้รับความนิยมจำนวนมาก คือ Forge และจะเป็นเช่นนั้นตลอดไป เก็บไว้สำหรับชุดเหล่านั้น

**Quilt** คือฟอร์กของ Fabric ที่รันม็อด Fabric ส่วนใหญ่ มีเหตุผลที่ดีในการดำรงอยู่ แต่หากคุณไม่มีเหตุผลเฉพาะในการเลือก ให้เลือก Fabric

ม็อดสำหรับตัวโหลดหนึ่งจะไม่ทำงานบนตัวโหลดอื่น หน้าม็อดที่ระบุว่า Fabric หมายถึง Fabric

## หากคุณกำลังติดตั้งชุดม็อด ชุดม็อดจะเป็นตัวกำหนด

อย่าเลือก ชุดม็อดจะระบุตัวโหลดและเวอร์ชัน Minecraft ที่แน่นอน และทั้งสองอย่างต้องตรงกัน "ใกล้เคียง" ไม่ใช่สิ่งที่มีอยู่จริง: ชุดม็อดสำหรับ 1.20.1 จะไม่ทำงานบน 1.20.4 และชุดม็อด NeoForge 1.20.1 จะไม่ทำงานบน Forge 1.20.1

ติดตั้งชุดม็อดตาม ID หรือลิงก์ แทนที่จะเลือกม็อดด้วยตนเอง และปักหมุดเวอร์ชัน ชุดม็อดมีการอัปเดต และการอัปเดตที่เกิดขึ้นโดยไม่คาดคิดระหว่างฤดูกาลคือสาเหตุที่โลกเสียหาย

## Java เวอร์ชันใด

ข้อกำหนดของ Minecraft จะเคลื่อนไปพร้อมกับเกม และการรันเวอร์ชันที่ไม่ถูกต้องจะทำให้เกิดข้อผิดพลาด `UnsupportedClassVersionError` ที่ไม่เป็นประโยชน์ แทนที่จะเป็นข้อความที่ชัดเจน

| เวอร์ชัน Minecraft | Java |
| ------------------ | ---- |
| 1.16.5 และเก่ากว่า | 8    |
| 1.17               | 16   |
| 1.18 และ 1.19      | 17   |
| 1.20 ถึง 1.20.4    | 17   |
| 1.20.5 ถึง 1.21.x  | 21   |
| 26.1 และใหม่กว่า   | 25   |

ชุดม็อดเก่าต้องการ Java 8 จริง ๆ นี่เป็นหนึ่งในไม่กี่กรณีในซอฟต์แวร์ที่เวอร์ชันล่าสุดนั้นผิด

## ใน Minecraft Server Manager

วิซาร์ดการสร้างจะถามว่าคุณต้องการรันอะไร และเลือกเวอร์ชัน Java จากตารางด้านบน ดังนั้นความไม่ตรงกันจึงไม่เกิดขึ้นโดยอุบัติเหตุ Vanilla, Paper และ Purpur อยู่ในแท็บ **Vanilla** ของมัน; แท็บ **From Mods** จะรับ Fabric, Forge, NeoForge หรือ Quilt พร้อมเวอร์ชัน Minecraft และบิลด์ตัวโหลด (ล่าสุด หรือที่คุณปักหมุด) การติดตั้งชุดม็อดจาก CurseForge, Modrinth หรือ GT New Horizons จะปักหมุดไว้ที่เวอร์ชันที่แน่นอน การอัปเกรดจะเกิดขึ้นเมื่อคุณนำไปใช้ (หรือหลังจากการตรวจสอบรายวัน หากนโยบายการอัปเดตของเซิร์ฟเวอร์คือ **Auto-Update**) จะสำรองข้อมูลก่อนเสมอ และสามารถย้อนกลับได้

เบราว์เซอร์ม็อดจะทราบว่าเซิร์ฟเวอร์รันตัวโหลดใด และกรองสิ่งที่นำเสนอตามนั้น ดังนั้นไฟล์ jar ของ Fabric จึงไม่สามารถตกไปอยู่ในเซิร์ฟเวอร์ NeoForge โดยไม่ได้ตั้งใจ
