儀表板是您的主控中心：顯示所有伺服器、其即時狀態以及正在發生的事件的動態摘要。

![儀表板](/docs/images/dashboard.png)

## 摘要磚塊

位於頂部：

- **線上伺服器** - 您目前正在執行的伺服器數量。
- **已連線玩家** - 所有執行中伺服器的總玩家數量。
- **可用更新** - 有新版本的伺服器、套件或模組的數量（[參見更新](/docs/updates/)）。
- **Docker** - 控制面板是否能連線到 Docker daemon，以及其版本。

## 伺服器卡片

每台伺服器都顯示為一張卡片，包含其狀態（執行中、啟動中、已停止、崩潰）、類型和 Minecraft 版本，以及遊戲連接埠。對於正在執行的伺服器，您還可以即時看到**玩家**、**CPU**、**記憶體**和**磁碟**使用率，這些資訊會持續更新。

點擊卡片即可開啟該伺服器。空白的**建立伺服器**卡片和頂部列的**建立伺服器**按鈕都會啟動[建立精靈](/docs/servers/)。

您可以搜尋和排序您的伺服器，並透過右側的切換按鈕在網格和列表佈局之間切換。

## 最近活動

底部的動態消息是一個即時、人類可讀的審計記錄：登入、備份、藍圖匯出、更新檢查、聊天指令變更、伺服器啟動和停止等。每筆記錄都標記了它所屬的伺服器（或控制面板本身）以及發生時間的長度。完整歷史記錄位於[活動](/docs/activity/)頁面。
