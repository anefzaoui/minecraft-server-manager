儀表板是您的主控中心：顯示所有伺服器、其即時狀態，以及近期活動的動態消息。

![儀表板](/docs/images/dashboard.png)

## 摘要磚塊

頂部顯示：

- **線上伺服器**：您目前正在執行的伺服器數量，以及總數。
- **連線玩家**：所有執行中伺服器的總玩家數量。
- **可用更新**：有多少伺服器、套件或模組有新版本（[參見更新](/docs/updates/)）。
- **Docker**：面板是否能連線到 Docker daemon，以及其版本。

第二列會顯示**配置的記憶體**（以及使用量）、所有伺服器資料夾的**已用儲存空間**、**健康狀況 · 24 小時**（過去一天內的崩潰、記憶體不足停止和自動重新啟動），以及分為模組和伺服器層級更新的**更新**。下方則是**依狀態分類的伺服器**（計算每個狀態的伺服器數量），以及**資源概覽**（圖表顯示每個伺服器佔用的記憶體和 CPU 比例）。

## 伺服器卡片

每台伺服器都顯示為一張卡片，包含其狀態（執行中、啟動中、已停止、已崩潰，以及介於中間的狀態，如不健康或停滯）、類型和 Minecraft 版本、遊戲連接埠，以及標籤。每張卡片都會顯示**玩家**和**磁碟**使用量與配額的比較；執行中的伺服器也會持續更新顯示即時的 **CPU** 和**記憶體**使用量。

點擊卡片即可開啟該伺服器。空白的**建立伺服器**卡片和頂部欄的**建立伺服器**按鈕都會啟動[建立精靈](/docs/servers/)。

您可以搜尋伺服器（依名稱、類型、版本或標籤），依狀態、名稱、大小、上次啟動時間或建立時間排序，並使用右側的切換按鈕在網格和列表佈局之間切換。

## 近期活動

底部的動態消息顯示了面板人類可讀審計日誌中的最新項目：登入、備份、藍圖匯出、更新檢查、聊天指令變更、伺服器啟動和停止等。每項記錄都會標記其所屬的伺服器（或面板本身）以及發生時間。**檢視全部**將在[活動](/docs/activity/)頁面上開啟完整的歷史記錄。
