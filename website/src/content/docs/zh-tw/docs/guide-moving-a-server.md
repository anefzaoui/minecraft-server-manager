移動一個世界非常簡單。但要移動一個玩家仍能登入、保留其物品欄、家園和權限的伺服器，這部分就容易出錯。以下的步驟能將停機時間縮短至幾分鐘，並在新的機器不符合預期時提供回退方案。

## 先盤點現況

在動手之前，請務必記錄以下資訊。每一個項目都曾導致遷移失敗，因為被想當然爾而非實際檢查：

- **Minecraft 版本和載入器**，必須完全一致。1.20.1 NeoForge 與 1.20.1 Forge 不同。
- **模組或外掛列表及其版本。** 沒有製作世界的模組，世界將無法載入。
- **Java 版本**，這通常與 Minecraft 版本相關。
- **`server.properties` 中的 `level-name`**。世界資料夾通常不一定命名為 `world`。
- **線上模式 (Online mode)**。如果舊伺服器設定為 `online-mode=false` 而新伺服器設為 `true`，反之亦然，每個玩家都會獲得一個不同的 UUID，因此會得到一個全新的、空的物品欄。這是本頁面中最令人痛苦的錯誤。
- **伺服器資料夾以外的任何東西**，例如外掛的 MySQL 資料庫。

## 先在運行時複製，然後停止時再複製一次

縮短停機時間的訣竅是先進行耗時較長的複製。

1. **在伺服器運行時**，將整個伺服器目錄複製到新機器。對於大型世界，這可能需要一個小時；但沒人會注意到，因為伺服器並未停止。
2. **宣布重新啟動，然後正常停止伺服器。** 正常關閉會讓遊戲將世界資料寫入磁碟；強制終止程序則不會。
3. **再次複製。** 這一次只移動變更的檔案，因此只需幾秒到幾分鐘。
4. **在新機器上啟動伺服器**，如果可以，請使用非公開的連接埠，並親自加入測試。檢查一個您熟悉的地標、您的物品欄，以及模組或外掛是否無誤載入。
5. **然後**再將玩家導向新伺服器。

`rsync -a --delete` 是步驟 1 和 3 的常用工具。請保留權限和時間戳記：以錯誤的使用者複製世界可能導致伺服器無法啟動，且錯誤訊息不會明確指出原因。

## 暫時不要刪除舊的伺服器

請保留舊機器，停止運行但保持完整，至少幾天。這是唯一真正的回退方案。將其關閉電源而非運行，以免有人意外加入被遺棄的伺服器並在那裡建造一週。

## 讓連線位址在遷移後保持不變

如果玩家透過純 IP 位址連線，每次遷移都會迫使所有玩家編輯他們的伺服器列表，而有些人永遠不會這麼做。

使用您控制的網域名稱，並將其指向伺服器。這樣遷移就變成了一個 DNS 變更，而玩家客戶端中的位址保持不變。在遷移前一天降低記錄的 TTL (Time-To-Live)，以便變更能快速傳播。

如果您希望玩家在伺服器運行於非標準連接埠時輸入純網域名稱，SRV 記錄可以實現這一點。這與商業託管服務用來提供 `play.something.net` 的機制相同。

## 在信任新機器之前先進行檢查

以下是不同主機之間可能存在的差異，並在遷移後造成問題的三個項目：

- **防火牆。** 您的遊戲連接埠必須開啟，且僅限您的遊戲連接埠。不要僅僅因為在 localhost 上能正常運作，就將管理面板或地圖暴露在網際網路上。
- **單核心速度。** Minecraft 比核心數量更關心單一核心的速度。八個慢速核心的體驗會比兩個快速核心差。
- **磁碟。** 運行於傳統硬碟或高度共享磁碟區上的世界，在載入區塊時會出現卡頓。

## 離開託管面板

如果您是從提供控制面板而非機器的託管服務商遷移，請找到下載或檔案管理員，並複製整個伺服器目錄，而不僅僅是世界資料夾。請取得模組和外掛的 jar 檔案本身，而非列表：版本很重要，而「最新版」下個月就會是不同的檔案。

同時也要檢查您的備份是否屬於您。只存在於您即將離開的面板中的備份，並非您擁有的備份。

## 在 Minecraft Server Manager 中

整個面板就是一個目錄。將其複製到另一台機器並在那裡啟動面板，會將所有伺服器、世界、備份和設定一併帶走，這使得遷移面板本身變成複製而非遷移。

對於單一伺服器而非全部伺服器，藍圖會將其設定、模組集和釘選的套件版本（如果勾選，還包括活躍的世界）捕捉為單一的 `.mcserver.zip` 檔案，可以在另一個面板中匯入以重建相同的伺服器。當只需要移動世界時，也可以單獨下載和安裝世界。

如果伺服器使用的遊戲連接埠在新機器上已被佔用，或者您想先在非公開連接埠上進行測試，請在 **設定 → 設定檔 (Settings → Configuration)** 中進行更改：**遊戲連接埠 (Game Port)** 卡片中有 **使用下一個可用連接埠 (Use Next Free Port)** 選項，運行中的伺服器會在新的連接埠上重新啟動前詢問，如果無法啟動，則會返回舊連接埠。當您將玩家導向新伺服器時，將其切換回公開連接埠。
