**藍圖**（Blueprint）能將伺服器的完整設定（類型、版本、資源、環境、模組包釘選、自訂模組，以及可選的設定檔和世界）封裝成單一可攜式的 `.mcserver.zip` 檔案，您可以用它來建立新的伺服器。密碼（環境中的密碼、令牌和金鑰）絕不會寫入藍圖。

![藍圖](/docs/images/blueprints.png)

## 匯出

從伺服器的「**設定 → 設定檔**」標籤頁，使用「**匯出為藍圖**」並選擇要包含的內容：伺服器設定檔（永遠包含）、設定檔目錄（預設啟用），以及可選的自訂模組檔案本身（檔案較大，安裝時無需下載任何東西）和活躍中的世界。結果會儲存到您的藍圖庫中，並可供下載分享。

同一個卡片上的「**複製伺服器**」功能，可在一步內完成匯出和匯入，以建立伺服器的副本，可包含或不包含其世界。

## 從藍圖匯入與建立

匯入藍圖檔案（在「**藍圖**」頁面上的「**匯入藍圖**」）或從庫中選擇一個（在其卡片上的「**建立伺服器**」，或精靈的「**從藍圖**」標籤頁）來建立一個與原始伺服器設定完全相同的新伺服器。新伺服器將擁有自己的連接埠和全新的 RCON 密碼。未嵌入的自訂模組會再次下載，並與藍圖記錄的雜湊值進行比對。庫中還包含兩個起始藍圖，一個是 Paper，另一個是 Fabric。

這是最快的方法，可用於：

- 快速啟動完全相同的伺服器（例如：迷你遊戲伺服器網路、生產環境的暫存副本）。
- 在不同面板之間移動伺服器。
- 保留一個已知良好的範本，以便隨時回滾。

由於藍圖會記錄精確的 [模組包釘選](/docs/modpacks/)，因此從藍圖建立的模組包伺服器會安裝相同的釘選版本，不會有意外的升級。
