**藍圖**（Blueprint）能將伺服器的完整設定（類型、版本、資源、環境、模組包釘選，以及可選的設定檔和世界）封裝成單一的可攜檔案，您可以用它來建立新的伺服器。

![藍圖](/docs/images/blueprints.png)

## 匯出

您可以從現有伺服器匯出藍圖，並選擇要包含的內容：設定檔是必選項，另外還可以選擇嵌入檔案和世界資料。匯出的結果會儲存到您的藍圖庫中，並可供下載分享。

## 從藍圖匯入與建立

匯入藍圖檔案（或從藍圖庫中選擇一個）即可建立一個與原始伺服器設定完全相同的新伺服器。這是最快速的方法，可用於：

- 建立完全相同的伺服器（例如：一系列小遊戲伺服器、生產環境的暫存副本）。
- 在不同的控制面板之間遷移伺服器。
- 保留一個已知良好的範本，以便隨時回滾。

由於藍圖會記錄確切的 [模組包釘選](/docs/modpacks/)，因此從藍圖重新建立的模組包伺服器將會安裝相同釘選的版本，不會有意外的升級。
