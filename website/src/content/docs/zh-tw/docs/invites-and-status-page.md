伺服器「設定」群組下的兩個分頁可協助玩家尋找並加入伺服器：「邀請」會寫下朋友連線所需的一切資訊，而「狀態頁面」則會發布一個小型公開頁面，顯示伺服器是否正在運行。兩者都需要伺服器的「設定」權限（[使用者與角色](/docs/users-and-roles/#per-server-permissions)）。

## 邀請

**設定 → 邀請** 包含一個「邀請朋友」卡片：

- **要分享的位址** 會列出您本機網路上的機器位址，加上伺服器的遊戲連接埠；您公開的位址（如果面板能偵測到）；以及「自訂位址…」選項，用於您自行設定的網域或位址，例如 `play.example.com:25565`。
- **邀請文字** 是一個可直接複製貼上的訊息，包含伺服器名稱、您選擇的位址，以及其 Minecraft 版本和類型。「複製邀請文字」會將其複製到剪貼簿。當白名單啟用時，文字會要求朋友提供其 Minecraft 使用者名稱，而卡片會提醒您在他們加入前，於「玩家」分頁中加入每位朋友。
- **朋友所需** 說明玩家端需要什麼：對於原版或插件伺服器（Paper 等），只需要正確的 Minecraft 版本；對於已安裝模組的伺服器，則需要伺服器的模組。

### 用戶端模組包

在已安裝模組的伺服器上，此卡片還會提供「下載用戶端模組包 (.mrpack)」。朋友可以將其匯入 Prism Launcher 或 Modrinth App，這將會安裝伺服器的 Minecraft 版本和模組載入器，下載模組，並將伺服器加入其多人遊戲列表，使用您選擇的位址。

該檔案是根據您自行新增到伺服器的模組（自訂模組疊加層）所建立，這些模組來自 Modrinth。來自其他來源的模組則會顯示在卡片上，以便朋友手動將這些檔案加入其 `mods` 資料夾。對於從模組包建立的伺服器，朋友應該在其啟動器中安裝該模組包，並使用伺服器運行的版本；「概覽」分頁會顯示版本。

### 透過網際網路遊玩

卡片底部的「透過網際網路遊玩（連接埠轉發）」說明了路由器端的設定：將伺服器的遊戲連接埠（TCP 和 UDP）轉發到運行面板的機器，然後分享您帶有連接埠的公開位址。如果您的網路服務供應商使用 CGNAT，則無法進行連接埠轉發，這時就需要使用隧道服務（例如 playit.gg）。面板本身不會開啟路由器連接埠。只有遊戲連接埠才應暴露於網際網路；請保持面板自身的連接埠和 RCON 連接埠關閉（[連接埠一覽](https://github.com/anefzaoui/minecraft-server-manager#ports-at-a-glance)）。

## 狀態頁面

**設定 → 狀態頁面** 可為單一伺服器啟用一個公開頁面，預設為關閉：

1. 開啟卡片。
2. 選擇「頁面位址」：頁面將位於您的面板上的 `/status/<位址>`，該位址為 3 到 40 個小寫字母、數字或連字號，在您的伺服器之間必須是唯一的。
3. 按下「儲存」。接著「開啟頁面」和「複製連結」會提供您可分享的連結。

任何擁有連結的人都可以看到伺服器的名稱、其 MOTD、版本、是否正在運行、玩家數量和上線時間，除此之外沒有其他資訊。該頁面沒有連結到面板，也不需要登入。它讀取面板記憶體中的狀態，因此訪客永遠不會對 Docker daemon 造成負擔。

關閉頁面會保留其位址，因此再次開啟時會恢復相同的連結。對於您自己的頁面或機器人，[公開 API](/docs/public-api/) 會以 JSON 格式返回與狀態相同的資訊。
