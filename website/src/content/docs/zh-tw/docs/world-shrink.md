隨著時間推移，世界會不斷擴展：玩家曾經走過、飛過或被終界珍珠傳送過的每一個地方，都會在磁碟上留下已生成的區塊，即使沒有人再回去過。**壓縮世界**會移除那些幾乎沒有人停留過的區塊，從而節省磁碟空間。當有人再次前往某個區域時，Minecraft 會從世界種子重新生成該區域，因此這對於無人使用的土地是安全的。但是，如果玩家在幾乎沒有停留過的地方建造了任何東西，那些建築也會被移除，這就是為什麼您應該先進行備份（備份就是撤銷操作）。

## 什麼被視為「罕見訪問」

每個區塊都會記錄玩家在其中停留的時間（Minecraft 稱之為 `InhabitedTime`）。預設情況下，壓縮世界會移除總玩家停留時間少於**30 秒**的區塊；壓縮對話方塊可讓您更改此閾值（1 秒至 1 小時），以及保留重生點周圍的區塊數量（預設為 8，`0` 會關閉重生點保護）。

總是會保留以下內容：

- 主世界中，世界**重生點**周圍的區域（從 `level.dat` 讀取）。地獄、終界和自訂維度沒有重生區域。
- 任何無法讀取訪問時間的區塊，例如使用面板無法解碼的壓縮格式（LZ4）保存的世界。預覽和結果會告訴您跳過了多少此類區塊。

世界的每個維度都會被處理：包括 Bukkit 風格的同級資料夾（`world_nether`、`world_the_end`）以及原版和 Forge/Fabric 的佈局（`world/DIM-1`、`world/DIM1`、`world/dimensions/<namespace>/<name>`）。當區塊被移除時，其中的實體和村民興趣點也會一併移除，因此重新生成的區塊不會繼承過時的生物、礦車或工作站點。

## 從「世界」標籤頁進行操作

1. 從「**備份**」標籤頁進行備份。從「世界」標籤頁壓縮不會自動為您備份。
2. 開啟「**世界 → 世界**」，找到您的世界，然後點擊壓縮圖示。
3. 點擊「**預覽**」以大致了解將會移除多少區塊（以及多少兆位元組）。此時尚未進行任何更改；預覽可以在伺服器運行時進行。
4. 點擊「**壓縮世界**」。壓縮會直接編輯世界檔案，因此伺服器必須停止：請先停止伺服器，或勾選選項以一次性停止伺服器、壓縮並重新啟動（即使壓縮失敗，伺服器也會重新啟動）。進度會顯示在任務列中。

## 作為備份的一部分進行操作

在「**備份**」標籤頁，點擊「**立即備份**」之前，請勾選「**之後也壓縮世界**」。備份封存會先寫入（該封存就是您的撤銷操作），然後壓縮世界，但前提是伺服器已停止。如果伺服器正在運行，備份仍會執行，但壓縮會被跳過並附帶提示。

排程備份也有相同的選項：在排程編輯器中，選擇「**備份**」任務，然後勾選「**每次備份後壓縮世界**」。如果您希望它自動執行，請在幾分鐘前搭配一個「**停止伺服器**」的排程。
