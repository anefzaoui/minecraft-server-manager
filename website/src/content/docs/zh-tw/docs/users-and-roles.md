此面板支援多使用者。請在「**設定 → 使用者**」中管理帳戶。

![使用者](/docs/images/settings-users.png)

## 三種角色

| 角色                  | 可執行操作                                                                                        |
| --------------------- | ------------------------------------------------------------------------------------------------- |
| **管理員 (admin)**    | 所有操作：管理使用者、API 金鑰、全域檔案、進階 Docker 設定覆寫，以及所有伺服器操作。              |
| **操作員 (operator)** | 執行和設定伺服器（啟動/停止、主控台、備份、世界、模組、大部分設定），但無法存取僅限管理員的區域。 |
| **檢視者 (viewer)**   | 唯讀。可查看伺服器及其狀態，但無法進行任何變更。                                                  |

所有使用者，包括檢視者，都可以管理自己的[雙重驗證](/docs/two-factor-authentication/)，因為保護自己的登入資訊並非伺服器管理操作。

## 僅限管理員的操作，以及原因

有些操作刻意限制為僅限管理員：

- **使用者管理、API 金鑰和全域檔案。**
- **[公開 API](/docs/public-api/)** - 啟用 `/api/v1` 並建立、範圍設定或撤銷其唯讀的 Bearer 權杖。
- **進階 Docker 設定覆寫** - 自訂容器名稱、額外的連接埠發佈和繫結掛載。繫結掛載可以將任何主機路徑對映到容器中，並與面板的 Docker 存取結合，這相當於主機上的 root 權限。這些欄位僅對管理員顯示。

自訂容器名稱也不能位於面板自身的 `msm-` 命名空間內，因此手動命名的容器永遠不會覆蓋另一個伺服器的名稱，並將停止或命令錯誤地導向到錯誤的實例。

## 管理帳戶

![個人資料圖片](/docs/images/profile-picture.png)

管理員可以從「使用者」表格中建立使用者、變更角色、重設密碼和刪除帳戶。**2FA** 欄顯示該使用者是否已啟用雙重驗證；管理員可以為其他使用者重設 2FA（用於手機遺失和備份代碼的情況），但無法在沒有密碼的情況下停用自己的 2FA，這部分由自助流程處理。

登入失敗會針對每個帳戶進行速率限制（同時有每 IP 和全域帳戶計數器），以減緩暴力破解嘗試，相同的限制也涵蓋 2FA 代碼步驟，因此正確的密碼無法在猜測代碼之前重設計數器。在此之前，登入/2FA/設定端點有一個更粗略的每客戶端 IP 要求限制器，可透過 `RATE_LIMIT_AUTH_PER_15MIN` 進行調整（預設為 100；在反向代理之後，請設定 `TRUST_PROXY` 以便根據實際客戶端 IP 進行計數）。
