面板支援多使用者。請在「**設定 → 使用者**」中管理帳戶。

![使用者](/docs/images/settings-users.png)

## 三種角色

| 角色                  | 每個伺服器的預設權限                                                                            |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| **管理員 (admin)**    | 所有權限：管理使用者、API 金鑰、全域檔案、進階 Docker 覆寫設定，以及所有伺服器操作。            |
| **操作員 (operator)** | 執行和設定伺服器（啟動/停止、主控台、備份、世界、模組、大部分設定），但無法存取管理員專用區域。 |
| **檢視者 (viewer)**   | 唯讀。可查看伺服器及其狀態，但無法進行任何變更。                                                |

所有使用者，包括檢視者，都可以管理自己的 [雙重驗證](/docs/two-factor-authentication/)，因為保護自己的登入資訊並非伺服器管理操作。

角色是每個伺服器的「**預設**」權限。若要在單一伺服器上授予某人不同的權限，請使用下方的「伺服器專用權限」。

## 伺服器專用權限

「**權限**」頁面（位於側邊欄，或「**設定 → 使用者**」下的「**伺服器權限**」）會顯示一個表格：左側列出所有操作員和檢視者，頂部列出所有伺服器。點擊儲存格即可決定該使用者在該單一伺服器上可執行的操作。管理員不會列出，因為他們始終擁有所有權限。

![權限](/docs/images/settings-permissions.png)

每個儲存格代表一組權限：

| 權限                 | 在該伺服器上允許的操作                                               |
| -------------------- | -------------------------------------------------------------------- |
| **檢視 (View)**      | 查看伺服器、其狀態、主控台輸出、玩家、歷史記錄和統計資料。           |
| **電源 (Power)**     | 啟動、停止、重新啟動、終止和重建伺服器。                             |
| **主控台 (Console)** | 執行主控台命令和世界快速操作、傳送聊天訊息，以及管理聊天命令。       |
| **玩家 (Players)**   | 踢出、封鎖、加入白名單、給予 OP 權限，以及編輯玩家備註。             |
| **內容 (Content)**   | 安裝和移除模組、外掛程式、模組包、世界、資料包，以及編輯物品欄。     |
| **備份 (Backups)**   | 建立、還原、下載和刪除備份。                                         |
| **檔案 (Files)**     | 瀏覽、編輯、上傳和下載伺服器檔案、封存的日誌和日誌捆綁包；匯出藍圖。 |
| **設定 (Settings)**  | 變更伺服器設定、屬性、整合、圖示，以及升級版本。                     |
| **刪除 (Delete)**    | 刪除伺服器。                                                         |

![權限編輯器](/docs/images/permissions-editor.png)

在表格下方，「**各權限涵蓋範圍**」會詳細說明每個權限允許的操作、不包含的項目，以及它所解鎖的確切面板路徑。最後一個清單會由測試套件與執行中的程式碼進行比對。

![權限參考](/docs/images/permissions-reference.png)

在手機上，表格會堆疊成每個使用者一張卡片，每台伺服器一列。

各部分如何協同運作：

- **角色是預設值。** 操作員預設擁有所有伺服器的所有權限；檢視者預設僅有檢視權限。儲存格中的淡色文字（工具提示顯示「角色預設值」）表示從未被變更過。
- **儲存格僅針對該伺服器覆寫角色設定。** 為檢視者在某一台伺服器上授予電源和主控台權限，他們就可以執行這些操作，而其他所有伺服器對他們來說仍然是唯讀的。從操作員的主要伺服器上移除刪除權限，他們仍然擁有該伺服器的其他所有權限。
- **所有權限都包含檢視權限。** 你無法對你看不到的伺服器進行操作。
- **關閉所有權限即可隱藏伺服器。** 該伺服器將從使用者的側邊欄、儀表板、備份、排程、活動、更新、模組包、即時狀態、執行中的任務和藍圖中消失，世界庫也會停止顯示該伺服器名稱。直接連結、API 呼叫或主控台連線將會回應「找不到」，如同不存在的伺服器一樣。
- **面板全域操作仍遵循角色設定。** 建立伺服器（包括複製伺服器）、儲存空間、使用者、API 金鑰、全域設定和面板全域排程並非伺服器專用，因此即使檢視者在某些伺服器上擁有權限，仍然無法執行這些操作。操作員保留伺服器建立和面板全域排程的權限；儲存空間、使用者、API 金鑰和全域設定僅限管理員存取。
- **排程遵循伺服器。** 對伺服器執行的排程重啟、備份或命令需要該伺服器上對應的權限（電源、備份或主控台），無論其角色為何。
- **藍圖也遵循伺服器。** 將伺服器匯出為藍圖需要該伺服器的檔案權限，因為封存檔會包含其檔案。從某人看不到的伺服器匯出的藍圖，對該使用者來說也是隱藏的。
- **管理員專用區域在所有伺服器上都保持管理員專用**：聊天機器人、備份保留設定和進階 Docker 覆寫設定。

所有變更都會寫入活動記錄，包含是誰變更了什麼；這些記錄僅對管理員顯示。刪除使用者會移除他們的所有相關記錄。移除伺服器則會保留使用者的記錄，因此對某人隱藏的伺服器在其歷史記錄和保留的備份中仍然保持隱藏。

現有的安裝將保持不變：直到管理員編輯儲存格，否則所有使用者都將擁有其角色先前賦予的權限。

## 管理員專用，及其原因

有些項目特意限制為僅限管理員存取：

- **使用者管理、儲存空間、全域設定、API 金鑰和全域檔案。**
- **[公開 API](/docs/public-api/)**：啟用 `/api/v1` 以及建立、設定範圍或撤銷其唯讀 Bearer 權杖。
- **進階 Docker 覆寫設定**：自訂容器名稱、額外的連接埠發佈和繫結掛載。繫結掛載可以將任何主機路徑對應到容器內，結合面板的 Docker 存取權，這相當於主機的 root 權限。這些欄位僅對管理員顯示。

自訂容器名稱也不能位於面板自身的 `msm-` 命名空間內，因此手動命名的容器永遠不會覆蓋另一個伺服器的名稱，並將停止或命令錯誤地導向到錯誤的實例。

## 管理帳戶

![個人資料圖片](/docs/images/profile-picture.png)

管理員可以從「使用者」表格中建立使用者、變更角色、重設密碼和刪除帳戶。**2FA** 欄位顯示該使用者是否已啟用雙重驗證；管理員可以在該使用者的操作選單中透過「**重設 2FA**」來重設其他使用者的雙重驗證（適用於遺失手機和備份代碼的情況），但無法在沒有密碼的情況下停用自己的雙重驗證，這部分由自助流程處理。

登入失敗會針對每個帳戶進行速率限制（同時有每個 IP 和全域帳戶的計數器），以減緩暴力破解嘗試，相同的限制也涵蓋雙重驗證碼步驟，因此正確的密碼無法在猜測代碼前重設計數器。在此之前，登入/雙重驗證/設定端點有一個更粗略的每個用戶端 IP 請求限制器，可透過 `RATE_LIMIT_AUTH_PER_15MIN` 進行調整（預設為 100；在反向代理後方，請設定 `TRUST_PROXY` 以便根據真實用戶端 IP 進行計數）。
