**儲存空間**頁面顯示您的磁碟使用情況：每個伺服器的用量及其隨時間的趨勢。

![儲存空間](/docs/images/storage.png)

## 磁碟配額由面板強制執行

Docker 無法限制 bind mount 的磁碟使用量，因此由面板來處理。背景的空間索引器會掃描資料目錄，快取每個伺服器的佔用空間，並強制執行您為每個伺服器設定的磁碟配額。當伺服器的資料（世界 + 備份 + 其他所有內容）接近其配額時，面板會阻止其無限制增長，而不是讓一個伺服器填滿您的主機。

在伺服器的[設定](/docs/servers/)中設定配額。模組化伺服器及其[備份](/docs/backups/)可能會很大，因此請為它們預留足夠的空間。

## 清理

儲存空間檢視可協助您在空間不足之前，找出要刪除的項目（舊備份、未使用過的伺服器世界，或遠遠超出預期的伺服器），以進行修剪。
