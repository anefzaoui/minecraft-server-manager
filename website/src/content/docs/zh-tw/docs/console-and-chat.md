## 即時主控台

**主控台**（Console）標籤頁會即時串流伺服器日誌，並提供一個指令方塊，讓您輸入任何伺服器指令。無需 `docker exec`，無需 SSH。輸出會直接顯示，包含顏色等所有格式。

![主控台](/docs/images/server-console.png)

主控台也是面板讀取伺服器狀態的地方：它會監控日誌來分類啟動階段（「載入模組」、「產生世界」、「完成啟動」），並呼叫 `list` 來追蹤誰在線上，因此儀表板和伺服器卡片始終反映實際情況。

這種輪詢會在每個週期開啟一個短暫的 RCON 連線，伺服器日誌會顯示為約每 20 秒一對 `Thread RCON Client … started` / `shutting down` 訊息，以及（在核心或外掛程式會回顯的伺服器上）每次唯讀輪詢的 `Rcon issued server command: …` 行——用於玩家計數的 `list`，以及在「世界控制」頁面開啟時讀取的 `time query …` 和 `gamerule <name>`。主控台日誌上方的「隱藏 RCON 雜訊」開關會過濾掉這些行（以及 RCON 監聽器啟動行）。此選項預設開啟，並會記住每個瀏覽器的設定；關閉它即可查看原始日誌串流。

從面板發送的指令可以根據伺服器標籤在遊戲內公告，讓玩家知道是管理員操作，而不是神秘的主控台。

## 聊天指令

聊天指令讓玩家可以透過在遊戲聊天中輸入前置指令來觸發面板動作，例如輸入 `!spawn` 進行隨機傳送。偵測是基於日誌的，執行也是透過伺服器進行，因此**無需安裝任何模組**。

![聊天指令](/docs/images/chat-commands.png)

每個指令包含：

- 一個**觸發詞**（例如 `spawn`）和一個**前置詞**（預設為 `!`）。
- 一個**動作**：隨機傳送、傳送到結構、傳送到生物群系，或執行原始主控台指令。
- 一個**權限等級**：所有人、白名單玩家，或僅限管理員。
- 一個**冷卻時間**，以及可自訂的待處理/成功/失敗訊息，包含 `{distance}` 等佔位符。

### 安全注意事項

可能破壞伺服器的指令（`stop`、`op`、`ban`、`whitelist` 等）僅允許用於**僅限管理員**的觸發詞。即使這些指令嵌套在 `execute … run …` 鏈中，面板也會進行檢查，因此低權限的觸發詞無法偷偷執行危險指令。僅僅提及這些詞彙的普通聊天文字（例如 `say` 訊息）則不受影響。
