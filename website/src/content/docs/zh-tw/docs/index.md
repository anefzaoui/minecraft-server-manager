一個完整、自行託管的控制面板，適用於 [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server)。透過瀏覽器建立、執行和管理 Minecraft 伺服器。無需命令列，無需手動編輯 YAML。

![儀表板](/docs/images/dashboard.png)

## 開始

- **[入門指南](/docs/getting-started/)** - 首次設定、登入以及熟悉介面。
- **[儀表板](/docs/dashboard/)** - 所有伺服器、玩家和活動的一目了然的檢視。

## 執行伺服器

- **[建立與管理伺服器](/docs/servers/)** - 建立精靈、伺服器類型、版本以及個別伺服器設定。
- **[主控台與聊天指令](/docs/console-and-chat/)** - 即時主控台，以及以玩家身分執行的自訂遊戲內聊天指令。
- **[模組包](/docs/modpacks/)** - 安裝 CurseForge、Modrinth、FTB 和 GT New Horizons 套件，始終固定到確切的版本。
- **[世界與檔案](/docs/worlds-and-files/)** - 在瀏覽器中交換世界、管理模組以及編輯檔案。
- **[縮減世界](/docs/world-shrink/)** - 透過移除無人訪問的區塊來回收磁碟空間，可單獨執行或作為備份的一部分。

## 資料與自動化

- **[個別伺服器聊天機器人](/docs/chatbot/)** - 本機/OpenAI 相容的對話、外展、保留的對話記錄以及受限的遊戲玩法權力。
- **[備份](/docs/backups/)** - 一鍵快照、排程備份和還原。
- **[藍圖](/docs/blueprints/)** - 擷取伺服器的完整設定，並從中建立新的伺服器。
- **[排程](/docs/schedules/)** - cron 驅動的重新啟動、備份和指令。
- **[儲存空間](/docs/storage/)** - 個別伺服器的磁碟使用量和面板強制配額。
- **[更新](/docs/updates/)** - 追蹤新的伺服器、套件、映像檔和模組版本。
- **[活動記錄](/docs/activity/)** - 所有事件的稽核記錄。
- **[整合](/docs/integrations/)** - Discord 訊息通知和「通知」類別。
- **[公開 API](/docs/public-api/)** - 一個僅供讀取的、透過權杖驗證的 HTTP API，用於從面板外部擷取伺服器狀態。

## 帳戶與安全性

- **[使用者與角色](/docs/users-and-roles/)** - 管理員、操作員和檢視者，以及他們各自的功能。
- **[雙重驗證](/docs/two-factor-authentication/)** - 使用驗證器應用程式保護您的登入。

## 底層架構

- **[架構](/docs/architecture/)** - 控制面板的組成方式。
- **[網站](/docs/website/)** - minecraft-server-manager.com 如何從此儲存庫建置、翻譯和部署。
