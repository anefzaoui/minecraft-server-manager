Ένα πλήρες, self-hosted control panel για το [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server). Δημιουργήστε, εκτελέστε και διαχειριστείτε servers Minecraft από τον browser σας. Χωρίς γραμμή εντολών, χωρίς χειροκίνητη επεξεργασία YAML.

![Dashboard](/docs/images/dashboard.png)

## Ξεκινήστε εδώ

- **[Οδηγός γρήγορης εκκίνησης](/docs/getting-started/)** - αρχική ρύθμιση, σύνδεση και πλοήγηση.
- **[Το dashboard](/docs/dashboard/)** - η επισκόπηση όλων των servers, παικτών και δραστηριοτήτων με μια ματιά.

## Εκτέλεση servers

- **[Δημιουργία & διαχείριση servers](/docs/servers/)** - ο οδηγός δημιουργίας, τύποι servers, εκδόσεις και ρυθμίσεις ανά server.
- **[Κονσόλα & εντολές chat](/docs/console-and-chat/)** - η ζωντανή κονσόλα και προσαρμοσμένες εντολές εντός παιχνιδιού που εκτελούνται ως ο παίκτης.
- **[Modpacks](/docs/modpacks/)** - εγκαταστήστε πακέτα CurseForge, Modrinth, FTB και GT New Horizons, πάντα καρφιτσωμένα σε μια ακριβή έκδοση.
- **[Κόσμοι & αρχεία](/docs/worlds-and-files/)** - εναλλαγή κόσμων, διαχείριση mods και επεξεργασία αρχείων απευθείας στον browser.
- **[Σμίκρυνση κόσμου](/docs/world-shrink/)** - ανάκτηση χώρου στο δίσκο αφαιρώντας κομμάτια (chunks) που κανείς δεν επισκέπτεται, αυτόνομα ή ως μέρος ενός αντιγράφου ασφαλείας.

## Δεδομένα & αυτοματισμός

- **[Chatbot ανά server](/docs/chatbot/)** - τοπική συνομιλία συμβατή με OpenAI, ειδοποιήσεις, διατήρηση ιστορικού συνομιλιών και περιορισμένες δυνατότητες παιχνιδιού.
- **[Αντίγραφα ασφαλείας (Backups)](/docs/backups/)** - στιγμιότυπα με ένα κλικ, προγραμματισμένα αντίγραφα ασφαλείας και επαναφορά.
- **[Πρότυπα (Blueprints)](/docs/blueprints/)** - αποτυπώστε ολόκληρη τη διαμόρφωση ενός server και δημιουργήστε νέους από αυτήν.
- **[Προγραμματισμός (Schedules)](/docs/schedules/)** - επανεκκινήσεις, αντίγραφα ασφαλείας και εντολές μέσω cron.
- **[Αποθήκευση (Storage)](/docs/storage/)** - χρήση δίσκου ανά server και όρια που επιβάλλονται από το panel.
- **[Ενημερώσεις (Updates)](/docs/updates/)** - παρακολούθηση νέων εκδόσεων server, πακέτων, εικόνων (images) και mods.
- **[Αρχείο δραστηριοτήτων (Activity log)](/docs/activity/)** - ένα αρχείο ελέγχου για οτιδήποτε συνέβη.
- **[Ενσωματώσεις (Integrations)](/docs/integrations/)** - ειδοποιήσεις webhook Discord και η κατηγορία Alerts.
- **[Δημόσιο API (Public API)](/docs/public-api/)** - ένα HTTP API μόνο για ανάγνωση, με έλεγχο ταυτότητας μέσω token, για τη λήψη της κατάστασης του server από εξωτερικά συστήματα.

## Λογαριασμοί & ασφάλεια

- **[Χρήστες & ρόλοι](/docs/users-and-roles/)** - διαχειριστής (admin), χειριστής (operator) και θεατής (viewer), και τι μπορεί να κάνει ο καθένας.
- **[Έλεγχος ταυτότητας δύο παραγόντων (Two-factor authentication)](/docs/two-factor-authentication/)** - προστατέψτε τη σύνδεσή σας με μια εφαρμογή ελέγχου ταυτότητας.

## Εσωτερική λειτουργία

- **[Αρχιτεκτονική](/docs/architecture/)** - πώς είναι δομημένο το panel.
- **[Ο ιστότοπος](/docs/website/)** - πώς κατασκευάζεται, μεταφράζεται και αναπτύσσεται το minecraft-server-manager.com από αυτό το αποθετήριο.
