Ένα πλήρες, αυτο-φιλοξενούμενο πάνελ ελέγχου για το [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server). Δημιουργήστε, εκτελέστε και διαχειριστείτε servers Minecraft από το πρόγραμμα περιήγησής σας. Χωρίς γραμμή εντολών, χωρίς χειροκίνητη επεξεργασία YAML.

![Dashboard](/docs/images/dashboard.png)

## Ξεκινήστε εδώ

- **[Οδηγός έναρξης](/docs/getting-started/)** - αρχική ρύθμιση, σύνδεση και πλοήγηση.
- **[Το ταμπλό](/docs/dashboard/)** - η επισκόπηση όλων των servers, παικτών και δραστηριότητας με μια ματιά.

## Εκτέλεση servers

- **[Δημιουργία & διαχείριση servers](/docs/servers/)** - ο οδηγός δημιουργίας, τύποι servers, εκδόσεις και ρυθμίσεις ανά server.
- **[Κονσόλα & εντολές συνομιλίας](/docs/console-and-chat/)** - η ζωντανή κονσόλα και προσαρμοσμένες εντολές συνομιλίας εντός παιχνιδιού που εκτελούνται ως ο παίκτης.
- **[Modpacks](/docs/modpacks/)** - εγκαταστήστε πακέτα CurseForge, Modrinth, FTB και GT New Horizons, πάντα καρφιτσωμένα σε μια ακριβή έκδοση.
- **[Κόσμοι & αρχεία](/docs/worlds-and-files/)** - εναλλαγή κόσμων, διαχείριση mods και επεξεργασία αρχείων απευθείας στο πρόγραμμα περιήγησης.
- **[Σμίκρυνση κόσμου](/docs/world-shrink/)** - ανάκτηση χώρου στο δίσκο αφαιρώντας κομμάτια που κανείς δεν επισκέπτεται, αυτόνομα ή ως μέρος αντιγράφου ασφαλείας.
- **[Ζωντανός χάρτης](/docs/live-map/)** - ένας τρισδιάστατος χάρτης του κόσμου με ένα κλικ από το BlueMap, πίσω από τη σύνδεση του πάνελ.
- **[Προσκλήσεις & σελίδα κατάστασης](/docs/invites-and-status-page/)** - η διεύθυνση, το κείμενο πρόσκλησης και το πακέτο mod πελάτη για φίλους, και μια δημόσια σελίδα κατάστασης.

## Δεδομένα & αυτοματισμός

- **[Chatbot ανά server](/docs/chatbot/)** - τοπική συνομιλία συμβατή με OpenAI, επικοινωνία, διατηρούμενες συνομιλίες και περιορισμένες δυνατότητες παιχνιδιού.
- **[Αντίγραφα ασφαλείας](/docs/backups/)** - στιγμιότυπα με ένα κλικ, προγραμματισμένα αντίγραφα ασφαλείας, πόσα να κρατήσετε (για ολόκληρο το πάνελ ή ανά server) και επαναφορά.
- **[Προσχέδια](/docs/blueprints/)** - καταγράψτε ολόκληρη τη διαμόρφωση ενός server και δημιουργήστε νέους από αυτήν.
- **[Προγραμματισμοί](/docs/schedules/)** - επανεκκινήσεις, αντίγραφα ασφαλείας και εντολές που οδηγούνται από cron.
- **[Αποθήκευση](/docs/storage/)** - χρήση δίσκου ανά server και όρια που επιβάλλονται από το πάνελ.
- **[Ενημερώσεις](/docs/updates/)** - παρακολούθηση νέων εκδόσεων server, πακέτων, εικόνων και mods, έλεγχος ποιες εκδόσεις Minecraft υποστηρίζουν τα mods σας και αναίρεση μιας ενημέρωσης mod.
- **[Αρχείο δραστηριοτήτων](/docs/activity/)** - ένα αρχείο ελέγχου για όλα όσα συνέβησαν.
- **[Ενσωματώσεις](/docs/integrations/)** - ειδοποιήσεις webhook Discord και η κατηγορία Ειδοποιήσεις.
- **[Δημόσιο API](/docs/public-api/)** - ένα API HTTP μόνο για ανάγνωση, πιστοποιημένο με token, για τη λήψη της κατάστασης του server από έξω από το πάνελ.

## Λογαριασμοί & ασφάλεια

- **[Χρήστες & ρόλοι](/docs/users-and-roles/)** - διαχειριστής, χειριστής και θεατής, τι μπορεί να κάνει ο καθένας και δικαιώματα ανά server που τους βελτιώνουν.
- **[Έλεγχος ταυτότητας δύο παραγόντων](/docs/two-factor-authentication/)** - προστατέψτε τη σύνδεσή σας με μια εφαρμογή ελέγχου ταυτότητας.

## Οδηγοί

Δεν αφορούν συγκεκριμένα αυτό το πάνελ: οι ερωτήσεις που αντιμετωπίζει κάθε ιδιοκτήτης server Minecraft.

- **[Πόση RAM χρειάζεται ένας server;](/docs/guide-server-memory/)** - οι δύο αριθμοί που πρέπει να οριστούν και γιατί ένας αδρανής server διαβάζει 12 GB.
- **[Vanilla, Paper, Fabric, Forge, NeoForge, Quilt](/docs/guide-choosing-a-loader/)** - ποιο να εκτελέσετε και η διαφορά plugin/mod πίσω από την επιλογή.
- **[Ο server σας δεν θα ξεκινήσει](/docs/guide-server-wont-start/)** - ανάγνωση του αρχείου καταγραφής και οι λίγες αιτίες πίσω από τις περισσότερες αποτυχίες.
- **[Αντίγραφα ασφαλείας που επαναφέρουν πραγματικά](/docs/guide-backups/)** - συνεπή αντίγραφα, τι άλλο να κρατήσετε και δοκιμή ενός πριν το χρειαστείτε.
- **[Μετακίνηση server σε άλλο host](/docs/guide-moving-a-server/)** - η σειρά που διατηρεί τον χρόνο διακοπής σύντομο και τα αποθέματα άθικτα.
