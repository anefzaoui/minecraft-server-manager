Η σελίδα **Modpacks** (και η καρτέλα **Από modpack** στον [οδηγό δημιουργίας](/docs/servers/)) εγκαθιστά ένα modpack ως διακομιστή, πάντα **καρφιτσωμένο σε ακριβή έκδοση του πακέτου** ώστε μια επανεκκίνηση να μην μπορεί ποτέ να αναβαθμίσει σιωπηλά το πακέτο κάτω από εσάς.

![Modpacks](/docs/images/modpacks.png)

## Υποστηριζόμενες πλατφόρμες

- **CurseForge** - αναζητήστε ή επικολλήστε ένα URL πακέτου. Χρειάζεται ένα κλειδί API του CurseForge για αναζήτηση και ιδιωτικά πακέτα (προσθέστε το στις Ρυθμίσεις → Κλειδιά API).
- **Modrinth** - αναζητήστε με όνομα.
- **FTB** - πακέτα Feed The Beast.
- **GT New Horizons** - το πακέτο ειδικών 1.7.10, εγκατεστημένο από τον δικό του δείκτη κυκλοφορίας του GTNH. Το GTNH επιλέγει το περιβάλλον εκτέλεσης Java του ανά έκδοση πακέτου (το 2.8.0+ εκτελείται σε **Java 25** μέσω ενσωματωμένων επιδιορθώσεων lwjgl3ify, παλαιότερες εκδόσεις σε Java 21 ή 17), και ο οδηγός αυξάνει τη RAM και τον δίσκο του διακομιστή σε λογικά ελάχιστα για αυτό.
- **Προσαρμοσμένο zip** - καθόλου δημοσιευμένο πακέτο: ανεβάστε μια **εξαγωγή modpack του CurseForge** (το zip με το `manifest.json` που παράγει η εφαρμογή του CurseForge για ένα επιλεγμένο σύνολο mods) ή **οποιοδήποτε zip αρχείων jar με mods**. Το πάνελ επιλύει το manifest μαζικά μέσω του API του CurseForge (ή αναγνωρίζει κάθε jar με hash/δακτυλικό αποτύπωμα/μεταδεδομένα), προεπισκοπεί τι ταιριάζει και εγκαθιστά τα πάντα σε μία εργασία - συμπεριλαμβανομένων των ρυθμίσεων `overrides/` του πακέτου αν επιλέξετε. Τα mods των οποίων οι δημιουργοί απαγορεύουν τις αυτοματοποιημένες λήψεις παρατίθενται με σύνδεσμο προγράμματος περιήγησης και μια θέση μη αυτόματης μεταφόρτωσης αντί να αποτύχει η εγκατάσταση.

## Πώς λειτουργεί το καρφίτσωμα

Όταν επιλέγετε ένα πακέτο, το πάνελ επιλύει την ακριβή έκδοση, την καταγράφει και την εγκαθιστά. Στη σελίδα **Ενημερώσεις** θα ενημερωθείτε όταν είναι διαθέσιμη μια νεότερη έκδοση. η αναβάθμιση είναι μια σκόπιμη, φυλασσόμενη ενέργεια με αντίγραφο ασφαλείας πριν την αναβάθμιση και επαναφορά. Οι διακομιστές σταθερής παρακολούθησης δεν προσφέρονται ποτέ σε beta.

Οι διακομιστές που δημιουργήθηκαν σε πολύ παλιές εκδόσεις του πάνελ (πριν από την 0.9.7) θα μπορούσαν να μείνουν _χωρίς καρφίτσωμα_, που σημαίνει ότι η εικόνα του κοντέινερ θα εγκαθιστούσε σιωπηλά την πιο πρόσφατη έκδοση του πακέτου σε κάθε εκκίνηση. Το πάνελ τώρα τα διορθώνει κατά την εκκίνηση: κλειδώνει το καθένα στην έκδοση που είναι πραγματικά εγκατεστημένη (διαβάζεται από τις δικές του καταγραφές του πάνελ ή το manifest εγκατάστασης της εικόνας, ποτέ ένα φρεσκο-επιλυμένο "latest") και καταγράφει ένα συμβάν. Εάν δεν μπορεί να προσδιορίσει τι είναι εγκατεστημένο, η σελίδα Ρυθμίσεις του διακομιστή εμφανίζει μια προειδοποίηση που σας ζητά να επιλέξετε την έκδοση χειροκίνητα, και οποιαδήποτε προσπάθεια αποθήκευσης μιας μη καρφιτσωμένης διαμόρφωσης modpack απορρίπτεται αμέσως.

## Πολιτική ενημέρωσης

Κάθε διακομιστής έχει μια πολιτική ενημέρωσης στις **Ρυθμίσεις**, και και οι τρεις επιλογές σημαίνουν ό,τι λένε:

- **Μόνο χειροκίνητα** - τίποτα δεν αλλάζει από μόνο του, και ο διακομιστής παραλείπεται εντελώς από την επισήμανση ενημέρωσης και τη σελίδα Ενημερώσεις. Η λειτουργία "άφησέ με ήσυχο": ιδανική για ένα χειροκίνητα ρυθμισμένο ή εισαγόμενο πακέτο που δεν θέλετε ποτέ να πειραχτεί.
- **Ειδοποίησέ με** (προεπιλογή) - ο καθημερινός έλεγχος εμφανίζει τις διαθέσιμες ενημερώσεις ως επισήμανση και στη σελίδα Ενημερώσεις. η εφαρμογή τους είναι πάντα με ένα κλικ σας.
- **Αυτόματη ενημέρωση** - μετά τον προγραμματισμένο καθημερινό έλεγχο, οι εκκρεμείς ενημερώσεις **πακέτου** εφαρμόζονται μέσω της ίδιας φυλασσόμενης διαδρομής με μια χειροκίνητη αναβάθμιση: αντίγραφο ασφαλείας πριν την αναβάθμιση, παρακολούθηση υγείας και αυτόματη επαναφορά εάν η νέα έκδοση αποτύχει να εκκινήσει. Οι ενημερώσεις που θα μετακινούσαν τον διακομιστή σε διαφορετική έκδοση Minecraft παραλείπονται πάντα με ένα συμβάν αντί γι' αυτό - η μετατροπή ενός κόσμου μόνιμα είναι μια απόφαση που το πάνελ αρνείται να λάβει για εσάς. Τα χειροκίνητα κουμπιά "έλεγχος τώρα" ελέγχουν μόνο. ποτέ δεν ενεργοποιούν αυτόματες ενημερώσεις.

## Αναβάθμιση ενός πακέτου

Από έναν καρφιτσωμένο διακομιστή μπορείτε να αναβαθμίσετε σε μια νεότερη έκδοση με μία ενέργεια. Το πάνελ παίρνει πρώτα ένα αντίγραφο ασφαλείας, αλλάζει την καρφιτσωμένη έκδοση, αναδημιουργεί το κοντέινερ (επιλύοντας ξανά τη Java αν η νέα έκδοση χρειάζεται διαφορετικό runtime) και παρακολουθεί την πρώτη εκκίνηση, με ένα γενναιόδωρο παράθυρο για μεγάλα πακέτα όπως το GTNH που κατεβάζουν μερικά gigabytes και δημιουργούν έναν κόσμο με εκατοντάδες mods κατά την πρώτη εκκίνηση.
