## Αρχική ρύθμιση

Την πρώτη φορά που θα ανοίξετε τον πίνακα ελέγχου, ένας σύντομος οδηγός ρύθμισης θα σας καθοδηγήσει:

1.  **Έλεγχος Συστήματος**: Εξασφαλίζει ότι το Docker είναι προσβάσιμο, το Node.js είναι επαρκώς ενημερωμένο και ο φάκελος δεδομένων έχει δικαιώματα εγγραφής. Αν το Docker δεν εκτελείται ακόμα, μπορείτε να συνεχίσετε· η δημιουργία και η εκκίνηση διακομιστών περιμένουν μέχρι να είναι διαθέσιμο.
2.  **Δημιουργία Λογαριασμού Διαχειριστή**: Αυτός είναι ο μοναδικός λογαριασμός που υπάρχει μέχρι να προσθέσετε άλλους και έχει πλήρη έλεγχο. Επιλέξτε ένα όνομα χρήστη (2 έως 32 χαρακτήρες) και έναν κωδικό πρόσβασης τουλάχιστον 8 χαρακτήρων. Θα συνδεθείτε αμέσως μόλις δημιουργηθεί.
3.  **Ρύθμιση Πίνακα Ελέγχου** (προαιρετικό): Ένα δημόσιο όνομα τομέα για να εμφανίζεται στους παίκτες στις διευθύνσεις σύνδεσης, ένα κλειδί API του CurseForge και η ζώνη ώρας σας. Όλα αυτά μπορούν να αλλάξουν αργότερα στις **Ρυθμίσεις**.

Το τελευταίο βήμα προσφέρει **Δημιουργία Διακομιστή** ή **Μετάβαση στον Πίνακα Ελέγχου**.

![Το βήμα Ελέγχου Συστήματος της αρχικής ρύθμισης](/docs/images/setup-system-check.png)

> **Οι δημόσιες εγκαταστάσεις προστατεύονται με PIN.** Αν ξεκινήσετε τον πίνακα ελέγχου συνδεδεμένο σε μια διεύθυνση που δεν είναι loopback (`PANEL_HOST` εκτός από `127.0.0.1`), η σελίδα ρύθμισης ζητά επίσης ένα **PIN 6 ψηφίων**. Ο πίνακας ελέγχου το εμφανίζει στην κονσόλα του κατά την εκκίνηση. Εισάγετέ το μαζί με το όνομα χρήστη και τον κωδικό πρόσβασής σας. Αυτό εμποδίζει έναν άγνωστο που φτάνει πρώτος στη θύρα να διεκδικήσει τον λογαριασμό διαχειριστή. Το PIN εξαφανίζεται μόλις δημιουργηθεί ο λογαριασμός διαχειριστή.

## Σύνδεση

Μετά τη ρύθμιση, ο πίνακας ελέγχου προστατεύεται από μια οθόνη σύνδεσης. Εισάγετε το όνομα χρήστη και τον κωδικό πρόσβασής σας για να συνεχίσετε.

![Σύνδεση](/docs/images/login.png)

Αν η [έλεγχος ταυτότητας δύο παραγόντων](/docs/two-factor-authentication/) είναι ενεργοποιημένη στον λογαριασμό σας, θα σας ζητηθεί ένας κωδικός 6 ψηφίων από την εφαρμογή ελέγχου ταυτότητας αμέσως μετά τον κωδικό πρόσβασής σας.

## Εύρεση του τρόπου λειτουργίας

Όλα κρέμονται από την αριστερή πλαϊνή μπάρα:

- **Πίνακας Ελέγχου**: Όλοι οι διακομιστές με μια ματιά ([λεπτομέρειες](/docs/dashboard/)).
- **Διακομιστές**, **Modpacks**, **Κόσμοι**, **Blueprints**: Δημιουργία και διαχείριση διακομιστών και του περιεχομένου τους.
- **Ενημερώσεις**, **Αντίγραφα Ασφαλείας**, **Προγραμματισμοί**, **Αποθήκευση**, **Δραστηριότητα**: Η λειτουργική πλευρά: τι είναι ξεπερασμένο, τα στιγμιότυπά σας, αυτοματισμός, χρήση δίσκου και το αρχείο καταγραφής ελέγχου.
- **Δικαιώματα** (κάτω, μόνο για διαχειριστές): Τι μπορεί να κάνει κάθε χρήστης σε κάθε διακομιστή ([λεπτομέρειες](/docs/users-and-roles/#per-server-permissions)).
- **Ρυθμίσεις** (κάτω, μόνο για διαχειριστές): Κλειδιά API, ρύθμιση πίνακα ελέγχου, προεπιλογές για νέους διακομιστές, [διατήρηση αντιγράφων ασφαλείας](/docs/backups/#retention), χρήστες, ασφάλεια σύνδεσης και το δημόσιο API.

Κάτω από αυτά, η πλαϊνή μπάρα παραθέτει τους διακομιστές σας. Το άνοιγμα ενός εμφανίζει τις δικές του καρτέλες: **Επισκόπηση**, **Κονσόλα**, **Παίκτες**, **Mods**, **Κόσμος**, **Αντίγραφα Ασφαλείας**, **Παρακολούθηση** και **Ρυθμίσεις**, οι περισσότερες με σχετικές υποκαρτέλες (για παράδειγμα, **Ρυθμίσεις → Διαμόρφωση** περιέχει τις ρυθμίσεις του διακομιστή και τη θύρα παιχνιδιού του). Δείτε [Ένας μεμονωμένος διακομιστής](/docs/servers/#a-single-server).

Η επάνω μπάρα έχει το κουμπί **Δημιουργία Διακομιστή**, έναν **εναλλάκτη θέματος** (σκούρο/φωτεινό) και το **μενού λογαριασμού σας**, όπου μπορείτε να αλλάξετε την εικόνα προφίλ σας, να διαχειριστείτε την [έλεγχο ταυτότητας δύο παραγόντων](/docs/two-factor-authentication/) ή να αποσυνδεθείτε.

## Τι χρειάζεστε

Ο πίνακας ελέγχου επικοινωνεί με το Docker για την εκτέλεση διακομιστών, επομένως χρειάζεται πρόσβαση σε ένα daemon Docker (Docker Desktop ή υποδοχή Docker Engine). Όταν το Docker είναι προσβάσιμο, το πλακίδιο Docker στον πίνακα ελέγχου εμφανίζει **Συνδεδεμένο** και την έκδοσή του. Αν δεν είναι, ο πίνακας ελέγχου εξακολουθεί να εκτελείται. Απλώς δεν μπορείτε να ξεκινήσετε διακομιστές μέχρι να είναι ενεργό το daemon.
