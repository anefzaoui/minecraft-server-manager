[← Επιστροφή στον δείκτη τεκμηρίωσης](/docs/)

Ένα μικρό, μόνο για ανάγνωση, HTTP API για τη λήψη της κατάστασης του διακομιστή από έξω από τον πίνακα ελέγχου: ένα
ταμπλό κατάστασης, ένας παρακολουθητής χρόνου λειτουργίας, ένα Discord bot, ένας κανόνας αυτοματισμού σπιτιού. Εξυπηρετείται
από τον ίδιο τον πίνακα ελέγχου και επιστρέφει τα ίδια ζωντανά δεδομένα που εμφανίζουν οι δικές του σελίδες
(από την κρυφή μνήμη στη μνήμη RAM), οπότε η αναζήτησή του δεν αγγίζει ποτέ το Docker.

Είναι **απενεργοποιημένο μέχρι να το χρησιμοποιήσει ένας διαχειριστής** και **ελέγχεται από διαχειριστή**. Τίποτα δεν εκτίθεται
μέχρι να υπάρχει ένα token.

## Ενεργοποίηση

**Ρυθμίσεις → Δημόσιο API → Νέο Κλειδί**. Δώστε του ένα όνομα, επιλέξτε τι μπορεί να δει (όλοι οι διακομιστές ή ένα συγκεκριμένο υποσύνολο) και, προαιρετικά, μια ημερομηνία λήξης. Το πλήρες κλειδί (ένα Bearer token) εμφανίζεται **μία φορά**, σε ένα παράθυρο διαλόγου· αντιγράψτε το τώρα, επειδή μόνο μια σύντομη πρόθεμα διατηρείται στη συνέχεια, για αναγνώριση στη λίστα.

![Ρυθμίσεις Δημόσιου API](/docs/images/settings-public-api.png)

Η δημιουργία του πρώτου κλειδιού ενεργοποιεί αυτόματα το API (ο διακόπτης **Να επιτρέπεται σε εξωτερικές εφαρμογές
να διαβάζουν την κατάσταση** είναι ένας έλεγχος παύσης: απενεργοποιήστε τον για να σταματήσετε την εξυπηρέτηση χωρίς να ακυρώσετε κανένα κλειδί). Ακυρώστε ένα κλειδί από τον ίδιο πίνακα ανά πάσα στιγμή· οι πελάτες που το χρησιμοποιούν χάνουν
άμεσα την πρόσβαση.

Τα tokens αποθηκεύονται ως hash SHA-256 (ποτέ σε απλό κείμενο), επιβιώνουν από επανεκκίνηση του πίνακα ελέγχου και υπερβαίνουν τους διακομιστές στους οποίους εστιάζουν (ένας διαγραμμένος διακομιστής απλώς
εξαφανίζεται από τα αποτελέσματα αυτού του token).

## Έλεγχος ταυτότητας

Στείλτε το token ως διαπιστευτήριο Bearer:

```
Authorization: Bearer msm_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Δεν υπάρχουν cookies και **όχι CORS**: αυτό είναι για κλήσεις από διακομιστή σε διακομιστή και CLI,
όχι για εφαρμογές περιηγητή από άλλη προέλευση. Εάν ο πίνακας ελέγχου βρίσκεται πίσω από έναν αντίστροφο διακομιστή μεσολάβησης (reverse proxy), βεβαιωθείτε ότι ο διακομιστής μεσολάβησης προωθεί την κεφαλίδα `Authorization`.

Οι αποτυχίες επιστρέφουν `401` με `{ "ok": false, "error": "..." }`. Οτιδήποτε άλλο εκτός από `GET`
(ή `HEAD`) επιστρέφει `405`. Άγνωστα μονοπάτια επιστρέφουν `404`. Όταν το API είναι απενεργοποιημένο, όλες οι διαδρομές
επιστρέφουν `404`.

## Όριο ρυθμού

Κάθε token λαμβάνει τον δικό του προϋπολογισμό, `RATE_LIMIT_PUBLIC_API_PER_MIN` (προεπιλογή `120`
αιτήματα/λεπτό· `0` απενεργοποιεί τον περιοριστή). Υπέρβαση του ορίου επιστρέφει `429`. Τα αιτήματα που
δεν παρουσιάζουν ποτέ ένα έγκυρο token (λείπει, είναι εσφαλμένο, έχει ανακληθεί ή έχει λήξει) περιορίζονται ξεχωριστά ανά διεύθυνση IP πελάτη πέντε φορές αυτόν τον αριθμό, ώστε η διερεύνηση να μην παρακάμπτει τον προϋπολογισμό περιστρέφοντας
tokens.

## Τελικά σημεία (Endpoints)

### `GET /api/v1/servers`

Κάθε διακομιστής στον οποίο εστιάζει το token.

```json
{
  "ok": true,
  "total": 1,
  "online": 1,
  "servers": [
    {
      "id": "srv_ab12cd34",
      "name": "SMP",
      "type": "PAPER",
      "state": "running",
      "cpuPct": 18.4,
      "memoryMb": 2048,
      "memoryLimitMb": 4096,
      "uptimeSeconds": 11722,
      "players": { "online": 3, "max": 20 }
    }
  ]
}
```

### `GET /api/v1/servers/:id`

Ένας διακομιστής, ίδιο αντικείμενο κάτω από ένα κλειδί `server`. Επιστρέφει `404` για άγνωστο id
**και** για έναν διακομιστή στον οποίο το token δεν εστιάζει (δεν υπάρχει μαντείο ύπαρξης), και `400`
για εσφαλμένο id.

## Πεδία απόκρισης

| Πεδίο           | Σημασία                                                                                                          |
| --------------- | ---------------------------------------------------------------------------------------------------------------- |
| `total`         | Πόσοι διακομιστές είναι ορατοί σε αυτό το token (μετά το φίλτρο εστίασης).                                       |
| `online`        | Πόσοι από αυτούς βρίσκονται σε κατάσταση: `running`.                                                             |
| `id`            | Σταθερό id διακομιστή (`srv_...`).                                                                               |
| `name`          | Όνομα εμφάνισης.                                                                                                 |
| `type`          | Τύπος διακομιστή itzg (`PAPER`, `FABRIC`, `AUTO_CURSEFORGE`, ...).                                               |
| `state`         | `running`, `starting`, `stopped`, ή `crashed` - μια σταθερή σύνοψη της εσωτερικής κατάστασης του πίνακα ελέγχου. |
| `cpuPct`        | Πρόσφατο ποσοστό CPU, ή `null` όταν ο διακομιστής δεν εκτελείται.                                                |
| `memoryMb`      | Μνήμη RAM σε MB, ή `null`.                                                                                       |
| `memoryLimitMb` | Ορισμένο όριο μνήμης του κοντέινερ σε MB, ή `null`.                                                              |
| `uptimeSeconds` | Δευτερόλεπτα από την έναρξη του κοντέινερ, ή `null`.                                                             |
| `players`       | `{ online, max }`, ή `null` μέχρι ο διακομιστής να αναφέρει μια λίστα παικτών.                                   |

## Παράδειγμα

```sh
curl -s https://panel.example.com/api/v1/servers \
  -H "Authorization: Bearer $MSM_TOKEN" | jq
```
