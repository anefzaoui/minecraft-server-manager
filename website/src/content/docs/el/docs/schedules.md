Η σελίδα **Προγραμματισμοί** αυτοματοποιεί επαναλαμβανόμενες εργασίες με εκφράσεις cron. Χωρίς εξωτερικό cron, χωρίς scripts.

![Προγραμματισμοί](/docs/images/schedules.png)

## Τι μπορείτε να προγραμματίσετε

- **Επανεκκινήσεις** - μια νυχτερινή επανεκκίνηση για να διατηρείται υγιής ένας διακομιστής που εκτελείται για μεγάλο χρονικό διάστημα.
- **Αντίγραφα ασφαλείας** - τακτικά στιγμιότυπα (με την ετικέτα `scheduled` στη σελίδα [Αντίγραφα ασφαλείας](/docs/backups/)).
- **Εντολές** - εκτέλεση οποιασδήποτε εντολής διακομιστή σε ένα πρόγραμμα.
- **Έλεγχοι ενημερώσεων** - περιοδική ανανέωση όσων είναι ξεπερασμένα.

Κάθε προγραμματισμός στοχεύει έναν συγκεκριμένο διακομιστή (ή τον πίνακα συνολικά), εκτελείται με τη δική του έκφραση cron και μπορεί να ενεργοποιηθεί ή να απενεργοποιηθεί χωρίς να διαγραφεί. Ο χρόνος της τελευταίας εκτέλεσης εμφανίζεται, ώστε να μπορείτε να επιβεβαιώσετε ότι εκτελείται.
