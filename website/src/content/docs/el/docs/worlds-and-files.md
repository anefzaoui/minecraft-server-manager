## Κόσμοι

Η σελίδα **Κόσμοι** είναι η βιβλιοθήκη κόσμων: κάθε αποθηκευμένος κόσμος σε ένα μέρος. Η **Αποστολή Κόσμου** δέχεται ένα αρχείο `.zip` ή `.tar` και βρίσκει αυτόματα τον κόσμο μέσα του, η **Αποθήκευση στη Βιβλιοθήκη** δημιουργεί ένα στιγμιότυπο του ζωντανού κόσμου ενός διακομιστή (λειτουργεί ενώ ο διακομιστής τρέχει), και κάθε κόσμος της βιβλιοθήκης μπορεί να ληφθεί ή να εγκατασταθεί σε οποιονδήποτε διακομιστή με την επιλογή **Εγκατάσταση σε…**. Η εγκατάσταση είτε αντικαθιστά τον κόσμο του διακομιστή (ο διακομιστής πρέπει να είναι σταματημένος και ο τρέχων κόσμος του δημιουργείται πρώτα αντίγραφο ασφαλείας) είτε τον προσθέτει παράλληλα, για να ενεργοποιηθεί αργότερα. Ένας έλεγχος συμβατότητας εκτελείται πριν από κάθε εγκατάσταση.

Η καρτέλα **Κόσμος → Κόσμοι** ενός διακομιστή παραθέτει τους κόσμους σε αυτόν τον διακομιστή. Από εκεί μπορείτε να ενεργοποιήσετε έναν άλλο κόσμο (με τον διακομιστή σταματημένο), να κατεβάσετε, να αντιγράψετε, να μετονομάσετε ή να [συρρικνώσετε](/docs/world-shrink/) έναν κόσμο, να τον αντιγράψετε σε έναν άλλο διακομιστή, να διαγράψετε έναν ανενεργό, και να επαναφέρετε τον ενεργό κόσμο με ένα νέο, διατηρημένο ή προσαρμοσμένο seed (προσφέρεται πρώτα ένα αντίγραφο ασφαλείας). Η ίδια βιβλιοθήκη βρίσκεται παρακάτω, με την επιλογή **Εγκατάσταση εδώ**.

![Κόσμοι](/docs/images/worlds.png)

## Ο διαχειριστής αρχείων

Στην ενότητα **Κόσμος** ενός διακομιστή, η καρτέλα **Αρχεία** είναι ένας πλήρης διαχειριστής αρχείων εντός του προγράμματος περιήγησης για τον κατάλογο δεδομένων αυτού του διακομιστή. Λίστα, ανάγνωση, επεξεργασία, μετονομασία, μετακίνηση, αντιγραφή, διαγραφή και αποστολή αρχείων, δημιουργία φακέλων και αναζήτηση του κειμένου αρχείων σε έναν φάκελο με την επιλογή **Εύρεση σε Αρχεία**: όλα όσα θα κάνατε κανονικά μέσω SSH, από το πρόγραμμα περιήγησης.

![Διαχειριστής αρχείων](/docs/images/server-files.png)

Τα αρχεία κειμένου ανοίγουν σε έναν επεξεργαστή με όριο 8 MB. Μεγαλύτερα αρχεία μπορούν να ληφθούν. Οι αποστολές δέχονται έως και 20 αρχεία ταυτόχρονα.

### Παραμένοντας εντός του sandbox

Κάθε λειτουργία αρχείου περιορίζεται στον δικό του κατάλογο δεδομένων του διακομιστή. Ο πίνακας επιλύει κάθε διαδρομή και αρνείται οτιδήποτε θα μπορούσε να ξεφύγει: `..` διάσχιση, απόλυτες διαδρομές, ακόμη και συμβολικούς συνδέσμους που δείχνουν εκτός του καταλόγου (συμπεριλαμβανομένων των αδέσποτων που δεν υπάρχουν ακόμη). Ένα mod ή plugin δεν μπορεί να δημιουργήσει έναν σύνδεσμο για να ξεγελάσει τον διαχειριστή αρχείων ώστε να διαβάσει ή να γράψει αλλού στον κεντρικό υπολογιστή.

## Mods

Για διακομιστές με mods και plugins, η καρτέλα **Mods** (η δική της ομάδα στην πλευρική γραμμή του διακομιστή) διαχειρίζεται το σύνολο των mods: περιηγηθείτε και προσθέστε mods, και δείτε τι είναι εγκατεστημένο. Από κάθε σειρά εγκατεστημένου mod μπορείτε να το ενημερώσετε (ή να αγνοήσετε αυτήν την ενημέρωση), να το [επαναφέρετε](/docs/updates/#undoing-a-mod-update), να το απενεργοποιήσετε ή να το αφαιρέσετε, και η επιλογή **Ενημέρωση Όλων** εφαρμόζει κάθε διαθέσιμη ενημέρωση με μία επανεκκίνηση. Οι ενημερώσεις mods και πακέτων εμφανίζονται επίσης στη σελίδα [Ενημερώσεις](/docs/updates/).

### Προσθήκη mods

![Mods](/docs/images/mods.png)

Τέσσερις τρόποι, όλοι από τη γραμμή εργαλείων της καρτέλας Mods:

- **Αναζήτηση Mods**: αναζήτηση σε **Modrinth ή CurseForge** (το τσιπ CurseForge εμφανίζεται μόλις αποθηκευτεί ένα κλειδί API στις **Ρυθμίσεις → Κλειδιά API**), και σε διακομιστές plugin επίσης σε **Hangar** (το δικό του μητρώο plugin του PaperMC) και **SpigotMC** (μέσω του CDN proxy του Spiget), και τα δύο χωρίς κλειδί. Μια καρτέλα **Datapacks** αναζητά datapacks του Modrinth. Όλα φιλτράρονται ανά loader και έκδοση Minecraft του διακομιστή (ένα πλαίσιο ελέγχου εμφανίζει επίσης builds που δεν αναφέρονται ως συμβατά, με δική σας ευθύνη). Οι διακομιστές Quilt βλέπουν αυτόματα και builds με ετικέτα fabric, καθώς το Quilt εκτελεί mods Fabric. Τα αποτελέσματα που βρίσκονται ήδη στον διακομιστή εμφανίζουν ένα σήμα **Εγκατεστημένο**. Εάν ένας συγγραφέας του CurseForge απαγορεύει τις αυτοματοποιημένες λήψεις (ή ένας πόρος του SpigotMC φιλοξενείται εκτός τοποθεσίας), ο πίνακας το αναφέρει εκ των προτέρων και προσφέρει μια διαδρομή **Άνοιγμα CurseForge** (ή **Άνοιγμα SpigotMC**) + **Αποστολή Jar** αντί να αποτύχει κατά την εγκατάσταση.

  ![Αναζήτηση Hangar](/docs/images/mods-search-hangar.png)

- **Εισαγωγή Zip**: ένα κουμπί, τρία σχήματα, αυτόματη ανίχνευση:
  - Ένα **Modrinth modpack (`.mrpack`)**: κάθε καρφιτσωμένο αρχείο κανονικοποιείται πίσω στο έργο του Modrinth μέσω αναζήτησης hash (έτσι τα εισαγόμενα mods διατηρούν πραγματικά ονόματα, εικονίδια και παραμένουν ελέγξιμα για ενημερώσεις· αρχεία που το Modrinth δεν γνωρίζει εγκαθίστανται από τη δική τους URL του πακέτου), επαληθεύεται έναντι των checksums sha512 του πακέτου κατά τη λήψη και προεπισκοπείται με αποφάσεις καταλληλότητας. Τα αρχεία μόνο για πελάτες παραλείπονται ορατά, και τα δύο δέντρα αντικατάστασης (`overrides/`, μετά `server-overrides/`· το αντίγραφο ειδικά για τον διακομιστή κερδίζει) μπορούν να εφαρμοστούν.

    ![Εισαγωγή mrpack](/docs/images/mrpack-import.png)

  - Μια **εξαγωγή modpack του CurseForge** (το zip που παράγει η εφαρμογή του CurseForge, με `manifest.json`): κάθε καρφιτσωμένο mod επιλύεται μαζικά, προεπισκοπείται με προειδοποιήσεις (λάθος loader/MC για αυτόν τον διακομιστή, αρχεία που δεν βρίσκονται πλέον στο CurseForge, mods που χρειάζονται χειροκίνητη λήψη) και εγκαθίσταται με πραγματική πρόοδο. Τα `overrides/` του πακέτου (configs, scripts) μπορούν προαιρετικά να εφαρμοστούν επίσης· οποιοδήποτε αρχείο που θα αντικατασταθεί δημιουργείται πρώτα αντίγραφο ασφαλείας στο `.import-backups/<timestamp>/` μέσα στον φάκελο του διακομιστή.
  - Ένα **απλό zip από jars** που συλλέξατε μόνοι σας: κάθε jar αναγνωρίζεται (Modrinth hash match → CurseForge fingerprint → τα δικά του metadata του jar) και κρίνεται έναντι του διακομιστή (_ταιριάζει / λάθος loader / λάθος έκδοση MC / ήδη εγκατεστημένο / μη αναγνωρισμένο_), ώστε να επιλέξετε τι πραγματικά ανήκει πριν εγκατασταθεί οτιδήποτε.
- **Προσθήκη μέσω URL**: επικολλήστε σχεδόν οτιδήποτε: σελίδες έργων Modrinth, CurseForge, Hangar ή SpigotMC, ένα αποθετήριο GitHub ή URL έκδοσης (ένα απλό `owner/repo` λειτουργεί επίσης· οι εγκαταστάσεις GitHub προτιμούν την πιο πρόσφατη σταθερή έκδοση και παραλείπουν τα `-sources`/`-javadoc` sidecar jars), ένα απλό Modrinth slug ή οποιαδήποτε άμεση URL `.jar`. Ο πίνακας επιλύει το σωστό build για τον loader και την έκδοση MC του διακομιστή.

  ![Προσθήκη μέσω συνδέσμου](/docs/images/mods-add-by-link.png)

- **Αποστολή Jar** (από την αναζήτηση fallback ή τον επιλυτή εκκρεμών λήψεων): τα ανεβασμένα jars αναγνωρίζονται με τον ίδιο τρόπο, ώστε να διατηρούν το πραγματικό τους όνομα, την έκδοση, το εικονίδιο και να γίνονται ελέγξιμα για ενημερώσεις.

Κάθε εγκατάσταση μητρώου **επαληθεύεται με checksum κατά τη λήψη**: η ροή ελέγχεται έναντι του ισχυρότερου digest που δημοσιεύει το μητρώο (sha512 → sha256 → sha1 → md5) και μια αναντιστοιχία διακόπτει πριν οτιδήποτε προσγειωθεί στον διακομιστή.

Ένα ολόκληρο zip (συμπεριλαμβανομένου του `.mrpack`) μπορεί επίσης να **δημιουργήσει έναν διακομιστή**: στον οδηγό, στην καρτέλα **Από Modpack**, ανεβάστε το και το manifest του πακέτου (ή μια πλειοψηφία ψήφων στα αναγνωρισμένα jars) συμπληρώνει τον loader, την έκδοση Minecraft και το build του loader.
