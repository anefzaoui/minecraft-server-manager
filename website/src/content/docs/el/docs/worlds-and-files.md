## Κόσμοι

Η σελίδα **Κόσμοι** διαχειρίζεται τα δεδομένα του κόσμου στους διακομιστές σας: εναλλαγή του ενεργού κόσμου, μεταφόρτωση ενός κόσμου ή λήψη ενός.

![Κόσμοι](/docs/images/worlds.png)

## Ο διαχειριστής αρχείων

Κάτω από την ενότητα **Κόσμος** ενός διακομιστή, η καρτέλα **Αρχεία** είναι ένας πλήρης διαχειριστής αρχείων εντός του προγράμματος περιήγησης για τον κατάλογο δεδομένων αυτού του διακομιστή. Λίστα, ανάγνωση, επεξεργασία, δημιουργία, μετονομασία, μετακίνηση, αντιγραφή, διαγραφή και μεταφόρτωση αρχείων: όλα όσα θα κάνατε κανονικά μέσω SSH, από τον περιηγητή.

![Διαχειριστής αρχείων](/docs/images/server-files.png)

Τα αρχεία κειμένου ανοίγουν σε έναν επεξεργαστή με όριο 2 MB. μεγαλύτερα αρχεία μπορούν να ληφθούν. Οι μεταφορτώσεις δέχονται πολλά αρχεία ταυτόχρονα.

### Παραμονή εντός του sandbox

Κάθε λειτουργία αρχείου περιορίζεται στον κατάλογο δεδομένων του διακομιστή. Το πάνελ επιλύει κάθε διαδρομή και απορρίπτει οτιδήποτε θα μπορούσε να διαφύγει: διάβαση `..`, απόλυτες διαδρομές, ακόμη και συμβολικούς συνδέσμους που δείχνουν εκτός του καταλόγου (συμπεριλαμβανομένων των κρεμασμένων που δεν υπάρχουν ακόμη). Ένα mod ή plugin δεν μπορεί να φυτέψει έναν σύνδεσμο για να εξαπατήσει τον διαχειριστή αρχείων ώστε να διαβάσει ή να γράψει αλλού στον κεντρικό υπολογιστή.

## Mods

Για τροποποιημένους διακομιστές, η καρτέλα **Mods** (η δική της ομάδα στην πλαϊνή μπάρα του διακομιστή) διαχειρίζεται το σύνολο των mods: περιήγηση και προσθήκη mods, και προβολή του τι είναι εγκατεστημένο. Οι ενημερώσεις mod και πακέτων εμφανίζονται στη σελίδα [Ενημερώσεις](/docs/updates/).

### Προσθήκη mods

![Mods](/docs/images/mods.png)

Τέσσερις τρόποι εισαγωγής, όλοι από τη γραμμή εργαλείων της καρτέλας Mods:

- **Αναζήτηση mods** - αναζήτηση στο **Modrinth ή CurseForge** (το τσιπ CurseForge εμφανίζεται μόλις αποθηκευτεί ένα κλειδί API στις Ρυθμίσεις → Κλειδιά API), και σε διακομιστές plugin επίσης στο **Hangar** (το δικό του μητρώο plugin του PaperMC) και στο **SpigotMC** (μέσω του proxy CDN του Spiget) - και τα δύο χωρίς κλειδί. Τα πάντα φιλτράρονται για τον φορτωτή και την έκδοση Minecraft του διακομιστή. Οι διακομιστές Quilt βλέπουν αυτόματα και τις ετικέτες fabric, καθώς το Quilt εκτελεί mods fabric. Τα αποτελέσματα που βρίσκονται ήδη στον διακομιστή εμφανίζουν μια ετικέτα **Εγκατεστημένο**. Εάν ένας συγγραφέας του CurseForge απαγορεύει τις αυτοματοποιημένες λήψεις - ή ένας πόρος SpigotMC φιλοξενείται εκτός ιστότοπου - το πάνελ το αναφέρει ευθέως και προσφέρει μια διαδρομή **Άνοιγμα σελίδας** + **Μεταφόρτωση jar** αντί να αποτύχει κατά την εγκατάσταση.

  ![Αναζήτηση Hangar](/docs/images/mods-search-hangar.png)

- **Εισαγωγή zip** - ένα κουμπί, τρία σχήματα, αυτόματη ανίχνευση:
  - Ένα **Modrinth modpack (`.mrpack`)**: κάθε καρφιτσωμένο αρχείο κανονικοποιείται πίσω στο έργο Modrinth του μέσω αναζήτησης hash (ώστε τα εισαγόμενα mods να διατηρούν πραγματικά ονόματα, εικονίδια και να παραμένουν ελέγξιμα για ενημερώσεις. αρχεία που το Modrinth δεν γνωρίζει εγκαθίστανται από το δικό του URL του πακέτου), επαληθεύεται έναντι των αθροισμάτων ελέγχου sha512 του πακέτου κατά τη λήψη και προεπισκοπείται με κατάλληλες αποφάνσεις. Τα αρχεία μόνο για πελάτη παραλείπονται ορατά, και και τα δύο δέντρα αντικατάστασης (`overrides/`, στη συνέχεια `server-overrides/` - το αντίγραφο ειδικά για τον διακομιστή κερδίζει) μπορούν να εφαρμοστούν.

    ![Εισαγωγή mrpack](/docs/images/mrpack-import.png)

  - Μια **εξαγωγή modpack του CurseForge** (το zip που παράγει η εφαρμογή του CurseForge, με `manifest.json`): κάθε καρφιτσωμένο mod επιλύεται μαζικά, προεπισκοπείται με προειδοποιήσεις (λάθος φορτωτής/έκδοση MC για αυτόν τον διακομιστή, αρχεία που δεν είναι πλέον στο CurseForge, mods που χρειάζονται χειροκίνητη λήψη) και εγκαθίσταται με πραγματική πρόοδο. Το `overrides/` του πακέτου (ρυθμίσεις, scripts) μπορεί προαιρετικά να εφαρμοστεί επίσης - κάθε αρχείο που θα αντικατασταθεί δημιουργεί αντίγραφο ασφαλείας πρώτα στο `.import-backups/<timestamp>/` μέσα στον φάκελο του διακομιστή.
  - Ένα **απλό zip από jars** που συλλέξατε μόνοι σας: κάθε jar αναγνωρίζεται (αντιστοίχιση hash Modrinth → δακτυλικό αποτύπωμα CurseForge → τα δικά του μεταδεδομένα του jar) και κρίνεται έναντι του διακομιστή - _ταιριάζει / λάθος φορτωτής / λάθος έκδοση MC / ήδη εγκατεστημένο / μη αναγνωρισμένο_ - ώστε να επιλέγετε τι ανήκει πραγματικά πριν εγκατασταθεί οτιδήποτε.
- **Προσθήκη μέσω συνδέσμου** - επικολλήστε σχεδόν οτιδήποτε: σελίδες έργου Modrinth, CurseForge, Hangar ή SpigotMC, ένα URL αποθετηρίου ή έκδοσης GitHub (ένα απλό `owner/repo` λειτουργεί επίσης - οι εγκαταστάσεις GitHub προτιμούν την πιο πρόσφατη σταθερή έκδοση και παραλείπουν τα δευτερεύοντα jars `-sources`/`-javadoc`), ένα απλό slug Modrinth, ή οποιοδήποτε άμεσο URL `.jar`. Το πάνελ επιλύει τη σωστή έκδοση για τον φορτωτή και την έκδοση MC του διακομιστή.

  ![Προσθήκη μέσω συνδέσμου](/docs/images/mods-add-by-link.png)

- **Μεταφόρτωση jar** (από την εφεδρεία αναζήτησης ή τον αναλυτή εκκρεμών λήψεων) - τα μεταφορτωμένα jars αναγνωρίζονται με τον ίδιο τρόπο, ώστε να διατηρούν το πραγματικό τους όνομα, έκδοση, εικονίδιο και να γίνονται ελέγξιμα για ενημέρωση.

Κάθε εγκατάσταση μητρώου **επαληθεύεται με άθροισμα ελέγχου κατά τη λήψη**: η ροή ελέγχεται έναντι της ισχυρότερης διάκρισης που δημοσιεύει το μητρώο (sha512 → sha256 → sha1 → md5) και μια ασυμφωνία διακόπτει πριν οτιδήποτε προσγειωθεί στον διακομιστή.

Ένα ολόκληρο zip (`.mrpack` συμπεριλαμβανομένου) μπορεί επίσης **να δημιουργήσει έναν διακομιστή**: στο πρόγραμμα εγκατάστασης, στην καρτέλα _Από modpack_, μεταφορτώστε το και ο κατάλογος του πακέτου (ή μια πλειοψηφία μεταξύ των αναγνωρισμένων jars) συμπληρώνει τον φορτωτή, την έκδοση Minecraft και την έκδοση του φορτωτή.
