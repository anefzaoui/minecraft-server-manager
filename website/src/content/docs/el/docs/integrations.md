[← Επιστροφή στο ευρετήριο τεκμηρίωσης](/docs/)

Κάθε διακομιστής έχει τις ενσωματώσεις του στην ομάδα **Ρυθμίσεις**: **Discord**, μια δημόσια **Σελίδα Κατάστασης**, **Προσκλήσεις** με ένα κλικ και την προαιρετική καρτέλα **Chatbot** (μόνο για διαχειριστές). Αυτή η σελίδα καλύπτει το Discord. οι [προσκλήσεις & η σελίδα κατάστασης](/docs/invites-and-status-page/) καλύπτουν αυτές τις δύο, και [το chatbot](/docs/chatbot/) έχει τη δική του σελίδα.

## Ειδοποιήσεις Discord

Το πάνελ προωθεί συμβάντα του διακομιστή σε ένα κανάλι Discord μέσω ενός webhook. Χωρίς bot, χωρίς OAuth.

### Ρύθμιση

1. Στο Discord: **Ρυθμίσεις διακομιστή → Ενσωματώσεις → Webhooks → Νέο Webhook**. Επιλέξτε το κανάλι και αντιγράψτε τη διεύθυνση URL του webhook.
2. Στο πάνελ, ανοίξτε την καρτέλα **Ρυθμίσεις → Discord** του διακομιστή, επικολλήστε τη διεύθυνση URL στο πεδίο **Διεύθυνση URL Webhook**, ενεργοποιήστε την κάρτα **on** και πατήστε **Αποθήκευση**. Η διεύθυνση URL αποθηκεύεται κρυπτογραφημένη (στον ίδιο χώρο αποθήκευσης κατά την ηρεμία με τα κλειδιά API σας).
3. Χρησιμοποιήστε το **Αποστολή Δοκιμής** για να επιβεβαιώσετε ότι λειτουργεί.

![Ενσωμάτωση Discord](/docs/images/integrations-discord.png)

Για να αντικαταστήσετε μια αποθηκευμένη διεύθυνση URL, επικολλήστε μια νέα και αποθηκεύστε. αφήστε το πεδίο κενό για να διατηρήσετε την τρέχουσα. Η αποθηκευμένη διεύθυνση URL εμφανίζεται κρυμμένη (το διακριτικό είναι κρυφό).

### Τι αποστέλλεται

Οι ειδοποιήσεις ομαδοποιούνται σε κατηγορίες που μπορούν να ενεργοποιηθούν/απενεργοποιηθούν. Όλες είναι ενεργές από προεπιλογή.

| Κατηγορία                  | Συμβάντα                                                                   |
| -------------------------- | -------------------------------------------------------------------------- |
| **Έναρξη / διακοπή**       | Ο διακομιστής ξεκίνησε, ο διακομιστής σταμάτησε                            |
| **Διακοπές**               | Εντοπίστηκε διακοπή, βρόχος διακοπής, νέα αναφορά διακοπής                 |
| **Αντίγραφα ασφαλείας**    | Δημιουργήθηκε αντίγραφο ασφαλείας, αποκαταστάθηκε αντίγραφο ασφαλείας      |
| **Ενημερώσεις**            | Εφαρμόστηκε ενημέρωση, αναιρέθηκε ενημέρωση, απέτυχε ενημέρωση             |
| **Αποβολές / αποκλεισμοί** | Ο παίκτης αποβλήθηκε, ο παίκτης αποκλείστηκε                               |
| **Ειδοποιήσεις**           | Τα πράγματα που αφήνουν σιωπηλά έναν διακομιστή χαλασμένο (δείτε παρακάτω) |

### Η κατηγορία Ειδοποιήσεις

Οι `Ειδοποιήσεις` είναι το κανάλι "κάτι χρειάζεται ανθρώπινη παρέμβαση", για συνθήκες που παλαιότερα ήταν ορατές μόνο στο πάνελ:

| Συμβάν                  | Σημασία                                                                                                                                   |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `oom`                   | Το κοντέινερ σταμάτησε λόγω έλλειψης μνήμης.                                                                                              |
| `unhealthy`             | Η διαδικασία είναι ενεργή αλλά η δοκιμή `mc-health` αποτυγχάνει: ένας ζωντανός αλλά νεκρός διακομιστής.                                   |
| `startup-stalled`       | Ακόμα ξεκινάει μετά από ~10 λεπτά χωρίς "Ολοκληρώθηκε" στα αρχεία καταγραφής (με διάγνωση του τι πρέπει να διορθωθεί, όπου είναι γνωστό). |
| `stop-failed`           | Μια ομαλή διακοπή δεν τέθηκε σε ισχύ και το κοντέινερ εξακολουθεί να εκτελείται.                                                          |
| `schedule-failed`       | Μια προγραμματισμένη επανεκκίνηση / αντίγραφο ασφαλείας / εντολή απέτυχε.                                                                 |
| `quota-exceeded`        | Το όριο ποσόστωσης δίσκου αυστηρής λειτουργίας ενεργοποιήθηκε και ο διακομιστής σταμάτησε.                                                |
| `offline-after-restart` | Ο διακομιστής ήταν ενεργός πριν από την επανεκκίνηση του πάνελ, τώρα δεν είναι και δεν θα ξεκινήσει αυτόματα.                             |
| `port-change-failed`    | Μια αλλαγή θύρας απέτυχε και ο διακομιστής δεν μπόρεσε να επαναφερθεί στην παλιά του θύρα, οπότε είναι εκτός λειτουργίας.                 |
| `auto-restart-gave-up`  | Ένας διακομιστής που παρουσίασε διακοπή δεν επανεκκινήθηκε επειδή μια άλλη ενέργεια τον κρατούσε απασχολημένο για πολύ καιρό.             |

### Πώς λειτουργεί η παράδοση

Μια γέφυρα στο παρασκήνιο ελέγχει το [αρχείο καταγραφής συμβάντων](/docs/activity/) κάθε 15 δευτερόλεπτα και προωθεί αντιστοιχισμένες γραμμές. Εάν μια δημοσίευση webhook αποτύχει παροδικά, αυτή η γραμμή επαναδοκιμάζεται σε μεταγενέστερους ελέγχους αντί να απορριφθεί. μετά από μερικές αποτυχημένες προσπάθειες, η γραμμή παραλείπεται και οι αποτυχίες παράδοσης καταγράφονται το πολύ μία φορά ανά ώρα ανά διακομιστή. Μετά από μια επανεκκίνηση του πάνελ, η γέφυρα στέλνει τα συμβάντα που δεν είχε παραδώσει ακόμη, αλλά ποτέ περισσότερο από δύο ώρες πίσω. κατά την πρώτη της εκτέλεση ξεκινά από το νεότερο συμβάν.
