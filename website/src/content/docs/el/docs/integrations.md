Κάθε διακομιστής φέρει τις ενσωματώσεις του στην ομάδα **Ρυθμίσεις**: **Discord**, μια δημόσια **Σελίδα Κατάστασης**, **Προσκλήσεις** με ένα κλικ και την προαιρετική καρτέλα **Chatbot**. Αυτή η σελίδα καλύπτει το Discord (οι άλλες έχουν τη δική τους τεκμηρίωση και βοηθούς ρύθμισης στον πίνακα).

## Ειδοποιήσεις Discord

Ο πίνακας προωθεί συμβάντα του διακομιστή σε ένα κανάλι Discord μέσω ενός webhook. Χωρίς bot, χωρίς OAuth.

### Ρύθμιση

1. Στο Discord: **Ρυθμίσεις διακομιστή → Ενσωματώσεις → Webhooks → Νέο Webhook**. Επιλέξτε το κανάλι και αντιγράψτε τη διεύθυνση URL του webhook.
2. Στον πίνακα, ανοίξτε την καρτέλα **Ρυθμίσεις → Discord** του διακομιστή, επικολλήστε τη διεύθυνση URL στο πεδίο **Webhook URL**, ενεργοποιήστε την κάρτα **on** και πατήστε **Αποθήκευση**. Η διεύθυνση URL αποθηκεύεται κρυπτογραφημένη (στο ίδιο κατάστημα αποθήκευσης κατά την ηρεμία με τα κλειδιά API σας).
3. Χρησιμοποιήστε το **Αποστολή δοκιμής** για να επιβεβαιώσετε ότι λειτουργεί.

![Ενσωμάτωση Discord](/docs/images/integrations-discord.png)

Για να αντικαταστήσετε μια αποθηκευμένη διεύθυνση URL, επικολλήστε μια νέα και αποθηκεύστε. αφήστε το πεδίο κενό για να διατηρήσετε την τρέχουσα. Η αποθηκευμένη διεύθυνση URL εμφανίζεται κρυμμένη (το διακριτικό είναι κρυφό).

### Τι αποστέλλεται

Οι ειδοποιήσεις ομαδοποιούνται σε κατηγορίες που μπορούν να ενεργοποιηθούν/απενεργοποιηθούν. Όλες είναι ενεργές από προεπιλογή.

| Κατηγορία                  | Συμβάντα                                                                       |
| -------------------------- | ------------------------------------------------------------------------------ |
| **Έναρξη / διακοπή**       | Ο διακομιστής ξεκίνησε, ο διακομιστής σταμάτησε                                |
| **Καταρρεύσεις**           | Κατάρρευση, ανιχνεύθηκε βρόχος κατάρρευσης, νέα αναφορά κατάρρευσης            |
| **Αντίγραφα ασφαλείας**    | Δημιουργήθηκε αντίγραφο ασφαλείας, αποκαταστάθηκε αντίγραφο ασφαλείας          |
| **Ενημερώσεις**            | Εφαρμόστηκε ενημέρωση, αναστράφηκε ενημέρωση, απέτυχε ενημέρωση                |
| **Αποβολές / αποκλεισμοί** | Παίκτης αποβλήθηκε, παίκτης αποκλείστηκε                                       |
| **Ειδοποιήσεις**           | Τα πράγματα που αφήνουν σιωπηλά έναν διακομιστή κατεστραμμένο (δείτε παρακάτω) |

### Η κατηγορία Ειδοποιήσεις

Η κατηγορία `Ειδοποιήσεις` είναι το "κάτι χρειάζεται ανθρώπινη παρέμβαση" κανάλι, για συνθήκες που παλαιότερα ήταν ορατές μόνο στον πίνακα:

| Συμβάν                  | Σημασία                                                                                                                          |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `oom`                   | Το κοντέινερ σταμάτησε λόγω έλλειψης μνήμης.                                                                                     |
| `unhealthy`             | Η διαδικασία είναι ενεργή αλλά η δοκιμή `mc-health` αποτυγχάνει: ένας ζωντανός αλλά νεκρός διακομιστής.                          |
| `startup-stalled`       | Ακόμα ξεκινά μετά από ~10 λεπτά χωρίς "Ολοκληρώθηκε" στα αρχεία καταγραφής (με διάγνωση του τι να διορθωθεί, όπου είναι γνωστό). |
| `stop-failed`           | Μια ομαλή διακοπή δεν τέθηκε σε ισχύ και το κοντέινερ εξακολουθεί να εκτελείται.                                                 |
| `schedule-failed`       | Μια προγραμματισμένη επανεκκίνηση / αντίγραφο ασφαλείας / εντολή απέτυχε.                                                        |
| `quota-exceeded`        | Η αυστηρή ποσόστωση δίσκου ενεργοποιήθηκε και ο διακομιστής σταμάτησε.                                                           |
| `offline-after-restart` | Ο διακομιστής ήταν ενεργός πριν από την επανεκκίνηση του πίνακα, δεν είναι τώρα και δεν θα ξεκινήσει αυτόματα.                   |
| `crash-report`          | Ένα νέο αρχείο αναφοράς κατάρρευσης καταγράφηκε και αναλύθηκε.                                                                   |
| `update-failed`         | Μια προστατευμένη αναβάθμιση δεν ήταν υγιής.                                                                                     |

### Πώς λειτουργεί η παράδοση

Μια γέφυρα στο παρασκήνιο ελέγχει το [ημερολόγιο συμβάντων](/docs/activity/) κάθε 15 δευτερόλεπτα και προωθεί αντιστοιχισμένες γραμμές. Εάν μια δημοσίευση webhook αποτύχει παροδικά, αυτή η γραμμή επαναδοκιμάζεται σε μεταγενέστερους ελέγχους αντί να απορριφθεί. ένα μόνιμα μη προσβάσιμο webhook σιωπάται (μία γραμμή αρχείου καταγραφής ανά ώρα) μετά από μερικές προσπάθειες. Η γέφυρα δεν αναπαίζει ποτέ συμβάντα από πριν την έναρξη του πίνακα.
