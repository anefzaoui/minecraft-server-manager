Ο πίνακας είναι πολυ-χρηστικός. Διαχειριστείτε λογαριασμούς στην ενότητα **Ρυθμίσεις → Χρήστες**.

![Χρήστες](/docs/images/settings-users.png)

## Οι τρεις ρόλοι

| Ρόλος        | Προεπιλογή σε κάθε διακομιστή                                                                                                                                            |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **admin**    | Τα πάντα: διαχείριση χρηστών, κλειδιών API, καθολικών αρχείων, προηγμένων παρακαμψέων Docker, και κάθε ενέργεια διακομιστή.                                              |
| **operator** | Εκτέλεση και ρύθμιση διακομιστών (εκκίνηση/τερματισμός, κονσόλα, αντίγραφα ασφαλείας, κόσμοι, mods, οι περισσότερες ρυθμίσεις), αλλά όχι περιοχές μόνο για διαχειριστές. |
| **viewer**   | Μόνο για ανάγνωση. Προβολή διακομιστών και της κατάστασής τους, χωρίς αλλαγές.                                                                                           |

Κάθε χρήστης, συμπεριλαμβανομένου του viewer, μπορεί να διαχειριστεί τον δικό του [έλεγχο ταυτότητας δύο παραγόντων](/docs/two-factor-authentication/), επειδή η προστασία της δικής σας σύνδεσης δεν είναι ενέργεια διαχείρισης διακομιστή.

Ένας ρόλος είναι η **προεπιλογή** για κάθε διακομιστή. Για να δώσετε σε κάποιον διαφορετικά δικαιώματα σε έναν διακομιστή, χρησιμοποιήστε τις δικαιοδοσίες ανά διακομιστή παρακάτω.

## Δικαιοδοσίες ανά διακομιστή

Η σελίδα **Δικαιοδοσίες** (στην πλαϊνή μπάρα, ή **Δικαιοδοσίες Διακομιστή** στην ενότητα **Ρυθμίσεις → Χρήστες**) εμφανίζει ένα πλέγμα: κάθε operator και viewer κατά μήκος της πλευράς, κάθε διακομιστής κατά μήκος της κορυφής. Κάντε κλικ σε ένα κελί για να αποφασίσετε τι μπορεί να κάνει αυτός ο χρήστης σε αυτόν τον έναν διακομιστή. Οι διαχειριστές δεν αναφέρονται επειδή έχουν πάντα τα πάντα.

![Δικαιοδοσίες](/docs/images/settings-permissions.png)

Κάθε κελί είναι ένα σύνολο δικαιοδοσιών:

| Δικαιοδοσία  | Τι επιτρέπει σε αυτόν τον διακομιστή                                                                                                                                         |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **View**     | Προβολή του διακομιστή, της κατάστασής του, της εξόδου κονσόλας, των παικτών, του ιστορικού και των στατιστικών.                                                             |
| **Power**    | Εκκίνηση, τερματισμός, επανεκκίνηση, τερματισμός (kill) και αναδημιουργία του διακομιστή.                                                                                    |
| **Console**  | Εκτέλεση εντολών κονσόλας και γρήγορων ενεργειών κόσμου, αποστολή μηνυμάτων συνομιλίας και διαχείριση εντολών συνομιλίας.                                                    |
| **Players**  | Αποβολή (kick), απαγόρευση (ban), προσθήκη σε λίστα επιτρεπόμενων (whitelist), ανάθεση δικαιωμάτων operator (op) και επεξεργασία σημειώσεων παικτών.                         |
| **Content**  | Εγκατάσταση και αφαίρεση mods, plugins, packs, κόσμων, datapacks και επεξεργασία αποθεμάτων (inventories).                                                                   |
| **Backups**  | Δημιουργία, επαναφορά, λήψη και διαγραφή αντιγράφων ασφαλείας.                                                                                                               |
| **Files**    | Περιήγηση, επεξεργασία, μεταφόρτωση και λήψη αρχείων διακομιστή, αρχειοθετημένων αρχείων καταγραφής (logs) και πακέτων αρχείων καταγραφής (log bundles); εξαγωγή blueprints. |
| **Settings** | Αλλαγή ρυθμίσεων διακομιστή, ιδιοτήτων, ενσωματώσεων, εικονιδίου και αναβάθμιση εκδόσεων.                                                                                    |
| **Delete**   | Διαγραφή του διακομιστή.                                                                                                                                                     |

![Επεξεργαστής δικαιοδοσιών](/docs/images/permissions-editor.png)

Κάτω από το πλέγμα, **Τι Καλύπτει Κάθε Δικαιοδοσία** επεκτείνει κάθε δικαιοδοσία σε ό,τι μπορεί να κάνει ένα άτομο, τι δεν περιλαμβάνεται, και τις ακριβείς διαδρομές του πίνακα που ξεκλειδώνει. Η τελευταία λίστα ελέγχεται έναντι του εκτελούμενου κώδικα από τη σουίτα δοκιμών.

![Αναφορά δικαιοδοσιών](/docs/images/permissions-reference.png)

Σε ένα τηλέφωνο, το πλέγμα στοιβάζεται σε μία κάρτα ανά χρήστη, με μια σειρά ανά διακομιστή.

Πώς ταιριάζουν τα κομμάτια:

- **Ο ρόλος είναι η προεπιλογή.** Ένας operator ξεκινά με κάθε δικαιοδοσία σε κάθε διακομιστή· ένας viewer ξεκινά μόνο με View. Ένα κελί με αχνό κείμενο (το tooltip του λέει "Role default") δεν έχει αλλάξει ποτέ.
- **Ένα κελί παρακάμπτει τον ρόλο μόνο για αυτόν τον διακομιστή.** Δώστε σε έναν viewer Power και Console σε έναν διακομιστή και μπορεί να τον εκτελέσει, ενώ όλοι οι άλλοι διακομιστές παραμένουν μόνο για ανάγνωση γι' αυτόν. Αφαιρέστε το Delete από έναν operator στον κύριο διακομιστή σας και αυτός διατηρεί όλα τα άλλα εκεί.
- **Κάθε δικαιοδοσία περιλαμβάνει το View.** Δεν μπορείτε να ενεργήσετε σε έναν διακομιστή που δεν μπορείτε να δείτε.
- **Απενεργοποιήστε τα πάντα για να κρύψετε έναν διακομιστή.** Εξαφανίζεται από την πλαϊνή μπάρα του χρήστη, τον πίνακα ελέγχου, τα αντίγραφα ασφαλείας, τα προγράμματα, τη δραστηριότητα, τις ενημερώσεις, τα modpacks, την κατάσταση σε πραγματικό χρόνο, τις τρέχουσες εργασίες και τα blueprints, και η βιβλιοθήκη κόσμων σταματά να τον αναφέρει. Ένας άμεσος σύνδεσμος, μια κλήση API ή μια κονσόλα socket απαντά "δεν βρέθηκε", όπως και ένας διακομιστής που δεν υπάρχει.
- **Οι ενέργειες σε όλο τον πίνακα εξακολουθούν να ακολουθούν τον ρόλο.** Η δημιουργία διακομιστών (συμπεριλαμβανομένης της κλωνοποίησης), η αποθήκευση, οι χρήστες, τα κλειδιά API, οι καθολικές ρυθμίσεις και τα προγράμματα σε όλο τον πίνακα δεν είναι ανά διακομιστή, οπότε ένας viewer με δικαιοδοσίες σε ορισμένους διακομιστές εξακολουθεί να μην μπορεί να κάνει τίποτα από αυτά. Οι operators διατηρούν τη δημιουργία διακομιστών και τα προγράμματα σε όλο τον πίνακα· η αποθήκευση, οι χρήστες, τα κλειδιά API και οι καθολικές ρυθμίσεις είναι μόνο για διαχειριστές.
- **Τα προγράμματα ακολουθούν τον διακομιστή.** Μια προγραμματισμένη επανεκκίνηση, αντίγραφο ασφαλείας ή εντολή σε έναν διακομιστή απαιτεί την αντίστοιχη δικαιοδοσία εκεί (Power, Backups, ή Console), ανεξάρτητα από τον ρόλο.
- **Τα Blueprints ακολουθούν επίσης τον διακομιστή.** Η εξαγωγή ενός διακομιστή ως blueprint απαιτεί Files εκεί, επειδή το αρχείο μεταφέρει τα αρχεία του. Ένα blueprint που εξάγεται από έναν διακομιστή που κάποιος δεν μπορεί να δει, κρύβεται επίσης από αυτόν.
- **Οι περιοχές μόνο για διαχειριστές παραμένουν μόνο για διαχειριστές** σε κάθε διακομιστή: το chatbot, η διατήρηση αντιγράφων ασφαλείας και οι προηγμένες παρακάμψεις Docker.

Κάθε αλλαγή καταγράφεται στο αρχείο δραστηριότητας με το ποιος άλλαξε τι· αυτές οι καταχωρήσεις εμφανίζονται μόνο σε διαχειριστές. Η διαγραφή ενός χρήστη αφαιρεί τις γραμμές του. Η αφαίρεση ενός διακομιστή τους διατηρεί, οπότε ένας διακομιστής που είναι κρυμμένος από κάποιον παραμένει κρυμμένος στην ιστορία του και στα αντίγραφα ασφαλείας που διατηρούνται.

Οι υπάρχουσες εγκαταστάσεις συνεχίζουν να λειτουργούν αμετάβλητες: μέχρι ένας διαχειριστής να επεξεργαστεί ένα κελί, κάθε χρήστης έχει ακριβώς ό,τι του έδωσε ο ρόλος του πριν.

## Μόνο για διαχειριστές, και γιατί

Λίγα πράγματα είναι σκόπιμα περιορισμένα στους διαχειριστές:

- **Διαχείριση χρηστών, αποθήκευση, καθολικές ρυθμίσεις, κλειδιά API και καθολικά αρχεία.**
- **Το [δημόσιο API](/docs/public-api/)**: ενεργοποίηση του `/api/v1` και δημιουργία, οριοθέτηση ή ανάκληση των token Bearer μόνο για ανάγνωση.
- **Προηγμένες παρακάμψεις Docker**: προσαρμοσμένο όνομα κοντέινερ, επιπλέον δημοσιεύσεις θυρών και bind mounts. Ένα bind mount μπορεί να αντιστοιχίσει οποιαδήποτε διαδρομή του host σε ένα κοντέινερ, και σε συνδυασμό με την πρόσβαση Docker του πίνακα, αυτό είναι ουσιαστικά root στον host. Αυτά τα πεδία εμφανίζονται μόνο για διαχειριστές.

Τα προσαρμοσμένα ονόματα κοντέινερ επίσης δεν μπορούν να ζήσουν στον δικό του χώρο ονομάτων `msm-` του πίνακα, οπότε ένα χειροκίνητα ονομασμένο κοντέινερ δεν μπορεί ποτέ να επισκιάσει έναν άλλο διακομιστή και να κατευθύνει λανθασμένα έναν τερματισμό ή μια εντολή σε λάθος παρουσία.

## Διαχείριση λογαριασμών

![Εικόνα προφίλ](/docs/images/profile-picture.png)

Οι διαχειριστές μπορούν να δημιουργήσουν χρήστες, να αλλάξουν ρόλους, να επαναφέρουν κωδικούς πρόσβασης και να διαγράψουν λογαριασμούς από τον πίνακα Χρηστών. Η στήλη **2FA** δείχνει αν κάθε χρήστης έχει ενεργοποιήσει τον έλεγχο ταυτότητας δύο παραγόντων· ένας διαχειριστής μπορεί να επαναφέρει το 2FA ενός άλλου χρήστη με το **Reset 2FA** στο μενού ενεργειών αυτού του χρήστη (για την περίπτωση χαμένου τηλεφώνου και κωδικών δημιουργίας αντιγράφων ασφαλείας), αλλά ποτέ να απενεργοποιήσει το δικό του χωρίς τον κωδικό πρόσβασης, κάτι που η ροή αυτοεξυπηρέτησης χειρίζεται αντ' αυτού.

Οι αποτυχημένες συνδέσεις περιορίζονται ανά λογαριασμό (τόσο ένας μετρητής ανά IP όσο και ένας καθολικός μετρητής λογαριασμού) για να επιβραδυνθούν οι προσπάθειες brute-force, και το ίδιο όριο καλύπτει το βήμα του κωδικού 2FA, ώστε ένας σωστός κωδικός πρόσβασης να μην μπορεί να επαναφέρει τον μετρητή πριν από την εικασία του κωδικού. Μπροστά από αυτό βρίσκεται ένας πιο χονδροειδής περιοριστής αιτήσεων ανά IP πελάτη στα τελικά σημεία σύνδεσης / 2FA / ρύθμισης, ρυθμιζόμενος μέσω του `RATE_LIMIT_AUTH_PER_15MIN` (προεπιλογή 100· πίσω από έναν αντίστροφο διαμεσολαβητή (reverse proxy), ορίστε το `TRUST_PROXY` ώστε να βασίζεται στην πραγματική IP του πελάτη).
