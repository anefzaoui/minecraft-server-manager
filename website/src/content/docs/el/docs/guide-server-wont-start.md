Δουλέψτε προς τα κάτω σε αυτήν τη λίστα. Είναι ταξινομημένη με βάση τη συχνότητα που κάθε μία αποτελεί την απάντηση, και οι πρώτες τέσσερις καλύπτουν τις περισσότερες περιπτώσεις.

## 1. Διαβάστε τις τελευταίες είκοσι γραμμές, όχι τις πρώτες

Κάντε κύλιση στο **τέλος** του αρχείου καταγραφής (log). Μια στοίβα σφαλμάτων Java (stack trace) εκτυπώνεται πρώτα από μέσα προς τα έξω, οπότε η κορυφή του "τοίχου κειμένου" είναι το λιγότερο ενδιαφέρον μέρος. Αυτό που θέλετε είναι η τελευταία γραμμή `Caused by:` και ό,τι ακολουθεί. Αυτή η μία γραμμή συνήθως ονομάζει το πρόβλημα.

Δύο σχήματα σας λένε πού βρίσκεστε:

- `Exception in thread "main"` ή μια διαδρομή αναφοράς σφάλματος (crash report path) κοντά στο τέλος σημαίνει ότι το ίδιο το παιχνίδι απέτυχε.
- Το αρχείο καταγραφής απλώς σταματά στη μέση μιας γραμμής, χωρίς καθόλου εξαίρεση, σημαίνει ότι κάτι τερμάτισε τη διαδικασία από έξω. Μεταβείτε στο σημείο 3.

## 2. Το UnsupportedClassVersionError σημαίνει λάθος Java

```
java.lang.UnsupportedClassVersionError: net/minecraft/server/Main has been compiled
by a more recent version of the Java Runtime (class file version 65.0)
```

Η κλάση 52 είναι Java 8, η 60 είναι 16, η 61 είναι 17, η 65 είναι 21, η 69 είναι 25. Το μήνυμα σημαίνει ότι ο διακομιστής χρειάζεται νεότερη Java από αυτήν που εκτελείται· το αντίστροφο, ένα παλιό πακέτο σε νέα Java, συνήθως αποτυγχάνει με σφάλμα mixin ή reflection.

| Έκδοση Minecraft       | Java |
| ---------------------- | ---- |
| 1.16.5 και παλαιότερες | 8    |
| 1.17                   | 16   |
| 1.18 και 1.19          | 17   |
| 1.20 έως 1.20.4        | 17   |
| 1.20.5 έως 1.21.x      | 21   |
| 26.1 και νεότερες      | 25   |

Τα παλιά πακέτα χρειάζονται πραγματικά Java 8. Το νεότερο δεν είναι καλύτερο εδώ.

## 3. Ο κωδικός εξόδου 137 είναι ο πυρήνας, όχι ένα mod

Το αρχείο καταγραφής σταματά στη μέση μιας πρότασης, δεν υπάρχει αναφορά σφάλματος και το κοντέινερ αναφέρει 137. Αυτό είναι τερματισμός λόγω έλλειψης μνήμης (out-of-memory kill): η διαδικασία ζήτησε μνήμη που η μηχανή δεν είχε, οπότε τερματίστηκε.

Σχεδόν πάντα, η στοίβα Java (heap) ορίστηκε στον ίδιο αριθμό με τη μνήμη της μηχανής. Η στοίβα χρειάζεται τη μνήμη της μηχανής **μείον** την δική της επιβάρυνση της JVM, η οποία είναι 0.5 έως 1.5 GB σε έναν modded διακομιστή. Μειώστε τη στοίβα, ή αυξήστε τη μηχανή. [Πόση RAM χρειάζεται ένας διακομιστής](/docs/guide-server-memory/) έχει τους αριθμούς.

## 4. Το EULA και η θύρα

Δύο κλασικά προβλήματα με λύσεις μιας γραμμής:

- `You need to agree to the EULA in order to run the server.` Ορίστε `eula=true`, στο `eula.txt` ή με τη μεταβλητή περιβάλλοντος που χρησιμοποιεί η εγκατάστασή σας.
- `Address already in use` ή `FAILED TO BIND TO PORT`. Κάτι άλλο κατέχει τη θύρα 25565, συχνά ένα προηγούμενο αντίγραφο του ίδιου διακομιστή που δεν σταμάτησε ποτέ πλήρως. Βρείτε το και σταματήστε το αντί να αλλάξετε τη θύρα, αλλιώς θα καταλήξετε με δύο.

## 5. Ένα mod λείπει η εξάρτησή του

```
Mod X requires mod Y, which is missing
Fabric API is not installed
```

Τα mods Fabric χρειάζονται συντριπτικά το Fabric API ως ξεχωριστό αρχείο. Τα mods Forge και NeoForge αναφέρουν τις εξαρτήσεις τους στο ίδιο το σφάλμα. Εγκαταστήστε την ονομαζόμενη έκδοση, όχι την πιο πρόσφατη: "requires 0.91.x" σημαίνει αυτή η γραμμή, και η 0.92 θα αποτύχει στον ίδιο έλεγχο.

Μερικές φορές η εξάρτηση που λείπει είναι ο ίδιος ο φορτωτής:

```
Mod X requires forge 47.4.14 or above
Mod ID: 'forge', Requested by: 'x', Expected range: '[47.4.14,)', Actual version: '47.4.10'
```

Η λύση είναι μια νεότερη έκδοση του φορτωτή, όχι ένα διαφορετικό mod. "47.4.14 or above" σημαίνει οποιαδήποτε έκδοση από εκεί και πάνω, και το Forge δεν δημοσιεύει κάθε αριθμό, οπότε η έκδοση που πρέπει να εγκατασταθεί μπορεί να είναι η επόμενη. Σε ένα modpack, ενημερώστε πρώτα το πακέτο: ένα πακέτο του οποίου η έκδοση του φορτωτή είναι πολύ παλιά για τα mods του είναι ένα σφάλμα που πρέπει να διορθώσει ο συγγραφέας του.

## 6. Ένα mod είναι για λάθος φορτωτή ή έκδοση

Ένα jar για διαφορετικό φορτωτή δεν αποτυγχάνει ευγενικά. Περιμένετε ένα σφάλμα mixin, ένα `NoClassDefFoundError`, ή ένα σφάλμα μέσα σε μια κλάση που δεν έχετε ακούσει ποτέ. Ελέγξτε τη σελίδα του jar: τόσο ο φορτωτής όσο και η έκδοση του Minecraft πρέπει να ταιριάζουν ακριβώς. Το 1.20.1 και το 1.20.4 είναι διαφορετικά παιχνίδια όσον αφορά τα mods.

## 7. Ο κόσμος είναι από νεότερη έκδοση

```
This world was created by a newer version of Minecraft
```

Οι κόσμοι αναβαθμίζονται προς τα εμπρός και ποτέ προς τα πίσω. Επαναφέρετε το αντίγραφο ασφαλείας από πριν την αναβάθμιση, ή εκτελέστε την έκδοση που περιμένει ο κόσμος. Δεν υπάρχει διαδρομή υποβάθμισης που να διατηρεί τα κομμάτια (chunks) άθικτα.

## Όταν συνέβη σφάλμα μετά από εβδομάδες λειτουργίας

Διαφορετική ερώτηση, συνήθως διαφορετική απάντηση:

- **Συνέβη σφάλμα υπό φορτίο**, με τα timings να δείχνουν μεγάλες παύσεις: συλλογή απορριμμάτων (garbage collection), οπότε κοιτάξτε το μέγεθος της στοίβας (heap size) πριν από τα mods.
- **Συνέβη σφάλμα στο ίδιο σημείο του κόσμου**: ένα κατεστραμμένο κομμάτι (corrupt chunk) ή μια σπασμένη οντότητα. Η αναφορά σφάλματος συνήθως αναφέρει συντεταγμένες.
- **Συνέβη σφάλμα αμέσως μετά από μια ενημέρωση**: το mod που ενημερώθηκε είναι ο ύποπτος, ακόμα κι αν η στοίβα σφαλμάτων δείχνει αλλού. Επαναφέρετέ το και δείτε.
- **Συνέβη σφάλμα κατά την επανεκκίνηση, ενώ πριν ήταν εντάξει**: ελέγξτε τον δίσκο. Ένας γεμάτος δίσκος παράγει θεαματικά και παραπλανητικά σφάλματα.

## Λήψη βοήθειας που πραγματικά βοηθά

Δημοσιεύστε ολόκληρο το **αρχείο καταγραφής**, όχι την τελευταία γραμμή, και πείτε τι αλλάξατε πριν χαλάσει. Επικολλήστε το κάπου που είναι σχεδιασμένο για αυτό, όπως το [mclo.gs](https://mclo.gs), αντί για τη συνομιλία. Συμπεριλάβετε την έκδοση του Minecraft, τον φορτωτή, το πακέτο και την έκδοσή του, και πόση στοίβα (heap) έχει ο διακομιστής. Μια αναφορά με αυτά τα τέσσερα στοιχεία απαντάται σε μία απάντηση· χωρίς αυτά χρειάζονται πέντε.

## Στο Minecraft Server Manager

Τα σφάλματα ανιχνεύονται από την έξοδο του ίδιου του κοντέινερ, οπότε ένας διακομιστής που πεθαίνει στις τρεις το πρωί καταγράφεται με το απόσπασμα του αρχείου καταγραφής του αντί να βρεθεί την επόμενη μέρα. Οι συνήθεις ύποπτοι σε αυτήν τη σελίδα (το EULA, η λάθος Java, ένας κόσμος από νεότερη έκδοση, μια θύρα που χρησιμοποιείται ήδη, η Java που ξεμένει από μνήμη) αναγνωρίζονται σε αυτό το αρχείο καταγραφής και ονομάζονται στην καταχώρηση ιστορικού με το τι πρέπει να γίνει γι' αυτά, και η αυτόματη επανεκκίνηση τα αφήνει ήσυχα, αφού η επανεκκίνηση δεν θα τα διορθώσει. Οι αναφορές σφαλμάτων αναλύονται κατά την άφιξη: η εξαίρεση επισημαίνεται, η στοίβα είναι αναδιπλούμενη και τα mods που εμφανίζονται στην ιχνηλασία αναφέρονται ως ύποπτοι.

Οποιαδήποτε αναφορά μπορεί να κοινοποιηθεί στο mclo.gs από την κάρτα της όταν χρειάζεστε βοήθεια (μετά από επιβεβαίωση, αφού η δημοσίευση είναι δημόσια), και το μενού **Λήψη** της κονσόλας έχει όλα τα αρχεία καταγραφής ως ένα zip, οπότε το "δημοσιεύστε ολόκληρο το αρχείο καταγραφής" είναι μια λήψη αντί για ένα αρχαιολογικό έργο. Ένας τερματισμός λόγω έλλειψης μνήμης καταγράφεται ως τέτοιος, γεγονός που εξοικονομεί τη συνήθη ώρα κατηγορώντας ένα mod. Εάν κάτι άλλο χρειάζεται πραγματικά τη θύρα, η κάρτα **Game Port** στις **Ρυθμίσεις → Διαμόρφωση** μετακινεί τον διακομιστή σε μια ελεύθερη.

Ένας φορτωτής που είναι πολύ παλιός αλλάζει από την καρτέλα **Εκδόσεις** του διακομιστή, η οποία ελέγχει αν η έκδοση υπάρχει και παίρνει ένα αντίγραφο ασφαλείας πριν ξαναδημιουργήσει τον διακομιστή ([αλλαγή της έκδοσης του φορτωτή mod](/docs/updates/#changing-the-mod-loader-version)).
