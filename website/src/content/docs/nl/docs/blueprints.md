Een **blueprint** legt de volledige configuratie van een server vast (type, versie, bronnen, omgeving, pack pin, en optioneel de configuratie en wereld) in één draagbaar bestand waaruit je nieuwe servers kunt maken.

![Blueprints](/docs/images/blueprints.png)

## Exporteren

Exporteer vanuit een server een blueprint en kies wat je wilt meenemen: altijd de configuratie, en optioneel ingesloten bestanden en de wereld. Het resultaat wordt opgeslagen in je blueprintbibliotheek en kan worden gedownload om te delen.

## Importeren & creëren vanuit een blueprint

Importeer een blueprintbestand (of kies er een uit de bibliotheek) om een nieuwe server te maken die exact is voorgeconfigureerd zoals het origineel. Het is de snelste manier om:

- Identieke servers op te zetten (een netwerk van minigame-servers, staging-kopieën van productie).
- Een server te verplaatsen tussen panels.
- Een bekende, goede sjabloon te bewaren waar je altijd op terug kunt vallen.

Omdat een blueprint de exacte [pack pin](/docs/modpacks/) vastlegt, installeert een modpack-server die opnieuw is gemaakt vanuit een blueprint dezelfde vastgepinde versie, zonder verrassende upgrades.
