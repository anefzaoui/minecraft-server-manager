Het dashboard is je thuisbasis: elke server, de live status ervan en een lopende feed van wat er is gebeurd.

![Dashboard](/docs/images/dashboard.png)

## De samenvattingtegels

Bovenaan:

- **Servers online** - hoeveel van je servers momenteel draaien.
- **Spelers verbonden** - het totale aantal spelers op alle draaiende servers.
- **Updates beschikbaar** - hoeveel servers, packs of mods een nieuwere versie hebben ([zie Updates](/docs/updates/)).
- **Docker** - of het paneel de Docker daemon kan bereiken, en de versie ervan.

## Serverkaarten

Elke server wordt weergegeven als een kaart met zijn status (Draait, Starten, Gestopt, Gecrasht), het type en de Minecraft-versie, en de gamepoort. Voor draaiende servers krijg je ook live **spelers**, **CPU**, **geheugen** en **schijf**gebruik, continu bijgewerkt.

Klik op een kaart om die server te openen. De lege **Maak een server aan** kaart en de **Maak een Server aan** knop in de bovenbalk starten beide de [aanmaak-wizard](/docs/servers/).

Je kunt je servers zoeken en sorteren, en schakelen tussen raster- en lijstweergaven met de schakelaar aan de rechterkant.

## Recente activiteit

De feed onderaan is een live, leesbaar audit trail: logins, back-ups, blueprint-exports, update-controles, chat-commando-wijzigingen, serverstarts en -stops, en meer. Elke vermelding is getagd met de server waartoe deze behoort (of het paneel zelf) en hoe lang geleden het gebeurde. De volledige geschiedenis bevindt zich op de [Activiteit](/docs/activity/) pagina.
