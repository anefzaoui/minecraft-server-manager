Страница **Modpacks** (и вкладка **Из модпака** в [мастере создания](/docs/servers/)) устанавливает модпак как сервер, всегда **привязанный к точной версии пакета**, поэтому перезапуск никогда не сможет незаметно обновить пакет без вашего ведома.

![Modpacks](/docs/images/modpacks.png)

## Поддерживаемые платформы

- **CurseForge** — поиск или вставка URL пакета. Требуется ключ API CurseForge для поиска и приватных пакетов (добавьте его в разделе Настройки → Ключи API).
- **Modrinth** — поиск по названию.
- **FTB** — пакеты Feed The Beast.
- **GT New Horizons** — пакет 1.7.10 для экспертов, устанавливаемый из собственного индекса релизов GTNH. GTNH выбирает среду выполнения Java для каждого пакета (2.8.0+ работает на **Java 25** через встроенные исправления lwjgl3ify, более старые релизы на Java 21 или 17), а мастер увеличивает объем ОЗУ и дискового пространства сервера до разумных минимумов для него.
- **Пользовательский zip** — совсем не опубликованный пакет: загрузите **экспорт модпака CurseForge** (zip-файл с `manifest.json`, который приложение CurseForge создает для выбранного набора модов) или **любой zip-файл с jar-файлами модов**. Панель массово обрабатывает манифест через API CurseForge (или идентифицирует каждый jar-файл по хешу/отпечатку/метаданным), предварительно просматривает, что подходит, и устанавливает все за одну задачу — включая конфигурации `overrides/` пакета, если вы согласитесь. Моды, авторы которых запрещают автоматические загрузки, перечислены со ссылкой на браузер и слотом для ручной загрузки вместо ошибки установки.

## Как работает привязка

Когда вы выбираете пакет, панель определяет точную версию, записывает ее и устанавливает. На странице **Обновления** вам сообщат, когда будет доступна новая версия; обновление — это преднамеренное, контролируемое действие с резервным копированием перед обновлением и возможностью отката. Серверам со стабильным отслеживанием никогда не предлагается бета-версия.

Серверы, созданные на очень старых версиях панели (до 0.9.7), могли остаться _непривязанными_, что означало, что образ контейнера незаметно устанавливал последнюю версию пакета при каждом запуске. Теперь панель исправляет это при загрузке: она привязывает каждый сервер к фактически установленной версии (считываемой из собственных записей панели или манифеста установки образа, но никогда не из свежеопределенного "последнего") и регистрирует событие. Если панель не может определить, что установлено, на странице настроек сервера появляется предупреждение с просьбой выбрать версию вручную, а любая попытка сохранить непривязанную конфигурацию модпака отклоняется.

## Политика обновлений

У каждого сервера есть политика обновлений в **Настройках**, и все три варианта означают именно то, что говорят:

- **Только вручную** — ничего никогда не меняется само по себе, и сервер полностью исключается из значка обновлений и страницы обновлений. Режим "оставьте меня в покое": идеально подходит для вручную настроенного или импортированного пакета, который вы никогда не хотите трогать.
- **Уведомлять меня** (по умолчанию) — ежедневная проверка отображает доступные обновления в виде значка и на странице обновлений; применение их всегда осуществляется вашим кликом.
- **Автоматическое обновление** — после запланированной ежедневной проверки ожидающие **обновления пакета** применяются тем же контролируемым путем, что и ручное обновление: резервное копирование перед обновлением, мониторинг работоспособности и автоматический откат, если новая версия не запускается. Обновления, которые перемещают сервер на другую версию Minecraft, всегда пропускаются с регистрацией события — преобразование мира навсегда является решением, которое панель отказывается принимать за вас. Кнопки ручной проверки "Проверить сейчас" только проверяют; они никогда не запускают автоматические обновления.

## Обновление пакета

С привязанного сервера вы можете обновить пакет до новой версии одним действием. Панель сначала создает резервную копию, меняет привязанную версию, пересоздает контейнер (переопределяя Java, если новой версии требуется другая среда выполнения) и отслеживает первый запуск, с достаточным окном для больших пакетов, таких как GTNH, которые загружают пару гигабайт и создают мир с несколькими сотнями модов при первом запуске.
