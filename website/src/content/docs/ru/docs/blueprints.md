**Шаблон** (blueprint) сохраняет всю конфигурацию сервера (тип, версию, ресурсы, окружение, привязку модпака и, опционально, его конфигурацию и мир) в один переносимый файл, из которого вы можете создавать новые серверы.

![Шаблоны](/docs/images/blueprints.png)

## Экспорт

Из сервера экспортируйте шаблон, выбрав, что включить: конфигурацию всегда, а также, опционально, встроенные файлы и мир. Результат сохраняется в вашей библиотеке шаблонов и может быть загружен для обмена.

## Импорт и создание из шаблона

Импортируйте файл шаблона (или выберите один из библиотеки), чтобы создать новый сервер, полностью сконфигурированный как оригинал. Это самый быстрый способ:

- Запустить идентичные серверы (сеть серверов мини-игр, тестовые копии продакшена).
- Переместить сервер между панелями управления.
- Сохранить известный рабочий шаблон, к которому вы всегда можете вернуться.

Поскольку шаблон записывает точную [привязку модпака](/docs/modpacks/), сервер с модпаком, воссозданный из шаблона, устанавливает ту же привязанную версию без неожиданных обновлений.
