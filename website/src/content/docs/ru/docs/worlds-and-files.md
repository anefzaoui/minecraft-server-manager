## Миры

Страница **Миры** управляет данными миров на ваших серверах: переключайте активный мир, загружайте или скачивайте мир.

![Миры](/docs/images/worlds.png)

## Файловый менеджер

В разделе **Мир** сервера вкладка **Файлы** представляет собой полноценный файловый менеджер в браузере для каталога данных этого сервера. Списки, чтение, редактирование, создание, переименование, перемещение, копирование, удаление и загрузка файлов: всё, что вы обычно делаете через SSH, теперь доступно из браузера.

![Файловый менеджер](/docs/images/server-files.png)

Текстовые файлы открываются в редакторе с ограничением в 2 МБ; более крупные файлы можно скачать. Загрузка поддерживает несколько файлов одновременно.

### Оставаясь в пределах песочницы

Каждая операция с файлами ограничена собственным каталогом данных сервера. Панель проверяет каждый путь и отклоняет всё, что может привести к выходу за его пределы: обход `..`, абсолютные пути и даже символические ссылки, указывающие за пределы каталога (включая "висячие" ссылки, которые ещё не существуют). Мод или плагин не сможет создать ссылку, чтобы обманом заставить файловый менеджер читать или записывать данные в другом месте хоста.

## Моды

Для серверов с модами вкладка **Моды** (отдельная группа в боковой панели сервера) управляет набором модов: просматривайте и добавляйте моды, а также смотрите, что установлено. Обновления модов и пакетов отображаются на странице [Обновления](/docs/updates/).

### Добавление модов

![Моды](/docs/images/mods.png)

Четыре способа добавления, все с панели инструментов вкладки "Моды":

- **Поиск модов** - поиск по **Modrinth или CurseForge** (метка CurseForge появляется после ввода API-ключа в Настройки → API-ключи), а на серверах с плагинами также по **Hangar** (собственный реестр плагинов PaperMC) и **SpigotMC** (через прокси CDN Spiget) - оба без ключа. Всё фильтруется по загрузчику и версии Minecraft сервера; серверы Quilt автоматически видят сборки с тегом Fabric, поскольку Quilt запускает моды Fabric. Результаты, уже имеющиеся на сервере, отображаются с меткой **Установлено**. Если автор CurseForge запрещает автоматическую загрузку - или ресурс SpigotMC размещён вне сайта - панель сообщит об этом заранее и предложит путь **Открыть страницу** + **Загрузить jar** вместо сбоя в середине установки.

  ![Поиск Hangar](/docs/images/mods-search-hangar.png)

- **Импорт zip** - одна кнопка, три формата, автоопределение:
  - **Модпак Modrinth (`.mrpack`)**: каждый закреплённый файл канонизируется обратно в свой проект Modrinth через поиск по хешу (так импортированные моды сохраняют реальные имена, иконки и остаются доступными для проверки обновлений; файлы, которые Modrinth не знает, устанавливаются по собственной ссылке пакета), проверяется по контрольным суммам sha512 пакета во время загрузки и предпросматривается с вердиктами соответствия. Клиентские файлы пропускаются с отображением, и оба дерева переопределения (`overrides/`, затем `server-overrides/` - серверная копия имеет приоритет) могут быть применены.

    ![Импорт mrpack](/docs/images/mrpack-import.png)

  - **Экспорт модпака CurseForge** (zip-файл, который генерирует приложение CurseForge, с `manifest.json`): каждый закреплённый мод массово разрешается, предпросматривается с предупреждениями (неправильный загрузчик/версия MC для этого сервера, файлы больше не доступны на CurseForge, моды, требующие ручной загрузки) и устанавливается с реальным прогрессом. Файлы `overrides/` пакета (конфиги, скрипты) также могут быть опционально применены - любой файл, который будет перезаписан, сначала резервируется в `.import-backups/<timestamp>/` внутри папки сервера.
  - **Простой zip-архив с jar-файлами**, собранными вами: каждый jar-файл идентифицируется (совпадение хеша Modrinth → отпечаток пальца CurseForge → метаданные самого jar-файла) и оценивается относительно сервера - _подходит / неправильный загрузчик / неправильная версия MC / уже установлен / не идентифицирован_ - так что вы выбираете, что действительно подходит, прежде чем что-либо будет установлено.
- **Добавить по ссылке** - вставьте почти что угодно: страницы проектов Modrinth, CurseForge, Hangar или SpigotMC, URL репозитория или релиза GitHub (достаточно просто `owner/repo` - GitHub предпочитает последнюю стабильную версию и пропускает файлы `-sources`/`-javadoc`), простой slug Modrinth или любой прямой URL `.jar`. Панель определяет правильную сборку для загрузчика и версии MC сервера.

  ![Добавить по ссылке](/docs/images/mods-add-by-link.png)

- **Загрузить jar** (из резервного варианта поиска или из решателя ожидающих загрузок) - загруженные jar-файлы идентифицируются тем же образом, поэтому они сохраняют своё реальное имя, версию, иконку и становятся доступными для проверки обновлений.

Каждая установка из реестра **проверяется по контрольной сумме во время загрузки**: поток проверяется по самому сильному хешу, который публикует реестр (sha512 → sha256 → sha1 → md5), и несоответствие прерывает процесс до того, как что-либо будет сохранено на сервере.

Целый zip-архив (`.mrpack` включительно) также может **создать сервер**: во вкладке мастера _Из модпака_ загрузите его, и манифест пакета (или большинство голосов среди идентифицированных jar-файлов) заполнит загрузчик, версию Minecraft и сборку загрузчика.
