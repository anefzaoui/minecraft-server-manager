## Миры

Страница **Миры** — это библиотека миров: все сохраненные миры в одном месте. **Загрузить мир** принимает архив `.zip` или `.tar` и автоматически находит мир внутри него, **Сохранить в библиотеку** создает снимок текущего мира сервера (работает, пока сервер запущен), и каждый мир из библиотеки можно скачать или установить на любой сервер с помощью **Установить на…**. Установка либо заменяет мир сервера (сервер должен быть остановлен, а его текущий мир сначала будет сохранен в резервную копию), либо добавляет его параллельно, чтобы активировать позже. Перед каждой установкой выполняется проверка совместимости.

Собственная вкладка **Мир → Миры** сервера перечисляет миры на этом сервере. Оттуда вы можете активировать другой мир (при остановленном сервере), скачать, дублировать, переименовать или [сжать](/docs/world-shrink/) мир, скопировать его на другой сервер, удалить неактивный и сбросить активный мир с новым, сохраненным или пользовательским сидом (сначала предлагается резервная копия для безопасности). Ниже находится та же библиотека с кнопкой **Установить сюда**.

![Миры](/docs/images/worlds.png)

## Файловый менеджер

В разделе **Мир** сервера вкладка **Файлы** представляет собой полноценный файловый менеджер в браузере для каталога данных этого сервера. Списки, чтение, редактирование, переименование, перемещение, копирование, удаление и загрузка файлов, создание папок и поиск текста в файлах в папке с помощью **Найти в файлах**: все, что вы обычно делаете через SSH, из браузера.

![Файловый менеджер](/docs/images/server-files.png)

Текстовые файлы открываются в редакторе с ограничением в 8 МБ; более крупные файлы можно скачать. Загрузка принимает до 20 файлов одновременно.

### Оставаясь в песочнице

Каждая файловая операция ограничена собственным каталогом данных сервера. Панель разрешает каждый путь и отказывает во всем, что выходит за его пределы: обход `..`, абсолютные пути и даже символические ссылки, указывающие за пределы каталога (включая "висячие", которых еще не существует). Мод или плагин не сможет создать ссылку, чтобы обмануть файловый менеджер и заставить его читать или записывать данные в другом месте хоста.

## Моды

Для серверов с модами и плагинами вкладка **Моды** (отдельная группа в боковой панели сервера) управляет набором модов: просмотр и добавление модов, а также просмотр установленных. Для каждой строки установленного мода вы можете обновить его (или проигнорировать это обновление), [откатить](/docs/updates/#undoing-a-mod-update) его, отключить или удалить, а кнопка **Обновить все** применяет все доступные обновления с одной перезагрузкой. Обновления модов и пакетов также отображаются на странице [Обновления](/docs/updates/).

### Добавление модов

![Моды](/docs/images/mods.png)

Четыре способа добавления, все с панели инструментов вкладки "Моды":

- **Поиск модов**: поиск по **Modrinth или CurseForge** (чип CurseForge появляется после ввода API-ключа в **Настройки → API-ключи**), а на серверах с плагинами также по **Hangar** (собственный реестр плагинов PaperMC) и **SpigotMC** (через прокси-сервер Spiget CDN), оба без ключей. Вкладка **Datapacks** ищет датапаки на Modrinth. Все фильтруется по загрузчику и версии Minecraft сервера (флажок также показывает сборки, не помеченные как совместимые, на ваш страх и риск); серверы Quilt автоматически видят сборки с тегом fabric, так как Quilt запускает моды Fabric. Результаты, уже имеющиеся на сервере, отображаются с меткой **Установлено**. Если автор CurseForge запрещает автоматические загрузки (или ресурс SpigotMC размещен вне сайта), панель сообщит об этом заранее и предложит путь **Открыть CurseForge** (или **Открыть SpigotMC**) + **Загрузить Jar** вместо сбоя в середине установки.

  ![Поиск Hangar](/docs/images/mods-search-hangar.png)

- **Импорт Zip**: одна кнопка, три формы, автоопределение:
  - **Modpack от Modrinth (`.mrpack`)**: каждый закрепленный файл канонизируется обратно в свой проект Modrinth через поиск по хешу (так что импортированные моды сохраняют реальные имена, значки и остаются доступными для обновления; файлы, которые Modrinth не знает, устанавливаются по собственному URL пакета), проверяется по контрольным суммам sha512 пакета во время загрузки и предпросматривается с вердиктами соответствия. Файлы, предназначенные только для клиента, пропускаются с отображением, и могут быть применены оба дерева переопределения (`overrides/`, затем `server-overrides/`; копия, специфичная для сервера, имеет приоритет).

    ![Импорт mrpack](/docs/images/mrpack-import.png)

  - **Экспорт модпака CurseForge** (zip, который создает приложение CurseForge, с `manifest.json`): каждый закрепленный мод разрешается оптом, предпросматривается с предупреждениями (неправильный загрузчик/MC для этого сервера, файлы больше не доступны на CurseForge, моды, требующие ручной загрузки) и устанавливается с реальным прогрессом. `overrides/` пакета (конфигурации, скрипты) также могут быть применены по желанию; любой файл, который будет перезаписан, сначала сохраняется в `.import-backups/<timestamp>/` внутри папки сервера.
  - **Простой zip с jar-файлами**, которые вы собрали сами: каждый jar-файл идентифицируется (совпадение хеша Modrinth → отпечаток CurseForge → собственный метаданные jar-файла) и оценивается относительно сервера (_подходит / неправильный загрузчик / неправильная версия MC / уже установлен / неопознан_), так что вы выбираете, что действительно принадлежит, прежде чем что-либо будет установлено.
- **Добавить по URL**: вставьте почти что угодно: страницы проектов Modrinth, CurseForge, Hangar или SpigotMC, URL репозитория или релиза GitHub (достаточно просто `owner/repo`; установки GitHub предпочитают последнюю стабильную версию и пропускают боковые jar-файлы `-sources`/`-javadoc`), простой slug Modrinth или любой прямой URL `.jar`. Панель разрешает правильную сборку для загрузчика и версии MC сервера.

  ![Добавить по ссылке](/docs/images/mods-add-by-link.png)

- **Загрузить Jar** (из резервного варианта поиска или из решателя ожидающих загрузок): загруженные jar-файлы идентифицируются тем же способом, поэтому они сохраняют свое реальное имя, версию, значок и становятся доступными для обновления.

Каждая установка из реестра **проверяется по контрольной сумме во время загрузки**: поток проверяется по самому надежному хешу, который публикует реестр (sha512 → sha256 → sha1 → md5), и несоответствие прерывает процесс до того, как что-либо будет сохранено на сервере.

Целый zip-архив (`.mrpack` включительно) также может **создать сервер**: на вкладке мастера **Из модпака** загрузите его, и манифест пакета (или большинство голосов среди идентифицированных jar-файлов) заполнит загрузчик, версию Minecraft и сборку загрузчика.
