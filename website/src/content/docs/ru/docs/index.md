Полная, саморазмещаемая панель управления для [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server). Создавайте, запускайте и управляйте серверами Minecraft из вашего браузера. Без командной строки, без ручного редактирования YAML.

![Dashboard](/docs/images/dashboard.png)

## Начните здесь

- **[Начало работы](/docs/getting-started/)** - первоначальная настройка, вход в систему и ориентация.
- **[Панель управления](/docs/dashboard/)** - обзор всех серверов, игроков и активности.

## Запуск серверов

- **[Создание и управление серверами](/docs/servers/)** - мастер создания, типы серверов, версии и настройки для каждого сервера.
- **[Консоль и команды чата](/docs/console-and-chat/)** - живая консоль и пользовательские внутриигровые команды чата, выполняемые от имени игрока.
- **[Модпаки](/docs/modpacks/)** - установка модпаков CurseForge, Modrinth, FTB и GT New Horizons, всегда привязанных к точной версии.
- **[Миры и файлы](/docs/worlds-and-files/)** - обмен мирами, управление модами и редактирование файлов непосредственно в браузере.
- **[Сжатие мира](/docs/world-shrink/)** - освобождение дискового пространства путем удаления неиспользуемых чанков, отдельно или как часть резервной копии.

## Данные и автоматизация

- **[Чат-бот для каждого сервера](/docs/chatbot/)** - локальный чат, совместимый с OpenAI, оповещения, сохранение истории переписки и ограниченные игровые возможности.
- **[Резервные копии](/docs/backups/)** - снимки в один клик, запланированные резервные копии и восстановление.
- **[Шаблоны](/docs/blueprints/)** - захват всей конфигурации сервера и создание новых серверов на ее основе.
- **[Расписания](/docs/schedules/)** - перезапуски, резервные копии и команды по расписанию cron.
- **[Хранилище](/docs/storage/)** - использование дискового пространства для каждого сервера и квоты, установленные панелью.
- **[Обновления](/docs/updates/)** - отслеживание новых версий серверов, модпаков, образов и модов.
- **[Журнал активности](/docs/activity/)** - журнал аудита всего произошедшего.
- **[Интеграции](/docs/integrations/)** - уведомления через Discord webhook и категория оповещений.
- **[Публичный API](/docs/public-api/)** - HTTP API только для чтения с аутентификацией по токену для получения статуса сервера извне панели.

## Учетные записи и безопасность

- **[Пользователи и роли](/docs/users-and-roles/)** - администратор, оператор и наблюдатель, и что каждый из них может делать.
- **[Двухфакторная аутентификация](/docs/two-factor-authentication/)** - защита вашего входа с помощью приложения-аутентификатора.

## Под капотом

- **[Архитектура](/docs/architecture/)** - как устроена панель.
- **[Веб-сайт](/docs/website/)** - как minecraft-server-manager.com собирается, переводится и развертывается из этого репозитория.

---

> Скриншоты в этой документации сделаны в темной теме панели. Панель запускается в темной теме, если ваша ОС не предпочитает светлую; используйте переключатель темы в верхней панели для смены.
