Полная, самостоятельно размещаемая панель управления для [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server). Создавайте, запускайте и управляйте серверами Minecraft из вашего браузера. Без командной строки, без ручного редактирования YAML.

![Dashboard](/docs/images/dashboard.png)

## Начните здесь

- **[Начало работы](/docs/getting-started/)** - первоначальная настройка, вход в систему и навигация.
- **[Панель управления](/docs/dashboard/)** - обзор всех серверов, игроков и активности.

## Запуск серверов

- **[Создание и управление серверами](/docs/servers/)** - мастер создания, типы серверов, версии и настройки для каждого сервера.
- **[Консоль и команды чата](/docs/console-and-chat/)** - живая консоль и пользовательские внутриигровые команды чата, выполняемые от имени игрока.
- **[Сборки модов (Modpacks)](/docs/modpacks/)** - установка сборок CurseForge, Modrinth, FTB и GT New Horizons, всегда привязанных к точной версии.
- **[Миры и файлы](/docs/worlds-and-files/)** - смена миров, управление модами и редактирование файлов непосредственно в браузере.
- **[Сжатие мира](/docs/world-shrink/)** - освобождение дискового пространства путем удаления неиспользуемых чанков, отдельно или как часть резервной копии.
- **[Живая карта](/docs/live-map/)** - 3D-карта мира BlueMap в один клик, доступная после входа в панель.
- **[Приглашения и страница статуса](/docs/invites-and-status-page/)** - адрес, текст приглашения и сборка модов клиента для друзей, а также общедоступная страница статуса.

## Данные и автоматизация

- **[Чат-бот для каждого сервера](/docs/chatbot/)** - локальный/совместимый с OpenAI чат, уведомления, сохранение истории переписки и ограниченные игровые возможности.
- **[Резервные копии](/docs/backups/)** - снимки в один клик, запланированные резервные копии, количество сохраняемых копий (для всей панели или для каждого сервера) и восстановление.
- **[Шаблоны (Blueprints)](/docs/blueprints/)** - захват полной конфигурации сервера и создание новых на ее основе.
- **[Расписания (Schedules)](/docs/schedules/)** - перезапуски, резервное копирование и команды по расписанию cron.
- **[Хранилище (Storage)](/docs/storage/)** - использование дискового пространства для каждого сервера и квоты, установленные панелью.
- **[Обновления](/docs/updates/)** - отслеживание новых версий сервера, сборок, образов и модов, проверка совместимости ваших модов с версиями Minecraft и отмена обновления мода.
- **[Журнал активности](/docs/activity/)** - журнал аудита всего, что произошло.
- **[Интеграции](/docs/integrations/)** - уведомления через вебхуки Discord и категория оповещений.
- **[Публичный API](/docs/public-api/)** - HTTP API только для чтения с аутентификацией по токену для получения статуса сервера извне панели.

## Учетные записи и безопасность

- **[Пользователи и роли](/docs/users-and-roles/)** - администратор, оператор и наблюдатель, их возможности и разрешения для каждого сервера, которые их уточняют.
- **[Двухфакторная аутентификация](/docs/two-factor-authentication/)** - защита вашего входа с помощью приложения-аутентификатора.

## Руководства

Не относятся конкретно к этой панели: вопросы, с которыми сталкивается каждый владелец сервера Minecraft.

- **[Сколько ОЗУ нужно серверу?](/docs/guide-server-memory/)** - два параметра для установки и почему простаивающий сервер потребляет 12 ГБ.
- **[Vanilla, Paper, Fabric, Forge, NeoForge, Quilt](/docs/guide-choosing-a-loader/)** - какой выбрать и разница в плагинах/модах, влияющая на выбор.
- **[Ваш сервер не запускается](/docs/guide-server-wont-start/)** - чтение логов и несколько причин большинства сбоев.
- **[Резервные копии, которые действительно восстанавливаются](/docs/guide-backups/)** - согласованные копии, что еще нужно сохранить и тестирование перед необходимостью.
- **[Перенос сервера на другой хост](/docs/guide-moving-a-server/)** - порядок действий, который сокращает время простоя и сохраняет инвентарь.
