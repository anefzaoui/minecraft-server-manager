## Консоль в реальном времени

Вкладка **Консоль** в реальном времени отображает журнал сервера и предоставляет поле для ввода команд, позволяющее отправлять любые команды сервера. Никакого `docker exec`, никакого SSH. Вывод возвращается непосредственно в журнал, включая цвета.

![Консоль](/docs/images/server-console.png)

Консоль также используется для определения состояния сервера: она отслеживает журнал, чтобы классифицировать фазу загрузки ("Загрузка модов", "Генерация мира", "Завершение запуска") и вызывает команду `list` для отслеживания подключенных игроков, поэтому панель управления и карточки серверов всегда отражают реальность.

Это периодическое сканирование открывает кратковременное RCON-соединение каждый цикл, которое регистрируется сервером как пара `Thread RCON Client … started` / `shutting down` примерно каждые ~20 секунд, а также (на серверах, где ядро или плагины дублируют вывод) строку `Rcon issued server command: …` для каждого запроса только для чтения — `list` для подсчета игроков, а также чтение `time query …` и `gamerule <name>`, когда открыта страница "Управление миром". Переключатель **Скрыть RCON-шум** над журналом фильтрует эти строки (вместе со строками запуска RCON-слушателя). Он включен по умолчанию и запоминается для каждого браузера; отключите его, чтобы увидеть необработанный поток.

Команды, отправленные с панели, могут быть объявлены в игре под меткой для каждого сервера, чтобы игроки знали, что действовал оператор, а не неизвестная консоль.

## Команды чата

Команды чата позволяют игрокам запускать действия панели, вводя команду с префиксом в игровом чате, например `!spawn` для случайной телепортации. Обнаружение основано на журнале, а выполнение происходит через сервер, поэтому **моды не требуются**.

![Команды чата](/docs/images/chat-commands.png)

Каждая команда имеет:

- **Триггер** (например, `spawn`) и **префикс** (`!` по умолчанию).
- **Действие**: случайная телепортация, телепортация к структуре, телепортация в биом или выполнение необработанных команд консоли.
- **Уровень разрешений**: все, игроки из белого списка или только операторы.
- **Время восстановления** и настраиваемые сообщения об ожидании / успехе / неудаче с плейсхолдерами, такими как `{distance}`.

### Примечание по безопасности

Команды, которые могут повредить сервер (`stop`, `op`, `ban`, `whitelist` и подобные), разрешены только для триггеров **только для операторов**. Панель проверяет это, даже когда команды вложены в цепочку `execute … run …`, поэтому триггер с низким уровнем разрешений не может незаметно передать опасную команду. Обычный текст чата, просто упоминающий эти слова (например, сообщение `say`), игнорируется.
