## Консоль в реальном времени

Вкладка **Консоль** в реальном времени отображает журнал сервера и предоставляет поле для ввода команд, которые можно отправлять на сервер. Никакого `docker exec`, никакого SSH. Вывод возвращается непосредственно в журнал, включая цвета. Для отправки команд требуется разрешение Console для этого сервера; без него вы можете только просматривать журнал.

Над журналом вы можете фильтровать строки по тексту (или по `/регулярному выражению/`) и по уровню (INFO, WARN, ERROR), а опция **Скачать** предлагает недавний вывод, полный файл `latest.log` или все файлы журналов в виде zip-архива.

![Консоль](/docs/images/server-console.png)

Консоль также используется для определения состояния сервера: панель отслеживает журнал, чтобы классифицировать фазу загрузки ("Loading mods", "Generating world", "Finishing startup"), и выполняет команду `list` для отслеживания подключенных игроков, поэтому панель управления и карточки серверов всегда отражают реальность.

Это периодическое сканирование открывает кратковременное RCON-соединение каждый цикл, которое в журналах сервера отображается как пара `Thread RCON Client … started` / `shutting down` примерно каждые ~20 секунд, а также (на серверах, где ядро или плагины дублируют его) строку `Rcon issued server command: …` для каждого запроса только для чтения (`list` для количества игроков, а также чтение `time query …` и `gamerule <name>`, когда открыты элементы управления миром). Переключатель **Скрыть шум консоли** над журналом фильтрует эти строки (вместе со строками запуска RCON-слушателя). Он включен по умолчанию и запоминается для каждого браузера; отключите его, чтобы увидеть необработанный поток.

Команды, отправленные с панели, могут быть объявлены в игре под меткой, специфичной для сервера (поле **Объявлять как…**), чтобы игроки знали, что действовал оператор, а не неизвестная консоль.

## Чат

**Консоль → Чат** отправляет сообщения в игру во время работы сервера: **Стилизованные** сообщения принимают цвета и форматирование и могут быть отправлены всем или одному онлайн-игроку, а **Простые** отправляют обычное широковещательное сообщение `[Server]` всем.

![Консоль → Чат](/docs/screenshots/04-chat.png)

## Команды чата

Команды чата (**Консоль → Команды**) позволяют игрокам запускать действия панели, вводя команду с префиксом в чате игры, например `!spawn` для случайной телепортации. Обнаружение основано на журнале, а выполнение происходит через сервер, поэтому **моды не требуются**.

![Команды чата](/docs/images/chat-commands.png)

Каждая команда имеет:

- **Триггер** (например, `spawn`), вводимый после **префикса** сервера (`!` по умолчанию, один или два символа, никогда не `/`).
- **Действие**: случайная телепортация, телепортация к структуре, телепортация к биому или выполнение необработанных команд консоли.
- **Уровень разрешения**: все, игроки из белого списка или только операторы.
- **Период восстановления** для каждого игрока (по умолчанию 30 секунд) и настраиваемые сообщения об ожидании / успехе / неудаче с плейсхолдерами, такими как `{distance}`.

### Примечание о безопасности

Команды, которые могут повредить сервер (`stop`, `op`, `ban`, `whitelist` и подобные), разрешены только для триггеров, доступных **только операторам**. Панель проверяет это, даже когда команды вложены в цепочку `execute … run …`, поэтому триггер с низким уровнем разрешений не может незаметно передать опасную команду. Обычный текст чата, который просто упоминает эти слова (например, сообщение `say`), остается без изменений.
