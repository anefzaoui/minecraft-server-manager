Страница **Расписания** автоматизирует повторяющиеся задачи с помощью cron-выражений. Никакого внешнего cron, никаких скриптов.

![Расписания](/docs/images/schedules.png)

## Что можно запланировать

- **Перезапуски** — ночной перезапуск для поддержания работоспособности сервера, работающего длительное время.
- **Резервные копии** — регулярные снимки (помеченные как `scheduled` на странице [Резервные копии](/docs/backups/)).
- **Команды** — выполнение любой команды сервера по расписанию.
- **Проверки обновлений** — периодическое обновление устаревших компонентов.

Каждое расписание нацелено на конкретный сервер (или на панель в целом), выполняется по собственному cron-выражению и может быть включено или отключено без удаления. Время последнего запуска отображается, чтобы вы могли подтвердить его срабатывание.
