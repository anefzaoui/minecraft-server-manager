Страница **Хранилище** показывает, куда уходит ваше дисковое пространство: использование на каждый сервер и его динамика с течением времени.

![Хранилище](/docs/images/storage.png)

## Квоты диска применяются панелью управления

Docker не может ограничить использование диска для bind mount, поэтому это делает панель управления. Фоновый индексатор размеров сканирует каталог данных, кэширует объем данных каждого сервера и применяет установленную вами квоту диска для каждого сервера. Когда данные сервера (мир + резервные копии + всё остальное) приближаются к своей квоте, панель управления останавливает неконтролируемый рост, а не позволяет одному серверу заполнить ваш хост.

Установите квоту сервера в его [настройках](/docs/servers/). Модифицированные серверы и их [резервные копии](/docs/backups/) могут быть большими, поэтому оставьте им достаточно места.

## Очистка

Представление "Хранилище" поможет вам найти, что удалить (старые резервные копии, неиспользуемые миры или сервер, который значительно превысил ожидания), прежде чем у вас закончится место.
