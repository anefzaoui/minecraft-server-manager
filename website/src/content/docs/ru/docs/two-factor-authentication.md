Двухфакторная аутентификация (2FA) добавляет второй шаг при входе: после ввода пароля вы вводите короткий код из приложения-аутентификатора на вашем телефоне. Даже если кто-то узнает ваш пароль, он не сможет войти без вашего устройства.

Она работает с любым стандартным TOTP-аутентификатором (Google Authenticator, Authy, 1Password, Microsoft Authenticator и другими), и доступна **каждому** аккаунту, а не только администраторам. Защита вашего собственного входа не является действием по управлению сервером, поэтому зрители и операторы также могут включить её.

## Включение 2FA

Откройте меню аккаунта (ваши инициалы, вверху справа) и выберите **Двухфакторная аутентификация**.

![Меню аккаунта](/docs/images/2fa-user-menu.png)

Появится диалоговое окно регистрации:

![Регистрация](/docs/images/2fa-enroll.png)

1. **Отсканируйте QR-код** с помощью вашего приложения-аутентификатора или нажмите **Копировать** и введите ключ вручную.
2. Введите **6-значный код**, который теперь отображается в вашем приложении.
3. **Подтвердите ваш пароль.** Включение 2FA повторно проверяет ваш пароль, поэтому случайная открытая сессия не сможет включить её с чужого устройства.
4. Нажмите **Включить**.

### Сохраните резервные коды

Сразу после включения 2FA панель покажет набор одноразовых **резервных кодов**.

![Резервные коды](/docs/images/2fa-backup-codes.png)

Каждый код действует **один раз** для входа, если вы потеряете доступ к своему приложению-аутентификатору. Сохраните их в надёжном месте (идеально — в менеджере паролей), так как они больше не будут показаны. Вы можете сгенерировать новый набор в любое время (что сделает старые коды недействительными).

## Вход с 2FA

С этого момента вход будет иметь второй шаг. После имени пользователя и пароля панель запросит ваш код:

![Вход с 2FA](/docs/images/2fa-login-challenge.png)

Введите текущий 6-значный код из вашего приложения (или один из ваших резервных кодов), и вы войдёте. До тех пор, пока вы не выполните этот шаг, сессия **не** будет авторизована: она не сможет получить доступ ни к одной странице или API.

## Управление или отключение 2FA

Откройте ту же запись **Двухфакторная аутентификация** в меню аккаунта, когда она включена. После подтверждения вашего пароля вы можете:

- **Сгенерировать новые резервные коды** — выдаёт новый набор и отзывает старый.
- **Отключить 2FA** — удаляет её из вашего аккаунта.

Оба действия сначала запрашивают ваш текущий пароль.

## Потеряли телефон _и_ резервные коды?

**Администратор** может сбросить 2FA другого пользователя в разделе **Настройки → Пользователи** (кнопка **Сбросить** в столбце 2FA). Это очистит 2FA для аккаунта, чтобы пользователь мог войти только с паролем и настроить её заново. Администраторы не могут сбрасывать свою собственную 2FA без пароля. Они проходят обычный процесс отключения с подтверждением пароля, поэтому скомпрометированная сессия администратора не сможет отключить свой собственный второй фактор.

## Полезно знать

- Коды основаны на времени и меняются каждые 30 секунд; панель допускает небольшое расхождение часов и тихо восстанавливается, если часы сервера впоследствии будут скорректированы.
- Код нельзя использовать повторно — как только он использован для входа, тот же код не сработает снова в течение своего окна действия.
- Неправильные коды подвергаются ограничению скорости. Ограничитель **общий** с шагом ввода пароля (блокировка аккаунта плюс ограничение `RATE_LIMIT_AUTH_PER_15MIN` на IP-адрес), поэтому ввод правильного пароля не может сбросить счётчик непосредственно перед подбором 6-значного кода.
- Изменения 2FA (включение, отключение, сброс, использование резервного кода) записываются в [Журнал активности](/docs/activity/).
