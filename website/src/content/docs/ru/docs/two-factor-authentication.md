Двухфакторная аутентификация (2FA) добавляет второй шаг при входе: после ввода пароля вы вводите короткий код из приложения-аутентификатора на вашем телефоне. Даже если кто-то узнает ваш пароль, он не сможет войти без вашего устройства.

Это работает с любым стандартным TOTP-аутентификатором (Google Authenticator, Authy, 1Password, Microsoft Authenticator и другими), и доступно **всем** учетным записям, а не только администраторам. Защита вашего собственного входа не является действием по управлению сервером, поэтому зрители и операторы также могут включить ее.

## Включение 2FA

Откройте меню учетной записи (ваша инициал или изображение профиля, в правом верхнем углу) и выберите **2FA**.

![Меню учетной записи](/docs/images/2fa-user-menu.png)

Появится диалоговое окно регистрации:

![Регистрация](/docs/images/2fa-enroll.png)

1. **Отсканируйте QR-код** с помощью вашего приложения-аутентификатора или нажмите **Копировать** и введите ключ вручную.
2. Введите **6-значный код**, который теперь отображается в вашем приложении.
3. **Подтвердите свой пароль.** Включение 2FA повторно проверяет ваш пароль, поэтому случайная открытая сессия не сможет включить его с устройства другого человека.
4. Нажмите **Включить**.

### Сохраните резервные коды

Как только 2FA будет включена, панель управления покажет набор одноразовых **резервных кодов**.

![Резервные коды](/docs/images/2fa-backup-codes.png)

Каждый код работает **один раз** для входа, если вы когда-либо потеряете доступ к своему приложению-аутентификатору. Сохраните их в надежном месте (идеально подходит менеджер паролей), так как они больше не будут показаны. Вы можете сгенерировать новый набор в любое время (что сделает старые недействительными).

## Вход с 2FA

С этого момента вход будет иметь второй шаг. После ввода имени пользователя и пароля панель запросит ваш код:

![Вход с 2FA](/docs/images/2fa-login-challenge.png)

Введите текущий 6-значный код из вашего приложения (или один из ваших резервных кодов), и вы войдете. До завершения этого шага сессия **не** считается вошедшей в систему: она не может получить доступ ни к одной странице или API.

## Управление или отключение 2FA

Откройте ту же запись **2FA** в меню учетной записи, когда она включена. После подтверждения вашего пароля вы можете:

- **Сгенерировать новые резервные коды** выдаст новый набор и отзовет старые.
- **Отключить 2FA** удалит ее из вашей учетной записи.

Оба действия сначала запрашивают ваш текущий пароль.

## Потеряли телефон _и_ резервные коды?

**Администратор** может сбросить 2FA другого пользователя через **Настройки → Пользователи** (**Сбросить 2FA** в меню действий этого пользователя). Это очистит 2FA для учетной записи, чтобы пользователь мог войти только с паролем и настроить ее заново. Администраторы не могут сбрасывать свою _собственную_ 2FA без пароля. Они проходят обычный процесс отключения с запросом пароля, поэтому скомпрометированная сессия администратора не может удалить свой собственный второй фактор.

## Полезно знать

- Коды основаны на времени и меняются каждые 30 секунд; панель допускает небольшое расхождение часов и тихо восстанавливается, если часы сервера будут позже скорректированы.
- Код не может быть повторно использован: как только он использован для входа, тот же код не будет работать снова в течение своего окна действия.
- Неправильные коды подвергаются ограничению скорости. Ограничитель **общий** с шагом пароля (блокировка на учетную запись плюс ограничение на IP-адрес `RATE_LIMIT_AUTH_PER_15MIN`), поэтому ввод правильного пароля не может сбросить счетчик непосредственно перед угадыванием 6-значного кода.
- Изменения 2FA (включение, отключение, сброс, использование резервного кода) записываются в [Журнал активности](/docs/activity/).
