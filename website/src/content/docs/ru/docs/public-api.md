Небольшой HTTP API только для чтения, позволяющий получать статус сервера извне панели:
панель состояния, монитор доступности, бот для Discord, правило автоматизации дома. Он
обслуживается самой панелью и возвращает те же данные в реальном времени, которые
отображаются на собственных страницах панели (из кэша в памяти), поэтому опрос
API не затрагивает Docker.

Он **отключен, пока администратор не воспользуется им**, и **контролируется администратором**.
Ничего не будет доступно, пока не существует токен.

## Включение

**Настройки → Публичный API → Новый ключ**. Присвойте ему имя, выберите, что он может
видеть (все серверы или определенный поднабор) и, при желании, дату истечения срока
действия. Полный ключ (токен Bearer) отображается **один раз** в диалоговом окне; скопируйте
его сейчас, потому что впоследствии будет сохраняться только короткий префикс для
идентификации в списке.

![Настройки Публичного API](/docs/images/settings-public-api.png)

Создание первого ключа автоматически включает API (переключатель **Разрешить внешним
приложениям читать статус** является элементом управления паузой: отключите его, чтобы
прекратить обслуживание без отмены каких-либо ключей). Отмените ключ из той же таблицы
в любое время; клиенты, использующие его, немедленно теряют доступ.

Токены хранятся в виде хеша SHA-256 (никогда в открытом виде), переживают перезапуск
панели и переживают серверы, к которым они привязаны (удаленный сервер просто
выпадает из результатов этого токена).

## Аутентификация

Отправьте токен как учетные данные Bearer:

```
Authorization: Bearer msm_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Нет никаких файлов cookie и **никакого CORS**: это предназначено для сервер-серверных
вызовов и вызовов из командной строки, а не для браузерных приложений с другого
источника. Если панель находится за обратным прокси-сервером, убедитесь, что прокси
пересылает заголовок `Authorization`.

Ошибки возвращают `401` с `{ "ok": false, "error": "..." }`. Любой метод, кроме `GET`
(или `HEAD`), возвращает `405`. Неизвестные пути возвращают `404`. Когда API отключен,
каждый маршрут возвращает `404`.

## Ограничение скорости

Каждый токен получает свой собственный бюджет, `RATE_LIMIT_PUBLIC_API_PER_MIN` (по умолчанию `120`
запросов/минуту; `0` отключает ограничитель). Превышение лимита возвращает `429`. Запросы,
которые никогда не представляют действительный токен (отсутствующий, некорректный,
отозванный или истекший), ограничиваются отдельно для каждого IP-адреса клиента в пять
раз больше этого числа, поэтому зондирование не может обойти бюджет, вращая токены.

## Конечные точки

### `GET /api/v1/servers`

Все серверы, к которым привязан токен.

```json
{
  "ok": true,
  "total": 1,
  "online": 1,
  "servers": [
    {
      "id": "srv_ab12cd34",
      "name": "SMP",
      "type": "PAPER",
      "state": "running",
      "cpuPct": 18.4,
      "memoryMb": 2048,
      "memoryLimitMb": 4096,
      "uptimeSeconds": 11722,
      "players": { "online": 3, "max": 20 }
    }
  ]
}
```

### `GET /api/v1/servers/:id`

Один сервер, тот же объект под ключом `server`. Возвращает `404` для неизвестного `id`
**и** для сервера, к которому токен не привязан (нет оракула существования), и `400`
для некорректного `id`.

## Поля ответа

| Поле            | Значение                                                                                                        |
| --------------- | --------------------------------------------------------------------------------------------------------------- |
| `total`         | Сколько серверов видно этому токену (после фильтра области действия).                                           |
| `online`        | Сколько из них в состоянии: `running`.                                                                          |
| `id`            | Стабильный идентификатор сервера (`srv_...`).                                                                   |
| `name`          | Отображаемое имя.                                                                                               |
| `type`          | Тип сервера itzg (`PAPER`, `FABRIC`, `AUTO_CURSEFORGE`, ...).                                                   |
| `state`         | `running`, `starting`, `stopped` или `crashed` - стабильное сводное представление внутреннего состояния панели. |
| `cpuPct`        | Недавний процент использования ЦП или `null`, когда сервер не запущен.                                          |
| `memoryMb`      | Используемая память в МБ или `null`.                                                                            |
| `memoryLimitMb` | Настроенный лимит памяти контейнера в МБ или `null`.                                                            |
| `uptimeSeconds` | Секунды с момента запуска контейнера или `null`.                                                                |
| `players`       | `{ online, max }` или `null` до тех пор, пока сервер не сообщит список игроков.                                 |

## Пример

```sh
curl -s https://panel.example.com/api/v1/servers \
  -H "Authorization: Bearer $MSM_TOKEN" | jq
```
