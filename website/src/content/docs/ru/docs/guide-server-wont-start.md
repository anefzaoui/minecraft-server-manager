## 1. Читайте последние двадцать строк, а не первые

Прокрутите до **конца** лога. Трассировка стека Java выводится сначала изнутри, поэтому верхняя часть стены текста — наименее интересная часть. Вам нужна последняя строка `Caused by:` и всё, что следует за ней. Эта одна строка обычно указывает на проблему.

Две формы подскажут вам, где вы находитесь:

- `Exception in thread "main"` или путь к файлу отчёта о сбое в конце означает, что сама игра завершилась с ошибкой.
- Лог просто обрывается на середине строки, без каких-либо исключений, означает, что процесс был остановлен извне. Перейдите к пункту 3.

## 2. UnsupportedClassVersionError означает неправильную версию Java

```
java.lang.UnsupportedClassVersionError: net/minecraft/server/Main has been compiled
by a more recent version of the Java Runtime (class file version 65.0)
```

Класс 52 — это Java 8, 60 — 16, 61 — 17, 65 — 21, 69 — 25. Сообщение означает, что серверу нужна более новая версия Java, чем та, на которой он работает; обратная ситуация, старый модпак на новой Java, обычно приводит к ошибке миксина или рефлексии.

| Версия Minecraft | Java |
| ---------------- | ---- |
| 1.16.5 и старше  | 8    |
| 1.17             | 16   |
| 1.18 и 1.19      | 17   |
| 1.20 to 1.20.4   | 17   |
| 1.20.5 to 1.21.x | 21   |
| 26.1 и новее     | 25   |

Старым модпакам действительно нужна Java 8. Новая версия здесь не лучше.

## 3. Код выхода 137 — это ядро, а не мод

Лог обрывается на полуслове, отчёта о сбое нет, и контейнер сообщает код 137. Это означает завершение работы из-за нехватки памяти (out-of-memory kill): процесс запросил память, которой не было у машины, поэтому он был остановлен.

Почти всегда размер Java heap устанавливался равным общему объёму памяти машины. Heap требует объёма памяти машины **минус** накладные расходы самой JVM, которые составляют от 0.5 до 1.5 ГБ на сервере с модами. Уменьшите размер heap или увеличьте объём памяти машины. [Сколько ОЗУ нужно серверу](/docs/guide-server-memory/) содержит цифры.

## 4. EULA и порт

Две классические проблемы с однострочными решениями:

- `You need to agree to the EULA in order to run the server.` Установите `eula=true` в `eula.txt` или с помощью переменной окружения, которую использует ваша установка.
- `Address already in use` или `FAILED TO BIND TO PORT`. Что-то другое уже использует порт 25565, часто это предыдущая копия того же сервера, которая так и не была полностью остановлена. Найдите её и остановите, вместо того чтобы менять порт, иначе у вас будет два сервера.

## 5. Моду не хватает зависимости

```
Mod X requires mod Y, which is missing
Fabric API is not installed
```

Моды Fabric подавляющим большинством требуют Fabric API как отдельный файл. Моды Forge и NeoForge перечисляют свои зависимости в самой ошибке. Установите указанную версию, а не самую новую: "requires 0.91.x" означает именно эту строку, а версия 0.92 вызовет ту же ошибку.

Иногда отсутствующей зависимостью является сам загрузчик:

```
Mod X requires forge 47.4.14 or above
Mod ID: 'forge', Requested by: 'x', Expected range: '[47.4.14,)', Actual version: '47.4.10'
```

Решение — более новая сборка загрузчика, а не другой мод. "47.4.14 or above" означает любую сборку начиная с этой, а Forge не публикует все номера, поэтому устанавливаемая сборка может быть следующей по порядку. В случае модпака сначала обновите сам модпак: модпак, версия загрузчика которого слишком стара для его модов, является ошибкой автора модпака.

## 6. Мод предназначен для другого загрузчика или версии

JAR-файл для другого загрузчика не выдаёт вежливую ошибку. Ожидайте ошибку миксина, `NoClassDefFoundError` или сбой внутри класса, о котором вы никогда не слышали. Проверьте страницу JAR-файла: загрузчик и версия Minecraft должны совпадать точно. 1.20.1 и 1.20.4 — это разные игры с точки зрения модов.

## 7. Мир из более новой версии

```
This world was created by a newer version of Minecraft
```

Миры обновляются только вперёд и никогда назад. Восстановите резервную копию, сделанную до обновления, или запустите версию, которую ожидает мир. Не существует пути отката, который сохранит чанки неповреждёнными.

## Когда сбой произошёл после нескольких недель нормальной работы

Другой вопрос, обычно другой ответ:

- **Сбой произошёл под нагрузкой**, с показаниями таймингов о длительных паузах: сборка мусора, поэтому посмотрите на размер heap до установки модов.
- **Сбой произошёл в одной и той же точке мира**: повреждённый чанк или сломанная сущность. Отчёт о сбое обычно указывает координаты.
- **Сбой произошёл сразу после обновления**: виноват обновлённый мод, даже если трассировка указывает на другое. Откатите его и посмотрите.
- **Сбой произошёл при перезапуске, хотя до этого всё работало**: проверьте диск. Полный диск вызывает эффектные и вводящие в заблуждение ошибки.

## Получение помощи, которая действительно помогает

Публикуйте **весь лог**, а не последнюю строку, и укажите, что вы изменили перед тем, как всё сломалось. Вставьте его туда, где он предназначен для этого, например, на [mclo.gs](https://mclo.gs), а не в чат. Укажите версию Minecraft, загрузчик, модпак и его версию, а также объём heap, выделенный серверу. Отчёт с этими четырьмя фактами будет рассмотрен за один ответ; без них потребуется пять.

## В Minecraft Server Manager

Сбои обнаруживаются по завершению работы самого контейнера, поэтому сервер, который падает в три часа ночи, записывается с выдержкой из лога, а не обнаруживается на следующий день. Обычные подозрения, перечисленные на этой странице (EULA, неправильная версия Java, мир из более новой версии, занятый порт, нехватка памяти Java), распознаются в логе и указываются в записи истории с инструкциями по их устранению, а автоматический перезапуск их игнорирует, поскольку перезапуск их не исправит. Отчёты о сбоях анализируются при получении: исключение выделяется, стек можно свернуть, а моды, фигурирующие в трассировке, перечислены как подозреваемые.

Любой отчёт можно отправить на mclo.gs из его карточки, когда вам понадобится помощь (после подтверждения, так как публикация является общедоступной), а в меню **Download** консоли все файлы логов собраны в один zip-архив, поэтому "опубликовать весь лог" — это скачать, а не археологический проект. Сбой из-за нехватки памяти записывается как сбой из-за нехватки памяти, что экономит обычный час, потраченный на обвинение мода. Если что-то другое действительно требует порт, карточка **Game Port** в **Settings → Configuration** переместит сервер на свободный порт.

Слишком старый загрузчик меняется на вкладке **Versions** сервера, которая проверяет наличие сборки и делает резервную копию перед пересборкой сервера ([изменение версии загрузчика модов](/docs/updates/#changing-the-mod-loader-version)).
