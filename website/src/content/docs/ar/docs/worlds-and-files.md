## العوالم

صفحة **العوالم** هي مكتبة العوالم: كل العوالم المحفوظة في مكان واحد. **تحميل عالم** يأخذ أرشيف `.zip` أو `.tar` ويجد العالم بداخله تلقائيًا، **حفظ في المكتبة** يلتقط لقطة للعالم المباشر للخادم (يعمل أثناء تشغيل الخادم)، ويمكن تنزيل كل عالم في المكتبة أو تثبيته على أي خادم باستخدام **التثبيت على...**. التثبيت إما يستبدل عالم الخادم (يجب إيقاف الخادم، ويتم عمل نسخة احتياطية من عالمه الحالي أولاً) أو يضيفه بجانبه، لتفعيله لاحقًا. يتم تشغيل فحص التوافق قبل كل تثبيت.

علامة تبويب **العالم → العوالم** الخاصة بالخادم تسرد العوالم الموجودة على هذا الخادم. من هناك يمكنك تفعيل عالم آخر (مع إيقاف الخادم)، تنزيل، نسخ، إعادة تسمية، أو [تقليص](/docs/world-shrink/) عالم، نسخه إلى خادم آخر، حذف عالم غير نشط، وإعادة تعيين العالم النشط ببذرة جديدة، محفوظة، أو مخصصة (يتم تقديم نسخة احتياطية أمان أولاً). نفس المكتبة تظهر أدناه، مع **التثبيت هنا**.

![العوالم](/docs/images/worlds.png)

## مدير الملفات

ضمن قسم **العالم** الخاص بالخادم، علامة التبويب **الملفات** هي مدير ملفات كامل داخل المتصفح لدليل بيانات هذا الخادم. سرد، قراءة، تحرير، إعادة تسمية، نقل، نسخ، حذف، وتحميل الملفات، إنشاء مجلدات، والبحث في نصوص الملفات تحت مجلد باستخدام **البحث في الملفات**: كل ما تفعله عادةً عبر SSH، من المتصفح.

![مدير الملفات](/docs/images/server-files.png)

تُفتح الملفات النصية في محرر بحد أقصى 8 ميجابايت؛ يمكن تنزيل الملفات الأكبر حجمًا. تقبل التحميلات ما يصل إلى 20 ملفًا في المرة الواحدة.

### البقاء داخل الصندوق الرملي

تقتصر كل عملية ملف على دليل بيانات الخادم الخاص به. يحل اللوحة كل مسار ويرفض أي شيء قد يهرب: اجتياز `..`، المسارات المطلقة، وحتى الروابط الرمزية التي تشير إلى خارج الدليل (بما في ذلك المعلقة التي لم يتم إنشاؤها بعد). لا يمكن لتعديل أو إضافة زرع رابط لخداع مدير الملفات لقراءة أو كتابة في مكان آخر على المضيف.

## التعديلات

بالنسبة للخوادم المعدلة والمزودة بإضافات، تدير علامة التبويب **التعديلات** (مجموعة خاصة بها في الشريط الجانبي للخادم) مجموعة التعديلات: تصفح وإضافة التعديلات، ورؤية ما تم تثبيته. من صف كل تعديل مثبت يمكنك تحديثه (أو تجاهل هذا التحديث)، [التراجع](/docs/updates/#undoing-a-mod-update) عنه، تعطيله، أو إزالته، و **تحديث الكل** يطبق كل التحديثات المتاحة مع إعادة تشغيل واحدة. تظهر تحديثات التعديلات والحزم أيضًا في صفحة [التحديثات](/docs/updates/).

### إضافة التعديلات

![التعديلات](/docs/images/mods.png)

أربع طرق للدخول، كلها من شريط أدوات علامة التبويب التعديلات:

- **البحث عن التعديلات**: ابحث في **Modrinth أو CurseForge** (يظهر زر CurseForge بمجرد تخزين مفتاح API ضمن **الإعدادات → مفاتيح API**)، وفي خوادم الإضافات أيضًا **Hangar** (سجل إضافات PaperMC الخاص) و **SpigotMC** (عبر وكيل CDN الخاص بـ Spiget)، كلاهما بدون مفتاح. علامة تبويب **حزم البيانات** تبحث في حزم بيانات Modrinth. يتم تصفية كل شيء ليناسب محمل الخادم وإصدار Minecraft (مربع اختيار يعرض أيضًا الإصدارات غير المدرجة كمتوافقة، على مسؤوليتك الخاصة)؛ ترى خوادم Quilt تلقائيًا الإصدارات المصنفة كـ fabric أيضًا، لأن Quilt تشغل تعديلات Fabric. تظهر النتائج الموجودة بالفعل على الخادم شارة **مثبت**. إذا منع مؤلف CurseForge التنزيلات الآلية (أو كان مورد SpigotMC مستضافًا خارج الموقع)، فإن اللوحة تخبرك بذلك مقدمًا وتعرض مسار **فتح CurseForge** (أو **فتح SpigotMC**) + **تحميل Jar** بدلاً من الفشل في منتصف التثبيت.

  ![بحث Hangar](/docs/images/mods-search-hangar.png)

- **استيراد Zip**: زر واحد، ثلاثة أشكال، يتم اكتشافها تلقائيًا:
  - **حزمة تعديلات Modrinth (`.mrpack`)**: يتم توحيد كل ملف مثبت مرة أخرى إلى مشروع Modrinth الخاص به عبر البحث عن الهاش (بحيث تحتفظ التعديلات المستوردة بالأسماء والأيقونات الحقيقية، وتبقى قابلة للتحديث؛ الملفات التي لا يعرفها Modrinth يتم تثبيتها من عنوان URL الخاص بالحزمة)، يتم التحقق منها مقابل مجاميع sha512 الخاصة بالحزمة أثناء التنزيل، ويتم معاينتها مع نتائج مناسبة. يتم تخطي الملفات الخاصة بالعميل بشكل مرئي، ويمكن تطبيق أشجار التجاوز (`overrides/`، ثم `server-overrides/`؛ النسخة الخاصة بالخادم هي الفائزة).

    ![استيراد mrpack](/docs/images/mrpack-import.png)

  - **تصدير حزمة تعديلات CurseForge** (ملف zip الذي ينتجه تطبيق CurseForge، مع `manifest.json`): يتم حل كل تعديل مثبت بشكل جماعي، ويتم معاينته مع تحذيرات (محمل / MC خاطئ لهذا الخادم، ملفات لم تعد موجودة على CurseForge، تعديلات تتطلب تنزيلًا يدويًا)، ويتم تثبيته مع تقدم حقيقي. يمكن أيضًا تطبيق `overrides/` الخاصة بالحزمة (الإعدادات، البرامج النصية) اختياريًا؛ يتم عمل نسخة احتياطية لأي ملف سيتم الكتابة فوقه أولاً في `.import-backups/<timestamp>/` داخل مجلد الخادم.
  - **ملف zip عادي من ملفات jar** جمعتها بنفسك: يتم تحديد كل ملف jar (مطابقة هاش Modrinth → بصمة CurseForge → بيانات التعريف الخاصة بملف jar نفسه) ويتم الحكم عليه مقابل الخادم (_مناسب / محمل خاطئ / إصدار MC خاطئ / مثبت بالفعل / غير محدد_)، لذا تختار ما ينتمي بالفعل قبل تثبيت أي شيء.
- **إضافة حسب عنوان URL**: الصق أي شيء تقريبًا: صفحات مشاريع Modrinth، CurseForge، Hangar، أو SpigotMC، عنوان URL لمستودع GitHub أو الإصدار (يكفي `owner/repo`؛ تفضل تثبيتات GitHub أحدث إصدار مستقر وتتخطى ملفات `sources-`/`javadoc` الجانبية)، اسم Modrinth بسيط، أو أي عنوان URL مباشر لملف `.jar`. يحل اللوحة الإصدار الصحيح لمحمل الخادم وإصدار MC.

  ![إضافة برابط](/docs/images/mods-add-by-link.png)

- **تحميل Jar** (من السقوط الاحتياطي للبحث أو محلل التنزيلات المعلقة): يتم تحديد ملفات jar المحملة بنفس الطريقة، لذا تحتفظ باسمها الحقيقي وإصدارها وأيقونتها وتصبح قابلة للتحديث.

يتم **التحقق من المجموع الاختباري لكل تثبيت من السجل أثناء تنزيله**: يتم فحص الدفق مقابل أقوى هضم تنشره السجل (sha512 → sha256 → sha1 → md5) ويتوقف عدم التطابق قبل وصول أي شيء إلى الخادم.

يمكن أيضًا لملف zip كامل (`.mrpack` مضمن) **إنشاء خادم**: في علامة التبويب **من حزمة التعديلات** في المعالج، قم بتحميله وسيتم ملء محمل الخادم وإصدار Minecraft وإصدار المحمل من خلال بيان الحزمة (أو تصويت الأغلبية عبر ملفات jar المحددة).
