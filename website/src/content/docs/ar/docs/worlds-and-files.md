## العوالم

تدير صفحة **العوالم** بيانات العوالم عبر خوادمك: قم بتبديل العالم النشط، أو قم بتحميل عالم، أو قم بتنزيله.

![العوالم](/docs/images/worlds.png)

## مدير الملفات

ضمن قسم **العالم** الخاص بالخادم، علامة التبويب **الملفات** هي مدير ملفات كامل داخل المتصفح لملف بيانات ذلك الخادم. قم بسرد، قراءة، تحرير، إنشاء، إعادة تسمية، نقل، نسخ، حذف، وتحميل الملفات: كل ما كنت تفعله عادةً عبر SSH، من المتصفح.

![مدير الملفات](/docs/images/server-files.png)

يتم فتح الملفات النصية في محرر بحد أقصى 2 ميجابايت؛ يمكن تنزيل الملفات الأكبر حجمًا. يقبل التحميل ملفات متعددة في وقت واحد.

### البقاء داخل الصندوق الرملي

تقتصر كل عملية ملف على دليل بيانات الخادم الخاص به. يقوم اللوحة بحل كل مسار ويرفض أي شيء قد يؤدي إلى الهروب: اجتياز `..`، المسارات المطلقة، وحتى الروابط الرمزية التي تشير إلى خارج الدليل (بما في ذلك الروابط المعلقة التي لم يتم إنشاؤها بعد). لا يمكن لتعديل أو إضافة زرع رابط لخداع مدير الملفات لقراءة أو الكتابة في مكان آخر على المضيف.

## التعديلات (Mods)

بالنسبة للخوادم المعدلة، تدير علامة التبويب **التعديلات** (مجموعة خاصة بها في الشريط الجانبي للخادم) مجموعة التعديلات: تصفح وإضافة التعديلات، ورؤية ما تم تثبيته. تظهر تحديثات التعديلات والحزم على صفحة [التحديثات](/docs/updates/).

### إضافة التعديلات

![التعديلات](/docs/images/mods.png)

أربع طرق للدخول، كلها من شريط أدوات علامة التبويب التعديلات:

- **البحث عن التعديلات** - ابحث في **Modrinth أو CurseForge** (يظهر شريحة CurseForge بمجرد تخزين مفتاح API ضمن الإعدادات ← مفاتيح API)، وعلى خوادم الإضافات أيضًا **Hangar** (سجل إضافات PaperMC الخاص) و **SpigotMC** (عبر وكيل CDN الخاص بـ Spiget) - كلاهما بدون مفاتيح. يتم تصفية كل شيء ليناسب مُحمّل الخادم وإصدار Minecraft؛ ترى خوادم Quilt تلقائيًا الإصدارات التي تحمل علامة Fabric أيضًا، لأن Quilt تشغل تعديلات Fabric. تظهر النتائج الموجودة بالفعل على الخادم شارة **مثبت**. إذا منع مؤلف CurseForge التنزيلات الآلية - أو تم استضافة مورد SpigotMC خارج الموقع - فإن اللوحة تخبرك بذلك مقدمًا وتقدم مسار **فتح الصفحة** + **تحميل jar** بدلاً من الفشل في منتصف التثبيت.

  ![بحث Hangar](/docs/images/mods-search-hangar.png)

- **استيراد zip** - زر واحد، ثلاثة أشكال، تم اكتشافها تلقائيًا:
  - **حزمة تعديلات Modrinth (`.mrpack`)**: يتم توحيد كل ملف مثبت في مشروعه الأصلي على Modrinth عبر البحث عن الهاش (بحيث تحتفظ التعديلات المستوردة بالأسماء والأيقونات الحقيقية، وتبقى قابلة للتحقق من التحديثات؛ يتم تثبيت الملفات التي لا يعرفها Modrinth من عنوان URL الخاص بالحزمة)، ويتم التحقق منها مقابل مجاميع التحقق sha512 للحزمة أثناء التنزيل، ويتم معاينتها مع نتائج مناسبة. يتم تخطي الملفات الخاصة بالعميل بشكل مرئي، ويمكن تطبيق كلا شجرتي التجاوز (`overrides/`، ثم `server-overrides/` - النسخة الخاصة بالخادم هي الفائزة).

    ![استيراد mrpack](/docs/images/mrpack-import.png)

  - **تصدير حزمة تعديلات CurseForge** (ملف zip الذي ينتجه تطبيق CurseForge، مع `manifest.json`): يتم حل كل تعديل مثبت بشكل جماعي، ويتم معاينته مع تحذيرات (مُحمّل خاطئ / إصدار MC خاطئ لهذا الخادم، ملفات لم تعد موجودة على CurseForge، تعديلات تتطلب تنزيلًا يدويًا)، ويتم تثبيتها مع تقدم حقيقي. يمكن أيضًا تطبيق `overrides/` الخاص بالحزمة (الإعدادات، البرامج النصية) اختياريًا - يتم عمل نسخة احتياطية لأي ملف سيتم الكتابة فوقه أولاً في `.import-backups/<timestamp>/` داخل مجلد الخادم.
  - **ملف zip عادي من ملفات jar** جمعتها بنفسك: يتم تحديد كل ملف jar (مطابقة هاش Modrinth ← بصمة CurseForge ← بيانات التعريف الخاصة بملف jar نفسه) ويتم الحكم عليه مقابل الخادم - _مناسب / مُحمّل خاطئ / إصدار MC خاطئ / مثبت بالفعل / غير محدد_ - لذا يمكنك اختيار ما ينتمي بالفعل قبل تثبيت أي شيء.
- **إضافة برابط** - الصق أي شيء تقريبًا: صفحات مشاريع Modrinth، CurseForge، Hangar، أو SpigotMC، عنوان URL لمستودع GitHub أو الإصدار (يعمل `owner/repo` بسيط أيضًا - تفضل تثبيتات GitHub أحدث إصدار مستقر وتتخطى ملفات `-sources`/`-javadoc` الجانبية)، اسم Modrinth بسيط، أو أي عنوان URL مباشر لـ `.jar`. يقوم اللوحة بحل الإصدار الصحيح لمُحمّل الخادم وإصدار MC.

  ![إضافة برابط](/docs/images/mods-add-by-link.png)

- **تحميل jar** (من النسخ الاحتياطي للبحث أو محلل التنزيلات المعلقة) - يتم تحديد ملفات jar التي تم تحميلها بنفس الطريقة، لذا تحتفظ باسمها الحقيقي وإصدارها وأيقونتها وتصبح قابلة للتحقق من التحديثات.

يتم **التحقق من مجاميع التحقق لكل تثبيت من السجل أثناء تنزيله**: يتم فحص التدفق مقابل أقوى هضم ينشره السجل (sha512 → sha256 → sha1 → md5) ويتوقف عدم التطابق قبل أن يصل أي شيء إلى الخادم.

يمكن أيضًا لملف zip كامل (`.mrpack` متضمن) **إنشاء خادم**: في علامة التبويب _من حزمة التعديلات_ في المعالج، قم بتحميله وسيملأ بيان الحزمة (أو تصويت الأغلبية عبر ملفات jar المحددة) المُحمّل وإصدار Minecraft وبناء المُحمّل.
