واجهة برمجة تطبيقات HTTP صغيرة للقراءة فقط لجلب حالة الخادم من خارج اللوحة: لوحة معلومات الحالة، ومراقب وقت التشغيل، وروبوت Discord، وقاعدة أتمتة منزلية. يتم تقديمها بواسطة اللوحة نفسها وتعيد نفس البيانات الحية التي تعرضها صفحات اللوحة الخاصة (من ذاكرة التخزين المؤقت في الذاكرة)، لذا فإن استقصائها لا يلمس Docker أبدًا.

إنها **متوقفة حتى يستخدمها مسؤول** و **محمية بواسطة المسؤول**. لا يتم كشف أي شيء حتى يوجد رمز مميز.

## تمكينها

**الإعدادات ← واجهة برمجة التطبيقات العامة ← مفتاح جديد**. امنحها اسمًا، واختر ما يمكنها رؤيته (جميع الخوادم، أو مجموعة فرعية محددة)، وتاريخ انتهاء اختياري. يتم عرض المفتاح الكامل (رمز مميز للحامل) **مرة واحدة**، في مربع حوار؛ انسخه الآن، لأنه لا يتم الاحتفاظ إلا ببادئة قصيرة بعد ذلك، لتحديد الهوية في القائمة.

![إعدادات واجهة برمجة التطبيقات العامة](/docs/images/settings-public-api.png)

إنشاء المفتاح الأول يقوم بتشغيل واجهة برمجة التطبيقات تلقائيًا (المفتاح **السماح للتطبيقات الخارجية بقراءة الحالة** هو عنصر تحكم للإيقاف المؤقت: قم بإيقافه لإيقاف الخدمة دون إلغاء أي مفاتيح). قم بإلغاء مفتاح من نفس الجدول في أي وقت؛ يفقد العملاء الذين يستخدمونه الوصول على الفور.

يتم تخزين الرموز المميزة كـ SHA-256 hash (لا يتم تخزينها أبدًا كنص عادي)، وتنجو من إعادة تشغيل اللوحة، وتتجاوز الخوادم التي تم تحديد نطاقها لها (يتم إسقاط الخادم المحذوف ببساطة من نتائج هذا الرمز المميز).

## المصادقة

أرسل الرمز المميز كبيانات اعتماد للحامل:

```
Authorization: Bearer msm_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

لا توجد ملفات تعريف ارتباط و **لا CORS**: هذا مخصص لمكالمات الخادم إلى الخادم و CLI، وليس لتطبيقات المتصفح من مصدر آخر. إذا كانت اللوحة خلف وكيل عكسي، فتأكد من أن الوكيل يقوم بتمرير رأس `Authorization`.

تعيد حالات الفشل `401` مع `{ "ok": false, "error": "..." }`. أي شيء آخر غير `GET` (أو `HEAD`) يعيد `405`. المسارات غير المعروفة تعيد `404`. عندما يتم تعطيل واجهة برمجة التطبيقات، تعيد كل مسارات `404`.

## حد المعدل

يحصل كل رمز مميز على ميزانيته الخاصة، `RATE_LIMIT_PUBLIC_API_PER_MIN` (الافتراضي `120` طلبًا/دقيقة؛ `0` يعطل المحدد). تجاوز الحد يعيد `429`. الطلبات التي لا تقدم أبدًا رمزًا مميزًا صالحًا (مفقود، أو تالف، أو ملغى، أو منتهي الصلاحية) يتم تحديد سقفها بشكل منفصل لكل عنوان IP للعميل بخمسة أضعاف هذا الرقم، لذلك لا يمكن للاستقصاء تجاوز الميزانية عن طريق تدوير الرموز المميزة.

## نقاط النهاية

### `GET /api/v1/servers`

كل خادم تم تحديد نطاق الرمز المميز له.

```json
{
  "ok": true,
  "total": 1,
  "online": 1,
  "servers": [
    {
      "id": "srv_ab12cd34",
      "name": "SMP",
      "type": "PAPER",
      "state": "running",
      "cpuPct": 18.4,
      "memoryMb": 2048,
      "memoryLimitMb": 4096,
      "uptimeSeconds": 11722,
      "players": { "online": 3, "max": 20 }
    }
  ]
}
```

### `GET /api/v1/servers/:id`

خادم واحد، نفس الكائن تحت مفتاح `server`. يعيد `404` لمعرف غير معروف **و** لخادم لم يتم تحديد نطاق الرمز المميز له (لا يوجد مصدر وجود)، و `400` لمعرف تالف.

## حقول الاستجابة

| حقل             | المعنى                                                                                   |
| --------------- | ---------------------------------------------------------------------------------------- |
| `total`         | عدد الخوادم المرئية لهذا الرمز المميز (بعد تصفية نطاقه).                                 |
| `online`        | عدد الخوادم التي في الحالة: `running`.                                                   |
| `id`            | معرف الخادم الثابت (`srv_...`).                                                          |
| `name`          | اسم العرض.                                                                               |
| `type`          | نوع خادم itzg (`PAPER`, `FABRIC`, `AUTO_CURSEFORGE`, ...).                               |
| `state`         | `running`، `starting`، `stopped`، أو `crashed` - ملخص ثابت لحالة اللوحة الداخلية.        |
| `cpuPct`        | نسبة استخدام وحدة المعالجة المركزية الأخيرة، أو `null` عندما لا يكون الخادم قيد التشغيل. |
| `memoryMb`      | الذاكرة المقيمة بالميجابايت، أو `null`.                                                  |
| `memoryLimitMb` | حد ذاكرة الحاوية المحدد بالميجابايت، أو `null`.                                          |
| `uptimeSeconds` | الثواني منذ بدء تشغيل الحاوية، أو `null`.                                                |
| `players`       | `{ online, max }`، أو `null` حتى يقوم الخادم بالإبلاغ عن قائمة اللاعبين.                 |

## مثال

```sh
curl -s https://panel.example.com/api/v1/servers \
  -H "Authorization: Bearer $MSM_TOKEN" | jq
```
