اعمل على هذه القائمة. وهي مرتبة حسب تكرار كون كل منها هو الإجابة، والأربعة الأولى تغطي معظمها.

## 1. اقرأ آخر عشرين سطرًا، وليس الأول

مرر إلى **نهاية** السجل. يتم طباعة تتبع مكدس Java بشكل داخلي أولاً، لذا فإن الجزء العلوي من جدار النص هو الجزء الأقل إثارة للاهتمام. ما تريده هو آخر سطر `Caused by:` وما يتبعه. هذا السطر الواحد عادة ما يحدد المشكلة.

شكلان يخبرانك بمكانك:

- `Exception in thread "main"` أو مسار تقرير الأعطال بالقرب من النهاية يعني أن اللعبة نفسها فشلت.
- توقف السجل ببساطة في منتصف السطر، دون أي استثناء على الإطلاق، يعني أن شيئًا ما قتل العملية من الخارج. انتقل إلى النقطة 3.

## 2. UnsupportedClassVersionError يعني Java خاطئة

```
java.lang.UnsupportedClassVersionError: net/minecraft/server/Main has been compiled
by a more recent version of the Java Runtime (class file version 65.0)
```

ملف الفئة 52 هو Java 8، و 60 هو 16، و 61 هو 17، و 65 هو 21، و 69 هو 25. الرسالة تعني أن الخادم يحتاج إلى Java أحدث مما يعمل عليه؛ العكس، حزمة قديمة على Java جديدة، تفشل عادةً بخطأ في المزج (mixin) أو خطأ في الانعكاس (reflection).

| إصدار Minecraft   | Java |
| ----------------- | ---- |
| 1.16.5 وما قبله   | 8    |
| 1.17              | 16   |
| 1.18 و 1.19       | 17   |
| 1.20 إلى 1.20.4   | 17   |
| 1.20.5 إلى 1.21.x | 21   |
| 26.1 وما بعده     | 25   |

الحزم القديمة تحتاج حقًا إلى Java 8. الأحدث ليس أفضل هنا.

## 3. رمز الخروج 137 هو النواة، وليس تعديلًا

يتوقف السجل في منتصف الجملة، ولا يوجد تقرير أعطال، ويبلغ الحاوية عن 137. هذا هو إنهاء بسبب نفاد الذاكرة: طلبت العملية ذاكرة لم تكن الآلة تمتلكها، لذلك تم إنهاؤها.

في معظم الأحيان، تم تعيين ذاكرة Java العشوائية (heap) لتكون نفس عدد ذاكرة الآلة. تحتاج الذاكرة العشوائية إلى ذاكرة الآلة **ناقص** النفقات العامة لـ JVM نفسها، والتي تتراوح بين 0.5 و 1.5 جيجابايت على خادم معدل. قلل الذاكرة العشوائية، أو زد الآلة. [كم تحتاج ذاكرة الخادم من الوصول العشوائي](/docs/guide-server-memory/) يحتوي على الأرقام.

## 4. اتفاقية ترخيص المستخدم النهائي (EULA) والمنفذ

اثنان كلاسيكيات بإصلاحات من سطر واحد:

- `You need to agree to the EULA in order to run the server.` اضبط `eula=true`، في `eula.txt` أو باستخدام متغير البيئة الذي يستخدمه إعدادك.
- `Address already in use` أو `FAILED TO BIND TO PORT`. شيء آخر يشغل المنفذ 25565، غالبًا نسخة سابقة من نفس الخادم لم تتوقف بالكامل. ابحث عنها وأوقفها بدلاً من تغيير المنفذ، وإلا سينتهي بك الأمر باثنين.

## 5. تعديل يفتقد إلى تبعيته

```
Mod X requires mod Y, which is missing
Fabric API is not installed
```

تتطلب تعديلات Fabric بشكل ساحق Fabric API كملف منفصل. تسرد تعديلات Forge و NeoForge تبعياتها في الخطأ نفسه. قم بتثبيت الإصدار المسمى، وليس الأحدث: "يتطلب 0.91.x" يعني هذا السطر، و 0.92 سيفشل في نفس الفحص.

في بعض الأحيان تكون التبعية المفقودة هي المحمل نفسه:

```
Mod X requires forge 47.4.14 or above
Mod ID: 'forge', Requested by: 'x', Expected range: '[47.4.14,)', Actual version: '47.4.10'
```

الإصلاح هو بناء محمل أحدث، وليس تعديلًا مختلفًا. "47.4.14 أو أعلى" يعني أي بناء من هناك فصاعدًا، و Forge لا ينشر كل رقم، لذا قد يكون البناء المراد تثبيته هو التالي. على حزمة تعديلات، قم بتحديث الحزمة أولاً: حزمة يكون إصدار محملها قديمًا جدًا بالنسبة لتعديلاتها هو خطأ يجب على مؤلفها إصلاحه.

## 6. تعديل مخصص للمحمل أو الإصدار الخاطئ

ملف jar لمحمل مختلف لا يفشل بأدب. توقع خطأ في المزج (mixin)، أو `NoClassDefFoundError`، أو عطل داخل فئة لم تسمع بها من قبل. تحقق من صفحة ملف jar: يجب أن يتطابق كل من المحمل وإصدار Minecraft تمامًا. 1.20.1 و 1.20.4 هما لعبتان مختلفتان بقدر ما يتعلق الأمر بالتعديلات.

## 7. العالم من إصدار أحدث

```
This world was created by a newer version of Minecraft
```

العوالم ترتقي للأمام ولا تعود أبدًا للخلف. استعد النسخة الاحتياطية من قبل الترقية، أو قم بتشغيل الإصدار الذي يتوقعه العالم. لا يوجد مسار تخفيض يحافظ على الأجزاء سليمة.

## عندما تعطل بعد العمل بشكل جيد لأسابيع

سؤال مختلف، إجابة مختلفة عادةً:

- **تعطل تحت الحمل**، مع إظهار التوقيتات لتوقفات طويلة: جمع القمامة (garbage collection)، لذا انظر إلى حجم الذاكرة العشوائية قبل التعديلات.
- **تعطل عند نفس النقطة في العالم**: جزء تالف أو كيان معطل. تقرير الأعطال عادة ما يحدد الإحداثيات.
- **تعطل مباشرة بعد التحديث**: التعديل الذي تم تحديثه هو المشتبه به، حتى لو كان التتبع يشير إلى مكان آخر. قم بإلغاء تثبيته وانظر.
- **تعطل عند إعادة التشغيل، بعد أن كان يعمل جيدًا من قبل**: تحقق من القرص. القرص الممتلئ ينتج أخطاء مذهلة ومضللة.

## الحصول على مساعدة مفيدة حقًا

انشر **السجل بأكمله**، وليس السطر الأخير، واذكر ما قمت بتغييره قبل أن يتعطل. الصقه في مكان مصمم لذلك، مثل [mclo.gs](https://mclo.gs)، بدلاً من الدردشة. قم بتضمين إصدار Minecraft، والمحمل، والحزمة وإصدارها، ومقدار الذاكرة العشوائية التي يمتلكها الخادم. يتم الرد على تقرير بهذه الحقائق الأربعة في رد واحد؛ بدونها يستغرق الأمر خمسة.

## في Minecraft Server Manager

يتم اكتشاف الأعطال من خروج الحاوية نفسها، لذا يتم تسجيل خادم يموت في الساعة الثالثة صباحًا مع مقتطف سجله بدلاً من العثور عليه في اليوم التالي. يتم التعرف على المشتبه بهم المعتادين في هذه الصفحة (اتفاقية ترخيص المستخدم النهائي، Java الخاطئة، عالم من إصدار أحدث، منفذ مشغول بالفعل، نفاد ذاكرة Java) في هذا السجل ويتم تسميتها في إدخال السجل مع ما يجب فعله بشأنها، وإعادة التشغيل التلقائي يتركها وشأنها، حيث أن إعادة التشغيل لن تصلحها. يتم تحليل تقارير الأعطال عند وصولها: يتم تمييز الاستثناء، ويمكن طي المكدس، ويتم سرد التعديلات التي تظهر في التتبع كمشتبه بهم.

يمكن مشاركة أي تقرير إلى mclo.gs من بطاقته عندما تحتاج إلى مساعدة (بعد تأكيد، حيث أن اللصق عام)، وقائمة **تنزيل** وحدة التحكم تحتوي على كل ملف سجل كملف مضغوط واحد، لذا فإن "نشر السجل بأكمله" هو تنزيل بدلاً من مشروع أثري. يتم تسجيل إنهاء نفاد الذاكرة كإنهاء نفاد الذاكرة، مما يوفر ساعة معتادة من لوم تعديل. إذا كان هناك شيء آخر يحتاج حقًا إلى المنفذ، فإن بطاقة **منفذ اللعبة** في **الإعدادات → التكوين** تنقل الخادم إلى منفذ مجاني.

يتم تغيير المحمل القديم جدًا من علامة التبويب **الإصدارات** للخادم، والتي تتحقق من وجود البناء وتأخذ نسخة احتياطية قبل إعادة بناء الخادم ([تغيير إصدار محمل التعديل](/docs/updates/#changing-the-mod-loader-version)).
