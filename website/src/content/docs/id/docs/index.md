Panel kontrol lengkap, self-hosted untuk [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server). Buat, jalankan, dan kelola server Minecraft dari peramban Anda. Tanpa baris perintah, tanpa mengedit YAML secara manual.

![Dashboard](/docs/images/dashboard.png)

## Mulai di sini

- **[Memulai](/docs/getting-started/)** - penyiapan pertama kali, masuk, dan cara menggunakan panel.
- **[Dasbor](/docs/dashboard/)** - tampilan ringkas semua server, pemain, dan aktivitas.

## Menjalankan server

- **[Membuat & mengelola server](/docs/servers/)** - wizard pembuatan, jenis server, versi, dan pengaturan per server.
- **[Konsol & perintah obrolan](/docs/console-and-chat/)** - konsol langsung, dan perintah obrolan dalam game kustom yang berjalan sebagai pemain.
- **[Modpack](/docs/modpacks/)** - instal paket CurseForge, Modrinth, FTB, dan GT New Horizons, selalu disematkan ke versi yang tepat.
- **[Dunia & file](/docs/worlds-and-files/)** - tukar dunia, kelola mod, dan edit file langsung di peramban.
- **[Mengecilkan dunia](/docs/world-shrink/)** - menghemat ruang disk dengan menghapus chunk yang tidak pernah dikunjungi, baik sendiri maupun sebagai bagian dari cadangan.
- **[Peta langsung](/docs/live-map/)** - peta 3D BlueMap satu klik dari dunia, di balik fitur masuk panel.
- **[Undangan & halaman status](/docs/invites-and-status-page/)** - alamat, teks undangan, dan modpack klien untuk teman, serta halaman status publik.

## Data & otomatisasi

- **[Chatbot per server](/docs/chatbot/)** - percakapan lokal/kompatibel OpenAI, jangkauan, transkrip yang disimpan, dan kekuatan gameplay yang terbatas.
- **[Cadangan](/docs/backups/)** - snapshot satu klik, cadangan terjadwal, berapa banyak yang harus disimpan (seluruh panel atau per server), dan pemulihan.
- **[Blueprint](/docs/blueprints/)** - tangkap seluruh konfigurasi server dan buat yang baru darinya.
- **[Jadwal](/docs/schedules/)** - restart, cadangan, dan perintah berbasis cron.
- **[Penyimpanan](/docs/storage/)** - penggunaan disk per server dan kuota yang diberlakukan panel.
- **[Pembaruan](/docs/updates/)** - lacak versi server, paket, gambar, dan mod baru, periksa versi Minecraft mana yang didukung mod Anda, dan batalkan pembaruan mod.
- **[Log aktivitas](/docs/activity/)** - jejak audit dari semua yang terjadi.
- **[Integrasi](/docs/integrations/)** - notifikasi webhook Discord dan kategori Peringatan.
- **[API Publik](/docs/public-api/)** - API HTTP hanya-baca yang diautentikasi token untuk mengambil status server dari luar panel.

## Akun & keamanan

- **[Pengguna & peran](/docs/users-and-roles/)** - admin, operator, dan penampil, apa yang dapat dilakukan masing-masing, dan izin per server yang menyempurnakannya.
- **[Autentikasi dua faktor](/docs/two-factor-authentication/)** - lindungi login Anda dengan aplikasi autentikator.

## Panduan

Tidak spesifik untuk panel ini: pertanyaan yang dihadapi setiap pemilik server Minecraft.

- **[Berapa banyak RAM yang dibutuhkan server?](/docs/guide-server-memory/)** - dua angka yang harus diatur, dan mengapa server idle terbaca sebagai 12 GB.
- **[Vanilla, Paper, Fabric, Forge, NeoForge, Quilt](/docs/guide-choosing-a-loader/)** - mana yang akan dijalankan, dan perbedaan plugin/mod di balik pilihan tersebut.
- **[Server Anda tidak akan mulai](/docs/guide-server-wont-start/)** - membaca log, dan beberapa penyebab paling umum dari kegagalan.
- **[Cadangan yang benar-benar dapat dipulihkan](/docs/guide-backups/)** - salinan yang konsisten, apa lagi yang harus disimpan, dan mengujinya sebelum Anda membutuhkannya.
- **[Memindahkan server ke host lain](/docs/guide-moving-a-server/)** - urutan yang menjaga waktu henti singkat dan inventaris tetap utuh.
