Panel kontrol lengkap, self-hosted untuk [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server). Buat, jalankan, dan kelola server Minecraft dari peramban Anda. Tanpa baris perintah, tanpa mengedit YAML secara manual.

![Dashboard](/docs/images/dashboard.png)

## Mulai di sini

- **[Memulai](/docs/getting-started/)** - penyiapan pertama kali, masuk, dan cara menggunakan panel.
- **[Dasbor](/docs/dashboard/)** - tampilan sekilas semua server, pemain, dan aktivitas.

## Menjalankan server

- **[Membuat & mengelola server](/docs/servers/)** - wizard pembuatan, jenis server, versi, dan pengaturan per server.
- **[Konsol & perintah obrolan](/docs/console-and-chat/)** - konsol langsung, dan perintah obrolan dalam game khusus yang berjalan sebagai pemain.
- **[Modpack](/docs/modpacks/)** - instal paket CurseForge, Modrinth, FTB, dan GT New Horizons, selalu disematkan ke versi yang tepat.
- **[Dunia & file](/docs/worlds-and-files/)** - tukar dunia, kelola mod, dan edit file langsung di peramban.
- **[Mengecilkan dunia](/docs/world-shrink/)** - dapatkan kembali ruang disk dengan menghapus chunk yang tidak pernah dikunjungi, baik sendiri atau sebagai bagian dari cadangan.

## Data & otomatisasi

- **[Chatbot per server](/docs/chatbot/)** - percakapan lokal/kompatibel OpenAI, jangkauan, transkrip yang disimpan, dan kekuatan gameplay yang terbatas.
- **[Cadangan](/docs/backups/)** - snapshot sekali klik, cadangan terjadwal, dan pemulihan.
- **[Cetakan Biru](/docs/blueprints/)** - tangkap seluruh konfigurasi server dan buat server baru darinya.
- **[Jadwal](/docs/schedules/)** - restart, cadangan, dan perintah berbasis cron.
- **[Penyimpanan](/docs/storage/)** - penggunaan disk per server dan kuota yang diberlakukan panel.
- **[Pembaruan](/docs/updates/)** - lacak versi server, paket, gambar, dan mod baru.
- **[Log aktivitas](/docs/activity/)** - jejak audit dari semua yang terjadi.
- **[Integrasi](/docs/integrations/)** - notifikasi webhook Discord dan kategori Peringatan.
- **[API Publik](/docs/public-api/)** - API HTTP hanya-baca yang diautentikasi token untuk mengambil status server dari luar panel.

## Akun & keamanan

- **[Pengguna & peran](/docs/users-and-roles/)** - admin, operator, dan penampil, serta apa yang dapat dilakukan masing-masing.
- **[Autentikasi dua faktor](/docs/two-factor-authentication/)** - lindungi login Anda dengan aplikasi autentikator.

## Di balik layar

- **[Arsitektur](/docs/architecture/)** - bagaimana panel ini dibuat.
- **[Situs web](/docs/website/)** - bagaimana minecraft-server-manager.com dibangun, diterjemahkan, dan diterapkan dari repositori ini.

> Tangkapan layar dalam dokumentasi ini diambil dalam tema gelap panel. Panel dimulai dengan tema gelap kecuali jika OS Anda lebih memilih terang; gunakan pengalih tema di bilah atas untuk beralih.
