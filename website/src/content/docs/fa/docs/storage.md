صفحه **ذخیره‌سازی** نشان می‌دهد که فضای دیسک شما چگونه مصرف می‌شود: میزان استفاده هر سرور و روند آن در طول زمان.

![Storage](/docs/images/storage.png)

## سهمیه‌بندی دیسک توسط پنل اعمال می‌شود

Docker نمی‌تواند استفاده از دیسک یک bind mount را محدود کند، بنابراین پنل این کار را انجام می‌دهد. یک شاخص‌کننده پس‌زمینه دایرکتوری داده‌ها را پیمایش می‌کند، فضای اشغال شده هر سرور را ذخیره می‌کند و سهمیه‌بندی دیسکی را که برای هر سرور تنظیم کرده‌اید، اعمال می‌کند. هنگامی که داده‌های یک سرور (جهان + پشتیبان‌ها + هر چیز دیگر) به سهمیه خود نزدیک می‌شود، پنل از رشد بی‌رویه جلوگیری می‌کند به جای اینکه اجازه دهد یک سرور میزبان شما را پر کند.

سهمیه سرور را در [تنظیمات](/docs/servers/) آن تنظیم کنید. سرورهای ماد شده و [پشتیبان‌های](/docs/backups/) آن‌ها می‌توانند بزرگ باشند، بنابراین به آن‌ها فضا بدهید.

## پاکسازی

نمای ذخیره‌سازی به شما کمک می‌کند تا قبل از اتمام فضا، مواردی را برای حذف پیدا کنید (پشتیبان‌های قدیمی، جهان‌های استفاده نشده، یا سروری که بسیار فراتر از حد انتظار رشد کرده است).
