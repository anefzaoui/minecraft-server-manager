Повна панель керування для [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server), яку можна розмістити самостійно. Створюйте, запускайте та керуйте серверами Minecraft з браузера. Без командного рядка, без ручного редагування YAML.

![Dashboard](/docs/images/dashboard.png)

## Почніть тут

- **[Початок роботи](/docs/getting-started/)** - початкове налаштування, вхід та навігація.
- **[Панель керування](/docs/dashboard/)** - огляд усіх серверів, гравців та активності.

## Запуск серверів

- **[Створення та керування серверами](/docs/servers/)** - майстер створення, типи серверів, версії та налаштування для кожного сервера.
- **[Консоль та команди чату](/docs/console-and-chat/)** - жива консоль та власні команди чату в грі, що виконуються від імені гравця.
- **[Набори модів (Modpacks)](/docs/modpacks/)** - встановлення наборів CurseForge, Modrinth, FTB та GT New Horizons, завжди прив'язаних до точної версії.
- **[Світи та файли](/docs/worlds-and-files/)** - обмін світами, керування модами та редагування файлів безпосередньо в браузері.
- **[Зменшення світу](/docs/world-shrink/)** - звільніть дисковий простір, видаливши чанки, які ніхто не відвідує, окремо або як частину резервної копії.
- **[Жива карта](/docs/live-map/)** - 3D-карта світу BlueMap в один клік, доступна після входу в панель.
- **[Запрошення та сторінка статусу](/docs/invites-and-status-page/)** - адреса, текст запрошення та набір модів для клієнта для друзів, а також загальнодоступна сторінка статусу.

## Дані та автоматизація

- **[Чат-бот для кожного сервера](/docs/chatbot/)** - локальний чат, сумісний з OpenAI, сповіщення, збережені транскрипти та обмежені ігрові можливості.
- **[Резервні копії](/docs/backups/)** - знімки в один клік, заплановані резервні копії, кількість для збереження (для всієї панелі або для кожного сервера) та відновлення.
- **[Шаблони (Blueprints)](/docs/blueprints/)** - збережіть всю конфігурацію сервера та створюйте нові на її основі.
- **[Розклади (Schedules)](/docs/schedules/)** - перезапуски, резервні копії та команди за розкладом cron.
- **[Сховище (Storage)](/docs/storage/)** - використання дискового простору для кожного сервера та квоти, встановлені панеллю.
- **[Оновлення](/docs/updates/)** - відстежуйте нові версії серверів, наборів модів, образів та модів, перевіряйте, які версії Minecraft підтримують ваші моди, та скасовуйте оновлення модів.
- **[Журнал активності](/docs/activity/)** - журнал аудиту всього, що сталося.
- **[Інтеграції](/docs/integrations/)** - сповіщення через Discord webhook та категорія "Сповіщення".
- **[Публічний API](/docs/public-api/)** - HTTP API тільки для читання з автентифікацією за токеном для отримання статусу сервера ззовні панелі.

## Облікові записи та безпека

- **[Користувачі та ролі](/docs/users-and-roles/)** - адміністратор, оператор та глядач, їхні можливості та дозволи для кожного сервера, що їх уточнюють.
- **[Двофакторна автентифікація](/docs/two-factor-authentication/)** - захистіть свій вхід за допомогою програми-автентифікатора.

## Посібники

Не стосуються цієї панелі: питання, з якими стикається кожен власник сервера Minecraft.

- **[Скільки оперативної пам'яті потрібно серверу?](/docs/guide-server-memory/)** - два числа для встановлення та чому неактивний сервер споживає 12 ГБ.
- **[Vanilla, Paper, Fabric, Forge, NeoForge, Quilt](/docs/guide-choosing-a-loader/)** - який вибрати та різниця між плагінами/модами, що стоїть за вибором.
- **[Ваш сервер не запускається](/docs/guide-server-wont-start/)** - читання журналу та кілька причин більшості збоїв.
- **[Резервні копії, які дійсно відновлюються](/docs/guide-backups/)** - послідовні копії, що ще потрібно зберігати, та тестування перед використанням.
- **[Перенесення сервера на інший хост](/docs/guide-moving-a-server/)** - порядок дій, що скорочує час простою та зберігає інвентар.
