Повноцінна панель керування для [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server), яку можна розмістити самостійно. Створюйте, запускайте та керуйте серверами Minecraft з браузера. Без командного рядка, без ручного редагування YAML.

![Dashboard](/docs/images/dashboard.png)

## Початок роботи

- **[Початок роботи](/docs/getting-started/)** - початкове налаштування, вхід та навігація.
- **[Панель керування](/docs/dashboard/)** - огляд усіх серверів, гравців та активності.

## Запуск серверів

- **[Створення та керування серверами](/docs/servers/)** - майстер створення, типи серверів, версії та налаштування для кожного сервера.
- **[Консоль та команди чату](/docs/console-and-chat/)** - жива консоль та власні команди чату в грі, які виконуються від імені гравця.
- **[Modpacks](/docs/modpacks/)** - встановлення пакетів CurseForge, Modrinth, FTB та GT New Horizons, завжди прив'язаних до точної версії.
- **[Світи та файли](/docs/worlds-and-files/)** - обмін світами, керування модами та редагування файлів безпосередньо в браузері.
- **[Зменшення розміру світу](/docs/world-shrink/)** - звільніть дисковий простір, видаливши чанки, які ніхто не відвідує, окремо або як частину резервної копії.

## Дані та автоматизація

- **[Чат-бот для кожного сервера](/docs/chatbot/)** - локальна розмова, сумісна з OpenAI, сповіщення, збережені транскрипти та обмежені ігрові можливості.
- **[Резервні копії](/docs/backups/)** - знімки в один клік, заплановані резервні копії та відновлення.
- **[Шаблони](/docs/blueprints/)** - збережіть всю конфігурацію сервера та створюйте нові на її основі.
- **[Розклади](/docs/schedules/)** - перезапуски, резервні копії та команди на основі cron.
- **[Сховище](/docs/storage/)** - використання диска для кожного сервера та квоти, встановлені панеллю.
- **[Оновлення](/docs/updates/)** - відстеження нових версій серверів, пакетів, образів та модів.
- **[Журнал активності](/docs/activity/)** - журнал аудиту всього, що сталося.
- **[Інтеграції](/docs/integrations/)** - сповіщення через Discord webhook та категорія "Сповіщення".
- **[Публічний API](/docs/public-api/)** - HTTP API тільки для читання з автентифікацією за токеном для отримання статусу сервера ззовні панелі.

## Облікові записи та безпека

- **[Користувачі та ролі](/docs/users-and-roles/)** - адміністратор, оператор та глядач, і що кожен з них може робити.
- **[Двофакторна автентифікація](/docs/two-factor-authentication/)** - захистіть свій вхід за допомогою програми-автентифікатора.

## Під капотом

- **[Архітектура](/docs/architecture/)** - як побудована панель.
- **[Вебсайт](/docs/website/)** - як minecraft-server-manager.com створюється, перекладається та розгортається з цього репозиторію.

---

> Знімки екрана в цій документації зроблені в темній темі панелі. Панель запускається в темній темі, якщо ваша ОС не віддає перевагу світлій; використовуйте перемикач теми у верхній панелі для перемикання.
