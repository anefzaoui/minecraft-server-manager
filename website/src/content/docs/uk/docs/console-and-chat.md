## Жива консоль

На вкладці **Консоль** журнал сервера транслюється в реальному часі, а поле для введення команд дозволяє надсилати будь-які команди сервера. Без `docker exec`, без SSH. Вивід повертається безпосередньо, з кольорами та всім іншим.

![Консоль](/docs/images/server-console.png)

Консоль також є місцем, де панель зчитує стан сервера: вона відстежує журнал, щоб класифікувати фазу завантаження ("Завантаження модів", "Генерація світу", "Завершення запуску") і викликає `list`, щоб відстежувати, хто онлайн, тому панель інструментів та картки серверів завжди відображають реальність.

Це опитування відкриває короткочасне RCON-з'єднання кожного циклу, яке сервер реєструє як пару `Thread RCON Client … started` / `shutting down` приблизно кожні ~20 секунд, і (на серверах, чиї ядра або плагіни відлунюють це) рядок `Rcon issued server command: …` для кожного опитування лише для читання — `list` для кількості гравців, плюс зчитування `time query …` та `gamerule <name>`, коли сторінка "Керування світом" відкрита. Перемикач **Приховати RCON-шум** над журналом фільтрує ці рядки (разом із рядками запуску RCON-слухача). Він увімкнений за замовчуванням і запам'ятовується для кожного браузера; вимкніть його, щоб побачити необроблений потік.

Команди, надіслані з панелі, можуть бути оголошені в грі під міткою для кожного сервера, щоб гравці знали, що діяв оператор, а не таємнича консоль.

## Команди чату

Команди чату дозволяють гравцям запускати дії панелі, вводячи команду з префіксом у ігровому чаті, наприклад `!spawn` для випадкової телепортації. Виявлення базується на журналі, а виконання відбувається через сервер, тому **моди не потрібні**.

![Команди чату](/docs/images/chat-commands.png)

Кожна команда має:

- **Тригер** (наприклад, `spawn`) та **префікс** (`!` за замовчуванням).
- **Дію**: випадкова телепортація, телепортація до структури, телепортація до біома або виконання необроблених команд консолі.
- **Рівень дозволу**: усі, гравці зі списку дозволених або лише оператори.
- **Час відновлення** та настроювані повідомлення про очікування / успіх / невдачу з плейсхолдерами, такими як `{distance}`.

### Примітка щодо безпеки

Команди, які можуть зруйнувати сервер (`stop`, `op`, `ban`, `whitelist` та подібні), дозволені лише для тригерів **лише для операторів**. Панель перевіряє це, навіть коли вони вкладені всередині ланцюжка `execute … run …`, тому тригер з низьким рівнем дозволу не може пронести небезпечну команду. Звичайний текст чату, який просто згадує ці слова (як повідомлення `say`), залишається без змін.
