## Жива консоль

Вкладка **Консоль** транслює журнал сервера в реальному часі та надає поле для введення команд для надсилання будь-якої команди сервера. Без `docker exec`, без SSH. Вивід повертається безпосередньо, з кольорами та всім іншим. Для надсилання команд потрібен дозвіл Console для цього сервера; без нього ви все ще можете спостерігати за журналом.

Над журналом ви можете фільтрувати рядки за текстом (або `/regex/`) та за рівнем (INFO, WARN, ERROR), а **Завантажити** пропонує нещодавній вивід, повний `latest.log` або кожен файл журналу як zip-архів.

![Консоль](/docs/images/server-console.png)

Консоль також є місцем, де панель зчитує стан сервера: вона відстежує журнал, щоб класифікувати фазу завантаження ("Loading mods", "Generating world", "Finishing startup") і викликає `list` для відстеження того, хто онлайн, тому панель інструментів та картки серверів завжди відображають реальність.

Це опитування відкриває короткочасне RCON-з'єднання кожного циклу, яке сервер реєструє як пару `Thread RCON Client … started` / `shutting down` кожні ~20 секунд, і (на серверах, чиє ядро або плагіни це відлунюють) рядок `Rcon issued server command: …` для кожного опитування лише для читання (`list` для кількості гравців, плюс `time query …` та `gamerule <name>` читання, коли відкрито World Controls). Перемикач **Приховати шум консолі** над журналом фільтрує ці рядки (разом з рядками запуску слухача RCON). Він увімкнений за замовчуванням і запам'ятовується для кожного браузера; вимкніть його, щоб побачити необроблений потік.

Команди, надіслані з панелі, можуть бути оголошені в грі під міткою для кожного сервера (поле **Оголошувати як…**), щоб гравці знали, що діяв оператор, а не таємнича консоль.

## Чат

**Консоль → Чат** надсилає повідомлення в гру під час роботи сервера: **Стилізовані** повідомлення отримують кольори та форматування і можуть надсилатися всім або одному онлайн-гравцю, а **Звичайний** надсилає просте широкомовне повідомлення `[Server]` всім.

![Консоль → Чат](/docs/screenshots/04-chat.png)

## Команди чату

Команди чату (**Консоль → Команди**) дозволяють гравцям запускати дії панелі, вводячи команду-префікс у чаті гри, наприклад `!spawn` для випадкової телепортації. Виявлення базується на журналі, а виконання відбувається через сервер, тому **моди не потрібні**.

![Команди чату](/docs/images/chat-commands.png)

Кожна команда має:

- **Тригер** (наприклад, `spawn`), що вводиться після **префікса** сервера (`!` за замовчуванням, один або два символи, ніколи `/`).
- **Дію**: випадкова телепортація, телепортація до структури, телепортація до біома або виконання необроблених команд консолі.
- **Рівень дозволу**: усі, гравці зі списку дозволених або лише оператори.
- **Персональне обмеження часу** (30 секунд за замовчуванням) та настроювані повідомлення про очікування / успіх / невдачу з плейсхолдерами, такими як `{distance}`.

### Примітка щодо безпеки

Команди, які можуть зруйнувати сервер (`stop`, `op`, `ban`, `whitelist` та подібні), дозволені лише для тригерів **лише для операторів**. Панель перевіряє їх навіть тоді, коли вони вкладені всередині ланцюжка `execute … run …`, тому тригер з низьким рівнем дозволу не може пронести небезпечну команду. Звичайний текст чату, який просто згадує ці слова (як повідомлення `say`), залишається без змін.
