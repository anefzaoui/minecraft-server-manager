Сторінка **Розклади** автоматизує повторювані завдання за допомогою виразів cron. Жодного зовнішнього cron, жодних скриптів.

![Розклади](/docs/images/schedules.png)

## Що можна запланувати

- **Перезапуски** — нічний перезапуск для підтримки стабільної роботи сервера, що працює тривалий час.
- **Резервні копії** — регулярні знімки (позначені як `scheduled` на сторінці [Резервні копії](/docs/backups/)).
- **Команди** — виконання будь-якої серверної команди за розкладом.
- **Перевірки оновлень** — періодичне оновлення застарілої інформації.

Кожен розклад націлений на конкретний сервер (або на панель глобально), працює за власним виразом cron і може бути ввімкнений або вимкнений без видалення. Час останнього запуску відображається, щоб ви могли підтвердити його спрацювання.
