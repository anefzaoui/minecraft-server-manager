Сторінка **Modpacks** (та вкладка **From Modpack** у [майстрі створення](/docs/servers/)) встановлює модпак як сервер, завжди **прив'язаний до точної версії паку**, тому перезапуск ніколи не зможе непомітно оновити пак.

![Modpacks](/docs/images/modpacks.png)

## Підтримувані платформи

- **CurseForge**: пошук за назвою. Потрібен ключ API CurseForge (додайте його в **Settings → API Keys**).
- **Modrinth**: пошук за назвою.
- **FTB**: паки Feed The Beast, тільки через API (числовий ID паку плюс явний ID версії). Панель поки що не перевіряє паки FTB на наявність оновлень.
- **GT New Horizons**: експертний пак 1.7.10, встановлюється з власного індексу релізів GTNH. GTNH обирає середовище виконання Java для кожного паку (2.8.0+ працює на **Java 25** через вбудовані патчі lwjgl3ify, старіші релізи на Java 21 або 17), а майстер підвищує RAM та дисковий простір сервера до розумних мінімумів для нього.
- **Custom zip**: зовсім не опублікований пак. Завантажте **експорт модпаку CurseForge** (zip з `manifest.json`, який створює додаток CurseForge для обраного набору модів), **Modrinth `.mrpack`**, або **будь-який zip з файлами модів**. Панель масово обробляє маніфест (або ідентифікує кожен jar за хешем/відбитком/метаданими), попередньо переглядає, що підходить, і встановлює все за один крок, включаючи конфігурації `overrides/` паку, якщо ви це дозволите. Моди, авторам яких заборонено автоматичне завантаження, перелічуються з посиланням на браузер та слотом для ручного завантаження замість помилки встановлення.

## Як працює прив'язка

Коли ви обираєте пак, панель визначає точну версію, записує її та встановлює. На сторінці **Updates** вам повідомлять, коли буде доступна новіша версія (якщо політика оновлення сервера [не встановлена як **Manual Only**](#update-policy)); оновлення є навмисною, захищеною дією з резервним копіюванням перед оновленням та відкатом. Серверам, що відстежують стабільні версії, ніколи не пропонується бета-версія. Власна вкладка **Versions** сервера відповідає на іншу частину питання: які майбутні версії Minecraft можуть підтримувати наявні моди ([оновлення](/docs/updates/#minecraft-version-compatibility)).

Версія завантажувача модів також постачається з паком: сервер встановлює збірку Forge, NeoForge або Fabric, яку декларує пак. Якщо Forge або Fabric CurseForge пак декларує версію, занадто стару для його модів, вкладка **Versions** може її перевизначити, доки пак не буде виправлено; оновлення паку видаляє перевизначення, оскільки нова версія декларує власну ([зміна версії завантажувача модів](/docs/updates/#changing-the-mod-loader-version)).

Сервери, створені на дуже старих версіях панелі (до 0.9.7), могли залишитися _неприв'язаними_, що означало, що образ контейнера тихо встановлював найновішу версію паку при кожному запуску. Панель тепер виправляє їх під час завантаження: вона прив'язує кожен до версії, яка фактично встановлена (читається з власних записів панелі або маніфесту встановлення образу, ніколи не з нововизначеної "найновішої") і реєструє подію. Якщо вона не може визначити, що встановлено, сторінка Settings сервера показує попередження з кнопкою **Pick a Version…** (паки CurseForge, Modrinth та GTNH), яка відкриває [вибір версії](#changing-the-pack-version), і будь-яка спроба зберегти неприв'язану конфігурацію модпаку відхиляється.

## Політика оновлення

Кожен сервер має картку **Update Policy** на вкладці **Settings → Configuration**, і всі три опції означають те, що вони говорять:

- **Manual Only** (за замовчуванням): нічого не змінюється самостійно, і сервер повністю виключається з значка оновлення та сторінки Updates. Режим "залиште мене в спокої": ідеально підходить для вручну налаштованого або імпортованого паку, який ви ніколи не хочете чіпати. Він не блокує версію: [**Change Version…**](#changing-the-pack-version) працює за будь-якої політики. Щоб отримувати сповіщення про нові версії та застосовувати їх одним кліком, виберіть **Notify Me**.
- **Notify Me**: щоденна перевірка показує доступні оновлення як значок та на сторінці Updates; застосування завжди залежить від вашого кліка.
- **Auto-Update**: після запланованої щоденної перевірки очікуючі оновлення **паку** застосовуються тим же захищеним шляхом, що й ручне оновлення: резервне копіювання перед оновленням, моніторинг стану та автоматичний відкат, якщо нова версія не запускається. Оновлення, які переведуть сервер на іншу версію Minecraft, завжди пропускаються з подією замість цього: перетворення світу назавжди є рішенням, яке панель відмовляється приймати за вас. Ручні кнопки **Check Now** лише перевіряють; вони ніколи не запускають автоматичні оновлення.

## Оновлення паку

З прив'язаного сервера ви можете оновитися до новішої версії за одну дію. Панель спочатку створює резервну копію, замінює прив'язану версію, перебудовує сервер (перевизначає Java, якщо нова версія потребує іншого середовища виконання) та відстежує перший запуск, з достатнім вікном для великих паків, як GTNH, які завантажують кілька гігабайтів і створюють світ з кількома сотнями модів під час першого запуску.

## Зміна версії паку

Щоб запустити певну версію, новішу чи старішу, скористайтеся **Change Version…** на картці паку вкладки **Overview** сервера. На сторінці **Modpacks** відкриття картки встановленого паку надає той самий вибір: виберіть версію у спадному списку та натисніть **Switch to This Version**. Обидва потребують дозволу **Content** сервера, і обидва доступні для паків CurseForge, Modrinth та GTNH (паки FTB ще не мають списку версій). Список показує 25 найновіших версій для CurseForge та Modrinth, і кожен реліз GTNH.

Перемикання відбувається тим же захищеним шляхом, що й оновлення: резервне копіювання перед оновленням, нова прив'язка, перебудова та відстежуваний перший запуск, з відкатом в один клік, якщо сервер не запускається належним чином. Ваші власні моди переносяться, як і вимкнені вами моди паку, разом з іншими налаштуваннями встановлення паку (примусово додані моди, файли для ігнорування, додаткові проєкти). Встановлення іншого паку скидає ці налаштування, оскільки вони мають сенс лише для паку, для якого вони були створені.

Кожна версія перелічується з версією Minecraft, яку вона запускає, порівняно з версією, якою ваш світ був останній раз збережений:

- **Та сама версія Minecraft**: перемикання після звичайного підтвердження. Повернення до старішої версії паку може призвести до втрати блоків та предметів з модів, яких немає в цій версії, тому резервна копія залишається на вкладці Backups в будь-якому випадку.
- **Новіша версія Minecraft**: дозволено після підтвердження, яке попереджає, що світ буде безповоротно конвертовано. Резервна копія, зроблена спочатку, є єдиним способом повернутися до старого світу.
- **Старіша версія Minecraft**: недоступно. Minecraft не може завантажити світ на старішій версії, ніж та, якою він був останній раз збережений, тому панель відмовляє, замість того, щоб залишити сервер, який аварійно завершує роботу під час завантаження.
