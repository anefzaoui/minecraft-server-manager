## Світи

Сторінка **Світи** керує даними світу на ваших серверах: перемикайте активний світ, завантажуйте або завантажуйте світ.

![Світи](/docs/images/worlds.png)

## Файловий менеджер

У розділі **Світ** сервера вкладка **Файли** — це повноцінний файловий менеджер у браузері для каталогу даних цього сервера. Переглядайте, читайте, редагуйте, створюйте, перейменовуйте, переміщуйте, копіюйте, видаляйте та завантажуйте файли: все, що ви зазвичай робите через SSH, але з браузера.

![Файловий менеджер](/docs/images/server-files.png)

Текстові файли відкриваються в редакторі з обмеженням у 2 МБ; більші файли можна завантажити. Завантаження підтримують кілька файлів одночасно.

### Залишаючись у пісочниці

Кожна операція з файлами обмежена власним каталогом даних сервера. Панель розпізнає кожен шлях і відмовляє у будь-яких спробах вийти за його межі: перехід через `..`, абсолютні шляхи та навіть символічні посилання, що вказують за межі каталогу (включаючи висячі, які ще не існують). Мод або плагін не зможе створити посилання, щоб обманом змусити файловий менеджер читати або записувати дані в іншому місці хоста.

## Моди

Для серверів з модами вкладка **Моди** (окрема група в бічній панелі сервера) керує набором модів: переглядайте та додавайте моди, а також дивіться, що встановлено. Оновлення модів та пакетів з'являються на сторінці [Оновлення](/docs/updates/).

### Додавання модів

![Моди](/docs/images/mods.png)

Чотири способи додати моди, усі з панелі інструментів вкладки "Моди":

- **Пошук модів** — шукайте на **Modrinth або CurseForge** (чіп CurseForge з'являється після введення API-ключа в Налаштування → API-ключі), а на серверах з плагінами також на **Hangar** (власний реєстр плагінів PaperMC) та **SpigotMC** (через проксі CDN Spiget) — обидва без ключа. Усе фільтрується за завантажувачем сервера та версією Minecraft; сервери Quilt автоматично бачать збірки з тегом Fabric, оскільки Quilt запускає моди Fabric. Результати, які вже є на сервері, мають позначку **Встановлено**. Якщо автор CurseForge забороняє автоматичне завантаження — або ресурс SpigotMC розміщено поза сайтом — панель повідомить про це заздалегідь і запропонує шлях **Відкрити сторінку** + **Завантажити jar** замість помилки під час встановлення.

  ![Пошук Hangar](/docs/images/mods-search-hangar.png)

- **Імпорт zip** — одна кнопка, три форми, автовизначення:
  - **Модпак Modrinth (`.mrpack`)**: кожен закріплений файл канонізується назад до свого проекту Modrinth через пошук хешу (тому імпортовані моди зберігають справжні назви, іконки та залишаються доступними для оновлення; файли, які Modrinth не знає, встановлюються з власного URL-адреси пакету), перевіряється за контрольними сумами sha512 пакету під час завантаження та попередньо переглядається з відповідними вердиктами. Файли, призначені лише для клієнта, пропускаються візуально, а обидва дерева перекриття (`overrides/`, потім `server-overrides/` — копія, специфічна для сервера, має пріоритет) можуть бути застосовані.

    ![Імпорт mrpack](/docs/images/mrpack-import.png)

  - **Експорт модпаку CurseForge** (zip-файл, який створює додаток CurseForge, з `manifest.json`): кожен закріплений мод масово розпізнається, попередньо переглядається з попередженнями (неправильний завантажувач/MC для цього сервера, файли більше не доступні на CurseForge, моди, які потребують ручного завантаження) та встановлюється з реальним прогресом. `overrides/` пакету (конфігурації, скрипти) також можна необов'язково застосувати — будь-який файл, який буде перезаписано, спочатку резервується в `.import-backups/<timestamp>/` всередині папки сервера.
  - **Звичайний zip-архів з jar-файлами**, які ви зібрали самостійно: кожен jar-файл ідентифікується (збіг хешу Modrinth → відбиток пальця CurseForge → власні метадані jar-файлу) та оцінюється відносно сервера — _підходить / неправильний завантажувач / неправильна версія MC / вже встановлено / не ідентифіковано_ — тому ви обираєте, що саме належить, перш ніж щось встановиться.
- **Додати за посиланням** — вставте майже будь-що: сторінки проектів Modrinth, CurseForge, Hangar або SpigotMC, URL репозиторію або релізу GitHub (можна просто `owner/repo` — для GitHub перевага надається найновішому стабільному релізу та пропускаються файли `-sources`/`-javadoc`), простий slug Modrinth або будь-який прямий URL `.jar`. Панель розпізнає правильну збірку для завантажувача та версії MC сервера.

  ![Додати за посиланням](/docs/images/mods-add-by-link.png)

- **Завантажити jar** (з резервного варіанту пошуку або розділювача завантажень) — завантажені jar-файли ідентифікуються так само, тому вони зберігають свою справжню назву, версію, іконку та стають доступними для оновлення.

Кожне встановлення з реєстру **перевіряється за контрольними сумами під час завантаження**: потік перевіряється за найсильнішим хешем, який публікує реєстр (sha512 → sha256 → sha1 → md5), і невідповідність призводить до скасування до того, як щось потрапить на сервер.

Цілий zip-архів (`.mrpack` включно) також може **створити сервер**: у майстрі на вкладці _З модпаку_ завантажте його, і маніфест пакету (або більшість голосів серед ідентифікованих jar-файлів) заповнить завантажувач, версію Minecraft та збірку завантажувача.
