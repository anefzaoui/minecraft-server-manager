Невеликий HTTP API лише для читання, призначений для отримання статусу сервера ззовні панелі: панелі статусу, монітор справності, бот Discord, правило домашньої автоматизації. Він обслуговується самою панеллю та повертає ті самі дані в реальному часі, які показують власні сторінки панелі (з кешу в пам'яті), тому опитування його ніколи не торкається Docker.

Він **вимкнений, доки його не використає адміністратор**, і **контролюється адміністратором**. Нічого не відображається, доки не існує токен.

## Увімкнення

**Налаштування → Публічний API → Новий ключ**. Надайте йому назву, виберіть, що він може бачити (усі сервери або певний підмножина), і необов'язково дату закінчення терміну дії. Повний ключ (токен Bearer) відображається **один раз** у діалоговому вікні; скопіюйте його зараз, оскільки згодом зберігається лише коротка префікс для ідентифікації у списку.

![Налаштування публічного API](/docs/images/settings-public-api.png)

Створення першого ключа автоматично вмикає API (перемикач **Дозволити зовнішнім програмам читати статус** є елементом керування паузою: вимкніть його, щоб припинити обслуговування без скасування будь-яких ключів). Скасуйте ключ з тієї ж таблиці в будь-який час; клієнти, які його використовують, негайно втрачають доступ.

Токени зберігаються як хеш SHA-256 (ніколи у відкритому тексті), переживають перезапуск панелі та переживають сервери, до яких вони прив'язані (видалений сервер просто випадає з результатів цього токена).

## Автентифікація

Надішліть токен як облікові дані Bearer:

```
Authorization: Bearer msm_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Немає файлів cookie та **немає CORS**: це для викликів сервер-сервер та CLI, а не для браузерних програм з іншого походження. Якщо панель знаходиться за зворотним проксі, переконайтеся, що проксі пересилає заголовок `Authorization`.

Помилки повертають `401` з `{ "ok": false, "error": "..." }`. Будь-що, крім `GET` (або `HEAD`), повертає `405`. Невідомі шляхи повертають `404`. Коли API вимкнено, кожен маршрут повертає `404`.

## Обмеження швидкості

Кожен токен отримує власний бюджет, `RATE_LIMIT_PUBLIC_API_PER_MIN` (за замовчуванням `120` запитів/хвилину; `0` вимикає обмежувач). Перевищення ліміту повертає `429`. Запити, які ніколи не надають дійсний токен (відсутній, неправильний формат, відкликаний або прострочений), обмежуються окремо за IP-адресою клієнта в п'ять разів більше цієї кількості, тому зондування не може обійти бюджет, обертаючи токени.

## Кінцеві точки

### `GET /api/v1/servers`

Кожен сервер, до якого прив'язаний токен.

```json
{
  "ok": true,
  "total": 1,
  "online": 1,
  "servers": [
    {
      "id": "srv_ab12cd34",
      "name": "SMP",
      "type": "PAPER",
      "state": "running",
      "cpuPct": 18.4,
      "memoryMb": 2048,
      "memoryLimitMb": 4096,
      "uptimeSeconds": 11722,
      "players": { "online": 3, "max": 20 }
    }
  ]
}
```

### `GET /api/v1/servers/:id`

Один сервер, той самий об'єкт під ключем `server`. Повертає `404` для невідомого id **та** для сервера, до якого токен не прив'язаний (немає оракула існування), і `400` для неправильного формату id.

## Поля відповіді

| Поле            | Значення                                                                                        |
| --------------- | ----------------------------------------------------------------------------------------------- |
| `total`         | Скільки серверів видно цьому токену (після фільтра його області видимості).                     |
| `online`        | Скільки з них у стані: `running`.                                                               |
| `id`            | Стабільний ідентифікатор сервера (`srv_...`).                                                   |
| `name`          | Відображувана назва.                                                                            |
| `type`          | Тип сервера itzg (`PAPER`, `FABRIC`, `AUTO_CURSEFORGE`, ...).                                   |
| `state`         | `running`, `starting`, `stopped` або `crashed` - стабільний підсумок внутрішнього стану панелі. |
| `cpuPct`        | Нещодавній відсоток використання ЦП або `null`, коли сервер не працює.                          |
| `memoryMb`      | Оперативна пам'ять у МБ або `null`.                                                             |
| `memoryLimitMb` | Конфігурований ліміт пам'яті контейнера в МБ або `null`.                                        |
| `uptimeSeconds` | Секунди з моменту запуску контейнера або `null`.                                                |
| `players`       | `{ online, max }` або `null`, доки сервер не повідомить список гравців.                         |

## Приклад

```sh
curl -s https://panel.example.com/api/v1/servers \
  -H "Authorization: Bearer $MSM_TOKEN" | jq
```
