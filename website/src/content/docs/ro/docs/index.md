Un panou de control complet, auto-găzduit pentru [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server). Creați, rulați și gestionați servere Minecraft din browserul dvs. Fără linie de comandă, fără editarea manuală a fișierelor YAML.

![Dashboard](/docs/images/dashboard.png)

## Începeți aici

- **[Primii pași](/docs/getting-started/)** - configurare la prima rulare, conectare și orientare.
- **[Panoul de control](/docs/dashboard/)** - vizualizarea rapidă a fiecărui server, jucători și activitate.

## Rularea serverelor

- **[Crearea și gestionarea serverelor](/docs/servers/)** - expertul de creare, tipurile de servere, versiunile și setările per server.
- **[Consolă și comenzi de chat](/docs/console-and-chat/)** - consola live și comenzile personalizate de chat din joc care rulează ca jucător.
- **[Modpack-uri](/docs/modpacks/)** - instalați pachete CurseForge, Modrinth, FTB și GT New Horizons, întotdeauna fixate la o versiune exactă.
- **[Lumi și fișiere](/docs/worlds-and-files/)** - schimbați lumi, gestionați moduri și editați fișiere direct în browser.
- **[Reducerea dimensiunii unei lumi](/docs/world-shrink/)** - recuperați spațiu pe disc prin eliminarea bucăților (chunks) pe care nimeni nu le vizitează, singur sau ca parte a unei copii de rezervă.

## Date și automatizare

- **[Chatbot per server](/docs/chatbot/)** - conversație locală/compatibilă cu OpenAI, outreach, transcrieri reținute și puteri de joc limitate.
- **[Copii de rezervă](/docs/backups/)** - instantanee cu un clic, backup-uri programate și restaurare.
- **[Șabloane (Blueprints)](/docs/blueprints/)** - capturați întreaga configurație a unui server și creați altele noi pe baza acesteia.
- **[Programări](/docs/schedules/)** - reporniri, backup-uri și comenzi controlate de cron.
- **[Stocare](/docs/storage/)** - utilizarea discului per server și cota impusă de panou.
- **[Actualizări](/docs/updates/)** - urmăriți versiunile noi de server, pachete, imagini și moduri.
- **[Jurnal de activitate](/docs/activity/)** - o pistă de audit a tot ce s-a întâmplat.
- **[Integrări](/docs/integrations/)** - notificări webhook Discord și categoria Alerte.
- **[API public](/docs/public-api/)** - un API HTTP numai pentru citire, autentificat prin token, pentru preluarea stării serverului din afara panoului.
