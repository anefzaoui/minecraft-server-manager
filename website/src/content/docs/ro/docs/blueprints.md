O **schemă** (blueprint) surprinde întreaga configurație a unui server (tip, versiune, resurse, mediu, fixare pachet, și opțional configurația și lumea sa) într-un singur fișier portabil din care poți crea noi servere.

![Blueprints](/docs/images/blueprints.png)

## Exportare

Dintr-un server, exportă o schemă și alege ce să incluzi: configurația întotdeauna, și opțional fișiere încorporate și lumea. Rezultatul este salvat în biblioteca ta de scheme și poate fi descărcat pentru partajare.

## Importare și creare dintr-o schemă

Importă un fișier schemă (sau alege unul din bibliotecă) pentru a crea un server nou pre-configurat exact ca originalul. Este cea mai rapidă metodă pentru:

- Pornirea unor servere identice (o rețea de servere de minigame, copii de staging ale producției).
- Mutarea unui server între panouri.
- Păstrarea unui șablon cunoscut și funcțional la care te poți întotdeauna baza.

Deoarece o schemă înregistrează exact [fixarea pachetului](/docs/modpacks/), un server cu pachet de moduri recreat dintr-o schemă instalează aceeași versiune fixată, fără upgrade-uri neașteptate.
