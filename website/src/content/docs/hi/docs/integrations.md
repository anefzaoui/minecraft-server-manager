प्रत्येक सर्वर **सेटिंग्स** समूह के अंतर्गत अपने एकीकरण रखता है: **Discord**, एक सार्वजनिक **स्थिति पृष्ठ**, एक-क्लिक **आमंत्रण**, और वैकल्पिक **चैटबॉट** टैब। यह पृष्ठ Discord को कवर करता है (अन्य के पास पैनल में अपने स्वयं के दस्तावेज़ और सेटअप सहायक हैं)।

## Discord सूचनाएं

पैनल वेबहुक के माध्यम से सर्वर घटनाओं को एक Discord चैनल पर अग्रेषित करता है। कोई बॉट नहीं, कोई OAuth नहीं।

### सेटअप

1. Discord में: **सर्वर सेटिंग्स → एकीकरण → वेबहुक → नया वेबहुक**। चैनल चुनें और वेबहुक URL कॉपी करें।
2. पैनल में, सर्वर की **सेटिंग्स → Discord** टैब खोलें, URL को **वेबहुक URL** में पेस्ट करें, कार्ड को **चालू** करें, और **सहेजें**। URL को एन्क्रिप्टेड रूप से संग्रहीत किया जाता है (उसी एट-रेस्ट स्टोर में जहां आपकी API कुंजियाँ हैं)।
3. यह पुष्टि करने के लिए **परीक्षण भेजें** का उपयोग करें कि यह काम करता है।

![Discord integration](/docs/images/integrations-discord.png)

संग्रहीत URL को बदलने के लिए, एक नया पेस्ट करें और सहेजें; वर्तमान URL को बनाए रखने के लिए फ़ील्ड को खाली छोड़ दें। संग्रहीत URL को मास्क्ड दिखाया गया है (टोकन छिपा हुआ है)।

### क्या भेजा जाता है

सूचनाओं को टॉगल करने योग्य श्रेणियों में समूहीकृत किया गया है। सभी डिफ़ॉल्ट रूप से चालू हैं।

| श्रेणी         | घटनाएँ                                                             |
| -------------- | ------------------------------------------------------------------ |
| **शुरू / बंद** | सर्वर शुरू हुआ, सर्वर बंद हुआ                                      |
| **क्रैश**      | क्रैश, क्रैश लूप का पता चला, नई क्रैश रिपोर्ट                      |
| **बैकअप**      | बैकअप बनाया गया, बैकअप बहाल किया गया                               |
| **अपडेट**      | अपडेट लागू किया गया, अपडेट वापस लिया गया, अपडेट विफल रहा           |
| **किक / बैन**  | खिलाड़ी को किक किया गया, खिलाड़ी को बैन किया गया                   |
| **अलर्ट**      | वे चीजें जो चुपचाप एक सर्वर को टूटा हुआ छोड़ देती हैं (नीचे देखें) |

### अलर्ट श्रेणी

`अलर्ट` "कुछ को एक इंसान की आवश्यकता है" चैनल है, उन स्थितियों के लिए जो पहले केवल पैनल में दिखाई देती थीं:

| घटना                    | अर्थ                                                                                                                     |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `oom`                   | मेमोरी खत्म होने के कारण कंटेनर बंद कर दिया गया था।                                                                      |
| `unhealthy`             | प्रक्रिया चालू है लेकिन `mc-health` जांच विफल हो रही है: एक लाइव लेकिन मृत सर्वर।                                        |
| `startup-stalled`       | लॉग में "Done" के बिना ~10 मिनट के बाद भी शुरू हो रहा है (ठीक करने के लिए क्या है, इसका निदान के साथ, जहां एक ज्ञात है)। |
| `stop-failed`           | एक सौम्य स्टॉप प्रभावी नहीं हुआ और कंटेनर अभी भी चल रहा है।                                                              |
| `schedule-failed`       | एक निर्धारित पुनरारंभ / बैकअप / कमांड विफल हो गया।                                                                       |
| `quota-exceeded`        | स्ट्रिक्ट-मोड डिस्क कोटा ट्रिप हुआ और सर्वर बंद कर दिया गया।                                                             |
| `offline-after-restart` | पैनल के पुनरारंभ होने से पहले सर्वर चालू था, अब नहीं है, और स्वचालित रूप से शुरू नहीं होगा।                              |
| `crash-report`          | एक नई क्रैश रिपोर्ट कैप्चर और पार्स की गई थी।                                                                            |
| `update-failed`         | एक संरक्षित अपग्रेड स्वस्थ नहीं आया।                                                                                     |

### डिलीवरी कैसे काम करती है

एक पृष्ठभूमि ब्रिज हर 15 सेकंड में [इवेंट लॉग](/docs/activity/) को पोल करता है और मैप की गई पंक्तियों को अग्रेषित करता है। यदि कोई वेबहुक POST अस्थायी रूप से विफल हो जाता है, तो उस पंक्ति को बाद के पोल पर पुनः प्रयास किया जाता है बजाय इसके कि वह गिर जाए; स्थायी रूप से अप्राप्य वेबहुक कुछ प्रयासों के बाद म्यूट कर दिया जाता है (प्रति घंटे एक लॉग लाइन)। ब्रिज पैनल शुरू होने से पहले की घटनाओं को कभी भी फिर से नहीं चलाता है।
