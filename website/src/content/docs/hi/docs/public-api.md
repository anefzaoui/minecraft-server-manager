पैनल के बाहर से सर्वर की स्थिति प्राप्त करने के लिए एक छोटा, केवल-पढ़ने योग्य HTTP API: एक
स्थिति डैशबोर्ड, एक अपटाइम मॉनिटर, एक डिस्कॉर्ड बॉट, एक होम-ऑटोमेशन नियम। यह
पैनल द्वारा ही सर्व किया जाता है और वही लाइव डेटा लौटाता है जो पैनल के अपने पेज
दिखाते हैं (इन-मेमोरी कैश से), इसलिए इसे पोल करने से कभी भी डॉकर को नहीं छुआ जाता है।

यह **तब तक बंद रहता है जब तक कोई एडमिन इसका उपयोग नहीं करता** और **एडमिन-गेटेड** है।
जब तक कोई टोकन मौजूद नहीं होता, तब तक कुछ भी एक्सपोज़ नहीं होता है।

## इसे सक्षम करना

**सेटिंग्स → पब्लिक API → नया की (Key)**। इसे एक नाम दें, चुनें कि यह क्या देख सकता है (सभी
सर्वर, या एक विशिष्ट सबसेट), और वैकल्पिक रूप से एक समाप्ति तिथि। पूरा की (एक
बेयरर टोकन) **एक बार**, एक डायलॉग में दिखाया जाता है; इसे अभी कॉपी करें, क्योंकि
बाद में केवल एक छोटा प्रीफिक्स, सूची में पहचान के लिए रखा जाता है।

![पब्लिक API सेटिंग्स](/docs/images/settings-public-api.png)

पहला की बनाना API को स्वचालित रूप से चालू कर देता है (**बाहरी ऐप्स को स्थिति
पढ़ने दें** स्विच एक पॉज़ कंट्रोल है: किसी भी की को रद्द किए बिना सर्व करना बंद
करने के लिए इसे बंद कर दें)। किसी भी समय उसी टेबल से एक की को रद्द करें; इसका उपयोग
करने वाले क्लाइंट तुरंत एक्सेस खो देते हैं।

टोकन SHA-256 हैश के रूप में संग्रहीत होते हैं (कभी भी प्लेनटेक्स्ट में नहीं), पैनल
पुनरारंभ होने पर बने रहते हैं, और उन सर्वरों से अधिक समय तक चलते हैं जिन पर वे
स्कोप किए गए हैं (एक डिलीट किया गया सर्वर बस उस टोकन के परिणामों से बाहर हो जाता है)।

## प्रमाणीकरण

टोकन को बेयरर क्रेडेंशियल के रूप में भेजें:

```
Authorization: Bearer msm_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

कोई कुकीज़ नहीं हैं और **कोई CORS नहीं**: यह सर्वर-से-सर्वर और CLI
कॉलर्स के लिए है, न कि किसी अन्य ओरिजिन के ब्राउज़र ऐप्स के लिए। यदि पैनल एक रिवर्स
प्रॉक्सी के पीछे है, तो सुनिश्चित करें कि प्रॉक्सी `Authorization` हेडर को फॉरवर्ड
करता है।

विफलताएं `{ "ok": false, "error": "..." }` के साथ `401` लौटाती हैं। `GET`
(या `HEAD`) के अलावा कुछ भी `405` लौटाता है। अज्ञात पाथ `404` लौटाते हैं। जब API
अक्षम होता है, तो हर रूट `404` लौटाता है।

## रेट लिमिट

प्रत्येक टोकन का अपना बजट होता है, `RATE_LIMIT_PUBLIC_API_PER_MIN` (डिफ़ॉल्ट `120`
अनुरोध/मिनट; `0` लिमिटर को अक्षम करता है)। लिमिट से ऊपर `429` लौटाता है। वे अनुरोध
जो कभी भी एक वैध टोकन प्रस्तुत नहीं करते (लापता, खराब प्रारूपित, रद्द, या समाप्त)
उन्हें प्रति क्लाइंट आईपी पर उस संख्या के पांच गुना पर अलग से कैप किया जाता है,
इसलिए जांच टोकन को घुमाकर बजट को बायपास नहीं कर सकती है।

## एंडपॉइंट्स

### `GET /api/v1/servers`

टोकन के स्कोप में आने वाले सभी सर्वर।

```json
{
  "ok": true,
  "total": 1,
  "online": 1,
  "servers": [
    {
      "id": "srv_ab12cd34",
      "name": "SMP",
      "type": "PAPER",
      "state": "running",
      "cpuPct": 18.4,
      "memoryMb": 2048,
      "memoryLimitMb": 4096,
      "uptimeSeconds": 11722,
      "players": { "online": 3, "max": 20 }
    }
  ]
}
```

### `GET /api/v1/servers/:id`

एक सर्वर, `server` की के तहत वही ऑब्जेक्ट। एक अज्ञात आईडी
**और** एक सर्वर के लिए `404` लौटाता है जिस पर टोकन स्कोप नहीं किया गया है (कोई अस्तित्व
ऑरेकल नहीं), और खराब प्रारूपित आईडी के लिए `400`।

## प्रतिक्रिया फ़ील्ड

| फ़ील्ड          | अर्थ                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------ |
| `total`         | इस टोकन के लिए कितने सर्वर दिखाई दे रहे हैं (इसके स्कोप फ़िल्टर के बाद)।                   |
| `online`        | उनमें से कितने `running` स्थिति में हैं।                                                   |
| `id`            | स्थिर सर्वर आईडी (`srv_...`)।                                                              |
| `name`          | प्रदर्शन नाम।                                                                              |
| `type`          | itzg सर्वर प्रकार (`PAPER`, `FABRIC`, `AUTO_CURSEFORGE`, ...)।                             |
| `state`         | `running`, `starting`, `stopped`, या `crashed` - पैनल की आंतरिक स्थिति का एक स्थिर सारांश। |
| `cpuPct`        | हाल का CPU %, या `null` जब सर्वर नहीं चल रहा हो।                                           |
| `memoryMb`      | MB में रेजिडेंट मेमोरी, या `null`।                                                         |
| `memoryLimitMb` | MB में कॉन्फ़िगर की गई कंटेनर मेमोरी सीमा, या `null`।                                      |
| `uptimeSeconds` | कंटेनर शुरू होने के बाद से सेकंड, या `null`।                                               |
| `players`       | `{ online, max }`, या `null` जब तक सर्वर खिलाड़ी सूची की रिपोर्ट नहीं करता।                |

## उदाहरण

```sh
curl -s https://panel.example.com/api/v1/servers \
  -H "Authorization: Bearer $MSM_TOKEN" | jq
```
