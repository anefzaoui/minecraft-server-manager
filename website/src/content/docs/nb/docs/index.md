Et komplett, selv-hostet kontrollpanel for [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server). Opprett, kjør og administrer Minecraft-servere fra nettleseren din. Ingen kommandolinje, ingen manuell redigering av YAML.

![Dashboard](/docs/images/dashboard.png)

## Start her

- **[Komme i gang](/docs/getting-started/)** - Førstegangsoppsett, innlogging og hvordan du navigerer.
- **[Kontrollpanelet](/docs/dashboard/)** - Oversikt over alle servere, spillere og aktivitet.

## Kjørende servere

- **[Opprette og administrere servere](/docs/servers/)** - Veiviseren for opprettelse, servertyper, versjoner og server-spesifikke innstillinger.
- **[Konsoll og chat-kommandoer](/docs/console-and-chat/)** - Live konsoll og egendefinerte chat-kommandoer i spillet som kjøres som spilleren.
- **[Modpacks](/docs/modpacks/)** - Installer CurseForge, Modrinth, FTB og GT New Horizons-pakker, alltid festet til en eksakt versjon.
- **[Verdener og filer](/docs/worlds-and-files/)** - Bytt verdener, administrer mods og rediger filer direkte i nettleseren.
- **[Krympe en verden](/docs/world-shrink/)** - Frigjør diskplass ved å fjerne deler ingen besøker, alene eller som del av en sikkerhetskopi.
- **[Live kart](/docs/live-map/)** - Et 3D-kart av verden med ett klikk via BlueMap, bak panelets innlogging.
- **[Invitasjoner og status side](/docs/invites-and-status-page/)** - Adressen, invitasjonstekst og klientmodpack for venner, og en offentlig status side.

## Data og automatisering

- **[Chatbot per server](/docs/chatbot/)** - Lokal/OpenAI-kompatibel samtale, utgående meldinger, lagrede transkripsjoner og begrensede spillkrefter.
- **[Sikkerhetskopier](/docs/backups/)** - Øyeblikksbilder med ett klikk, planlagte sikkerhetskopier, hvor mange som skal beholdes (panel-vidt eller per server), og gjenoppretting.
- **[Blåkopier](/docs/blueprints/)** - Fang en servers hele konfigurasjon og lag nye basert på den.
- **[Planer](/docs/schedules/)** - Cron-drevet omstart, sikkerhetskopiering og kommandoer.
- **[Lagring](/docs/storage/)** - Diskforbruk per server og kvoter håndhevet av panelet.
- **[Oppdateringer](/docs/updates/)** - Spor nye server-, pakke-, bilde- og mod-versjoner, sjekk hvilke Minecraft-versjoner moddene dine støtter, og angre en mod-oppdatering.
- **[Aktivitetslogg](/docs/activity/)** - En revisjonsspor av alt som har skjedd.
- **[Integrasjoner](/docs/integrations/)** - Discord webhook-varsler og Varslingskategorien.
- **[Offentlig API](/docs/public-api/)** - Et skrivebeskyttet HTTP API med token-autentisering for å hente serverstatus utenfra panelet.

## Kontoer og sikkerhet

- **[Brukere og roller](/docs/users-and-roles/)** - Administrator, operatør og seer, hva hver kan gjøre, og server-spesifikke tillatelser som avgrenser dem.
- **[Tofaktorautentisering](/docs/two-factor-authentication/)** - Beskytt innloggingen din med en autentiseringsapp.

## Guider

Ikke spesifikt for dette panelet: spørsmålene enhver Minecraft-servereier støter på.

- **[Hvor mye RAM trenger en server?](/docs/guide-server-memory/)** - De to tallene som skal settes, og hvorfor en inaktiv server leser som 12 GB.
- **[Vanilla, Paper, Fabric, Forge, NeoForge, Quilt](/docs/guide-choosing-a-loader/)** - Hvilken som skal kjøres, og forskjellen på plugins/mods bak valget.
- **[Serveren din vil ikke starte](/docs/guide-server-wont-start/)** - Lese loggen, og de få årsakene bak de fleste feil.
- **[Sikkerhetskopier som faktisk kan gjenopprettes](/docs/guide-backups/)** - Konsistente kopier, hva annet som må beholdes, og testing av en før du trenger den.
- **[Flytte en server til en annen vert](/docs/guide-moving-a-server/)** - Rekkefølgen som holder nedetid kort og inventar intakt.
