Et komplett, selv-hostet kontrollpanel for [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server). Opprett, kjør og administrer Minecraft-servere fra nettleseren din. Ingen kommandolinje, ingen manuell redigering av YAML.

![Dashboard](/docs/images/dashboard.png)

## Start her

- **[Komme i gang](/docs/getting-started/)** - Førstegangs oppsett, innlogging og hvordan du finner frem.
- **[Kontrollpanelet](/docs/dashboard/)** - Oversikt over alle servere, spillere og aktivitet.

## Kjørende servere

- **[Opprette og administrere servere](/docs/servers/)** - Veiviseren for opprettelse, servertyper, versjoner og server-spesifikke innstillinger.
- **[Konsoll og chat-kommandoer](/docs/console-and-chat/)** - Live konsoll, og egendefinerte chat-kommandoer i spillet som kjøres som spilleren.
- **[Modpacks](/docs/modpacks/)** - Installer CurseForge, Modrinth, FTB og GT New Horizons-pakker, alltid festet til en eksakt versjon.
- **[Verdener og filer](/docs/worlds-and-files/)** - Bytt verdener, administrer mods og rediger filer direkte i nettleseren.
- **[Krympe en verden](/docs/world-shrink/)** - Frigjør diskplass ved å fjerne deler som ingen besøker, alene eller som del av en sikkerhetskopi.

## Data og automatisering

- **[Server-spesifikk chatbot](/docs/chatbot/)** - Lokal/OpenAI-kompatibel samtale, utgående meldinger, lagrede transkripsjoner og begrensede spill-krefter.
- **[Sikkerhetskopier](/docs/backups/)** - Øyeblikksbilder med ett klikk, planlagte sikkerhetskopier og gjenoppretting.
- **[Blåkopier](/docs/blueprints/)** - Fang en servers hele konfigurasjon og lag nye basert på den.
- **[Tidsplaner](/docs/schedules/)** - Cron-drevet omstart, sikkerhetskopiering og kommandoer.
- **[Lagring](/docs/storage/)** - Server-spesifikk diskbruk og kvoter håndhevet av panelet.
- **[Oppdateringer](/docs/updates/)** - Spor nye server-, pakke-, bilde- og mod-versjoner.
- **[Aktivitetslogg](/docs/activity/)** - En revisjonsspor over alt som har skjedd.
- **[Integrasjoner](/docs/integrations/)** - Discord webhook-varsler og Varslings-kategorien.
- **[Offentlig API](/docs/public-api/)** - Et skrivebeskyttet HTTP API med token-autentisering for å hente serverstatus utenfra panelet.

## Kontoer og sikkerhet

- **[Tofaktorautentisering](/docs/two-factor-authentication/)** - Beskytt innloggingen din med en autentiseringsapp.
