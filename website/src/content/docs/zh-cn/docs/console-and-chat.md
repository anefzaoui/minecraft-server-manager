## 实时控制台

**控制台**选项卡实时显示服务器日志，并提供一个命令框来发送任何服务器命令。无需 `docker exec`，无需 SSH。输出会直接显示，包括颜色。

![控制台](/docs/images/server-console.png)

控制台也是面板读取服务器状态的地方：它会监视日志以分类启动阶段（“Loading mods”、“Generating world”、“Finishing startup”）并调用 `list` 来跟踪在线玩家，因此仪表板和服务器卡片始终反映真实情况。

这种轮询会在每个周期打开一个短暂的 RCON 连接，服务器日志会显示为一对 `Thread RCON Client … started` / `shutting down`，大约每 20 秒一次，并且（在核心或插件会回显的服务器上）每次只读轮询会显示一行 `Rcon issued server command: …` —— `list` 用于玩家计数，在“世界控制”页面打开时还会读取 `time query …` 和 `gamerule <name>`。控制台日志上方的“**隐藏 RCON 噪音**”切换按钮会过滤掉这些行（以及 RCON 监听器的启动行）。此选项默认开启，并会为每个浏览器记住设置；关闭它即可查看原始日志流。

从面板发送的命令可以在游戏中以每个服务器为单位的标签进行公告，这样玩家就知道是管理员而不是某个神秘控制台执行了操作。

## 聊天命令

聊天命令允许玩家通过在游戏聊天中输入前缀命令来触发面板操作，例如 `!spawn` 进行随机传送。检测基于日志，执行通过服务器进行，因此**无需任何模组**。

![聊天命令](/docs/images/chat-commands.png)

每个命令都包含：

- 一个**触发器**（例如 `spawn`）和一个**前缀**（默认为 `!`）。
- 一个**动作**：随机传送、传送到结构、传送到生物群系或运行原始控制台命令。
- 一个**权限级别**：所有人、白名单玩家或仅限管理员。
- 一个**冷却时间**，以及可自定义的等待中/成功/失败消息，包含 `{distance}` 等占位符。

### 安全注意事项

可能破坏服务器的命令（`stop`、`op`、`ban`、`whitelist` 等）仅允许在**仅限管理员**的触发器上使用。即使这些命令嵌套在 `execute … run …` 链中，面板也会进行检查，因此低权限触发器无法偷偷传递危险命令。普通聊天文本中仅仅提及这些词语（例如 `say` 消息）则不会受到影响。
