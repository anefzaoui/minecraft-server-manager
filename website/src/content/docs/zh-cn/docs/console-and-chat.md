## 实时控制台

**控制台**选项卡实时流式传输服务器日志，并提供一个命令框，用于发送任何服务器命令。无需 `docker exec`，无需 SSH。输出会内联返回，包括颜色。发送命令需要该服务器上的 Console 权限；如果没有该权限，您仍然可以查看日志。

在日志上方，您可以按文本（或 `/正则表达式/`）和级别（INFO、WARN、ERROR）过滤行，**下载**选项提供最近的输出、完整的 `latest.log` 或所有日志文件作为 zip 压缩包。

![控制台](/docs/images/server-console.png)

控制台也是面板读取服务器状态的地方：它会监视日志以对启动阶段进行分类（“Loading mods”、“Generating world”、“Finishing startup”），并调用 `list` 来跟踪在线玩家，因此仪表板和服务器卡片始终反映实际情况。

这种轮询会在每个周期打开一个短暂的 RCON 连接，服务器日志会显示为大约每 20 秒一对 `Thread RCON Client … started` / `shutting down`，以及（在核心或插件回显它的服务器上）每次只读轮询（用于玩家数量的 `list`，以及在 World Controls 打开时的 `time query …` 和 `gamerule <name>` 读取）的 `Rcon issued server command: …` 行。日志上方的 **隐藏控制台噪音** 切换按钮会过滤掉这些行（以及 RCON 监听器启动行）。此选项默认开启，并会为每个浏览器记住设置；关闭它即可查看原始流。

从面板发送的命令可以在游戏内以每个服务器为单位的标签（**宣布为…**框）进行公告，这样玩家就知道是管理员执行了操作，而不是一个神秘的控制台。

## 聊天

**控制台 → 聊天** 在服务器运行时将消息发送到游戏中：**样式化**消息会带有颜色和格式，可以发送给所有人或单个在线玩家，而**纯文本**则会向所有人发送一个简单的 `[Server]` 广播。

![控制台 → 聊天](/docs/screenshots/04-chat.png)

## 聊天命令

聊天命令（**控制台 → 命令**）允许玩家通过在游戏聊天中输入前缀命令来触发面板操作，例如 `!spawn` 进行随机传送。检测基于日志，执行通过服务器进行，因此**无需任何模组**。

![聊天命令](/docs/images/chat-commands.png)

每个命令都有：

- 一个**触发器**（例如 `spawn`），在服务器的**前缀**（默认为 `!`，一个或两个字符，绝不为 `/`）之后输入。
- 一个**操作**：随机传送、传送到结构、传送到生物群系或运行原始控制台命令。
- 一个**权限级别**：所有人、白名单玩家或仅限管理员。
- 每个玩家的**冷却时间**（默认为 30 秒），以及可自定义的待处理/成功/失败消息，带有 `{distance}` 等占位符。

### 安全注意事项

可能破坏服务器的命令（`stop`、`op`、`ban`、`whitelist` 等）仅允许在**仅限管理员**的触发器上使用。即使这些命令嵌套在 `execute … run …` 链中，面板也会进行检查，因此低权限的触发器无法偷偷传递危险命令。普通聊天文本中仅仅提及这些词语（例如 `say` 消息）则不受影响。
