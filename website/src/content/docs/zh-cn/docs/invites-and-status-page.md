服务器的“**设置**”组下的两个选项卡可帮助玩家查找并加入服务器：“**邀请**”会生成朋友连接所需的所有信息，而“**状态页面**”则会发布一个小型公共页面，显示服务器是否正在运行。两者都需要服务器的“**设置**”权限（[用户和角色](/docs/users-and-roles/#per-server-permissions)）。

## 邀请

“**设置 → 邀请**”中有一个“**邀请好友**”卡片：

- **要分享的地址**列出了您本地网络上机器的地址以及服务器的游戏端口，您公共地址（如果面板能够检测到它；网络外的玩家只能通过端口转发访问），以及用于您自己设置的域名或地址的“**自定义地址…**”，例如 `play.example.com:25565`。
- **邀请文本**是一条可直接粘贴的消息，包含服务器名称、您选择的地址以及其 Minecraft 版本和类型。“**复制邀请文本**”将其复制到剪贴板。当白名单开启时，文本会要求朋友提供他们的 Minecraft 用户名，并且卡片会提醒您在他们加入之前，在“**玩家**”选项卡中添加每个朋友。
- **好友需要什么**说明了玩家端需要什么：对于原版或插件服务器（Paper 等），只需要正确的 Minecraft 版本；对于模组服务器，则需要服务器的模组。

### 客户端模组包

在模组服务器上，该卡片还提供“**下载客户端模组包 (.mrpack)**”。朋友将其导入 Prism Launcher 或 Modrinth App，该应用会安装服务器的 Minecraft 版本和模组加载器，下载模组，并将服务器添加到他们的多人游戏列表中，使用您选择的地址。

该文件由您添加到服务器的模组（自定义模组覆盖）构建而成，这些模组来自 Modrinth。其他来源的模组会列在卡片上，以便朋友手动将这些文件添加到他们的 `mods` 文件夹。对于从模组包创建的服务器，朋友应该在他们的启动器中安装该模组包，并使用服务器运行的版本；“**概览**”选项卡会显示版本。

### 在互联网上玩游戏

卡片底部的“**在互联网上玩游戏（端口转发）**”解释了路由器方面的内容：将服务器的游戏端口（TCP 和 UDP）转发到运行面板的机器，然后分享您的公共地址和端口。如果您的互联网服务提供商使用 CGNAT，则端口转发将不起作用，此时可以使用隧道服务（例如 playit.gg）。面板本身不会打开路由器端口。只有游戏端口应该暴露在互联网上；保持面板自身的端口和 RCON 端口关闭（[端口一览](https://github.com/anefzaoui/minecraft-server-manager#ports-at-a-glance)）。

## 状态页面

“**设置 → 状态页面**”为单个服务器开启一个公共页面，默认关闭：

1. 打开卡片。
2. 选择“**页面地址**”：该页面位于您的面板上的 `/status/<address>`，地址是 3 到 40 个小写字母、数字或连字符，在您的服务器之间是唯一的。
3. 按“**保存**”。然后“**打开页面**”和“**复制链接**”会提供您要分享的链接。

任何拥有该链接的人都可以看到服务器名称、其 MOTD、版本、是否正在运行、玩家数量和正常运行时间，除此之外别无其他。该页面没有链接到面板，也不需要登录。它读取面板的内存状态，因此访问者永远不会对 Docker 守护进程产生工作负载。

关闭页面会保留其地址，因此重新开启它会恢复相同的链接。对于您自己的页面或机器人，[公共 API](/docs/public-api/) 以 JSON 格式返回相同类型的状态。
