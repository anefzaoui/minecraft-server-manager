仪表板是你的主页：显示所有服务器的实时状态以及近期活动记录。

![Dashboard](/docs/images/dashboard.png)

## 概览磁贴

顶部区域：

- **在线服务器**：当前运行的服务器数量占总数的比例。
- **连接玩家**：所有运行中服务器的总玩家数量。
- **可用更新**：有多少服务器、整合包或模组有新版本（[查看更新](/docs/updates/)）。
- **Docker**：面板是否能连接到 Docker守护进程及其版本。

第二行显示 **分配的内存**（以及使用量）、所有服务器数据文件夹的 **已用存储空间**、**健康状况 · 24小时**（过去一天内的崩溃、内存不足停止和自动重启次数），以及分为模组和服务器级别更新的 **更新**。下方是按状态分类的 **服务器统计**，以及显示每个服务器内存和 CPU 占用的 **资源概览** 图表。

## 服务器卡片

每个服务器显示为一个卡片，包含其状态（运行中、启动中、已停止、崩溃、以及不健康或卡住等中间状态）、类型和 Minecraft 版本、游戏端口以及标签。每张卡片显示 **玩家** 和 **磁盘** 使用量与配额的对比；运行中的服务器还会实时显示 **CPU** 和 **内存** 使用情况，并持续更新。

点击卡片可打开该服务器。空的 **创建服务器** 卡片和顶部的 **创建服务器** 按钮都会启动[创建向导](/docs/servers/)。

你可以按名称、类型、版本或标签搜索服务器，按状态、名称、大小、最后启动或创建时间排序，并使用右侧的切换按钮在网格和列表布局之间切换。

## 近期活动

底部的活动流显示了面板人类可读审计日志的最新条目：登录、备份、蓝图导出、更新检查、聊天命令更改、服务器启动和停止等。每个条目都标记了所属的服务器（或面板本身）以及发生的时间。**查看全部** 会在 [活动](/docs/activity/) 页面打开完整的历史记录。
