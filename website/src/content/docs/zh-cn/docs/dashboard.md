仪表板是您的主页：显示所有服务器的实时状态以及正在发生的事件的动态信息流。

![Dashboard](/docs/images/dashboard.png)

## 摘要卡片

位于顶部：

- **在线服务器** - 您当前正在运行的服务器数量。
- **已连接玩家** - 所有运行中服务器的总玩家数量。
- **可用更新** - 有多少服务器、整合包或模组有新版本（[查看更新](/docs/updates/)）。
- **Docker** - 面板是否可以连接到 Docker 守护进程及其版本。

## 服务器卡片

每台服务器都显示为一个卡片，包含其状态（运行中、启动中、已停止、已崩溃）、类型和 Minecraft 版本，以及游戏端口。对于正在运行的服务器，您还可以实时查看**玩家**、**CPU**、**内存**和**磁盘**使用情况，这些信息会持续更新。

点击卡片即可打开该服务器。空白的**创建服务器**卡片和顶部的**创建服务器**按钮都会启动[创建向导](/docs/servers/)。

您可以搜索和排序您的服务器，并通过右侧的切换按钮在网格和列表布局之间切换。

## 最近活动

底部的动态信息流是一个实时的、人类可读的审计日志：登录、备份、蓝图导出、更新检查、聊天命令更改、服务器启动和停止等。每条记录都标记了它所属的服务器（或面板本身）以及发生的时间。完整的历史记录位于[活动](/docs/activity/)页面。
