**存储**页面显示了磁盘使用情况：每个服务器的使用量以及随时间推移的趋势。

![存储](/docs/images/storage.png)

## 磁盘配额由面板强制执行

Docker 无法限制绑定挂载的磁盘使用量，因此由面板来完成。后台的磁盘使用量索引器会遍历数据目录，缓存每个服务器的占用空间，并强制执行您为每个服务器设置的磁盘配额。当服务器的数据（世界 + 备份 + 其他所有内容）接近其配额时，面板会阻止其无限制增长，而不是让一个服务器填满您的主机。

在服务器的[设置](/docs/servers/)中设置服务器的配额。模组服务器及其[备份](/docs/backups/)可能会很大，因此请为它们留出空间。

## 清理

存储视图可帮助您在空间不足之前找到要删除的内容（旧备份、未使用的世界或远超预期的服务器），以进行清理。
