双重身份验证 (2FA) 为登录过程增加了第二个步骤：在输入密码后，您需要输入手机上身份验证器应用生成的6位数字代码。即使有人知道了您的密码，没有您的设备也无法登录。

它兼容任何标准的 TOTP 身份验证器（如 Google Authenticator、Authy、1Password、Microsoft Authenticator 等），并且**所有**账户都可以使用，不仅仅是管理员。保护您自己的登录信息并非服务器管理操作，因此查看者和操作员也可以启用它。

## 启用 2FA

打开账户菜单（右上角的您的头像）并选择 **双重身份验证**。

![账户菜单](/docs/images/2fa-user-menu.png)

您将看到一个注册对话框：

![注册](/docs/images/2fa-enroll.png)

1. 使用您的身份验证器应用 **扫描二维码**，或者点击 **复制** 手动输入密钥。
2. 输入您的应用当前显示的 **6位数字代码**。
3. **确认您的密码**。启用 2FA 会重新验证您的密码，因此一个未关闭的会话无法在他人设备上启用它。
4. 点击 **启用**。

### 保存您的备用代码

2FA 启用后，面板会显示一组一次性的 **备用代码**。

![备用代码](/docs/images/2fa-backup-codes.png)

每个代码 **仅限使用一次**，用于在您丢失身份验证器应用访问权限时登录。请将它们保存在安全的地方（密码管理器是理想选择），因为它们不会再次显示。您可以随时重新生成一组新的代码（旧代码将失效）。

## 使用 2FA 登录

此后，登录将需要第二个步骤。在输入用户名和密码后，面板会要求输入您的代码：

![2FA 登录](/docs/images/2fa-login-challenge.png)

输入您应用当前显示的6位数字代码（或您的备用代码之一），即可登录。在此步骤完成之前，会话 **未** 登录：无法访问任何页面或 API。

## 管理或关闭 2FA

在 2FA 启用状态下，打开账户菜单中相同的 **双重身份验证** 条目。在确认密码后，您可以：

- **重新生成备用代码** - 生成一组新代码并使旧代码失效。
- **关闭 2FA** - 从您的账户中移除它。

两者都会先重新验证您当前的密码。

## 手机和备用代码都丢失了？

**管理员** 可以从 **设置 → 用户**（2FA 列中的 **重置** 按钮）重置其他用户的 2FA。这将清除该账户的 2FA，以便用户仅凭密码即可登录并重新设置。管理员无法重置他们 **自己** 的 2FA。他们需要通过正常的密码验证流程来关闭 2FA，因此被劫持的管理员会话无法移除自身的二次验证。

## 良好实践

- 代码是基于时间的，每30秒轮换一次；面板允许轻微的时钟漂移，并在服务器时钟校正后自动恢复。
- 代码不能重放 - 一旦用于登录，在有效期内该代码将不再有效。
- 错误代码会受到速率限制。此限制器与密码步骤 **共享**（每个账户有锁定机制，外加每个 IP 的 `RATE_LIMIT_AUTH_PER_15MIN` 限制器），因此输入正确密码无法在猜测6位数字代码前重置计数器。
- 所有 2FA 的更改（启用、禁用、重置、使用备用代码）都会记录在 [活动日志](/docs/activity/) 中。
