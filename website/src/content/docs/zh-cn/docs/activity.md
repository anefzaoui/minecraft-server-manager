**活动**页面是完整的审计日志：一个可搜索的、按时间顺序记录面板中发生的所有事件的记录。

![Activity](/docs/images/activity.png)

## 记录内容

- **认证** - 登录（包括是否使用了双因素认证或备用代码），以及双因素认证的启用、禁用或重置。
- **服务器生命周期** - 创建、启动、停止、重启、崩溃和内存不足事件。
- **警报** - 启动卡顿、停止失败、计划任务失败、配额停止、容器不健康、重启后离线。
- **数据** - 备份创建和恢复、蓝图导出、资源包安装和升级。
- **配置** - 聊天命令更改、角色更改和设置编辑。

每条记录都会记录是谁执行的操作（用户名，或面板/调度器用于自动化操作）、它关联到哪个服务器以及何时执行。 [仪表盘](/docs/dashboard/) 显示最近的条目；此页面是完整的历史记录。生命周期和警报事件也可以转发到 Discord（请参阅 [集成](/docs/integrations/)）。

由于它捕获了安全相关的事件（登录、双因素认证更改、角色更改），因此如果某个账户出现异常，活动日志也是您的首要检查之处。
