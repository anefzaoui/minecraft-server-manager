**活动**页面是完整的审计日志：一个可搜索的、按时间顺序记录面板中发生的所有事件的记录。按服务器或事件类型进行筛选，搜索摘要，并将筛选结果导出为 CSV 或 JSON。捕获了日志（例如崩溃）的条目会在原地打开它。

![Activity](/docs/images/activity.png)

## 记录内容

- **认证**：登录（包括是否使用了双重身份验证或备用代码）、账户锁定、密码更改以及双重身份验证的启用、禁用或重置。
- **服务器生命周期**：创建、启动、停止、重启、崩溃、自动重启和内存不足事件。
- **警报**：启动停滞、停止失败、计划失败、配额停止、容器不健康、重启后离线。
- **数据**：创建和恢复的备份、导出的蓝图、安装和升级的包、模组和世界更改以及文件编辑。
- **玩家**：踢出、封禁、白名单和管理员更改以及玩家备注。
- **配置**：聊天命令更改、用户和角色更改、每个服务器的权限更改、游戏端口更改以及设置编辑。

每个条目都记录了谁执行了操作（用户名，或面板/调度器用于自动化操作）、它关联的服务器以及时间。 [仪表板](/docs/dashboard/) 显示最近的条目；此页面是完整的历史记录。管理员和查看者只能看到他们有权查看的服务器的条目（以及面板范围内的条目），并且每个服务器的权限更改仅对管理员显示。生命周期和警报事件也可以转发到 Discord（请参阅 [集成](/docs/integrations/)）。

由于它捕获了与安全相关的事件（登录、双重身份验证更改、角色和权限更改），因此如果账户出现异常，活动日志也是您的首选。
