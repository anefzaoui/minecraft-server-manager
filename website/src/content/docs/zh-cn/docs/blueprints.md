**蓝图**将服务器的全部配置（类型、版本、资源、环境、包固定、自定义模组，以及可选的配置文件和世界）捕获到一个可移植的 `.mcserver.zip` 文件中，您可以从中创建新的服务器。蓝图永远不会写入敏感信息（环境变量中的密码、令牌和密钥）。

![蓝图](/docs/images/blueprints.png)

## 导出

在服务器的“**设置 → 配置**”选项卡中，使用“**导出为蓝图**”并选择要包含的内容：始终包含服务器的配置，其配置文件目录（默认开启），以及可选的自定义模组文件本身（一个更大的文件，安装时无需下载任何内容）和活动世界。结果将保存在您的蓝图库中，并可下载以供共享。

同一卡片上的“**克隆服务器**”一步完成导出和导入，以创建服务器的副本，包含或不包含其世界。

## 从蓝图导入和创建

导入蓝图文件（在“**蓝图**”页面上点击“**导入蓝图**”）或从库中选择一个（在卡片上点击“**创建服务器**”，或在向导的“**从蓝图创建**”选项卡中）来创建一个与原始服务器完全相同的新服务器。新服务器将拥有自己的端口和新的 RCON 密码。未嵌入的自定义模组将再次下载，并与蓝图记录的哈希值进行比对。库中还包含两个初始蓝图，一个用于 Paper，一个用于 Fabric。

这是最快的方法：

- 快速启动相同的服务器（例如，一个小型游戏服务器网络，生产环境的暂存副本）。
- 将服务器从一个面板迁移到另一个面板。
- 保留一个已知的良好模板，以便随时回滚。

因为蓝图会记录确切的 [包固定](/docs/modpacks/) 版本，所以从蓝图中创建的模组包服务器将安装相同的固定版本，不会有意外的升级。
