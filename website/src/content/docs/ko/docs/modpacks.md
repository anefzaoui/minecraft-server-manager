**모드팩** 페이지(및 [생성 마법사](/docs/servers/)의 **모드팩에서** 탭)는 모드팩을 서버로 설치하며, 항상 **정확한 팩 버전에 고정**되어 있어 재시작 시 팩이 예고 없이 업그레이드되는 것을 방지합니다.

![Modpacks](/docs/images/modpacks.png)

## 지원되는 플랫폼

- **CurseForge** - 팩 URL을 검색하거나 붙여넣습니다. 검색 및 비공개 팩에는 CurseForge API 키가 필요합니다(설정 → API 키에서 추가).
- **Modrinth** - 이름으로 검색합니다.
- **FTB** - Feed The Beast 팩.
- **GT New Horizons** - 1.7.10 전문가 팩으로, GTNH 자체 릴리스 인덱스에서 설치됩니다. GTNH는 팩 버전에 따라 Java 런타임을 선택합니다(2.8.0+는 번들 lwjgl3ify 패치를 통해 **Java 25**에서 실행되고, 이전 릴리스는 Java 21 또는 17에서 실행됨). 마법사는 서버의 RAM 및 디스크를 합리적인 최소값으로 조정합니다.
- **사용자 지정 zip** - 게시된 팩이 아닙니다. **CurseForge 모드팩 내보내기**(CurseForge 앱이 선택한 모드 세트에 대해 생성하는 `manifest.json`이 포함된 zip) 또는 **모드 jar의 zip 파일**을 업로드합니다. 패널은 CurseForge API를 통해 매니페스트를 일괄 처리하거나(또는 각 jar를 해시/지문/메타데이터로 식별) 설치 가능한 항목을 미리 보고 한 번의 작업으로 모든 것을 설치합니다. 여기에는 팩의 `overrides/` 구성도 포함됩니다(선택 사항). 저작자가 자동 다운로드를 허용하지 않는 모드는 설치 실패 대신 브라우저 링크와 수동 업로드 슬롯으로 표시됩니다.

## 고정 작동 방식

팩을 선택하면 패널이 정확한 버전을 확인하고 기록한 다음 설치합니다. **업데이트** 페이지에서 새 버전을 사용할 수 있을 때 알려주며, 업그레이드는 사전 업데이트 백업 및 롤백을 통해 신중하게 제어되는 작업입니다. 안정 버전 추적 서버에는 베타 버전이 제공되지 않습니다.

매우 오래된 패널 버전(0.9.7 이전)에서 생성된 서버는 _고정되지 않은_ 상태로 남아 있을 수 있습니다. 이는 컨테이너 이미지가 시작될 때마다 최신 팩 버전을 조용히 설치한다는 의미입니다. 패널은 이제 부팅 시 이를 복구합니다. 각 서버를 실제로 설치된 버전에 고정하고(패널 자체 기록 또는 이미지의 설치 매니페스트에서 읽음, 새로 확인된 "최신" 아님) 이벤트를 기록합니다. 설치된 버전을 알 수 없는 경우 서버의 설정 페이지에 수동으로 버전을 선택하라는 경고가 표시되며, 고정되지 않은 모드팩 구성을 저장하려는 시도는 즉시 거부됩니다.

## 업데이트 정책

각 서버에는 **설정**에 업데이트 정책이 있으며, 세 가지 옵션 모두 말 그대로의 의미를 갖습니다.

- **수동만** - 아무것도 자동으로 변경되지 않으며 서버는 업데이트 배지 및 업데이트 페이지에서 완전히 제외됩니다. "날 내버려 둬" 모드로, 수동으로 조정하거나 가져온 팩을 절대 건드리지 않으려는 경우에 이상적입니다.
- **알림** (기본값) - 일일 검사 시 사용 가능한 업데이트가 배지 및 업데이트 페이지에 표시되며, 적용은 항상 사용자의 클릭으로 이루어집니다.
- **자동 업데이트** - 예약된 일일 검사 후, 보류 중인 **팩** 업데이트는 수동 업그레이드와 동일한 제어 경로를 통해 적용됩니다. 사전 업데이트 백업, 상태 모니터링 및 새 버전이 부팅에 실패할 경우 자동 롤백이 포함됩니다. 서버를 다른 Minecraft 버전으로 이동하는 업데이트는 항상 이벤트로 건너뜁니다. 패널은 월드를 영구적으로 변환하는 결정을 대신 내리지 않습니다. 수동 "지금 확인" 버튼은 확인만 하며 자동 업데이트를 트리거하지 않습니다.

## 팩 업그레이드

고정된 서버에서 새 버전으로 한 번의 작업으로 업그레이드할 수 있습니다. 패널은 먼저 백업을 수행하고, 고정된 버전을 전환하고, 컨테이너를 다시 생성합니다(새 버전이 다른 런타임을 필요로 하는 경우 Java 재확인 포함). 그런 다음 첫 번째 부팅을 모니터링하며, GTNH와 같이 몇 기가바이트를 다운로드하고 첫 시작 시 수백 개의 모드로 월드를 구축하는 대형 팩을 위해 충분한 시간을 제공합니다.
