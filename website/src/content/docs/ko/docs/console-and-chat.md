## 실시간 콘솔

**콘솔** 탭은 서버 로그를 실시간으로 스트리밍하고 서버 명령을 보낼 수 있는 명령 상자를 제공합니다. `docker exec`나 SSH가 필요 없습니다. 출력은 색상 등을 포함하여 인라인으로 돌아옵니다. 명령을 보내려면 해당 서버에 대한 콘솔 권한이 필요합니다. 권한이 없어도 로그를 볼 수 있습니다.

로그 위에서 텍스트(또는 `/정규식/`) 및 수준(INFO, WARN, ERROR)별로 줄을 필터링할 수 있으며, **다운로드**는 최근 출력, 전체 `latest.log` 또는 모든 로그 파일을 zip으로 제공합니다.

![콘솔](/docs/images/server-console.png)

콘솔은 패널이 서버의 상태를 읽는 곳이기도 합니다. 로그를 감시하여 부팅 단계("모드 로딩 중", "월드 생성 중", "시작 완료 중")를 분류하고 `list`를 호출하여 온라인 상태인 플레이어를 추적하므로 대시보드와 서버 카드는 항상 실제를 반영합니다.

이 폴링은 주기마다 짧은 RCON 연결을 열며, 서버 로그에는 약 20초마다 `Thread RCON Client … started` / `shutting down` 쌍으로 기록되고, 월드 제어가 열려 있는 동안 플레이어 수 확인(`list`), `time query …` 및 `gamerule <name>` 읽기를 위한 각 읽기 전용 폴링에 대해 (코어 또는 플러그인이 이를 에코하는 서버의 경우) `Rcon issued server command: …` 줄이 기록됩니다. 로그 위의 **콘솔 노이즈 숨기기** 토글은 해당 줄(RCON 리스너 시작 줄 포함)을 필터링합니다. 이 설정은 기본적으로 켜져 있으며 브라우저별로 기억됩니다. 원시 스트림을 보려면 끄십시오.

패널에서 보낸 명령은 서버별 레이블(**다음으로 발표...** 상자) 아래 게임 내에서 발표될 수 있으므로 플레이어는 신비로운 콘솔이 아닌 운영자가 작동했음을 알 수 있습니다.

## 채팅

**콘솔 → 채팅**은 서버가 실행되는 동안 게임에 메시지를 보냅니다. **스타일 지정된** 메시지는 색상과 서식을 적용하며 모든 사람 또는 온라인 플레이어 한 명에게 보낼 수 있고, **일반**은 모든 사람에게 간단한 `[서버]` 브로드캐스트를 보냅니다.

![콘솔 → 채팅](/docs/screenshots/04-chat.png)

## 채팅 명령

채팅 명령(**콘솔 → 명령**)을 사용하면 플레이어가 게임 채팅에 접두사 명령을 입력하여 패널 작업을 트리거할 수 있습니다. 예를 들어 `!spawn`으로 무작위 순간이동할 수 있습니다. 감지는 로그 기반이며 실행은 서버를 통해 이루어지므로 **모드가 필요하지 않습니다**.

![채팅 명령](/docs/images/chat-commands.png)

각 명령에는 다음이 있습니다.

- **트리거**(예: `spawn`): 서버의 **접두사**(`!` 기본값, 한두 글자, `/` 아님) 뒤에 입력합니다.
- **작업**: 무작위 순간이동, 구조물로 순간이동, 생물 군계로 순간이동 또는 원시 콘솔 명령 실행.
- **권한 수준**: 모든 사람, 화이트리스트에 등록된 플레이어 또는 운영자만.
- 플레이어별 **쿨다운**(기본값 30초) 및 `{distance}`와 같은 자리 표시자를 사용한 사용자 정의 보류/성공/실패 메시지.

### 안전 관련 참고 사항

서버를 망가뜨릴 수 있는 명령(`stop`, `op`, `ban`, `whitelist` 등)은 **운영자 전용** 트리거에서만 허용됩니다. 패널은 `execute … run …` 체인 안에 중첩된 경우에도 이를 확인하므로 낮은 권한의 트리거가 위험한 명령을 몰래 전달할 수 없습니다. `say` 메시지와 같이 단순히 해당 단어를 언급하는 일반 채팅 텍스트는 그대로 둡니다.
