## 실시간 콘솔

**콘솔** 탭은 서버 로그를 실시간으로 스트리밍하고 서버 명령을 보낼 수 있는 명령 상자를 제공합니다. `docker exec`나 SSH가 필요 없습니다. 출력은 색상까지 그대로 인라인으로 표시됩니다.

![콘솔](/docs/images/server-console.png)

콘솔은 패널이 서버 상태를 읽는 곳이기도 합니다. 로그를 감시하여 부팅 단계("모드 로딩 중", "월드 생성 중", "시작 완료")를 분류하고 `list`를 호출하여 온라인 상태인 플레이어를 추적하므로 대시보드와 서버 카드는 항상 실제 상태를 반영합니다.

이 폴링은 주기마다 짧은 RCON 연결을 열며, 서버 로그에는 약 20초마다 `Thread RCON Client … started` / `shutting down` 쌍으로 기록되고, (코어나 플러그인이 이를 에코하는 서버에서는) 읽기 전용 폴링마다 `Rcon issued server command: …` 줄이 기록됩니다. 플레이어 수를 위한 `list`, 월드 제어 페이지가 열려 있을 때의 `time query …` 및 `gamerule <name>` 읽기 등이 포함됩니다. 로그 위쪽의 **RCON 노이즈 숨기기** 토글은 (RCON 리스너 시작 줄과 함께) 해당 줄을 필터링합니다. 이 설정은 기본적으로 켜져 있으며 브라우저별로 기억됩니다. 원시 스트림을 보려면 끄십시오.

패널에서 보낸 명령은 서버별 레이블 아래 게임 내에서 공지될 수 있으므로, 플레이어는 알 수 없는 콘솔이 아닌 운영자가 작동했음을 알 수 있습니다.

## 채팅 명령

채팅 명령을 사용하면 플레이어는 게임 채팅에 접두사 명령을 입력하여 패널 작업을 트리거할 수 있습니다. 예를 들어 `!spawn`을 입력하면 무작위 순간이동을 합니다. 감지는 로그 기반이며 실행은 서버를 통해 이루어지므로 **모드가 필요하지 않습니다**.

![채팅 명령](/docs/images/chat-commands.png)

각 명령에는 다음이 포함됩니다.

- **트리거**(예: `spawn`) 및 **접두사**(`!`가 기본값).
- **작업**: 무작위 순간이동, 구조물로 순간이동, 생물 군계로 순간이동 또는 원시 콘솔 명령 실행.
- **권한 수준**: 모든 사용자, 화이트리스트에 등록된 플레이어 또는 운영자만.
- **쿨다운** 및 `{distance}`와 같은 플레이스홀더를 사용한 사용자 정의 보류 중/성공/실패 메시지.

### 안전 관련 참고 사항

서버를 망가뜨릴 수 있는 명령(`stop`, `op`, `ban`, `whitelist` 등)은 **운영자 전용** 트리거에서만 허용됩니다. 패널은 이러한 명령이 `execute … run …` 체인 안에 중첩되어 있더라도 이를 확인하므로, 낮은 권한의 트리거가 위험한 명령을 몰래 전달할 수 없습니다. `say` 메시지와 같이 단순히 해당 단어를 언급하는 일반 채팅 텍스트는 그대로 둡니다.
