플레이어가 설치하길 원하는 것을 기준으로 선택하세요. 가장 빠르다고 생각되는 것을 기준으로 선택하지 마세요.

| 원하는 것                                  | 실행할 것            | 플레이어 설치 |
| ------------------------------------------ | -------------------- | ------------- |
| 친구들과 함께하는 서바이벌, 특별한 것 없음 | Vanilla              | 없음          |
| 랭크, 보호, 관리 기능이 있는 공개 서버     | Paper                | 없음          |
| CurseForge 또는 Modrinth의 특정 모드 팩    | 설명된 대로          | 팩            |
| 직접 구축하는 최신 모드 팩                 | Fabric 또는 NeoForge | 동일한 모드   |
| 1.7 ~ 1.12 버전대의 오래된 팩              | Forge                | 동일한 모드   |

대부분의 사람들에게는 이것으로 충분합니다. 나머지 내용은 그 이유입니다.

## 플러그인과 모드는 다릅니다

이것이 다른 모든 것의 기준이 되는 구분입니다.

**플러그인**은 서버에서만 실행됩니다. Paper, Spigot, Bukkit이 이를 로드합니다. 플레이어는 일반적인
수정되지 않은 클라이언트로 접속하며, 플러그인이 있는지조차 모릅니다. 규칙, 권한, 경제,
보호, 미니게임, 관리 등 근본적으로 게임에 관련된 모든 것이 플러그인이며, 거의 모든 공개 서버가 Paper를 실행하는 이유입니다.

**모드**는 게임 자체를 변경합니다: 새로운 블록, 새로운 차원, 새로운 기계. 서버가 보내는 것을 이해하려면 클라이언트도 서버와 동일한 모드를 로드해야 합니다. 모드가 적용된 서버에 접속하는 사람은 먼저 팩을 설치해야 합니다.

서버는 의미상 둘 다일 수 없습니다. 모드 로더에 플러그인 API를 덧붙인 하이브리드 프로젝트도 존재하지만, 작동하다가도 결국에는 작동하지 않게 됩니다. 둘 다 필요하다면, 모드가 적용된 서버와 플러그인 서버 뒤에 프록시를 두는 것이 하나의 하이브리드 서버를 사용하는 것보다 낫습니다.

## 플러그인 측면

**Paper**가 기본 선택입니다. 수년간의 성능 개선 작업과 관리자가 불편해했던 거의 모든 동작에 대한 설정 파일을 갖춘 Spigot의 포크입니다. Bukkit 시대의 Vanilla 플러그인 대부분은 여전히 작동합니다.

**Purpur**는 Paper의 포크로, 게임 플레이 관련 설정을 포함하여 훨씬 더 많은 옵션을 제공합니다. 이러한 특정 설정을 원한다면 Purpur를 선택하세요. 그렇지 않다면 Paper를 사용하세요.

**Vanilla**는 변경되지 않은 게임 자체를 즐기는 것이 목적일 때 실행할 가치가 있습니다. 플레이어가 많을 경우 속도가 느려지고, 권한 시스템이 없어 관리가 수동으로 이루어집니다.

Paper는 성능 향상을 위해 기본적으로 일부 Vanilla 동작을 변경합니다. 비디오에서 본 레드스톤 장치가 서버에서 작동하지 않는다면, 대부분 그 이유 때문이며 보통 설정 문제입니다.

## 모드 측면

**Fabric**은 가볍고, 며칠 안에 새로운 Minecraft 버전으로 업데이트되며, 대부분의 최신 성능 모드를 지원합니다. 거의 모든 Fabric 모드는 별도 다운로드가 필요한 Fabric API도 함께 요구합니다.
몇 가지 편의성 모드를 갖춘 빠른 서버를 목표로 한다면 이것이 좋습니다.

**NeoForge**는 현재 버전에서 이전 Forge 생태계의 작업이 이루어지는 곳입니다. 1.20.1 버전 중에 Forge에서 분기되었으며, 1.20.2 버전 이상을 위해 구축된 대부분의 대형 팩이 이를 대상으로 합니다. 오늘날 새로운 대규모 팩을 시작한다면 이것이 좋습니다.

**Forge**는 여전히 과거를 지배합니다. 1.7.10, 1.12.2, 1.16.5 버전대의 많은 사랑받는 팩들은 Forge이며 앞으로도 그럴 것입니다. 이러한 팩을 위해서는 Forge를 유지하세요.

**Quilt**는 대부분의 Fabric 모드를 실행하는 Fabric의 포크입니다. 좋은 이유로 존재하지만, 특별한 이유가 없다면 Fabric을 선택하세요.

한 로더용 모드는 다른 로더에서 실행되지 않습니다. 모드 페이지에 Fabric이라고 표시되어 있다면 Fabric용입니다.

## 팩을 설치하는 경우, 팩이 결정합니다

선택하지 마세요. 팩은 로더와 정확한 Minecraft 버전을 명시하며, 둘 다 일치해야 합니다.
"거의 비슷하다"는 여기서는 통하지 않습니다. 1.20.1용 팩은 1.20.4에서 실행되지 않으며, 1.20.1 NeoForge 팩은 1.20.1 Forge에서 실행되지 않습니다.

모드를 직접 선택하기보다는 팩의 ID 또는 링크로 설치하고 버전을 고정하세요. 팩은 업데이트되며, 시즌 중에 예기치 않은 업데이트는 월드를 손상시키는 원인이 됩니다.

## 어떤 Java 버전

Minecraft의 요구 사항은 게임 버전에 따라 변경되며, 잘못된 버전을 실행하면 명확한 메시지 대신 유용한 `UnsupportedClassVersionError` 오류가 발생합니다.

| Minecraft 버전  | Java |
| --------------- | ---- |
| 1.16.5 이하     | 8    |
| 1.17            | 16   |
| 1.18 및 1.19    | 17   |
| 1.20 ~ 1.20.4   | 17   |
| 1.20.5 ~ 1.21.x | 21   |
| 26.1 이상       | 25   |

오래된 팩은 Java 8이 정말로 필요합니다. 소프트웨어에서 최신 버전이 잘못되는 몇 안 되는 경우 중 하나입니다.

## Minecraft Server Manager에서

생성 마법사는 실행하려는 것을 묻고 위의 표에서 Java 버전을 선택하므로 실수로 버전 불일치가 발생하지 않습니다. Vanilla, Paper, Purpur는 **Vanilla** 탭에 있으며, **모드에서 가져오기** 탭은 Fabric, Forge, NeoForge 또는 Quilt를 선택하고 Minecraft 버전과 로더 빌드(최신 또는 고정된 버전)를 지정합니다. CurseForge, Modrinth 또는 GT New Horizons에서 팩을 설치하면 정확한 버전으로 고정됩니다. 업그레이드는 적용할 때(또는 서버의 업데이트 정책이 **자동 업데이트**인 경우 일일 확인 후) 발생하며, 항상 먼저 백업을 수행하고 롤백할 수 있습니다.

모드 브라우저는 서버가 어떤 로더를 실행하는지 알고 해당 로더에 맞는 모드만 제공하므로, Fabric jar 파일이 NeoForge 서버에 실수로 들어가는 일이 없습니다.
