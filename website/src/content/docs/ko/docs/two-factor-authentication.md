2단계 인증(2FA)은 로그인에 두 번째 단계를 추가합니다. 비밀번호를 입력한 후 휴대폰의 인증 앱에서 받은 짧은 코드를 입력합니다. 누군가 비밀번호를 알아내더라도 기기 없이는 로그인할 수 없습니다.

Google Authenticator, Authy, 1Password, Microsoft Authenticator 등 표준 TOTP 인증 앱과 함께 작동하며, 관리자뿐만 아니라 **모든** 계정에서 사용할 수 있습니다. 자신의 로그인을 보호하는 것은 서버 관리 작업이 아니므로 시청자 및 운영자도 이 기능을 활성화할 수 있습니다.

## 2FA 활성화하기

계정 메뉴(프로필 사진 또는 이니셜, 오른쪽 상단)를 열고 **2FA**를 선택합니다.

![계정 메뉴](/docs/images/2fa-user-menu.png)

등록 대화 상자가 표시됩니다.

![등록](/docs/images/2fa-enroll.png)

1. 인증 앱으로 **QR 코드를 스캔**하거나 **복사**를 탭하여 수동 키를 입력합니다.
2. 앱에 표시되는 **6자리 코드**를 입력합니다.
3. **비밀번호를 확인**합니다. 2FA를 활성화하면 비밀번호를 다시 확인하므로, 열려 있는 세션이 다른 사람의 기기로 2FA를 켤 수 없습니다.
4. **활성화**를 클릭합니다.

### 백업 코드 저장하기

2FA가 활성화되는 즉시 패널에 일회용 **백업 코드** 세트가 표시됩니다.

![백업 코드](/docs/images/2fa-backup-codes.png)

각 코드는 **한 번만** 사용할 수 있으며, 인증 앱에 액세스할 수 없게 될 경우 로그인하는 데 사용됩니다. 다시 표시되지 않으므로 안전한 곳(비밀번호 관리자가 이상적)에 저장하세요. 언제든지 새 세트를 다시 생성할 수 있습니다(기존 코드는 무효화됨).

## 2FA로 로그인하기

그 후부터 로그인은 두 번째 단계를 거칩니다. 사용자 이름과 비밀번호를 입력한 후 패널에서 코드를 요청합니다.

![2FA 로그인](/docs/images/2fa-login-challenge.png)

앱의 현재 6자리 코드(또는 백업 코드 중 하나)를 입력하면 로그인됩니다. 이 단계를 완료하기 전까지는 세션이 로그인되지 않은 상태이며, 어떤 페이지나 API에도 액세스할 수 없습니다.

## 2FA 관리 또는 비활성화하기

2FA가 활성화된 상태에서 계정 메뉴의 동일한 **2FA** 항목을 엽니다. 비밀번호를 확인한 후 다음을 수행할 수 있습니다.

- **백업 코드 다시 생성**: 새 세트를 발급하고 이전 세트를 비활성화합니다.
- **2FA 비활성화**: 계정에서 2FA를 제거합니다.

둘 다 먼저 현재 비밀번호를 다시 확인합니다.

## 휴대폰과 백업 코드를 모두 분실했나요?

**관리자**는 **설정 → 사용자**(**해당 사용자의 작업 메뉴에서 2FA 재설정**)에서 다른 사용자의 2FA를 재설정할 수 있습니다. 이렇게 하면 해당 계정의 2FA가 지워져 사용자가 비밀번호만으로 로그인하고 다시 설정할 수 있습니다. 관리자는 자신의 2FA를 비밀번호 없이 재설정할 수 없습니다. 일반적인 비밀번호 확인 후 비활성화 절차를 따르므로, 탈취된 관리자 세션이 자체적인 두 번째 요소를 제거할 수 없습니다.

## 알아두면 좋은 점

- 코드는 시간 기반이며 30초마다 순환됩니다. 패널은 약간의 시간 차이를 허용하며, 서버 시계가 나중에 수정될 경우 조용히 복구됩니다.
- 코드는 재사용할 수 없습니다. 로그인에 사용된 코드는 해당 시간 창 내에서 다시 작동하지 않습니다.
- 잘못된 코드는 속도 제한이 적용됩니다. 이 제한은 비밀번호 단계와 **공유**됩니다(계정별 잠금 및 IP별 `RATE_LIMIT_AUTH_PER_15MIN` 제한). 따라서 올바른 비밀번호를 입력해도 6자리 코드를 추측하기 직전에 카운터를 재설정할 수 없습니다.
- 2FA 변경(활성화, 비활성화, 재설정, 백업 코드 사용)은 모두 [활동 로그](/docs/activity/)에 기록됩니다.
