## 1. 처음이 아닌 마지막 스무 줄을 읽으세요

로그의 **끝**으로 스크롤하세요. Java 스택 트레이스는 가장 안쪽부터 출력되므로, 텍스트 벽의 맨 위는 가장 흥미롭지 않은 부분입니다. 원하는 것은 마지막 `Caused by:` 줄과 그 뒤에 오는 내용입니다. 이 한 줄이 보통 문제를 명확히 합니다.

두 가지 모양이 현재 위치를 알려줍니다:

- `Exception in thread "main"` 또는 끝 근처의 크래시 보고서 경로가 보이면 게임 자체에 문제가 생긴 것입니다.
- 로그가 중간에 아무 예외 없이 갑자기 멈추면, 외부에서 프로세스를 종료시킨 것입니다. 3번 항목으로 이동하세요.

## 2. UnsupportedClassVersionError는 잘못된 Java를 의미합니다

```
java.lang.UnsupportedClassVersionError: net/minecraft/server/Main has been compiled
by a more recent version of the Java Runtime (class file version 65.0)
```

클래스 파일 52는 Java 8, 60은 16, 61은 17, 65는 21, 69는 25입니다. 이 메시지는 서버가 실행 중인 것보다 최신 버전의 Java를 필요로 한다는 의미입니다. 반대로, 오래된 팩을 최신 Java에서 실행하면 보통 믹스인(mixin) 또는 리플렉션(reflection) 오류가 발생합니다.

| Minecraft 버전  | Java |
| --------------- | ---- |
| 1.16.5 이하     | 8    |
| 1.17            | 16   |
| 1.18 및 1.19    | 17   |
| 1.20 ~ 1.20.4   | 17   |
| 1.20.5 ~ 1.21.x | 21   |
| 26.1 이상       | 25   |

오래된 팩은 실제로 Java 8이 필요합니다. 새 버전이 더 좋지는 않습니다.

## 3. 종료 코드 137은 모드가 아닌 커널 문제입니다

로그가 문장 중간에 멈추고, 크래시 보고서가 없으며, 컨테이너가 137을 보고합니다. 이것은 메모리 부족으로 인한 종료입니다. 프로세스가 기계에 없는 메모리를 요청했기 때문에 종료되었습니다.

거의 항상 Java 힙이 기계의 메모리와 동일한 크기로 설정되었을 때 발생합니다. 힙은 기계 메모리에서 JVM 자체의 오버헤드(모드 서버의 경우 0.5~1.5GB)를 **제외한** 만큼의 메모리가 필요합니다. 힙 크기를 줄이거나, 기계의 메모리를 늘리세요. [서버에 필요한 RAM 양](/docs/guide-server-memory/)에 자세한 수치가 나와 있습니다.

## 4. EULA와 포트

한 줄 해결책으로 해결되는 두 가지 고전적인 문제입니다:

- `You need to agree to the EULA in order to run the server.` (서버를 실행하려면 EULA에 동의해야 합니다.) `eula=true`로 설정하거나, `eula.txt` 파일 또는 사용 중인 설정의 환경 변수를 통해 설정하세요.
- `Address already in use` (주소가 이미 사용 중입니다) 또는 `FAILED TO BIND TO PORT` (포트 바인딩 실패). 25565 포트를 다른 무언가가 사용 중입니다. 종종 완전히 종료되지 않은 이전 서버 복사본일 수 있습니다. 포트를 변경하는 대신 해당 프로세스를 찾아 중지하세요. 그렇지 않으면 두 개의 서버가 실행될 수 있습니다.

## 5. 모드에 종속성이 누락되었습니다

```
Mod X requires mod Y, which is missing
Fabric API is not installed
```

Fabric 모드는 별도의 파일로 Fabric API를 요구하는 경우가 많습니다. Forge 및 NeoForge 모드는 오류 자체에 종속성을 나열합니다. 최신 버전이 아닌 명시된 버전을 설치하세요. "requires 0.91.x"는 해당 줄을 의미하며, 0.92는 동일한 검사를 실패하게 합니다.

때로는 누락된 종속성이 로더 자체인 경우도 있습니다:

```
Mod X requires forge 47.4.14 or above
Mod ID: 'forge', Requested by: 'x', Expected range: '[47.4.14,)', Actual version: '47.4.10'
```

해결책은 다른 모드가 아닌 최신 로더 빌드입니다. "47.4.14 이상"은 해당 버전부터 올라가는 모든 빌드를 의미하며, Forge는 모든 숫자를 게시하지 않으므로 설치할 빌드는 다음 번호일 수 있습니다. 모드팩의 경우, 먼저 모드팩을 업데이트하세요. 자체 로더 버전이 모드에 비해 너무 오래된 모드팩은 작성자가 수정해야 할 버그입니다.

## 6. 모드가 잘못된 로더 또는 버전에 맞습니다

다른 로더용 JAR 파일은 정중하게 실패하지 않습니다. 믹스인 오류, `NoClassDefFoundError` 또는 들어본 적 없는 클래스 내부의 충돌을 예상하세요. JAR 파일 페이지를 확인하세요. 로더와 Minecraft 버전이 정확히 일치해야 합니다. 모드 관점에서 1.20.1과 1.20.4는 다른 게임입니다.

## 7. 월드가 최신 버전에서 왔습니다

```
This world was created by a newer version of Minecraft
```

월드는 앞으로만 업그레이드되고 뒤로는 절대 업그레이드되지 않습니다. 업그레이드 전의 백업을 복원하거나, 월드가 예상하는 버전을 실행하세요. 청크를 그대로 유지하는 다운그레이드 경로는 없습니다.

## 몇 주 동안 잘 실행되다가 충돌했을 때

다른 질문, 보통 다른 답변:

- **부하 시 충돌**: 타이밍이 긴 지연을 보여줍니다. 가비지 컬렉션이므로 모드 이전에 힙 크기를 확인하세요.
- **월드의 동일한 지점에서 충돌**: 손상된 청크 또는 깨진 엔티티. 크래시 보고서에 보통 좌표가 명시됩니다.
- **업데이트 직후 충돌**: 추적 결과가 다른 곳을 가리키더라도, 업데이트된 모드가 용의자입니다. 롤백하고 확인하세요.
- **이전에 괜찮았는데 재시작 시 충돌**: 디스크를 확인하세요. 디스크가 꽉 차면 극적이고 오해의 소지가 있는 오류가 발생합니다.

## 실제로 도움이 되는 도움 받기

**전체 로그**를 게시하세요. 마지막 줄만 올리지 말고, 문제가 발생하기 전에 무엇을 변경했는지 설명하세요. 채팅창이 아닌 [mclo.gs](https://mclo.gs)와 같이 로그 게시를 위해 만들어진 곳에 붙여넣으세요. Minecraft 버전, 로더, 모드팩 및 해당 버전, 서버에 할당된 힙 크기를 포함하세요. 이 네 가지 정보가 포함된 보고서는 한 번의 답장으로 답변받을 수 있습니다. 그렇지 않으면 다섯 번의 답장이 필요할 수 있습니다.

## Minecraft Server Manager에서

충돌은 컨테이너 자체의 종료로부터 감지되므로, 새벽 3시에 종료된 서버는 다음 날 발견되는 대신 로그 발췌와 함께 기록됩니다. 이 페이지의 일반적인 용의자(EULA, 잘못된 Java, 최신 버전의 월드, 이미 사용 중인 포트, 메모리 부족 Java)는 해당 로그에서 인식되며, 기록 항목에 무엇을 해야 하는지 명시됩니다. 자동 재시작은 이러한 문제를 그대로 두지 않습니다. 재시작해도 해결되지 않기 때문입니다. 크래시 보고서는 도착 시 구문 분석됩니다. 예외가 강조 표시되고, 스택은 접을 수 있으며, 추적에 나타나는 모드는 용의자로 나열됩니다.

도움이 필요할 때 카드에서 mclo.gs로 보고서를 공유할 수 있습니다(붙여넣기는 공개적이므로 확인 후). 콘솔의 **다운로드** 메뉴에는 모든 로그 파일이 하나의 zip 파일로 제공되므로 "전체 로그 게시"는 고고학 프로젝트가 아닌 다운로드입니다. 메모리 부족 종료는 메모리 부족 종료로 기록되어, 모드를 비난하는 일반적인 한 시간을 절약합니다. 다른 무언가가 실제로 포트를 필요로 하는 경우, **설정 → 구성**의 **게임 포트** 카드가 서버를 사용 가능한 포트로 이동시킵니다.

너무 오래된 로더는 서버의 **버전** 탭에서 변경됩니다. 이 탭은 빌드가 존재하는지 확인하고 백업을 수행한 후 서버를 다시 빌드합니다([모드 로더 버전 변경](/docs/updates/#changing-the-mod-loader-version)).
