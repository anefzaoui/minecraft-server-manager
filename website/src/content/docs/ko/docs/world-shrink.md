시간이 지남에 따라 월드가 확장됩니다. 플레이어가 걸었거나, 날았거나, 엔더 진주로 이동했던 모든 장소는 아무도 다시 방문하지 않았더라도 디스크에 청크를 생성합니다. **월드 축소**는 거의 아무도 시간을 보내지 않은 청크를 제거하여 월드 공간을 줄입니다. Minecraft는 누군가 다시 해당 지역으로 이동하는 순간 월드 시드에서 제거된 영역을 다시 구축하므로, 사용되지 않는 땅에는 안전하지만, 플레이어가 거의 머물지 않은 곳에 _건축_한 것은 무엇이든 함께 사라질 수 있습니다. 그렇기 때문에 먼저 백업을 해야 합니다(백업은 실행 취소입니다).

## "거의 방문하지 않은"으로 간주되는 기준

모든 청크는 플레이어가 그 안에 머문 시간을 기록합니다(Minecraft는 이를 `InhabitedTime`이라고 부릅니다). 월드 축소는 기본적으로 총 플레이어 시간 **30초** 미만의 모든 청크를 제거합니다. 축소 대화 상자를 통해 임계값(1초 ~ 1시간)과 스폰 주변에 유지할 청크 수(기본값 8개, `0`은 스폰 보호를 비활성화)를 변경할 수 있습니다.

항상 유지되는 것:

- 오버월드의 **스폰 지점** 주변 영역 (`level.dat`에서 읽음). 네더, 엔드, 사용자 지정 차원은 스폰 영역이 없습니다.
- 방문 시간을 읽을 수 없는 청크(예: 패널이 디코딩하지 못하는 압축 형식(LZ4)으로 저장된 월드). 미리 보기와 결과는 이러한 청크가 몇 개나 건너뛰어졌는지 알려줍니다.

월드의 모든 차원이 포함됩니다. Bukkit 스타일의 형제 폴더(`world_nether`, `world_the_end`)와 바닐라 및 Forge/Fabric 레이아웃(`world/DIM-1`, `world/DIM1`, `world/dimensions/<namespace>/<name>`) 모두 해당됩니다. 청크가 제거되면 엔티티와 주민 관심 지점도 함께 제거되므로, 재생성된 청크는 오래된 몹, 광산 수레 또는 직업 사이트를 상속하지 않습니다.

## 월드 탭에서 수행하기

1. **백업** 탭에서 백업을 수행합니다. 월드 탭에서 축소해도 자동으로 백업되지 않습니다.
2. **월드 → 월드**를 열고 월드를 찾아 축소 아이콘을 클릭합니다.
3. **미리 보기**를 클릭하여 제거될 청크 수(및 메가바이트 수)를 대략적으로 확인합니다. 아직 아무것도 변경되지 않았습니다. 미리 보기는 서버가 실행 중일 때도 작동합니다.
4. **월드 축소**를 클릭합니다. 축소는 월드 파일을 직접 수정하므로 서버를 중지해야 합니다. 먼저 중지하거나, 중지하고, 축소한 다음, 한 번에 다시 시작하는 옵션을 선택하세요(축소가 실패하더라도 서버는 다시 시작됩니다). 진행 상황은 작업 트레이에 표시됩니다.

## 백업의 일부로 수행하기

**백업** 탭에서 **지금 백업**을 클릭하기 전에 **"이후에 월드도 축소"**를 선택하세요. 백업 아카이브가 먼저 작성되고(해당 아카이브가 실행 취소 기능입니다), 그런 다음 서버가 중지된 경우에만 월드가 축소됩니다. 서버가 실행 중이면 백업은 계속 실행되고 축소는 참고 사항과 함께 건너뜁니다.

예약된 백업도 동일한 옵션을 가집니다. 예약 편집기에서 **백업** 작업을 선택하고 **"각 백업 후 월드 축소"**를 선택하세요. 자동 실행을 원하면 몇 분 전에 **서버 중지** 예약을 함께 설정하세요.
