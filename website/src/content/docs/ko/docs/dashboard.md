대시보드는 여러분의 홈베이스입니다. 모든 서버, 실시간 상태, 그리고 진행 상황에 대한 피드를 볼 수 있습니다.

![대시보드](/docs/images/dashboard.png)

## 요약 타일

상단에 표시됩니다:

- **온라인 서버**: 총 서버 수 중 현재 실행 중인 서버의 수입니다.
- **연결된 플레이어**: 실행 중인 모든 서버의 총 플레이어 수입니다.
- **사용 가능한 업데이트**: 더 새로운 버전을 가진 서버, 팩 또는 모드의 수입니다 ([업데이트 보기](/docs/updates/) 참조).
- **Docker**: 패널이 Docker 데몬에 접근할 수 있는지 여부와 해당 버전입니다.

두 번째 행에는 **할당된 메모리** (및 사용량), 모든 서버 데이터 폴더의 **사용된 저장 공간**, **상태 · 24시간** (지난 하루 동안의 충돌, 메모리 부족 중단, 자동 재시작), 그리고 모드와 서버 레벨 업데이트로 나뉜 **업데이트**가 추가됩니다. 그 아래에는 **상태별 서버**가 각 상태의 서버 수를 표시하고, **리소스 개요**는 각 서버의 메모리 및 CPU 점유율을 차트로 보여줍니다.

## 서버 카드

각 서버는 상태(실행 중, 시작 중, 중지됨, 충돌, 비정상 또는 지연과 같은 중간 상태), 유형 및 Minecraft 버전, 게임 포트, 태그와 함께 카드로 표시됩니다. 각 카드는 할당량 대비 **플레이어** 및 **디스크** 사용량을 보여주며, 실행 중인 서버는 실시간 **CPU** 및 **메모리** 사용량도 지속적으로 업데이트하여 보여줍니다.

카드를 클릭하면 해당 서버가 열립니다. 비어 있는 **서버 생성** 카드와 상단 바의 **서버 생성** 버튼은 모두 [생성 마법사](/docs/servers/)를 시작합니다.

서버를 검색(이름, 유형, 버전 또는 태그별)하고, 상태, 이름, 크기, 마지막 시작 시간 또는 생성일별로 정렬하고, 오른쪽에 있는 토글로 그리드 및 목록 레이아웃 간에 전환할 수 있습니다.

## 최근 활동

하단의 피드는 패널의 사람이 읽을 수 있는 감사 로그의 가장 최근 항목을 보여줍니다: 로그인, 백업, 블루프린트 내보내기, 업데이트 확인, 채팅 명령 변경, 서버 시작 및 중지 등. 각 항목에는 해당 서버(또는 패널 자체)와 얼마 전에 발생했는지에 대한 태그가 붙습니다. **모두 보기**를 클릭하면 [활동](/docs/activity/) 페이지에서 전체 기록을 볼 수 있습니다.
