대시보드는 여러분의 홈베이스입니다. 모든 서버, 실시간 상태, 그리고 진행 상황을 보여주는 피드가 표시됩니다.

![대시보드](/docs/images/dashboard.png)

## 요약 타일

상단에 표시됩니다:

- **온라인 서버** - 현재 실행 중인 서버 수입니다.
- **연결된 플레이어** - 실행 중인 모든 서버의 총 플레이어 수입니다.
- **사용 가능한 업데이트** - 더 새로운 버전이 있는 서버, 팩 또는 모드 수입니다 ([업데이트 보기](/docs/updates/) 참조).
- **Docker** - 패널이 Docker 데몬에 연결할 수 있는지 여부와 해당 버전입니다.

## 서버 카드

각 서버는 상태(실행 중, 시작 중, 중지됨, 충돌함), 유형 및 Minecraft 버전, 게임 포트와 함께 카드로 표시됩니다. 실행 중인 서버의 경우 실시간 **플레이어**, **CPU**, **메모리**, **디스크** 사용량도 지속적으로 업데이트됩니다.

카드를 클릭하면 해당 서버가 열립니다. 비어 있는 **서버 생성** 카드와 상단 바의 **서버 생성** 버튼을 클릭하면 [생성 마법사](/docs/servers/)가 시작됩니다.

서버를 검색하고 정렬할 수 있으며, 오른쪽에 있는 토글로 그리드 및 목록 레이아웃 간에 전환할 수 있습니다.

## 최근 활동

하단의 피드는 로그인, 백업, 청사진 내보내기, 업데이트 확인, 채팅 명령 변경, 서버 시작 및 중지 등 실시간으로 사람이 읽을 수 있는 감사 추적입니다. 각 항목에는 해당 서버(또는 패널 자체)와 발생한 시간 정보가 태그로 지정됩니다. 전체 기록은 [활동](/docs/activity/) 페이지에 있습니다.
