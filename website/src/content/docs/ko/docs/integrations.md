각 서버는 **설정** 그룹 아래에 통합 기능을 포함합니다: **Discord**, 공개 **상태 페이지**, 원클릭 **초대**, 그리고 선택 사항인 **챗봇** 탭입니다. 이 페이지는 Discord에 대해 다룹니다 (다른 기능들은 패널 내 자체 문서와 설정 도우미를 가지고 있습니다).

## Discord 알림

패널은 웹훅을 통해 서버 이벤트를 Discord 채널로 전달합니다. 봇이나 OAuth는 필요하지 않습니다.

### 설정

1. Discord에서: **서버 설정 → 통합 → 웹훅 → 새 웹훅**. 채널을 선택하고 웹훅 URL을 복사합니다.
2. 패널에서, 서버의 **설정 → Discord** 탭을 열고, **웹훅 URL**에 URL을 붙여넣고, 카드를 **켜기**로 설정한 후 **저장**합니다. URL은 암호화되어 저장됩니다 (API 키와 동일한 저장소에).
3. **테스트 보내기**를 사용하여 작동하는지 확인합니다.

![Discord 통합](/docs/images/integrations-discord.png)

저장된 URL을 교체하려면, 새 URL을 붙여넣고 저장하세요. 현재 URL을 유지하려면 필드를 비워두세요. 저장된 URL은 마스킹되어 표시됩니다 (토큰은 숨겨짐).

### 전송되는 내용

알림은 토글 가능한 카테고리로 그룹화됩니다. 기본적으로 모두 켜져 있습니다.

| 카테고리        | 이벤트                                            |
| --------------- | ------------------------------------------------- |
| **시작 / 중지** | 서버 시작됨, 서버 중지됨                          |
| **충돌**        | 충돌, 충돌 루프 감지됨, 새 충돌 보고서            |
| **백업**        | 백업 생성됨, 백업 복원됨                          |
| **업데이트**    | 업데이트 적용됨, 업데이트 롤백됨, 업데이트 실패됨 |
| **추방 / 차단** | 플레이어 추방됨, 플레이어 차단됨                  |
| **경고**        | 서버를 조용히 망가뜨리는 것들 (아래 참조)         |

### 경고 카테고리

`경고`는 "사람의 주의가 필요한" 채널로, 이전에는 패널에서만 볼 수 있었던 조건에 대한 알림입니다:

| 이벤트                  | 의미                                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------ |
| `oom`                   | 메모리 부족으로 컨테이너가 중지되었습니다.                                                             |
| `unhealthy`             | 프로세스는 실행 중이지만 `mc-health` 프로브가 실패하고 있습니다: 살아있지만 죽은 서버입니다.           |
| `startup-stalled`       | 로그에 "완료" 메시지 없이 약 10분 동안 시작 중입니다 (수정해야 할 사항에 대한 진단 포함, 가능한 경우). |
| `stop-failed`           | 정상 종료가 적용되지 않았고 컨테이너가 계속 실행 중입니다.                                             |
| `schedule-failed`       | 예약된 재시작 / 백업 / 명령이 실패했습니다.                                                            |
| `quota-exceeded`        | 엄격 모드 디스크 할당량이 초과되어 서버가 중지되었습니다.                                              |
| `offline-after-restart` | 패널이 재시작되기 전에는 서버가 실행 중이었지만, 현재는 실행 중이 아니며 자동 시작되지 않습니다.       |
| `crash-report`          | 새 충돌 보고서가 캡처되고 파싱되었습니다.                                                              |
| `update-failed`         | 보호된 업그레이드가 정상적으로 시작되지 않았습니다.                                                    |

### 전달 방식

백그라운드 브리지가 15초마다 [이벤트 로그](/docs/activity/)를 폴링하고 매핑된 행을 전달합니다. 웹훅 POST가 일시적으로 실패하면, 해당 행은 삭제되지 않고 나중에 폴링될 때 다시 시도됩니다. 영구적으로 접근할 수 없는 웹훅은 몇 번의 시도 후 음소거됩니다 (시간당 한 줄의 로그). 브리지는 패널 시작 이전의 이벤트는 절대 다시 재생하지 않습니다.
