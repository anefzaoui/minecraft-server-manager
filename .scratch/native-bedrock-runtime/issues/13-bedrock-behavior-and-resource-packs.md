# 13: Manage Behavior and Resource Packs

**What to build:** Provide a Native Bedrock Packs experience for uploading, installing, and removing behavior and resource packs without reusing the Java Mods interface.

**Blocked by:** 02: Create and operate a Native Bedrock server.

**Status:** ready-for-agent

- [ ] Operators can add and remove valid Bedrock behavior and resource packs through a dedicated Bedrock Packs experience.
- [ ] Native Bedrock servers do not expose Java mod, plugin, or modpack installation controls.
