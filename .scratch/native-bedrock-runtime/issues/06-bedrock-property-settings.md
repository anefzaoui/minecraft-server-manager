# 06: Configure Bedrock server properties

**What to build:** Provide a Bedrock-appropriate settings experience for supported server properties and shared resource controls, without exposing Java, JVM, or RCON settings.

**Blocked by:** 02: Create and operate a Native Bedrock server.

**Status:** ready-for-agent

- [ ] Operators can view and change documented Bedrock properties through the settings experience, with normal validation and restart behavior.
- [ ] Java heap, Java runtime, RCON, and other Java-only fields are unavailable for Native Bedrock servers.
