# 02: Create and operate a Native Bedrock server

**What to build:** Let an operator choose Bedrock in Create Server, accept the EULA, choose Latest, Preview, or a pinned version, and start, stop, and read logs from the dedicated Bedrock container.

**Blocked by:** 01: Add Server runtime and preserve Java servers.

**Status:** ready-for-agent

- [ ] Create Server offers Bedrock alongside Java server types and persists the chosen Native Bedrock runtime.
- [ ] A created Bedrock server uses the Bedrock container contract and supports lifecycle actions and log viewing without Java/RCON requirements.
